# 자체 학습 평가 모델

`regicide-small-v1.nn`은 자체 대국 수집부터 학습·C++ 연결까지 확인하기 위한 첫 실험 모델이다. **별도 시험 자료의 오차가 기물 점수 기준보다 커졌으므로 기본 대국에는 사용하지 않는다.** 기력이나 Elo 향상은 측정하지 않았다.

| 항목 | 내용 |
|---|---|
| 구조 | 768 → 32 ReLU → 16 ReLU → 1, 파라미터 25,153개 |
| 평가 | 현재 차례 기준 기물 점수 + 학습 보정, ±10,000cp 제한 |
| 자료 | Regicide v0.5.8 자체 대국 32판, 588개 위치 |
| 분할 | 학습 367개 / 검증 96개 / 시험 125개, 오프닝 계열 분리 |
| 학습 | NumPy 2.3.5 CPU float64, Adam, 100회, 시드 20261018 |
| 모델 선택 | 검증 손실 최저 97회차 |
| 시험 오차 | 기물 점수 기준 0.052026 → 신경망 0.070073, 악화 |

SHA-256:

```text
bef74501fa114eaa0059533e186faf3a0ac16983bf11b50efd87d38f6bd34bdc
```

같은 환경·자료·시드의 재학습에서 같은 해시를 확인했다. 모델은 `REGICIDE_NN_V1 768 32 16 600` 헤더와 float64 가중치를 담은 텍스트다. 외부 가중치나 개인 기보는 사용하지 않았다.

실험 대국은 저장소의 `Play-Regicide-Learned.cmd`로 실행한다. 기존 Regicide 바로가기는 기존 평가를 사용한다. 새 모델 수집·학습은 `Learn-Regicide.cmd`로 시작하며 결과는 `build/learning/run-…/model/`에 별도로 저장된다. 새 모델을 다시 실행하려면 `scripts/play_godot.ps1 -NeuralModel <모델 경로>`를 사용한다. 기본 모델의 자동 교체는 없다.

구조·학습 정답·검증 방법·직접 명령은 [신경망 평가 설명](../docs/NEURAL_EVALUATION.md), 원자료·보고서는 [첫 실행 검증 기록](../docs/checks/2026-10-18-neural-v1/)을 참고한다.
