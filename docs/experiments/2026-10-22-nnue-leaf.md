# 실제 탐색 평가 위치를 학습하는 NNUE

2026-10-22. MSE·NNUE v3 구조·과적합 방지를 유지하고 실제 탐색 중 신경망이 평가한 위치를
Stockfish 정답으로 학습하도록 구현했다. 한 번 학습했으나 기존 위치 보호 기준을 만족하는
새 가중치를 얻지 못해 학습 전 모델을 복원했다. 미리 분리한16위치의 수 선택 검사와 조건부
16판 대국은 실행하지 않았다. 수 선택·경기력 개선을 확인한 결과는 아니다.

## 구현과 검증할 가설

한 수 직후의 위치를 잘 평가해도, 실제 탐색이 더 진행한 끝의 위치를 잘 평가한다는 보장은
없다. 예를 들어 같은 폰을 폰으로 잡거나 나이트로 잡은 뒤의 판단에는 상대 응수와 이어지는
교환까지 영향을 준다. 이번 가설은 실제 평가 호출의 위치 분포를 학습에 넣으면 탐색이
사용하는 점수를 더 잘 맞출 수 있다는 것이다.

단순히 출력된 PV의 끝을 학습 위치로 쓰지는 않았다. 기존 탐색은 전이표의 저장 결과를
재사용할 때 PV를 중간에서 끝낼 수 있다. `SearchOptions.static_evaluation_observer`는
정규 탐색의 깊이0 평가와 quiescence(교환·체크를 더 확인하는 탐색)의 stand-pat 평가가
실제로 호출된 지점만 관측한다. terminal·TT 반환·루트의 예비 평가를 관측하지 않는다.

별도 실행 파일 `regicide_leaf_data`는 시작 FEN·루트까지의 전체 수순·실제 탐색 경로·
평가 시점의 FEN·차례·원래/제한 후 점수·깊이·평가 호출 번호를 기록한다. 샘플 수에 닿아도
탐색을 멈추지 않으며, 고정 시드 reservoir로 실제 호출 중 일부만 보관한다. 체크·무승부
청구·청구에 따른 값 보정이 있는 표본은 학습 수집에서 제외한다.

이 자료는 실제로 평가된 위치의 분포다. 마지막 완성 PV에 기여한 끝 위치만 뽑았다는 뜻은
아니다. 중단된 반복 깊이의 평가와 stand-pat으로 잘린 가지도 포함하며 이를 기록한다.
256개 원본 표본 중170개는 마지막 미완성 깊이에서 나왔다. 교사 정답은 해당 위치를
Stockfish로 독립 채점한 흰색 관점 cp이며 Regicide의 탐색 점수를 정답으로 복사하지 않는다.

## 학습 전 분리한 검사 위치

새 gate는 이전 검사에 쓰지 않은 M2의 고정16개 계열에서 골랐다. 과거 NNUE 학습·선택·
교사 질의·진단·기록된 합법 PV와 지난 gate의 모든 합법 자식을 포함한143파일·104,660개
기물 배치 식별자와 대조했다. 색/랭크 대칭과 같은 기물 배치는 차례가 달라도 제외한다.

16부모와 모든 합법 자식을 합친581개 입력의 과거 노출 겹침은0개다. index27만 원래
위치의 자식 하나가 노출돼, 결과를 보지 않고 미리 정한 사전순 비포획·비체크2반수
`a2a3 a7a5`를 덧붙였다. 다른15개는 원본 수순 그대로다. 이581개는 이번 점수·비교 학습과
모델 선택에서도 모두 제외했다. 기보 출처 자체는 과거 M2에 사용한 프로젝트 개시 자료라,
완전히 새로운 체스 개시 계열이나 독립 Elo 평가 집단이라고 부르지는 않는다.

통과 기준은 이전과 같다: 정확한 자식 점수로 비교 가능한 위치12개 이상, 교사1순위 일치
2개 이상 증가, 선택수 뒤 교사 점수의 원래 차례 관점 평균20cp 이상 개선, 200cp 이상
악화0개, 실제 모델 계산 불일치0개. 교사는 처음부터 깊이10과100,000노드 중 먼저 도달한
조건에서 끝내고 bound·메이트는 제외한다. 통과 시에만 기본 수식 Regicide와100ms·8시작
양색의16판을 허용한다. 후보/시드 재선택·재학습·기준 완화는 허용하지 않았다.

## 실제 자료와 비용

기존 원본32계열의64개 루트를 재사용하고 루트당10,000노드를 탐색했다. 실제 신경망 평가
526,076회 중 루트당4개를 수집했고, 교사 답을 보기 전에 해시 순서로 최대2개씩 골랐다.
전체 수순을 재생하고 기록된 원래 NNUE 점수와 Python 정수 평가가 정확히 같은지 확인했다.

| 단계 | 실제 결과 |
| --- | --- |
| 새 native 수집 | 64검색, 256표본, 1.60초 |
| 교사 채점 | 128질의, 깊이10·최대50,000노드, 1.68초 |
| 승인·제외 | 정확한 cp126개, 메이트2개 제외, 보충 없음 |
| 새 학습 위치 | 94개·24계열 |
| 새 모델 선택 위치 | 32개·8계열 |
| 최종 점수 자료 | 학습1,520개·선택369개·기존 사후 점검69개 |
| 기존 비교 자료 | 학습26쌍·선택16쌍, 바이트 그대로 보존 |

새 위치는 weight4의 기존 정수 반복 방식을 사용하고 이전 자료의 가중치는 보존했다.
학습의 유효 행 수는2,030개, 배치128로16개 배치다. 비교 쌍은 기존 계열 순환 방식으로
회차당 한 번씩 사용한다. 신경망 입력은 실제 자식 FEN에서 다시 계산하며, 상속된 부모의
기물 수·차례 메타데이터를 대신 쓰지 않는다. 새126개 중125개 정답은 Regicide 기록 점수와
달라 실제 교사 정답을 사용했음을 확인했다.

## 구조·손실·과적합 방지와 실제 학습

위치 점수 MSE + 두 후보 수의 점수차 MSE·계수1을 유지했다. 이번 변경은 새 평가 호출
위치의 점수 자료를 추가하며, 서로 다른 깊이의 위치를 같은 부모의 직접 자식이라고 묶지
않는다. 기존26/16개 비교는 그대로다. NNUE v3·기물768+상대 차례1·은닉16·S32와 Adam·
학습률·시드20261020·기울기 상한10을 유지했다.

매5회 선택 점검,5번 연속 개선 없으면 중단, epoch0 포함, 최적 가중치 복원과 기존263개
위치 MSE가 시작보다 악화되면 차단하는 보호를 모두 유지했다. 앵커와 선택용 자료는
미분에 들어가지 않고 기존69개는 최종 가중치를 저장한 뒤 한 번만 점검한다.

한 번 학습해25회·400업데이트에서 중단했다. 실제 학습 시간은1.21초다.

5회 시점은 합계 오차가 조금 줄었어도 기존 위치의 오차가 늘어 선택할 수 없었다.
10·15·20·25회도 모두 같은 보호 기준에 걸렸다. 학습 자료의 오차는 낮아졌지만 다른 자료의
판단을 함께 보존하지 못했으므로, 보호를 풀지 않고 **epoch0을 복원**했다.

최종 모델 SHA256은 시작 모델과 같은
`4e54305bce4a495ff3bb0d961e397f78eac12d387ff30e7766202fcdf7d3bdee`다.
이는 이번 학습 방식에서 채택할 새 가중치를 얻지 못했다는 뜻이다. 현재 망 구조로 개선이
불가능하다거나, 보호 장치가 잘못됐다는 증거는 아니다.

## 수 선택 검사와 대국을 생략한 이유

모델 바이트가 같고 같은 엔진·동일한 초기화·고정 노드 조건을 사용하면 두 수 선택도 같다.
따라서 교사1순위가2개 늘거나 평균20cp 개선되는 기준은 통과할 수 없다. 동일 모델을 두 번
검색하고 새 검사 정답을 소비하는 일을 줄이기 위해 **모델 동일성 사전 단계에서 중단**했다.

새16위치의 실제 수 선택 검색0회·교사 질의0회·기본 Regicide 대국0판이다. 16개 정답률이나
평균 수 평가를 측정한 것처럼 보고하지 않는다. 예약한 위치는 아직 성능을 측정하지 않아
다음 연구에서 사용할 수 있다. 기본 게임·설치 모델·기존 실행 파일은 바꾸지 않았다.

전체 사전 계획의 `valid_gate_runs: 1`은 허용한 최대 횟수다. 실제 실행 횟수는0이며,
실제 판정은 `screen-decision.json`에 별도로 기록했다.

독립 검토에서235개 파일 해시,256개 실제 평가 표본,126개 교사 정답, 자료 분할과 보호
기준을 확인했다. 전체 지표 재계산 차이는0이고, 저장 float 가중치와 정수 모델이 시작
가중치와 정확히 같음을 별도로 확인했다. 검토 중 추가 엔진·교사·학습 실행은 없다.

## 정확성과 재현

- 새 witness 자료 검사6개와 새 gate 검사6개 통과.
- native observer6그룹·52,321확인, 기존 search61그룹·21,389확인 통과.
- NNUE10그룹·51,270확인, 빌드 모델13그룹·30,348확인 통과.
- 이전/새 실행 파일12개 기존 위치×3설정·36건에서 수·점수·PV·노드·TT·LMR 등 모든 비시간
  출력이 정확히 같다. 속도 향상을 측정한 결과는 아니다.
- 수집 표본8개의 반복 생성 바이트 일치·전체 수순 재생·전체/증분 점수 일치.
- 실제 저장 모델2,004위치의 Python·전체·증분 점수 불일치0개. 모델13그룹·25,521확인 통과.

`build-m3-leaf` 별도 빌드에서 검증했다. 게임 실행 경로에는 수집 CLI를 추가하지 않았고,
observer를 지정하지 않은 기본 검색은 기존 동작을 보존한다. 재현은 새 출력 폴더를 사용한다.

```powershell

# 동일 모델이 복원되면 새 검사와 대국은 생략한다.
# 변경된 보호 통과 모델만 nnue_leaf_gate.py label/run으로 판정한다.
```
