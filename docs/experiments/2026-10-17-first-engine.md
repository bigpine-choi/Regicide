## 달성한 범위와 고정 버전

- 규칙 기준: `567b93ac9e7c94945251de22fb9343f062ae286f`.
- 탐색·UCI·대국 도구 코드: **`56d482899edd4a22e6837951bc08897ebd3e9a29`**.
- 위 커밋을 만든 뒤 변경 없는 체크아웃에서 Windows 실행 파일을 다시 빌드했다.
- 실행 파일 SHA256: `524aa51bfe22dad45849f4e008ef91231cdafe3d13a3dabe2b719f32de311468`.
- 대국을 무시되는 `build/evidence/`에 먼저 저장해 모든 JSON의 `source.dirty`가 `false`임을 확인했다. 이후 원본을 `docs/games/`로 복사했다. 이 문서·기보의 후속 커밋은 엔진 코드를 바꾸지 않는다.

## 조건

- 날짜: 2026-10-17, Asia/Seoul. JSON의 시각은 UTC이며 같은 날짜다.
- CPU: AMD Ryzen AI 7 350 w/ Radeon 860M, 논리 CPU 16개; 메모리 약 31.3 GiB.
- Windows 11 x64, MSVC 19.51.36260.0, C++20 `/O2 /W4 /WX /permissive-`.
- 탐색은 한 번에 작업 스레드 1개, UCI 입력을 처리하는 스레드는 별도다. 백·흑은 각각 Regicide 0.2.0 프로세스이며 번갈아 탐색한다. 다른 상대 엔진·오프닝 북·학습 데이터·GPU는 없다.
- 기물 점수 P100/N320/B330/R500/Q900. 동점 수 순서는 고정하며 난수를 쓰지 않는다.
- Python 3.13.16, `chess==1.11.2`. Python은 UCI 전달·독립 합법성/종료 검사·PGN 저장에만 사용한다.
- 초기 배치 깊이 대국: 깊이 2, 노드/시간 제한 없음, 수 제한 1000반수, 가능한 무승부를 항상 청구.

- 표적 포지션: 깊이 2, 시작 FEN은 각 JSON/PGN에 저장. 75수 검증만 청구를 하지 않는 `automatic` 정책.

## 재현과 다음 검증

소스와 빌드 환경은 위 코드 커밋을 사용하고, 자세한 빌드 명령은 [엔진 문서](../ENGINE.md)를 따른다. 예를 들어:

```powershell
.\.venv-tests\Scripts\python.exe scripts/play_game.py build/regicide.exe --depth 2 --games 2 --pgn games/reproduced-depth2.pgn
.\.venv-tests\Scripts\python.exe scripts/play_game.py build/regicide.exe --movetime 40 --pgn games/reproduced-time.pgn
```

기존 출력에 덮어쓰지 않는 새 경로를 사용한다. 실행 파일의 빌드 시각/도구 차이로 해시가 달라지면 새 해시를 기록한다. 시간 조건은 동일 수순을 보장하지 않는다.

남은 제한은 복잡한 죽은 포지션의 일반 판정, 깊이 밖의 캡처 연쇄, 기물 전개·위치 평가의 부재다. 다음에는 안정화 탐색과 간단한 위치 평가를 각각 분리해서 적용하고, 규칙 검증을 유지한 상태에서 전술 사례와 통제된 상대 대국으로 효과를 비교한다. 이번 결과에는 Elo·상대 대비 승률·최정상급 경기력 주장이 없다.
