# 종반 연구 검증 절차 수정 — 학습 전 확정

사용자가 2026-10-19 KST에 "오래 걸리더라도 내가 컴퓨터 사용을 멈추지 않아도 되는 방식"을 요청했다. 자료 수집과 정답 정제는 끝났으나, 아직 학습 곡선·모델 가중치·개발 대국 결과는 만들어지지 않은 시점에 다음 절차를 확정한다.

기존 [사전 계획](2026-10-19-endgame-learning-scale-plan.md)의 자료 분리, 정답 안정성, 모델 구조와 시드, 중첩 자료 규모, 후보 고정 및 채택 공식은 유지한다. 다음 실행 장소와 개발 비교 예산만 수정한다.

- 자료 규모별 개발 대국은 같은 16개 시작 위치·선후공·수당 1,000노드를 사용한다. 브라우저나 다른 프로그램의 사용 중단을 요구하지 않는다. 전체 이력과 실제 규칙 판정을 보존한다. 이 결과는 같은 계산량의 개발 비교이며 같은 시간의 기력 증명이나 모델 채택 자료로 사용하지 않는다.
- 최종 후보는 기존 32쌍·64판·수당 100ms의 예약 분포와 동일한 채택 공식을 사용한다. 정확히 같은 Windows 실행 파일과 후보 모델을 해시로 고정해 GitHub Actions의 별도 Windows 작업 환경에서 실행한다. 원격 하드웨어를 기록하며 사용자 PC에서 측정한 성능으로 표현하지 않는다.
- 완성되고 자원 검사를 통과한 선후공 쌍마다, 남은 모든 쌍에서 만점을 얻어도 기존 최종 기준에 미달하는지 검사한다. 불가능하면 실제 기록만 보존하고 조기 기각한다. 가상 승리는 가능성 상한 계산에만 사용하며 기보·승패·실제 점수에 추가하지 않는다. 조기 채택은 없다. 통과하려면 기존 전체 최소 대국 수와 모든 원자료 검증을 충족해야 한다.
- 원격 작업은 모델을 채택하지 않는다. 원격 실행 신원·요청·소스·실행 파일·모델·기보·자원 기록을 로컬에서 다시 확인하고 기존 등록부가 허용할 때만 반영한다. 실패·부하 오염·미완료는 유효한 조기 기각과 구분한다.

시도 5는 PGN 합본 경계의 빈 줄 부족을 발견해 학습 전에 실패했다. 원본 128판·1,877위치, 안정성 통과 학습 1,314위치와 새 보류 130위치는 보존한다. 원본을 수정하거나 시도 번호를 초기화하지 않고, 다음 시도 6에서 신원·해시·정답 정책을 재확인한 완료 자료만 복사해 재사용한다. 학습·검증 결과를 보고 자료나 후보를 다시 고르지 않는다.

신경망 입력 기준 중복 제거 후 새 학습 위치 1,211개이므로 사전 목표 0/128/512/1,024개를 모두 실행할 수 있다. 시드 2026101901/2026101902와 100epoch 및 원래 검증 자료의 epoch 선택을 유지한다. 가장 큰 규모·첫 시드가 고정 후보이며, 보조 학습량 통제와 시험 성적은 후보를 바꾸지 못한다.

로컬 학습의 BLAS/OMP/MKL 연산 스레드는1개로 고정해 다른 프로그램의 사용 여유를 남긴다. 모든 규모와 학습량 통제에 같은 설정을 적용하고 실행 환경을 기록한다. 이 설정의 벽시계 시간을 기력 비교에 사용하지 않는다.

기각으로 절약되는 판수는 실제 결과에 따라 달라진다. 64판 통과를 몇 분 안에 끝낸다는 보장은 하지 않는다. 사용자 PC의 장시간 사용 중단은 검증 요건에서 제거한다.
