# 왕 앞 폰 방패 평가: 개발·검증 계획

작성일: 2026-10-18 (한국 시간). 기준 코드: `b3a782262a19db514c8dcd295bf5c8b50e8fc54e`, 자체 엔진 v0.5.3. 결과를 보기 전에 검사 범위와 비교 표본을 정하며, 후보는 v0.5.4로 식별한다.

## 가설과 범위

현재 평가는 기물 가치·기물 좌표·국면을 사용하지만, 같은 왕 좌표에서 자기 폰 방패가 남아 있는지는 구별하지 않는다. 왕보다 앞의 가까운 자기 폰을 중반 평가에 반영하면 방패를 잃는 비용을 표현할 수 있다는 가설이다. 이 가설은 실제 기력 향상이나 특정 패배의 원인을 입증한 사실이 아니다.

- 왕의 파일과 양옆 파일을 조사한다. a/h 파일에서는 보드 안의 두 파일만 본다.
- 각 파일에서 왕보다 앞의 가장 가까운 자기 폰까지 거리가 1/2/3/4칸 이상 또는 없음이면 각각 0/4/8/12cp를 감점한다. 뒤나 같은 랭크의 폰은 방패로 세지 않는다.
- 색마다 감점 합에 상대 N/B=1, R=2, Q=4의 합(최대 12)을 곱하고 12로 정수 나눗셈한다. 상대가 왕과 폰만 가지면 새 감점은 0이다.
- 백·흑 감점 차를 기존 중반 점수에만 넣고, 기존 전체 국면 가중치(최대 24)와 종반 점수를 그대로 혼합한다. 기존 왕 중앙화와 폰 전진 항목은 유지한다.
- 특정 왕 파일·랭크에서 항목을 갑자기 끄지 않는다. 이동으로 인위적인 적용 경계를 벗어나 감점만 없애는 효과를 피한다.
- 계수는 작은 자체 초기 가정이며 대국·문제 결과에 맞춰 튜닝하지 않는다. 코드·평가 표·가중치를 외부 엔진에서 가져오지 않는다.
- 공격 지도, 상대 폰 폭풍, 통과폰·고립폰, 캐슬링 예측, 새 가지치기는 범위 밖이다. 정상 피앙케토도 작은 거리 비용을 낼 수 있으며 전술적 보상을 별도로 평가하지 않는다.

`UsePawnShield`/`SearchOptions::king_pawn_shield`는 기본 켬, 콘솔 `--no-pawn-shield`로 끈다. `UsePositionalEvaluation=false`에서는 적용하지 않는다. OFF는 기존 v0.5.3 평가를 재현해야 한다. 실제 대국과 추천 수 모두 같은 새 자체 엔진을 사용한다.

## 검사와 완료 기준

1. 기존 6개 C++ 회귀 실행 파일을 모두 실행한다. 규칙·수 적용/되돌리기·반복·무승부·특수 수·전이표·SEE·탐색 검증을 삭제하거나 완화하지 않는다.
2. 방패만 다른 동일 재료·왕 좌표, 양색·퀸쪽·가장자리, 가까운 앞 폰/뒤 폰/겹친 폰, 피앙케토, 비대칭 잔여 기물, 폰 종반, 색 반전·부호·상태 보존을 확인한다. 신규 옵션의 일반·안정화·중단 fallback·재사용 전이표 경로도 검사한다.
3. 기존 Python 독립 규칙 교차검증(기본 2,997사례), UCI 통합 검사와 신규 옵션 수명 검사를 실행한다. 기존 사람 대국·평가 막대·핸디캡·보관함·추천 수 회귀와 Godot 실제 연결도 확인한다.
4. `tests/data/profile_positions.json` 전체 10위치, 깊이 3, warmup 1, repeats 2, seed 20261018, Hash 16, Move Overhead 20으로 이전 바이너리 대 후보 OFF의 수·점수·노드·깊이·seldepth·PV·TT 카운터 정확 일치를 검사한다. 같은 고정 표본의 후보 OFF/ON은 점수 차이를 허용하며 위치별 변화와 비용을 기록한다. 서로 다른 탐색 트리의 시간 차이를 평가 함수의 단독 비용이나 기력으로 해석하지 않는다.
5. 가능하면 Linux GCC의 경고 오류 빌드와 ASan/UBSan으로 신규 평가·탐색을 확인한다. 로컬 실행과 원격 CI 결과는 구분한다.
6. 실제 설치본·실행 파일·개인 기보를 백업한 뒤 검증한 실행 파일을 배포한다. 바탕화면 바로가기에서 v0.5.4와 추천 기능 연결을 확인하고, 개인 기보 원본 해시를 대조한다.
7. 결과·재현 명령·검사 로그·파일 해시를 기록하고 커밋·푸시 후 로컬/원격 SHA와 깨끗한 작업 폴더를 확인한다.

기존에 중단한 v0.5.0/v0.5.3 대국 비교를 재개하지 않는다. 이번 범위는 기능·규칙·비용의 검증이며 동일 시간 대국에 의한 일반 기력 향상이나 Elo를 주장하지 않는다.
