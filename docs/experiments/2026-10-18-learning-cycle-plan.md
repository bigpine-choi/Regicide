# 자체 학습 자동 순환 사전 계획

기준 소스 `c6ab7128087621adab9021041fe1ec0644cbb0ba`, 기준 엔진 v0.6.0. 목적은 패배 진단·누적 자료·재학습·이전 채택 모델과의 대국·조건부 채택을 한 번의 실행으로 연결하는 것이다. 작은 망의 강도 향상을 미리 가정하지 않는다. 새 엔진 v0.6.1의 기본 무제한 루트 탐색과 기존 규칙은 유지한다.

1. 현재 채택 모델로 16개 학습 계열의 자체 대국을 수집한다. 처음에는 기존 수식 평가가 채택 모델이다. 매 순환의 시드는 영속 시도 번호로 바뀐다. 더 큰 노드 예산의 자체 수식 평가를 교사로 사용한다.
2. 완결 패배에서 패한 쪽의 최대 8개 수를 기존 점수 변화로 사전 선별한다. 전체 이력을 보존한 동일 뿌리 위치에서 자유 탐색과 실제 수 강제 탐색을 비교한다. 충분한 완료 깊이·유한 점수·100cp 이상 손실을 확인한 학습 계열 표본만 교정 자료에 추가한다. 원인 분류와 제한 탐색의 답은 추정이다.
3. 처음 설치된 자료의 검증·시험 위치를 저장소별 불변 사본으로 고정한다. 이후 실행의 학습 위치와 교정 표본을 누적하고, 보류 위치와 입력이 같은 새 학습 위치는 제외한다. 기보·해시·규칙 재생을 확인한다. 아레나의 위치·수순·점수는 학습 자료로 사용하지 않는다.
4. 채택된 신경망이 있으면 거기서 이어서 학습하며 Adam 상태는 새로 시작한다. 없다면 난수 초기화한다. 검증 오차로 epoch를 고르며 epoch 0도 후보다. 시험 오차는 진단 보고용이고 채택 신호로 사용하지 않는다.
5. 별도 예약 오프닝 분포에서 매번 추출한 최소 32개 쌍, 선후공 교대 총64판을 수당100ms 이상·Hash16MiB·단일 탐색 스레드로 비교한다. 같은 실행 파일과 설정을 사용하며 평가 모델만 바꾼다. 미완료·프로토콜 오류·불법 수·인식된 외부 엔진/브라우저 CPU 증가·자원 감시 공백은 전체 비교를 무효로 한다. 규칙 회귀 검사도 통과해야 한다.
6. 통계 단위는 같은 시작 위치의 두 판을 평균한 쌍이다. 시도 k의 오판 예산은 `alpha_k=0.05/(k*(k+1))`, 쌍 수 n과 평균 점수 s의 단측 하한은 `max(0,s-sqrt(log(1/alpha_k)/(2*n)))`다. 하한이0.5를 초과할 때만 채택한다. 실패·중단도 시도 번호를 소비하고 반복해서 유리한 결과가 나올 때까지 같은 비교를 재사용하지 않는다. 이는 예약 분포와 시간 조건 내의 기준이며 세계 전체 기력 보장이나 Elo가 아니다.
7. 판정·전체 수순·모델/실행 파일·자원 증거를 재검산한 뒤 챔피언 명세를 원자적으로 바꾼다. 어느 단계든 실패하면 기존 챔피언을 보존한다. 다음에 대국 화면을 열 때 채택 모델을 읽는다. 진행 중인 대국의 모델은 바뀌지 않는다.

첫 실제 검증은 같은 사전 설정으로 최소 한 번의 전체 순환과 별도의 반복·실패·원자 채택 회귀 검사를 수행한다. 실측 조건과 결과는 후속 결과 문서에 기록한다. 실행 시간을 줄인 소표본 smoke는 채택할 수 없다.

통계 근거는 [Hoeffding 원논문(1963)](https://www.tandfonline.com/doi/abs/10.1080/01621459.1963.10500830)의 독립 유계 변수 부등식이다(2026-10-18 확인). 쌍의 조건부 독립 표집과 정한 분포·자원 조건을 전제로 하며, 알 수 없는 호스트 부하·온도 변화·분포 밖 일반화는 이 식으로 보장하지 않는다. 합산 오판 예산은 망원급수 `sum 1/(k(k+1))=1`을 이용한다. 기존 엔진/모델의 코드나 가중치를 가져오지 않는다.
