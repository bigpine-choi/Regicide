# 위치 평가·안정화 탐색 비교 계획

작성일: 2026-10-17. 아래 조건과 시작 포지션은 개선 버전의 대국 결과를 보기 전에 정한다. 결과를 본 뒤 평가 계수를 조정하거나 불리한 대국을 제외하지 않는다.

## 가설과 비교 기준

1. 자체 위치 평가가 중앙 장악·기물 전개·국면별 킹 위치를 점수에 반영하면 기물 가치 동점 때문에 발생한 단순 왕복이 줄어든다.
2. 안정화 탐색이 깊이 끝의 캡처·승격과 체크 회피를 더 읽으면 기물 교환 도중 평가를 끊어서 생기는 전술 실수가 줄어든다.
3. 두 변경의 전체 경기력 효과는 이전 버전과 같은 조건의 실제 대국으로 별도로 점검한다. 개별 전술 검사의 개선을 전체 경기력으로 대신하지 않는다.

기준 버전은 `6dc69292baa5da0aeb61a66bd25ab016ef3c6272`의 Regicide 0.2.0이다. 해당 커밋을 별도 빌드 폴더에 추출하고 같은 PC·MSVC 버전·C++20 Release `/O2` 설정으로 빌드한다. 개선 버전은 소스를 커밋한 뒤 같은 설정으로 다시 빌드한다. 두 실행 파일의 SHA256과 소스 커밋을 결과에 남긴다.

## 고정할 조건

- 시작 포지션: `tests/data/comparison_openings.json`의 순서대로 8개. 짧은 자체 작성 합법 수순이며 외부 엔진으로 유불리를 선별하지 않는다.
- 각 시작 포지션에서 같은 두 엔진이 선후공을 바꿔 2판을 둔다. 각 세트는 16판이다.
- 주 비교: 양쪽 모두 수당 **1,000노드**, 깊이 상한 64, 시간 제한 없음. 안정화 노드도 같은 총 노드 예산에 포함한다.
- 보조 비교: 양쪽 모두 UCI **수당 40ms**, Move Overhead 20ms, 깊이 상한 64. 같은 명목 시간 제한을 사용하며 실제 사용 시간·노드는 따로 기록한다.
- 이전 실행 조건 확인: 양쪽 모두 **깊이 2**, 시간/노드 제한 없음. 안정화 연장 때문에 계산량은 다를 수 있으므로 같은 연산 자원 비교로 해석하지 않는다.
- 기여도 확인: 위치 평가만 켠 버전과 안정화 탐색만 켠 버전을 각각 기준 버전과 비교한다. 시작 목록의 앞 4개를 사용해 각 8판, 수당 1,000노드다.
- 총 예정 대국: 64판. 조건별 결과를 분리하고 서로 다른 자원 조건을 합쳐 단일 승률로 만들지 않는다.
- 양쪽 모두 탐색 작업 스레드 1개, 오프닝 북·학습 모델 없음. 대국은 동시에 돌리지 않아 시간 경쟁을 피한다.
- 무승부 정책: 가능한 3회 반복·50수 청구를 항상 처리하며 자동 종료도 확인한다. 수순 전체를 엔진과 독립 검증기에 보존한다.
- 안전 제한: 대국당 전체 500반수. 한도 도달·오류는 미완료 `*`로 저장한다. 완료 무승부로 바꾸지 않으며 개수와 원인을 별도 보고한다.

## 지표와 해석

- 개선 버전 기준 승/무/패, 득점률 `(승 + 0.5 × 무) / 완료 대국 수`, 시작 포지션별 두 판의 결과.
- 짧은 표본이며 같은 시작 포지션의 두 판은 독립이 아니므로 포지션 쌍 단위의 불확실성과 개별 결과를 함께 본다. Elo 환산이나 인간 상대 실력 추정은 하지 않는다.
- 왕복 지표는 수순에서 같은 기물이 자기의 다음 차례에 직전 이동을 되돌리는 경우를 정의해 집계한다. 비율의 분모·예외를 결과 파일에 고정한다. 강제 회피·정당한 반복도 가능하므로 이 지표만으로 수의 질을 판정하지 않는다.
- 전술 회귀 검사는 알려진 재캡처 함정, 체크 중 조용한 회피, 앙파상·승격과 종료 판정, 예산 중단·상태 복원을 확인한다. 비교 대국 포지션을 보고 학습한 결과가 아니다.
- 기존 규칙 테스트·6포지션 perft·2,997개 외부 기준 사례는 그대로 유지한다.

실제 실행 조건·기보·실행 파일 해시·오류/미완료와 관찰된 한계는 별도의 결과 기록에 남긴다. 결과가 개선을 뒷받침하지 않으면 그 사실도 그대로 기록한다.
