# 외부 참고 분석의 추가 깊이 대조

2026-10-18. 최초 계획의 위치 선정과 100만·400만 노드 확인을 수행한 뒤, 추가 질의 전에 기록한다. 선정 위치는 바꾸지 않는다.

수정된 raw UCI 점수 수집에서도 g1-p49의 실제 수 강제 검색은 두 노드 한도 모두 최종 lowerbound였다. g13-p81의 100만 노드 최선 검색에도 실제 bound가 있다. 범위값을 정확한 cp처럼 빼면 손실 크기를 잘못 확정할 수 있다. 원래 결과와 cp_gap=null은 그대로 보존한다. python-chess의 과거 flag 누적 문제와 현재 엔진이 실제 보고한 bound는 구분한다.

보조 확인은 선정된 5곳과 pair2 보조 위치 **모두**에 Stockfish 동일 깊이16·20, 각 질의 최대4,000,000노드를 적용한다. 자유 검색·실제 수 강제 검색, 보조 위치의 짝 대국 대안 강제 검색을 수행한다. 기존 단일 스레드·Hash32MiB·매 질의 초기화·테이블베이스 미사용 조건을 유지한다. 결과를 본 뒤 위치나 깊이를 골라 바꾸지 않는다.

요청 깊이 완료 여부와 최종 점수의 bound 여부를 각각 기록한다. 완료·무bound 결과만 공통 깊이의 점수 비교에 사용한다. 그래도 유한 탐색의 추정치이며 Regicide의 cp와 직접 빼거나 최선 수의 증명으로 부르지 않는다. 이 대조는 원래 노드 한도 실험을 대체하지 않으며, 추가 예산으로 자기대국을 수행하거나 기력 향상을 주장하지 않는다.

최초 누적 bound 수집 버전의 screen/confirm과 중단한 자체 probe는 별도 제외 시도로 보존한다. 선정 위치가 수정 후 같아도 최초 시도의 분석 수치는 최종 판단에 합산하지 않는다.
