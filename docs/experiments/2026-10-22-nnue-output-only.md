# 입력·은닉 표현을 고정한 출력 가중치 학습

2026-10-22. 이전 비교 학습에서 TRAIN 손실은 줄었지만 기존263위치의 보호 오차가
늘어 시작 모델을 복원했다. 이번에는 입력·은닉 표현을 그대로 두고 기존 출력 가중치
16개만 학습한다. MSE·NNUE 구조·자료·과적합 방지를 유지하며, 보존한 미학습16위치
검사를 통과했을 때만 기본 Regicide와16판을 비교한다. 한 번의 학습으로 기존 보호
위치와 선택 자료의 MSE를 모두 낮춘 후보를 얻었다. 그러나 보존한16위치의 실제
수 선택 검사에는 실패했다. 추천수 일치는4→4개였고, 교사 평가상 평균 이득은
−10.6875cp였다. 조건에 따라 비교 대국은0판이며 기본 모델을 유지한다.

## 변경 이유와 구현

기존 학습은 한 위치의 점수를 바꾸면서 많은 위치가 공유하는 기물·은닉 표현도 함께
수정했다. TRAIN 손실의 감소가 기존 검증 위치의 판단 보존으로 이어지지 않은 것이
직전 결과다. 공유 표현을 고정하고 마지막 점수 조합만 보정하면 이런 간섭의 범위를
줄일 수 있는지 확인한다. 이 제한이 실제 수 선택을 개선할지는 별도 검사로 판단한다.

NNUE v3의 기물 입력768개·상대 차례 입력1개·은닉16개·정수 입력 배율32를 유지한다.
입력 가중치12,288개·은닉 bias16개·차례 가중치16개, 합계12,320개를 고정하고
기존 출력 가중치16개만 학습한다. 별도 출력 bias나 새 파라미터를 추가하지 않는다.

새 `neural_stm_output_only.py`는 출력 가중치의 미분만 계산한다. 고정 파라미터에는
미분 배열·Adam 상태·수정 제안을 만들지 않는다. 크기10의 gradient clipping도 실제로
학습하는16개 미분값의 크기만 사용한다.

축소 후보는 고정 표현을 그대로 복사해 구성한다. 각 Adam 제안 후·검증 회차·최종
선택에서 고정 파라미터의 float 바이트와 양자화된 정수값을 확인한다.
학습 래퍼 `train_nnue_output_only.py`도 별도로 검사하며,
저장한 float 파일과 정수 모델을 다시 읽어 선택된 값과 같은지 확인한다.
배열별 shape·dtype·SHA256과 최종 출력 가중치 변경 수를 결과에 남긴다.

## 기존 자료와 시작 모델 재사용

시작 모델은 이전 보존 학습의 `nnue-preservation/attempt-002`이며 SHA256은
`85e3032a87f3145670aa666f8e1359a610c08937f5f0a20cb14ad81dfd507b33`이다.
직전 비교 학습의 epoch0 복원 결과와 같은 모델이지만, 재현 기준은 원래 보존 체크포인트다.

`nnue-choice/data-002`의 정식 자료를 그대로 재사용한다.

| 자료 | TRAIN | 선택용 tuning | 기존 사후 점검 |
| --- | ---: | ---: | ---: |
| 점수 위치 | 1,520 | 369 | 69 |
| 기존 즉시 자식 비교 | 26쌍 | 16쌍 | 사용 안 함 |
| 검증된 탐색 끝 비교 | 29쌍 | 8쌍 | 사용 안 함 |
| 합친 비교 | 55쌍 | 24쌍 | 사용 안 함 |

이번 자료 수집용 Stockfish 질의·native 탐색·새 point 추가는 모두0회다. 앞서 완료한
교사 영수증과 탐색 영수증, 중복을 제거한 자료의 원본 바이트를 사용한다. 선택되지
않았던 자료를 검사 결과에 따라 추가하거나 새로 뽑지 않는다.

탐색 끝 비교의 정답은 두 root 첫 수 직후 위치의 교사 점수차다. 입력은 현재 모델의
강제 탐색점수를 실제로 뒷받침한 leaf 쌍이다. 이는 고정된 탐색 경로를 통하는
**root 자식 가치의 대리 목표**이며, Stockfish가 해당 leaf를 직접 평가한 점수가 아니다.
수정된 모델의 실제 탐색 경로는 바뀔 수 있으므로 비교 MSE만으로 수 선택 개선을
단정하지 않는다. 원래의 point 정답과 기존 비교 정답은 바꾸지 않는다.

## 고정한 학습 조건과 보호

학습 손실은 이전과 같은 세 MSE 평균의 합이다.

```text
교사 위치 MSE
+ 1 × TRAIN55쌍 전체의 점수차 MSE
+ 4 × 기존 TRAIN1,426위치에서 시작 모델 출력과의 MSE
```

미분은 기존과 같이10,000으로 정규화한다. 보존 정답은 시작 모델의 실제 정수 백색
점수이며, 기존 TRAIN1,426개만 사용한다. 교사 정답을 보존 정답으로 대체하지 않는다.

| 조건 | 고정값과 용도 |
| --- | --- |
| 실행 수 | 시드 하나, 실제 학습 최대1회 |
| 학습 | MSE, Adam, 시드20261020, 배치128, 최대500회 |
| 학습률 | 출력0.005; 기존 설정의 입력·bias0.0002는 보존하되 고정 파라미터에 적용하지 않음 |
| 비교 배치 | 계열을 섞고 각 TRAIN 비교를 회차마다 한 번 사용 |
| 정수 TRAIN 보호 | 실제 전체 point+gap+보존 목적값이 늘지 않는 첫 축소 제안만 허용 |
| 축소 순서 | 1, 0.5, 0.25, 0.125, 0.0625, 0.03125; 모두 실패하면 수정 생략 |
| Adam 상태 | 제안마다 한 번 갱신하며 건너뛴 제안도 포함; 축소는 파라미터 변화량에만 적용 |
| 모델 선택 | 5회마다 tuning 위치 MSE+점수차 MSE 확인 |
| 기존263위치 보호 | 정수 MSE가 시작값62,230.90874524715 이하인 후보만 채택 |
| 조기 종료 | 1cp²를 넘는 의미 있는 개선이5번의 검증 동안 없으면 종료 |
| 최종 선택 | epoch0 보호 및 최적 가중치 복원 유지 |

tuning·보호263위치·미학습 검사 위치는 미분에 넣지 않는다. tuning·보호 위치로
TRAIN 제안의 축소 배율을 고르지 않는다. 기존 사후 점검69위치는 최종 파일을 저장한
뒤 한 번만 계산하며 선택·중단·재학습에 사용하지 않는다. 이69개는 이미 노출된 개발
자료이므로 새로운 독립 검증이라고 부르지 않는다.

소스와 의존 코드, 자료·시작 모델·실행 파일·기본 프로필·예약 검사 파일의 해시를
학습 전 계획과 실행 기록에 저장한다. 실행 폴더와 소스 사본을 별도로 보존한다.

## 구현 검증과 실제 모델 검증

출력 전용 학습 회귀 검사는8개,0.190초로 통과했다. 기존 세 MSE의 출력 미분과의
동등성, 전체 목적값, 모든 축소 제안의 고정 표현, 실제 출력 수정·최적 복원,
263위치 보호에 의한 epoch0 복원, 활성16개만 사용하는 clipping, 검증 정답이
미분·축소 경로에 들어가지 않는 점, 미세한 고정 배열 변경 거부를 검사한다.

래퍼의 별도 검사는 실제 시작 모델에서 고정12,320개와 출력16개를 확인했다.
정수값이 그대로인 은닉 bias의1e-9 float 변경도 거부했고 출력 가중치 변경은 허용했다.
이 검증은 실제 학습·엔진 실행·교사 질의를 하지 않았다.

선택된 실제 모델의 Python·native 전체·증분 계산은 특수 위치를 포함한2,078위치에서
불일치0개였다. native 실제 모델 회귀는13개 그룹·25,521개 단언·실패0개였다.
계산 일치와 수 선택·경기력은 별도 결과로 보고한다.

## 보존한 미학습16위치와 조건부16판

직전 작업에서 조회하지 않은 `nnue-choice/gate-001`의16위치를 그대로 사용한다.
검사 root와 모든 합법 자식의 정규화된604개 입력을 학습 자료에서 제외한다. 개시
계열은 기존 계열을 합법적인 조용한 수로 연장한 것이며, 완전히 새로운 외부 계열이라는
뜻은 아니다. 후보를 고른 뒤 모델과 실제 계산 검증 결과를 봉인하고 최종 검사를
한 번만 실행한다.

통과하려면 확정 교사 점수로 비교할 수 있는 위치가12개 이상이고, 시작 모델보다
교사 추천수 일치가2개 이상 늘며, 선택한 수의 교사 평가상 평균 이득이20cp 이상이어야
한다. 200cp 이상 악화된 위치와 native 계산 불일치는 각각0개여야 한다. 제한된
Stockfish 탐색 점수는 해당 조건의 비교 기준이며 완전한 체스 정답은 아니다.

검사로 체크포인트를 다시 고르거나 학습·시드·한도를 바꾸지 않는다. 계획상 최종 모델이
시작 모델과 같으면 검사를 사용하지 않고 보존하며, 실패하면 대국은0판이다.
통과한 경우에만 같은 native 엔진의 기본 classical Regicide와 후보를8개 시작 위치,
선후공 교대로 정확히16판 비교한다. 수당100ms, Hash16MB, 최대500ply, claim 무승부
정책을 사용하며 자동 모델 승격은 하지 않는다. 16판 결과는 빠른 방향 확인용이고
안정적인 경기력 향상이나 Elo를 입증하는 표본으로 해석하지 않는다.

## 한 번의 학습 결과

학습은1회66.95821초 진행했다. 조기 종료로60회에서 멈췄고35회 체크포인트를 선택했다.
고정12,320개의 float 바이트와 정수값은 모두 시작값과 같았다. 최종 출력16개 중
float 값은15개, 배포 정수값은12개가 바뀌었다.

하지만 비교 MSE가 줄어도 비교 순서 일치는 오히려1개 줄었다. 이 결과만으로 실제

실제 계산 검증과 함께 미학습 검사 전에 봉인했다.

## 미학습 수 선택 검사 결과와 대국 결정

봉인한 최종 모델로 보존한16위치 검사를 한 번만 실행했다. 16위치 모두 확정 교사
점수로 비교할 수 있었다. 시작 모델과 후보의 native 탐색은 합계32회였고, 교사
질의는 root16회와 선택 자식17회였다. 이는 위의 자료 수집용 질의0회와 구분한다.
기록된 검사 시간2.0167초는 앞서 진행한 노출 이력 확인 시간을 포함하지 않는다.

| 검사 기준 | 실제 결과 | 충족 |
| --- | ---: | --- |
| 비교 가능한 확정 위치12개 이상 | 16개 | 예 |
| 교사 추천수 일치2개 이상 증가 | 4/16→4/16, 증가0개 | 아니오 |
| 선택한 수의 평균 교사 평가 이득20cp 이상 | −10.6875cp | 아니오 |
| 200cp 이상 악화0개 | 0개 | 예 |
| native 계산 불일치0개 | 0개 | 예 |

15위치는 같은 수를 골랐고1위치만 바뀌었다. 바뀐 위치는 `choice-gate-opening-30`의
흑 차례였으며, `f6g4`에서 `c8f5`로 바뀌었다. 교사 추천수는 `f6e4`라서 새 선택도
일치하지 않았다. 두 선택수 직후의 교사 점수로 비교하면 후보의 선택이171cp
낮았다. 제한된 교사 탐색에서 얻은 결과이며, 전체 경기력 손실이나 절대적 수의
가치를 확정하는 수치는 아니다.

결과는 **검사 실패**다. 미리 정한 조건에 따라 기본 Regicide와의 비교 대국은0판이며,
추가 학습·모델 재선택·검사 재시도·통과 기준 변경은 하지 않았다. 기본 게임 모델도
그대로다. 이번16위치는 이제 결과가 노출됐으므로 이후의 새 미학습 검사로 재사용하지
않는다.

출력만 학습해도 기존263위치의 MSE를 보존하면서 실제 수정된 모델을 얻을 수 있다는
점은 확인했다. 그러나 MSE 개선이 실제 추천수 개선으로 이어지지는 않았다. 계산
정확성·점수 근사·수 선택·경기력을 나누어 보고하는 이유가 이번에도 드러났다.

다음 코드 연구의 가설은 **평소 탐색 설정에서 실제로 선택을 결정한 평가 위치를 더
정확히 추적하는 것**이다. 현재 비교 자료는 깊이3·TT/PVS/LMR을 끈 탐색의 증거를
사용하지만 최종 검사는 기본 탐색 설정으로 진행한다. 이 차이가 학습 효과의 전달을
제한했을 가능성은 있으나 이번 결과만으로 원인이라고 확정할 수 없다. 기본 탐색의
증거 추적을 구현하고 검증한 뒤 별도의 새 검사 위치를 예약해야 한다. 이번 작업에서
이 추가 구현·수집·학습은 실행하지 않았다.

계획과 실행 산출물은 `docs/checks/2026-10-22-nnue-output-only/`, 재사용한 자료와
검사 예약은 `docs/checks/2026-10-22-nnue-choice/`에 있다. 새 코드는
