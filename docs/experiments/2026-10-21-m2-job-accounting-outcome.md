# M2 CPU 계측 수정과 재대국 결과 — 2026-10-21

계측 수정과 검증은 완료했으며, 정식 M2 경기력 기준선은 미완료다. 사전 대국이 부하 기준을 충족하지 못했으므로 본768판은 시작하지 않았다.

## 변경과 검증

Windows Job 누적 CPU로 실험 작업을 측정해 샘플 사이에 시작·종료한 자식 작업도 포함한다. 진행·감시 프로그램 자체 CPU를 별도로 측정하고 나머지는 시스템·백그라운드 추정치로 기록한다. root의 주기 검증용 Git 자식 작업도 제거했다. v3는 측정 전 실제 검증 뒤에는 입력 동결 때 봉인한 정확한 query 응답을 사용하며, 미등록 요청은 오류로 중단한다.

v2 최종 회귀63개와 v3 최종 회귀19개, 보존 도구 fixture11개가 통과했다. 실제 긴 작업4개, 짧은 자식32개, 진행·감시 CPU, Job 밖 자체 작업, 종료·정리를 독립 native API·보유 프로세스 timer와 대조했다. Job/guard 원시 재계산은 일치했다. 짧은 작업의 held timer 합계와0.078125 CPU초 차이가 남아 보정 없이 보존했으며 일반적인 오차 상한으로 해석하지 않는다.

비동기·양자화된 API와 rolling 보간의 근사다. 잔여 부하를 특정 앱, 사용자 행동 또는 개별 탐색 경합의 증거로 해석하지 않는다.
