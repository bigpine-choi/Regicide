# 스파링 접전 효과 비교 계획

대국 결과를 보기 전에 고정한 계획입니다. 비교 대상은 심판 추가 전 `307f33a`와 심판 v1 `7fc666c`이며, 둘 다 별도 읽기 전용 실험 체크아웃으로 보존합니다. 부족한 부분을 수정하면 그 후보 버전도 동결한 뒤 재검증합니다. C++ 자체 Regicide 바이너리는 같은 SHA256 `5011da4c5e6ef01c452bd7125e4e22b372d2c9cfb858ed8759057325acb0e6ba`를 사용합니다.

## 질문과 측정

질문은 **처음 20수 동안 형세가 균형에 더 가까운가**입니다. 승률·Elo·사람의 체감 난이도를 측정하지 않습니다.

- 첫 40반수(각 측 20수)의 모든 실제 착수 직후 위치를, 대국 종료 후 별도 full-strength Stockfish 18로 깊이 14까지 재평가합니다. 시작 위치는 분모에서 제외합니다. 동일 버전 Stockfish의 별도 프로세스·고정 깊이 검사이며, 다른 엔진의 독립 정답이라고 부르지 않습니다.
- 주 지표는 게임별 `|백 기준 cp| ≤ 100`의 비율을 동일 가중한 평균입니다. ±200cp도 병기합니다. 메이트는 범위 밖, 불완전 평가는 unknown으로 표시하고 분모에서 조용히 제외하지 않습니다.
- 조기 종국이 짧은 균형 비율로 유리해지지 않도록 `범위 안 위치 수 / 40`도 보고합니다. 40반수 도달·법적 조기 종국·오류·평가 누락·40위치 연속 유지 성공을 별도로 셉니다.
- 불균형의 크기 `D=max(|cp|-100, 0)`가 한 수에 200cp 이상 증가한 사건을 셉니다. 단순 AI 방향 점수 손실은 의도적인 양보일 수 있으므로 구분합니다.
- 범위 이탈의 착수 주체, 우세/열세 방향, 첫 이탈, 회복을 기록합니다. 20수 뒤 관측이 필요한 회복 사건은 우측 검열로 표시하거나 최대 44반수까지 관측하고 주 지표에는 40반수만 사용합니다.

## 동일 조건

- 표준 시작 위치, 설정·색·시드로 짝을 만듭니다. Stockfish 상대는 UCI_Elo 1320/1700/2100/2500 중 사전에 선택한 설정, 각 백·흑을 사용합니다. 이 숫자를 사람의 플랫폼 레이팅으로 해석하지 않습니다.
- 실제 `HumanGame.new_game(sparring_mode=True, time_control='10+5')`와 실제 착수 경로를 사용합니다. 자동 생각시간·회복 탐색·종료 규칙은 유지합니다. 인위적인 착수 후 대기만 실험용 하위 클래스에서 제거하며 취소 이벤트를 켜지 않습니다.
- 상대 Stockfish는 고정 1,000ms·Threads 1·Hash 16MiB·기력 제한 설정을 사용합니다. 심판은 기본 생산 설정을 유지합니다. 화면용 추천/형세 백그라운드 계산은 양 조건에서 제외하며 심판 후보 검사는 그대로 실행합니다.
- 사후 판정은 대국 이후에 수행하여 시계와 다음 수 자동 배분을 오염시키지 않습니다. 각 위치 평가 전에 TT를 비웁니다. 실제 수순·사후 점수·정책 판단·탐색 예산·처리 시간·오류·소스/실행 파일 해시를 보존합니다.
- 동일한 시간제는 동일 CPU 사용량을 의미하지 않습니다. 추가 심판 계산의 비용도 보고하고, 자체 엔진의 기력 상승으로 표현하지 않습니다. 공유 PC의 다른 사용자 프로세스는 종료하지 않습니다.
- Stockfish 약화 선택의 내부 난수 시드를 UCI로 통제하지 못합니다. 설정과 자기 정책 시드를 짝지어도 수순의 동일 재현을 보장하지 않습니다. 작은 표본과 색/설정별 편차를 공개합니다.

## 실행 순서와 채택

1. 1320·백의 짧은 짝 대국으로 실행 경로·심판 활성·기록·사후 평가를 확인합니다. 이 시범을 효과 입증으로 사용하지 않습니다.
2. 사전에 고정한 설정·색 조합에서 변경 전/심판 v1을 비교합니다. 주 지표뿐 아니라 불균형 급락·오류·비용을 함께 확인합니다.
3. 개선이 작거나 해로운 경우, 관측한 원인을 해결한 후보를 같은 조건에서 비교합니다. 동일 조건 재시험은 개발 자료로 표시합니다.
4. 후보를 고정한 뒤 새 시드의 추가 짝 대국을 수행합니다. 개선 방향이 재현되는지 확인하고, 설정별 악화와 표본 불확실성을 함께 보고합니다. 미달하면 채택을 보류하거나 추가 개선합니다.

대국 상한은 무승부로 계산하지 않습니다. 첫 20수의 구간 대국은 전체 경기 승패 검증과 구분합니다. 최종 결과와 실제 실행한 표본 수는 별도 보고서에 기록합니다.
