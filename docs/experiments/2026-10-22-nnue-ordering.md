# MSE로 후보 수의 점수 차이 학습

2026-10-22. **수 선택은2/10→3/10으로 일부 개선됐지만 고정한 사전 기준에는 미달했다.**
사용자 지시대로16판 대국은 실행하지 않았다. MSE·현재 NNUE 구조·과적합 방지를 유지하며
후보 수의 순서를 직접 학습하는 코드를 구현했고, 후보1개·사전 검사1회만 수행했다.
기본 엔진과 설치 모델은 유지한다.

## 무엇을 바꿨는가

기존 학습은 각 위치의 점수를 맞췄지만 두 후보 중 어느 수가 더 좋아야 하는지를 직접
비교하지 않았다. 새 `neural_stm_ordering.py`는 **각 위치 MSE + 같은 위치에서 나온
두 후보 뒤 점수 차이의 MSE**를 사용한다. 두 항의 계수는1로 사전에 고정했다.

예를 들어 참조 점수가 좋은 수+100·나쁜 수-100이면, 두 위치의 점수와 함께 그 차이200cp도
맞춘다. 제곱오차(MSE)를 유지하며 다른 분류 손실은 도입하지 않는다. 백 관점 점수로 두
자식의 차이를 계산하고, 순서 지표를 낼 때만 원래 수를 두는 쪽의 색을 반영한다.
자식 위치의 차례를 쓰면 부호가 반대가 되므로 원본 수순 재생·색 검사를 둔다.

교사 추천수라는 이름만으로 항상 더 좋은 수라고 가정하지 않는다. 독립적으로 검색한 두
자식의 실제 정확한 Stockfish cp 차이를 목표로 사용한다. 실제로 추천수 뒤 참조가 더 낮은
쌍도 있어 음수 차이를 그대로 보존한다. 차이가50cp 미만인 쌍은 학습에서 삭제하지 않고,
명확한 순서 성공률을 보고할 때 따로 구분한다.

## 적은 새 자료로 실제 선택 오류 보강

기존 패배30위치의 정답을 재사용하고 현재02cc 모델이 고른 수 뒤의 위치만 추가 확인했다.
새 Stockfish 질의는15개(위치당50,000노드),13개 승인,1.19초다. 기존 정확한 정답111개를
재사용했고 현재 모델의 추가 탐색15회·10,000노드도 포함해 자료 생성은 총2.49초였다.
교사의 메이트·bound·점수 범위 제외 정책은 그대로다.

| 자료 | 고유 위치 | 수 비교 쌍 | 50cp 이상 차이 |
| --- | ---: | ---: | ---: |
| 학습 | 1,370 | 18 | 11 |
| 선택용 | 311 | 11 | 6 |
| 사후 점검 | 69 | 없음 | 해당 없음 |

원본 패배 개시 쌍1~6은 학습,7~8은 선택용으로 유지했다. 같은 기보 계열 및 색 반전
기물 특징이 분할을 넘지 않는지 확인했다. 같은 위치가 여러 비교에 등장하는 것은 새 독립
표본으로 세지 않는다. 사후69개는 이미 개발에 노출된 자료이며 새 독립 시험이 아니다.

자식 점수 자체는 정확했지만 처음 생성할 때 부모의 교사 메타데이터가 복사된 필드는
캐시된 실제 자식 질의의 값으로 정규화했다. 목표 점수·FEN·수순·비교 관계는 바꾸지 않았다.
수정 전후 SHA와 실제 실행 소스 스냅숏을 보존했고 교사·엔진을 다시 실행하지 않았다.

## 구조와 과적합 방지 유지

NNUE v3·기물768+상대 손번1·공유 은닉16·S32, 기존 STE·Adam·학습률·batch128·seed20261020·
기울기 상한10을 유지한다. 기존02cc 모델에서 이어서 학습했다. 최대500회 안에서 매5회
선택용 MSE를 확인하고,5번 연속 개선이 없으면 중단한 뒤 최적 가중치를 복원한다.

학습 전(epoch0)도 항상 후보에 포함한다. 선택용 점수 MSE와 점수 차이 MSE의 합으로
후보를 고르되, **원래 선택용263위치의 MSE가 epoch0보다 나빠진 가중치는 채택하지 않는다.**
선택용·기존263개·사후69개와 사전 수 선택 검사는 학습 미분에 들어가지 않는다.

한 번 학습은1.18초,30회에서 중단해5회 모델을 복원했다. 25·30회는 기존263개 보호 기준에도
걸려 채택 불가였다. 학습 후 사전 검사로 다른 가중치를 다시 고르거나 재학습하지 않았다.

| 같은 비교 자료 | 학습 전 | 복원 후 |
| --- | ---: | ---: |
| 학습18쌍 순서 일치 | 7/18 | 14/18 |
| 선택11쌍 순서 일치 | 3/11 | 3/11 |
| 선택11쌍 점수 차이 MSE(cp²) | 23,658.09 | 22,894.00 |
| 기존263위치 MSE(cp²) | 64,156.66 | 62,807.95 |
| 사후69개 MAE(cp) | 248.20 | 247.14 |

학습 자료에서는 순서 관계가 개선됐지만 선택용 순서에는 이어지지 않았다. 평균 제곱오차의
감소만으로 좋은 수 선택이나 일반화가 개선됐다고 결론내리지 않는다.

## 실제 엔진 수 선택 검사와 대국 중단

대상10위치와 다음 통과 기준은 학습 전에 고정했다.

1. 교사1순위와 실제 선택이 일치하는 위치가 최소5/10개일 것. 현재02cc는2개,
   이전c73은4개라 둘을 넘는 기준이다.
2. 현재 이미 맞힌2곳(원본6·14번 대국)을 모두 유지할 것.
3. 선택용 개시 계열7~8의4곳에서 최소2개 일치할 것(현재1개).

같은 실행 파일·Hash16MiB·전체 원본 이력·Clear Hash·새 탐색 상태·10,000노드로 비교한다.
현재 모델10회 기록은 해시로 인증해 재사용하고 후보만10회 검색했다. 검사0.31초,
재시도0회다. 결과는 **전체2→3/10, 선택용1→1/4, 기존 정답2개 모두 보존**이었다.

원본1번 대국33수 위치에서 이전 `Be5` 대신 교사의 `g4`를 선택하게 됐다.
그러나13번 대국은 `e4`에서 긴 캐슬링으로 바뀌어도 교사 추천 `e3`와는 달랐다.
알려진 개발 위치의 회귀 검사이며 교사의 유한 탐색1순위가 완전한 정답은 아니다.

**전체5개·선택용2개 기준에 미달해 대국 권한을0판으로 기록했고,16판은 시작하지 않았다.**
기준 완화·추가 시드·재학습·다른 체크포인트 검사도 하지 않았다. 이번 결과는 점수 차이
MSE가 학습 자료의 순서를 고칠 수 있지만 다른 위치의 실제 탐색까지 개선하는 데는
한계가 있음을 보여준다. 이 검사에서 실패한 후보를 긴 대국에 보내지 않는 흐름도 구현했다.
