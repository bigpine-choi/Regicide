# v0.6.5 종반 진단·자료 규모 실험 사전 계획

기준은 `527289e74dbdfb28a98625ef961c7470e9c78ff9`(v0.6.4)다. 학습 결과와 새 대국 성적을 보기 전에 이 계획을 고정한다. C++ 평가·탐색·규칙은 변경하지 않고 실행 버전만0.6.5로 표시한다.

## 질문과 원인 구분

1. 기존 학습용 자가대국 패배의 종반에서 어떤 위치 유형이 반복되는가?
2. 더 깊은 자체 교사와 같은 깊이의 실제 수/대안 비교가 손실을 지지하는가? 위치의 문맥을 곧바로 패배 원인으로 단정하지 않는다.
3. 같은 모델/학습 설정에서 신뢰 조건을 통과한 다양한 종반 학습 위치를 늘리면 보지 않은 위치의 오차와 같은 시간 대국 성적이 개선되는가?

예약 채택 아레나의 기보·점수·위치는 진단을 통한 자료/설정 선택에 사용하지 않는다. 기존 bootstrap와 각 완료 수집 run의 train 대국만 진단한다. 종반은 `퀸 없음 & 전체 기물12개 이하` 또는 `위상점수8 이하 & 전체 기물16개 이하`로 정의한다. 위상점수는 N/B=1,R=2,Q=4의 양쪽 합이다. 패한 쪽의 종반 결정에서 기존 얕은 검색의 점수 변화로 우선순위를 정하고, 기보당 최대2개·전체 최대24개를 자세히 검사한다.

진단은 자체 수식 평가의50,000/200,000노드 재검색과 깊이4(검색당200,000노드 상한)에서 대안/실제 수 강제 비교를 사용한다. 정확한 유한 점수·요청한 깊이 완료·합법 PV·깊은 두 검색의 추천수/점수 안정성을 확인한다. 같은 깊이의 대안 점수가 실제 수보다100cp 이상 높고 신뢰 조건을 만족할 때만 제한된 자체 교사가 지지한 손실로 분류한다. 메이트를 임의CP로 바꾸거나 객관적 최선 수 증명으로 해석하지 않는다.

## 새 자료와 정답

외부 코드·모델·데이터를 가져오지 않고 직접 구성한 합법 종반 시작 위치를 사용한다. 폰 경주/통과폰, 룩과 폰, 경·중기물 안전, 킹 활동 문맥을 포함하고 차례를 균형 배치한다. 위치 구조의 계열을 사전에 train/validation/test로 나누며 단순 색 반전 복사 라벨을 만들지 않는다. 실제 자체 엔진이 끝까지 둔 대국과 전체 이력·규칙으로 확인한 결과만 수집한다.

새 종반 검증/시험 계열을 먼저 수집해 전체 궤적의 보드·신경망 입력을 동결하고 학습에서 제외한다. 기존 bootstrap 검증96/시험125의 JSONL 행·게임/PGN 바이트는 보존한다. 기존 예약 오프닝과 이미 수행한 아레나의 모든 위치도 제외 목록으로만 읽고 학습에 사용하지 않는다. 훈련 중에는 대국 판정의 원래 이력과 차례를 보존한다.

새 학습용 수집의 기본 규모는 train 시작32개×4반복=128판이다. 새 종반 보류 자료는 validation/test의 시작16개를 각1회 수집한다. 수집은 수당1,000노드, 최초 교사10,000노드, 최대384반수, 표본 간격2다. 부족할 때 학습 성적을 보지 않고 표본 수와 품질 통과 수만으로 반복 수를 늘릴 수 있으며 변경을 기록한다.

신뢰 정답은 기존10,000→50,000→200,000노드 절차, 마지막 두 정확 유한CP·완료깊이3이상·같은 추천수·30cp 이내 점수차를 사용한다. 새 보류 자료도 최초 동결 전에 같은 안정성을 확인하고 이후 수정하지 않는다. 기존 보류 라벨을 다시 쓰지 않는다. 유한 탐색의 합의는 참정답 보장이 아니며 메이트/불안정 라벨은 제외한다.

## 자료 규모와 모델 선택

기준 train은 직전 quality 자료1,071위치를 그대로 사용한다. 새 quality train 중 기준/모든 보류 자료와 동일한 보드/신경망 입력을 제외한다. 새 자료 추가량의 사전 목표는0,128,512,1,024다. 품질 통과 수만으로 가능한 목표를 확정하고,128개 미만이면 수집을 보강한다. 데이터 크기 간 표본은 중첩되며 계열·실제 차례를 층화한다. 원본과 각 규모의 선택 행·해시·시드를 남긴다.

모델은 V2 768→32→16→1, 기존 평가+100cp 보정, L2=0.0001, Adam0.003, batch64,100epoch를 고정한다. 시드는2026101901/2026101902이며 같은 시드의 모든 규모는 같은 초기 가중치로 시작한다. 기존 bootstrap validation만으로 epoch를 선택하고 test와 새 종반 보류 자료는 보고용이다.

채택 후보는 **첫 번째 시드의 가장 큰 실행 가능한 사전 목표 규모**로 고정한다. 중간 성적·시험 오차·개발 대국을 보고 다른 규모나 시드로 바꾸지 않는다. 두 번째 시드는 학습 변동을 보기 위한 반복이며 채택 후보로 바꾸지 않는다. 영속 시도번호는 기존4 이후5를 실험 시작 전에 소비하고 실패해도 되돌리지 않는다.

같은100epoch에서도 큰 자료는 샘플 제시와 Adam 갱신이 늘어난다. 이를 자료량만의 효과로 단정하지 않도록 갱신 수와 샘플 제시 수를 기록한다. 보조 비교로 기준 자료만 사용해 가장 큰 규모와 Adam 갱신 수가 가깝도록 epoch를 반올림해 늘린 모델도 두 시드에서 학습한다. 최대 오차는 기준 자료 한 epoch 갱신 수의 절반이며, 이 보조 모델은 후보 선택·채택에 사용하지 않는다.

## 실제 대국과 채택

첫 번째 시드의 각 자료 규모를 동일한 별도 종반 개발 시작 위치에서 기존 수식 평가와 선후공 교대 대국시킨다. 새 보류 계열의 시작 위치를 사전에 고정하고 최대16쌍/32판, 수당100ms, Hash16MiB·단일 스레드·같은 옵션/실행 파일·전체 이력·실제 규칙 판정을 사용한다. 모든 규모에 같은 시작 위치/순서/예산을 사용한다. 미완료 판을 무승부로 만들지 않는다. 이 소표본은 자료 규모의 개발용 비교이고 모델 채택 판정이 아니다.

고정 후보는 기존 `learning_arena.py`의 예약 분포에서32쌍/64판·수당100ms로 독립 검증한다. 가중치 고정 뒤 새 난수를 뽑고, 알려진 브라우저·외부 엔진 CPU와 감시 공백이 있으면 전체 비교를 무효 처리한다. 기존 영속 시도별 alpha, 점수 하한>0.5, 최소 대국 수·시간·규칙 검증·아티팩트 검증·원자적 채택을 그대로 유지한다. 통과한 경우만 기본 모델을 바꾼다. 개발용 대국/새 보류 자료를 예약 아레나로 위장하지 않는다.

## 완료 조건과 보고

기존 native/Python/규칙 교차 검증·클라이언트·학습/채택 회귀, 새 도구의 데이터 누설/중첩 규모/원자료/실패 검증을 통과한다. 진단·계열별 빈도·수집량/품질 통과·학습 곡선·개발 대국·별도 채택 결과를 나눠 보고한다. 단조 개선이 없으면 그대로 보고하고 원인을 단정하지 않는다. 소스/실행 파일/모델/자료/시작 위치/자원 로그의 해시와 환경을 보존한다.

이전 모델·규칙·고정 보류 자료·기존 학습 이력을 보존하고 새 자료를 누적한다. 검증한 소스·실행 파일·학습 상태를 로컬에 반영하고 GitHub에 커밋·푸시한다. 개인 대국·동기화 `sources/`는 수정하지 않는다. 측정 중 임시 절전 방지는 종료 후 해제한다.
