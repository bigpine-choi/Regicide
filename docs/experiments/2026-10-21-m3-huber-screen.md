# M3 Huber 후보: 학습 연결 수정과 16판 검토

2026-10-21 KST. 준비된 Huber 후보 한 개를 실제 기존 NNUE와 **16판만** 비교했다.
대국은 **130.341451초(약 2분 10초)**에 끝났고, 후보 성적은 **3승 7무 6패,
6.5/16점·40.625%**다. 오류·미완료·미시작은 0이며 독립 기보 검증 PASS다.
이번 표본에서 기존 NNUE를 넘는 개선은 확인하지 못했다. 모델과 기본 평가기를 교체하지 않는다.
이로써 요청한 M3의 첫 짧은 검토는 끝났지만, 재현 가능한 기력 향상이라는 M3 전체 목표는 미달이다.

## 학습 코드에서 바꾼 것

`scripts/neural_precision.py`의 일반 `select_model` 경로는 이미 H100을 학습할 수 있었지만,
선택 결과의 `loss` 설명을 항상 MSE라고 저장했다. 선택된 설정에 맞게 H100/MSE 설명을
저장하도록 수정했다. 기존 MSE 기본 문구·손실 수식·최적화·준비된 모델·동결 스냅샷은 유지했다.

일반 선택 경로를 소형 합성 자료로 실제 실행하는 H100 기록·MSE 기본값 검사 2개와 기존
MSE 동일성/관측 callback·H100 결정성/직렬화 검사 2개, 총 4개를 통과했다.
이는 학습 출처 기록의 정확성 개선이며 기력 향상은 아니다. 기존 12모델의 재학습이나
이전 전체 native 검사를 반복하지 않았다. 실제 실행 근거는
[학습 코드 검증](../checks/2026-10-21-m3-huber-screen/learning-code-verification.json)에 있다.

## 기존 학습 결과가 말하는 것

같은 자료·초기 배열·시드·배치 순서·구조·120epoch를 쓴 B-MSE/B-H100의 저장된 검증
723행을 비교했다. 평균 절대오차는 **89.4550→85.1452cp(4.82% 감소)**,
RMSE는177.1414→176.6964cp다. 큰 두 정답 차이 집단51행의 평균 절대오차는
580.2745→584.0392cp로 악화했고 학습 행의 RMSE도 증가했다.
평균적인 교사 점수 모방은 조금 좋아졌지만 극단값 전체가 개선됐다는 뜻은 아니다.
교사는 자체 10,000노드 탐색 점수이며 절대적인 체스 정답이나 기력 지표가 아니다.

  양쪽 옵션은 `NeuralModelFile`만 다르다. 단일 검색 스레드·Hash16·Move Overhead20,

- **이번 16판은 세대 간 실용 비교다.** 실제 M2 NNUE와 준비된 H100은 자료·초기값·시드가

실행 코드 HEAD는 `7fe771b1b98f98f8cb6058fe20a51e27adc265aa`다. 대국 시작의 Git 상태에
표시된 두 untracked 파일은 실행 전에 생성된 stdout/stderr 출력 로그다. 제품 소스·모델·
