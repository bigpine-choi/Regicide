# 100ms 패배 분석과 개선: 사전 실험 계획

기준은 전이표 메모리 재사용 버전 **v0.4.1**, 소스 `a31091548033d538e01d2c194f05bada403d5263`이다. 분석 대상은 `docs/matches/2026-10-17-hash-memory/time100-retry.json/.pgn`에서 기준이 진 7판이다. 이번 후보는 이들 개발 기보에서 확인한 약점을 우선 수정한다. 규칙 오류, 탐색 범위, 평가 누락을 구분하고, 패배 직전의 강제 희생을 패배의 첫 원인이라고 단정하지 않는다.

## 수정 전 분석

- 원래 엔진의 수·깊이·점수·재료 변화·전체 이력과 제한된 더 깊은 자체 탐색을 비교한다.
- Stockfish 16을 별도 진단 도구로 사용해 전환점을 검토한다. Ubuntu `16-1build1` 패키지, 단일 스레드·Hash 32 MiB, 위치당 50,000노드 및 선택한 전환점 500,000노드다. 버전·SHA256·옵션·예산·유한 탐색이라는 한계를 기록한다.
- Stockfish는 기보 분석에만 사용한다. Regicide의 실제 수는 계속 자체 코드가 선택하며 외부 코드·평가 표·모델 가중치를 가져오지 않는다. 외부 참조의 값은 절대 정답이나 Regicide 센티폰과 동일한 척도라고 간주하지 않는다.
- 두 기보는 중반 이후 같은 위치·93반수 수순을 공유하므로 패턴 수를 7개 독립 사례로 세지 않는다.
- 기보에서 확인한 반복 약점을 회귀 위치로 보존하고, 먼저 근거가 강한 작은 변경을 구현한다. 개발 위치의 결과로 구현을 점검한 뒤 후보·설정·계수를 고정한다.

## 과적합과 비교 조건

`tests/data/comparison_openings.json`의 기존 8개는 개발 표본이다. 이 파일은 바꾸지 않고 같은 시작·선후공·시간으로 **100ms/수 16판**을 진행해 이전 버전 대비 진단한다.

새 `tests/data/heldout_openings_2026-10-17.json`의 8개 수순은 후보 구현과 대국 결과 전에 이 계획과 함께 고정한다. 직접 작성한 합법 수순이며 외부 오프닝 북·강한 엔진의 추천으로 고르지 않았다. 기존 8개와 다른 최종 위치이고 백/흑 차례가 4개씩이다. 후보 구현·조정에 이 위치의 점수나 대국 결과를 사용하지 않는다. 후보 동결 뒤 이 전체 8개에서 선후공을 바꾼 **100ms/수 16판**을 주 비교로 수행한다. 첫 평가 뒤에는 이 표본도 개발 자료가 되므로 결과를 보고 수정한 뒤 같은 표본을 새로운 보류 검증이라고 부르지 않는다.

두 묶음은 총 32판이며 결과를 합쳐 보류 표본의 승률로 제시하지 않는다. 설정·판수·시작 위치를 성적을 보고 변경하지 않는다. 주 비교에서 개선이 없거나 악화되면 그대로 보고하고 유리한 실행만 고르지 않는다.

## 자원·버전 고정·오류 처리

- 기준 커밋을 별도 `git archive`로 추출해 빌드하고, 후보도 엔진·도구·설정 고정 커밋에서 재빌드한다. 소스 커밋·실행 파일 SHA256·컴파일러·하드웨어를 기록한다.
- 같은 Windows PC·MSVC C++20 Release `/O2 /DNDEBUG`, 단일 탐색 스레드, 양쪽 Hash 16 MiB 및 Move Overhead 20ms를 유지한다. 요청 100ms 중 내부 탐색 할당은 80ms다.
- 엔진마다 전체 이력을 전달한다. 대국 전 준비 검색 없이 첫 할당을 포함하고 프로세스는 각 묶음 동안 유지한다.
- 가능한 현재/예정 수 반복·50수 청구를 항상 처리하고 자동 종료는 별도 확인한다. 500반수 안전 한도. 미완료·불법·오류는 무승부로 바꾸지 않는다.
- 대국·비용 측정은 다른 분석 부하와 동시에 실행하지 않는다. 유휴 절전은 실행 중만 임시로 억제하고 이전 실행 상태로 복원한다. 영구 전원 정책·화면 켜짐 요구는 바꾸지 않는다. 오류가 나면 원본을 보존하고 원인·재측정 여부를 먼저 기록한다.
- Python chess 1.11.2는 통신·합법성·판정만 담당한다. 실제 수는 두 자체 엔진이 선택한다.

## 통과 기준과 해석

기존 규칙/perft 8,325개·외부 기준 2,997사례, 탐색·평가·전이표·이력·메모리·UCI·대국 도구 검증을 유지한다. 변경한 기능에 대해 작은 독립 검증과 패배 위치 회귀 검사를 추가한다. 실제 수·PV·종결·색 배분·기록된 예산·해시를 독립 재생한다.

정확성·실행 비용·패배 위치의 판단 변화·같은 시간 대국 성적은 각각 보고한다. 16판의 작은 보류 표본은 일반적인 강도·Elo·인간 또는 강한 외부 엔진 상대 실력을 입증하지 않는다. 같은 시작 쌍을 묶은 참고 부트스트랩도 이 한계를 유지한다.
