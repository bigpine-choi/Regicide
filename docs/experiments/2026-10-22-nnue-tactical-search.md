# 상대의 조용한 전술 대응을 보는 탐색

2026-10-22. **원래 제외했던 전술 수순을 실제로 탐색하도록 구현했지만, 문제 위치의
수 선택 개선은 실패했다.** 같은10,000노드에서 Bf5와 Bg5 선택이 유지됐고, Ng5 직전
위치는 첫 반복도 완료하지 못했다. 따라서 새 미학습16위치는 예약만 보존하고,
기본 Regicide와의 비교 대국은0판이다. 기본 옵션과 설치 게임은 바꾸지 않았다.

## 가설과 구현

직전171cp 사례에서 exf6는 원래도 잡기 후보였다. 문제는
흑 Bf5 → 백 exf6 → 흑 Bxb1 → 백 Ng5라는 **정확한 무체크 준비 수순**이
얕은 정상 탐색 밖이며 기존 안정화 탐색의 잡기·승격·조용한 체크 목록에도 없다는
점이었다. 기존 탐색이 다른 수순에서 체크 회피로 Ng5를 살펴본 경우까지 없었다고
주장하지 않는다.

새 UCI 옵션 UseQuiescenceThreats는 기본false다. 다음 동작을 함께 선택한다.

1. 조용한 나이트 이동이 상대 룩·퀸 둘을 공격하거나, 다음 합법적인 SEE 비손해
   잡기로 그런 포크를 만드는 경우, 안정화 탐색에서 경로당 한 번 추가한다.
   Ng5 → Nxf7 → 퀸d8·룩h8 포크가 두 번째 유형이다. 특정 FEN·칸·수 이름은
   엔진 판별에 넣지 않았다. 가상 잡기의 합법성·교환 손익은 별도 보드에서 확인한다.
2. 위협 직후 상대는 **조용한 방어까지 모든 합법 수**를 검색하며, 가만히 있는
   정적 점수를 선택할 수 없다. 위협을 발견했다고 무조건 이득을 주지 않는다.
3. 비용을 보완해 일반 비체크 안정화 노드에서는 SEE<0인 보통 잡기를 생략한다.
   체크 회피, 위협 직후 모든 방어, 체크하는 잡기, 승격, 앙파상은 보호한다.

SEE는 한 칸에서의 교환 손익 추정이다. 마지막 규칙은 뒤늦은 보상을 받는 비체크
희생을 놓칠 수 있는 선택적 가지치기다. 모든 전술·모든 포크를 해결하거나 전체
minimax와 같은 값을 보장하지 않는다. 기존 UseSEE는 여전히 수 정렬만 제어하며,
새 가지치기는 별도 연구 옵션에 속한다.

기존 체크 예산, 최대 안정화32ply, 전체 노드·시간·중단 한도와 무승부 규칙을 유지한다.
추가 작업도 같은 카운터에 포함한다. 후보 수·실제 확장 수·전체 응수 노드 수·
qsee_pruned를 기록한다. 옵션OFF에서는 모두0이며 원래 경로다.

## 개발 단계에서 확인한 비용 문제

처음 조용한 포크만 추가한6회 개발 탐색은 root 완료 깊이를2→1로 줄였다.
Ng5 직전 위치는 기존 탐색부터10,000노드 안에 깊이1을 끝내지 못했다. 첫 결과와
소스를 보존한 뒤, 공식 검사 전에 SEE 비용 보완을 한 번 추가하도록 계획을 수정했다.
같은 노드·모델·문제 위치·새 검사·대국 기준은 유지했다. 파라미터 그리드는 실행하지 않았다.

개정6회 개발 탐색에서는 root 완료 깊이2를 회복했다. 새 옵션만 정확한
Bf5 exf6 Bxb1 Ng5 Bxa2와 exf6 Bxb1 Ng5 Bxa2 경로를 반복1의 실제
평가 호출까지 확인했다. Bxb1은 백 나이트, Bxa2는 백 룩을 잡는 수다.
관측은 실제 경로 방문을 증명하며, 그 가지의 값이 최종 root 결정의 근거였다는
뜻은 아니다. 다른 검증과 동시 실행했으므로 경과 시간으로 속도 개선을 주장하지 않는다.
