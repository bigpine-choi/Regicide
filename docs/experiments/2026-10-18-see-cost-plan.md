# SEE 비용 개선: 손실 분석·비용 측정·새 위치 대국 계획

이번에는 직전 외부 부하 통제 재현실험의 **1초 SEE 패배 7판**을 개발 자료로 분석하고, SEE 계산에서 효과가 큰 병목을 우선 수정한다. 수정 전 SEE v0.5.2와 한 번 고정한 후보를 비교한다. 이전 PVS와 비교하거나 이전에 유리했던 결과와 합산하지 않는다. 이 계획과 새 시작 위치는 새 위치에 대한 엔진 검색 전에 고정한다.

## 고정 버전과 개발·확인 자료의 구분

- 기준: SEE v0.5.2, 소스 `0edc06e437b934d177fc1e9b0907600b6287be72`, 실행 파일 `build-see-native/regicide.exe`, SHA256 `2ba41c8303f266149323b55186f5c6a806c33f73d529d6911d6ca4b33bfa53db`.
- 후보: SEE 비용 개선 v0.5.3, 실행 파일 `build-see-cost/regicide.exe`. 구현과 검증 뒤 실제 소스 커밋과 바이너리 SHA256을 [동결 명세](../../tests/data/see_cost_freeze_2026-10-18.json)에 채운다. 빈 값은 실행기와 감사가 거부한다.
- 후보 엔진 소스 커밋과 깨끗한 최종 실행기 커밋을 분리해 기록한다. 측정 전 바이너리·전체 규칙 검증·실행기·명세·시작 위치를 동결하고, 각 시간 묶음 전후 해시와 깨끗한 체크아웃을 확인한다.
- 직전 패배 기보와 기존 프로파일 위치는 원인 분석·회귀·비용 측정용 개발 자료다. 새 8개 위치는 후보 변경의 선택·튜닝·사전 검색에 사용하지 않는다. 엔진 수정 후 고정 깊이 또는 비계측 성능 수치를 보고 후보를 다시 조정하지 않고, 단일 후보로 최종 대국한다.

## 먼저 확인할 약점과 비용 가설

패배 기보의 평가 급락·교환 수순·완료 깊이·시간을 대조한다. 얕은 탐색으로 놓친 전술과 평가 함수의 한계를 구분하며, 엔진 자신의 점수 변화만으로 객관적인 실수를 확정하지 않는다. 원래 SEE를 프로파일링해 본 탐색에서 차지하는 비용과 호출 수를 확인한다. 원본·수정 SEE 함수의 호출당 시간(ns)은 별도 계측으로 남긴다.

비용 측정은 같은 위치·깊이에서 같은 점수·선택 수·탐색량을 확인하는 `--require-same-search` 경로를 사용한다. 계측용 결과를 실전 속도와 혼동하지 않고, 최종 시간 대국에는 계측하지 않은 바이너리를 사용한다.

- 기존 `profile_positions`의 전체 10위치, 깊이 3·4 각각 **5회**, seed **20261020**. 엔진 역할의 선실행 순서를 교대한다. 엔진당 워밍업 1회는 기록하되 통계에서 제외한다.
- SEE를 끈 대조는 전체 10위치, 깊이 4 **1회**다. 이 대조를 최종 대국의 SEE 설정과 혼동하지 않는다.
- 손실 개발 부분집합 `analysis/development-cost-subset.json`의 **5위치**, 깊이 4 **3회**, `--require-same-search`다. 선택 기준은 7패 중 완료 깊이가 낮은 상위 3위치와 현재 평가가 -200cp 이상인 평가 급락 상위 3위치의 중복 제거다. 비교 후 유리한 위치만 선택하지 않는다.
- 같은 위치의 벽시계·노드·완료 깊이·선택 수·점수를 보존한다. 평균·중앙값·반복 변동을 함께 보고하고, 시간 감소와 경기력 향상을 별도로 판정한다.

## 새 시작 위치와 32판

[새 시작 수순](../../tests/data/see_cost_openings_2026-10-18.json)은 엔진 평가·추천·탐색·대국 결과 없이 손으로 작성한 10~12반수의 8개 수순이다. 백 차례 4개·흑 차례 4개이며, 파일 SHA256은 `9dafe565121ddad88cef0ca9060bd87b73a7bc52c837240835be0cf5f599ea9e`다.

사전 python-chess 검사에서 모든 수의 합법성·유효 보드·진행 가능 상태·내부 중복 부재·기존 실행기 호환을 확인했다. 당시 저장된 JSON **105개**, PGN **290판**의 **348개 고유 시작/기준 위치**와 최종 8위치가 모두 다르다. 이전 검사의 339위치와 직전 SEE 복제 위치를 포함한다. 비교 기준은 카운터를 제외한 앞 4개 FEN 필드이며, 포획할 수 없는 앙파상 칸을 정규화한다. 원자료 해시 목록과 수순별 FEN은 `build/see-cost-evidence/preflight-opening-validation.json`에 기록했다.

파일 순서대로 각 위치에서 후보 백·후보 흑을 모두 사용한다. **100ms/수 16판 → 1,000ms/수 16판**, 총 **32판**이다. 이 수순은 손으로 정한 작은 고정 표본이며 전체 체스 위치의 무작위 대표 표본이 아니다. 한 번 사용한 뒤에는 이후 연구의 개발 자료로 취급한다. 결과를 보고 위치·순서·판수·시간을 변경하지 않는다.

## 시간·자원·대국 판정

동일 PC에서 양측 단일 탐색 스레드, Hash 16MiB, Move Overhead 20ms, PVS 켬, **양측 SEE 켬**을 유지한다. 기존 v0.5.2의 기본 옵션과 후보 설정을 각각 기록하고, 광고한 기본값에 요청 값을 합친 실제 옵션이 서로 같은지 감사한다. 요청 100/1,000ms에 내부 할당 80/980ms를 유지한다.

새 위치에서 검색 워밍업을 하지 않아 최초 전이표 할당도 포함한다. 엔진은 각 시간 묶음 동안 유지하고 매 수 전체 이력을 전달하며 매 판 새 대국 상태를 설정한다. 현재·예정 수의 반복/50수 무승부는 `claim`, 최대 500반수다. 한도 도달·오류·중단을 무승부로 바꾸지 않는다. 모든 수의 요청/내부 시간 초과를 보존한다. 기존 비교에 없던 별도 강제 몰수 시계를 추가하지 않는다.

## 규칙 검증과 외부 엔진 부하 통제

기존 C++ 규칙·탐색·평가·보드·전이표·SEE, 외부 합법 수 차등, UCI·대국·Godot·무르기·핸디캡·기보 회귀를 먼저 실행한다. 기준 엔진 규칙·차등도 확인한다. [동결 명세](../../tests/data/see_cost_freeze_2026-10-18.json)의 21개 gate에 실제 바이너리·로그 해시·시작/종료 시각을 남긴다. 후보 C++ 그룹/검증 수는 이전 고정 숫자로 가정하지 않고 실제 6개 네이티브 검사 로그의 요약을 합산해 검증한다. Windows 심볼릭 링크 권한 1건의 기존 예상 건너뜀은 기록한다.

모든 빌드·테스트·프로파일·다른 에이전트의 엔진 계산을 끝낸 뒤 대국을 순차 실행한다. [새 실행기](../../scripts/run_see_cost_comparison.ps1)는 이미 검증한 [기존 외부 CPU 감시](../../scripts/see_clean_guard.py)를 변경 없이 재사용한다. 실제 UCI transport PID·생성 시각·부모 계층으로 측정용 두 엔진만 식별하고, 이름이나 경로만 같다는 이유로 다른 엔진을 제외하지 않는다.

측정 전 **10초 연속 유휴**, 감시 **0.5초 간격**, 최대 스냅샷 간격/지속 시간 **2초**, 외부 엔진 CPU 증가 허용치 **0 native ticks**다. 외부 CPU 증가·외부 엔진 신원 변화·감시 실패 시 해당 시간의 전체 묶음을 무효로 보존하고 이후 판/시간을 시작하지 않는다. 사용자 대국을 닫거나 외부 프로세스를 종료하지 않는다. 유휴 회복 후 오염된 시간의 전체 16판만 새 연속 시도 번호로 재시작한다. **각 시간에서 처음 정상 완료한 묶음을 반드시 채택**하며 깨끗한 결과를 다시 선택하지 않는다. 비외부/소유권/엔진 실패는 자동 재시도를 허용하지 않는다.

실행 중 임시 절전 방지와 이전 상태 복원을 정상·실패·중단 모두 기록한다. 알려진 엔진 이름 및 샘플 범위의 관측이며, 샘플 사이의 짧은 프로세스나 다른 앱·열·전력 상태 전체를 배제하는 증명은 아니다.

## 결과 해석과 보존

각 시간의 후보 승·무·패·득점률을 분리하고, 시작 위치의 선후공 두 판을 묶은 seed **20261020**, **20,000회** 참고 부트스트랩 구간을 제시한다. 이전 SEE 재현실험 결과와 유리하게 합산하지 않고 Elo로 환산하지 않는다. 작은 표본과 구간에 50%가 포함되는 불확실성을 밝힌다. 대국 중 서로 다른 위치에서 얻은 평균 노드/깊이를 고정 위치 가속 증거로 대체하지 않는다.

[독립 감사](../../tests/audit_see_cost_results.py)는 엔진 실행 없이 실제 수·PV·최종 FEN·결과·선후공·득점·새 위치·엔진/도구 커밋·옵션·바이너리·검증 로그·감시 원자료·모든 시도·첫 정상 묶음 채택을 대조한다. 기존 PVS/SEE 원자료와 도구는 수정하지 않는다. 실패 시도·도구 수정 사유·원자료를 보존하며 개인 대국은 포함하지 않는다. 최종 보고에는 실제로 수행한 분석·검증·측정과 남은 가설을 구분한다.
