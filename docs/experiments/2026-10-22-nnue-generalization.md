# 다른 개시와 학습하지 않은 위치로의 일반화

2026-10-22. 앞선 순서 학습이 다른 계열로 이어지지 않은 원인을 진단하고, MSE·현재 NNUE
구조·과적합 방지를 유지한 채 비교 자료의 계열과 학습 배치를 개선했다. 새 후보는 한 번만
학습했다. 사전에 분리한 수 선택 검사에서 개선되지 않아 조건부16판은 실행하지 않았다.

## 원인: 비교 자료의 범위와 반복 노출

이전 학습18쌍은 실제 부모 위치13개·개시 계열6개뿐이었다. 두 후보를 비교할 때 변한 기물칸
특징은 공유 가중치의 양 관점을 합쳐96개였고, 선택용11쌍의44개 특징과 공유한 것은16개다.
선택 쌍별 학습 범위 겹침은 평균40.15%, `e3`와 `Rd1`/`e4`의 첫 두 비교는0%였다.
즉 전체 위치 점수를 많이 배웠어도, 새로운 수의 상대적 순서에 대한 직접 학습은 부족했다.

같은18쌍을 위치 minibatch13개마다 전부 반복해 한 회차에234쌍을 방문했다. 새로운 사례가
늘지 않은 채 소수 특징에 반복 노출된 것이다. 학습 순서는7→14/18이었지만 선택 순서는
3→3/11이었다. 선택 계열7의 점수차 MSE는 줄었고 계열8은 악화됐다.

25·30회 모델은 기존263위치 보호 기준에 걸리고 선택용 전체 목적값도 악화됐다. 따라서
과적합 보호를 풀거나 더 오래 학습하는 해결은 지지되지 않는다. 이것만으로 현재 구조의
표현력 한계나 원인별 기여율을 확정하지는 않는다.

## 개선: 계열을 넓히고 같은 쌍을 회차마다 한 번 사용

새 `prepare_nnue_generalization.py`는 기존 원본 기보에서32개 계열·64개 부모 위치를
교사 결과를 보기 전에 고정했다. 원래 학습24계열·선택8계열에서 각각2개씩이며,
기물20개 이상·물질 차이200cp 이내·16반수 이후·부모 간8반수 이상 차이로 골랐다.
초반/중반과 양쪽 차례의 범위를 넓혔다. 원본 전체 수순과 계열 분할을 검증했다.

원본 자료의32개 학습/선택 파일에 있는7,521개 위치와 같은 입력의 부모는 제외했다.
현재 모델의 실제 선택수와 교사 추천수 뒤의 위치를 비교하고, 같은 수이면 NNUE 정적
평가가 높은 다른 합법 수를 비교 대상으로 삼았다. 어떤 쪽이 좋다는 가정 없이 정확한
두 자식 점수 차이를 MSE 목표로 사용한다.

위치당50,000노드, 최대192질의 중 실제138질의·교사13.07초였다. 원본64위치에서37개,
자식74위치에서52개가 정확한 cp 정답으로 승인됐다. 양 자식이 모두 승인된 새 비교는
학습14쌍·선택5쌍이다. 확정되지 않은 bound·메이트는 보충 없이 제외했다.

기존 학습 쌍은 계열당 최대2개로 제한하고 일반 점수 자료는 보존했다. 최종 사용 범위는:

| 자료 | 고유 위치 | 비교 쌍 | 비교 계열 | 비교 부모 |
| --- | ---: | ---: | ---: | ---: |
| 학습 | 1,426 | 26 | 18 | 25 |
| 선택 | 337 | 16 | 6 | 12 |
| 기존 사후 점검 | 69 | 없음 | 해당 없음 | 해당 없음 |

선정32계열이 모두 유효 비교가 된 것은 아니다. 새 완성 비교는 학습12계열·선택4계열이며
기존 비교와 합쳐18/6계열이 됐다. 자식 행의 `mover`·`piece_count`는 원래 부모 메타데이터이므로
실제 특징·차례·분포와 검증은 항상 자식 FEN에서 다시 계산한다.

초기 합본 단계의 임의 최소16개 조건은 새 학습14쌍에서 멈췄다. 이미 생성한 정확한 질의
기록을 보존하고, 재질의 없이 실제 학습 배치의 충족 여부를 검사하도록 합본을 수정했다.
목표 점수·수순·손실·검사 기준은 바꾸지 않았으며 학습·새 검사 성능을 보기 전의 수정이다.
원본 생성 소스·합본 소스·이유를 별도 영수증으로 보존했다.

`neural_stm_ordering.py`의 선택 기능은 계열 내부·계열 순서를 시드로 섞고 계열을 순환해
26쌍을13개 위치 배치에2개씩 배분한다. 이번 학습에서는 각 쌍을 회차당 정확히 한 번,
같은 크기의 배치로 사용했다. 기존 방식은 옵션을 주지 않으면 연산과 결과가 그대로다.

## 구조와 과적합 방지

위치 MSE + 점수차 MSE·계수1, NNUE v3·기물768+상대 손번1·은닉16·S32를 유지했다.
Adam·학습률·batch128·시드·기울기 상한10도 유지했다. 매5회 선택 점검·5번 연속 개선
없으면 중단·epoch0 포함·최적 복원·원래263위치 MSE 악화 차단을 모두 유지했다.

현재4e54 모델에서 한 번 학습해30회에서 중단,5회 가중치를 복원했다. 학습1.20초,
390업데이트, 각 회차26쌍씩 방문했다. 선택용·별도 검사 입력은 미분에 들어가지 않는다.

| 같은 자료의 지표 | 시작 모델 | 새 모델 |
| --- | ---: | ---: |
| 학습 비교 순서 | 11/26 | 15/26 |
| 선택 비교 순서 | 5/16 | 5/16 |
| 선택 점수차 MSE(cp²) | 62,155.56 | 61,165.00 |

기존69개는 과거 개발에 이미 노출됐으므로 이 변화만으로 일반화를 주장하지 않는다.

## 새로 분리한 수 선택 검사

기존10개 패배 위치는 여러 번 개발에 쓰였으므로 새 일반화 검사의 근거로 재사용하지 않는다.
기존 프로젝트 M2 개시 은행에서16위치·16계열·7개 군집을 모델·교사 선택 결과를 보기 전에
고정했다. 각 부모와 모든 합법 자식을 합친583개 위치 입력은 과거 학습/선택7,521개와
겹치지 않는다. 기물 배치와 색/랭크 대칭을 고려한 식별자로 비교하며, 차례가 달라도 같은
기물 배치는 보수적으로 제외한다. 이583개를 새
점수·비교 학습과 모델 선택에서도 모두 제외하고 훈련 진입 때 다시 검사한다. 과거 M2
대국에 등장한 개시 자료이므로 완전히 새로운 출처라고 부르지는 않는다.

통과 기준은 사전에 고정했다. 정확한 자식 점수로 비교 가능한 위치12개 이상, 교사1순위
일치 최소2개 증가, 두 모델 선택수 뒤의 교사 점수를 원래 차례로 비교한 평균20cp 이상 개선,
200cp 이상 악화 위치0개, 실제 native 계산 불일치0개를 모두 만족해야 한다.
교사1순위가 완전한 최적 수라는 가정은 하지 않는다.

첫 교사 수집은100,000노드에서 탐색을 끊어16개 중14개가 bound였다. 정확한 부모가2개뿐이라
후보·기준 모델의 실제 검색은0회였고 성능을 판정하지 못했다. 이는0점이나 일반화 실패가
아니다. 원래 기록을 보존하고 같은 후보·같은16위치·같은 기준으로 점수 수집만 교정했다.
교사가 깊이10을 완료하거나100,000노드 상한에 닿으면 끝내도록 해, 완성된 깊이의 cp를
받는다. 둘 중 먼저 도달한 조건에서 끝나며 유한 탐색의 참조 점수라는 한계는 같다.

교정 계획과 소스·후보 해시를 실행 전에 별도 커밋했다. 부모16개와 선택수 뒤18개가 모두
정확한 cp로 승인됐다. 수집은2회지만 후보의 실제 수 선택 성능 검사는1회이며 재학습·
가중치 재선택·위치 교체·기준 완화는 없다. 교정 수집0.63초, 수 선택·자식 교사를 합친
검사1.79초였다. 교사도 깊이10의 유한 탐색이므로 참조 점수의 한계가 있다.

| 학습·선택에서 제외한16위치 | 시작 모델 | 새 모델 | 사전 통과 기준 |
| --- | ---: | ---: | --- |
| 교사1순위 일치 | 7/16 | 6/16 | 최소2개 증가 |
| 선택수 뒤 교사 점수 변화 | 기준 | 평균−5.75cp | 원래 차례 관점 평균+20cp 이상 |
| 200cp 이상 악화 | 기준 | 0개 | 0개 |
| 계산 불일치 | 0개 | 0개 | 0개 |

14곳은 같은 수를 골랐고 바뀐2곳은 모두 교사 참조상 낮았다. 님조 계열 흑 차례에서
`Nh5` 대신 `Bd7`을 골라11cp 낮았고, 시실리안 모스크바 백 차례에서 교사와 같았던
`cxd4` 대신 `Nxd4`를 골라81cp 낮았다. 후자는 백 관점 자식 점수가+66에서−15로 바뀌었다.
이 검사로 모든 경우의 장기 기력을 판정하지 않으며, 해당 후보가 사전 기준에 미달했다는
결론만 낸다. **기본 Regicide와의16판은0판, 기본 게임·모델 채택도 변경 없음**이다.

비교 자료를 넓히고 반복 편중을 줄이는 코드는 완성했으나 학습 순서15/26의 개선이 선택
5/16·새 수 선택6/16으로 이어지지 않았다. 전체 점수차 MSE의 작은 감소만으로 실제 수
선택 개선을 보장하지 못한다. 다음 가설은 한 수 직후의 위치 대신 실제 탐색이 최종 평가하는
안정된 후속 위치의 점수차를 학습하면 수 선택과 학습 목표가 더 잘 맞는다는 것이다.
이번 검사 위치는 이후 개발에 노출된 자료로 취급해야 하며,
다음 독립 판정에는 새로 분리한 위치가 필요하다. 추가 실험은 자동 시작하지 않았다.
