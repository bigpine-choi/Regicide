# 기존 판단 보존과 새 탐색 평가 위치 학습

2026-10-22. 이전 leaf 학습에서 기존 검증 위치의 오차가 늘어난 원인을 재현하고,
기존 TRAIN 출력 보존 MSE와 실제 정수 학습 손실을 확인하는 단계 축소를 구현했다.
MSE·현재 NNUE v3·조기 중단·최적 복원·기존263위치 보호 기준은 유지한다.
이전부터 보존한 미학습16위치는 최종 후보의 검사에만 사용했다. 점수 오차와 일부 수 선택은
나아졌으나 고정 검사 기준에 미달해 조건부16판 대국은 실행하지 않았다.

## 확인한 원인

이전 학습의 첫5회·80업데이트를 같은 자료·시드로1.46초에 정확히 재현했다. 새 후보를
만들거나 추가 정답을 수집하지 않은 진단이다. 기존 학습 자료의 오차는 오히려 줄었지만
학습에 쓰지 않은 기존 위치에서는 오차가 늘었다.

| 이전 5회 학습의 MSE(cp²) | 시작 | 5회 뒤 |
| --- | ---: | ---: |
| 기존 TRAIN, 원래 반복 가중 | 54,521.85 | 51,691.24 |
| 기존 선택 자료 | 74,459.40 | 75,686.26 |
| 기존263개 보호 위치 | 62,807.95 | 64,253.49 |

따라서 기존 학습 내용을 단순히 잊었다는 설명만으로는 부족하다. 새 leaf에 등장한
기물·칸 입력386개 중374개(96.89%)가 기존 학습과 공유됐다. 공유 가중치의 수정이
기존 위치에도 전파돼 기존 TRAIN 출력은 가중 평균24.92cp, 보호 위치는25.38cp 움직였다.

보호 위치의 MSE 증가1,445.54는 출력 이동 제곱1,016.96과 기존 잔차와의 교차항428.58로
분해된다. 실수 가중치 평가의 MSE도 증가해 정수 반올림만의 문제는 아니다. 입력 가중치만
시작값으로 되돌린 진단에서는 보호 MSE가61,829.27로 회복됐지만 새 leaf 선택 오차는
악화됐다. 이는 공유 입력 변경을 통한 적응과 기존 위치 보존 사이의 충돌을 보여준다.
그룹별 효과를 합산한 원인 기여율이나 현재 구조의 불가능성 증명으로 해석하지 않는다.

## 첫 개선: 기존 TRAIN 출력 변화도 MSE로 제한

기존 Stockfish 위치 점수 MSE와 후보 수 점수차 MSE는 그대로다. 여기에 기존 TRAIN
1,426개에서 시작 모델의 정수 흰색 점수와 새 모델 점수의 MSE를 가중치4로 추가했다.
새로운 판단의 학습 정답은 여전히 Stockfish이며, 시작 모델 점수는 변화폭 제한에만 쓴다.

```text
학습 손실 = Stockfish 위치 MSE + Stockfish 후보 수 점수차 MSE
          + 4 × 기존 TRAIN에서 시작 모델 출력과의 MSE
```

각 항은 자체 표본 수로 평균한다. 매 point minibatch에 전체 기존 TRAIN의 보존 평균을
사용하고 보존 정답은 학습 전에 한 번 고정한다. TRAIN의 중복 없는 부분집합인지 검사해
선택·사후 점검·보호263개가 미분에 들어가지 않게 했다. 기존 정답을 다시 학습하는 것과
기존 출력의 변화를 직접 제한하는 것은 다른 목적이다. 모든 옛 수 선택을 고정한다는
뜻은 아니며, 실제 수 선택 보존·개선은 별도 검사해야 한다.

새 자료 수집 없이 이전 leaf 자료를 재사용한다. 학습1,520개·선택369개·기존 사후 점검69개,
기존 비교26/16쌍은 바이트 그대로다. 새 leaf94/32개의 가중치4와 기존 가중치를 유지했다.
입력768+상대 차례1·은닉16·S32, Adam·학습률·시드·배치128·기울기 상한10도 유지한다.

첫 후보 학습은7.01초,25회·400업데이트였다. 5회 보존 TRAIN 출력 변화는 평균14.57cp로
줄었지만 보호 위치 MSE가63,762.77로 기준을 넘었다. 10·25회는 보호 위치 MSE가 각각
62,716.22·62,159.03으로 기준을 만족했다. 그러나 선택용 위치+점수차 합계가 시작보다
악화돼 채택할 수 없었다. epoch0을 복원했으며 미학습16위치는 조회하지 않았다.

| 선택 지표(cp²) | 시작 | 5회 | 10회 | 25회 |
| --- | ---: | ---: | ---: | ---: |
| 선택 점수+점수차 MSE | 151,746.17 | 151,732.19 | 151,777.77 | 160,538.41 |
| 보호263개 MSE | 62,807.95 | 63,762.77 | 62,716.22 | 62,159.03 |
| 두 조건을 함께 개선 | 기준 | 아니오 | 아니오 | 아니오 |

보존 효과는 일부 확인됐으나 일반화 개선 모델을 얻은 결과는 아니다. 기존 보호 기준이나
선택 목적값을 완화해 10회 모델을 채택하지 않았다.

## 두 번째 개선: 실제 정수 TRAIN 손실로 수정 폭 확인

첫 사전 계획은 후보1회였지만, 보호와 새 학습을 함께 만족하지 못해 추가 코드 개선
한 번을 진행하기로 명시적으로 수정했다. 첫 소스·학습 결과·원래 계획은 그대로 보존하고
두 번째 계획을 실행 전에 고정한다. 총 후보 학습은 최대2회이며 미학습 검사 뒤의 재학습이나
시드·가중치 후보 탐색을 허용하지 않는다. 원인 진단의 과거5회 재구성은 별도로 기록한다.

두 번째 학습은 자료·시드·MSE 가중치·Adam·보호 기준을 그대로 두고 단계 채택만 바꾼다.
Adam이 제안한 수정 폭을 `1, 1/2, 1/4, 1/8, 1/16, 1/32` 순서로 확인해 전체 TRAIN의
실제 배포 정수 손실이 늘지 않는 첫 단계를 사용하고, 없으면 그 수정을 건너뛴다.
같은 정수 점수의 plateau에서는 실수 가중치의 작은 진행을 허용한다. Adam 누적량은
업데이트마다 한 번 갱신한다. 선택·보호·사후 점검·미학습16위치는 단계 선택에 쓰지 않는다.

이 방식은 MSE 근사 기울기의 제안을 실제 정수 모델에서 확인한다. TRAIN 손실의 비증가가
미학습 판단 향상을 보장하지는 않는다. 기존 조기 중단과 최적 복원,263개 보호를 적용한
최종 가중치만 수 선택 검사의 대상이 된다.

## 두 번째 학습 결과

추가 학습36.66초,30회·480수정 제안에서 중단하고5회 가중치를 복원했다. 제안139개를
받아들이고341개를 건너뛰었으며 실제 정수 손실 평가2,377회를 수행했다. TRAIN의 전체
정수 목적값은 회차 사이에 늘지 않았다. 최종 저장 가중치는 마지막30회 것이 아니라
기존 보호와 선택 목적값을 함께 만족한5회 것이다.

| 저장한 최종 모델의 지표 | 시작 모델 | 새 모델 |
| --- | ---: | ---: |
| 기존263개 MSE(cp²) | 62,807.95 | 62,230.91 |
| 새 leaf 학습94개 MSE(cp²) | 117,886.15 | 113,553.24 |
| 새 leaf 선택32개 MSE(cp²) | 146,450.88 | 144,329.25 |
| 선택 점수+점수차 MSE(cp²) | 151,746.17 | 149,716.21 |

기존 TRAIN1,426개에서 시작 점수와의 차이는 평균 절댓값9.99cp·최대57cp다. 기존 점수를
그대로 고정한 모델은 아니며1351개 점수가 달라졌다. 기존 보호 위치의 평균 오차를
악화시키지 않으면서 새 자료도 학습한 것은 확인했지만, 이 지표만으로 경기력 향상을
주장하지 않는다. 기존69개 사후 점검은 과거부터 개발에 노출돼 독립 검증 표본이 아니다.

새 모델 SHA256:
`85e3032a87f3145670aa666f8e1359a610c08937f5f0a20cb14ad81dfd507b33`.
미학습16개 정답을 보기 전에 모델·학습·선택·계획을 별도 커밋과 해시로 고정했다.

## 보존한 미학습16위치의 실제 수 선택 검사

원래 leaf 실험의 gate 경로·16부모·모든 합법 자식581개·통과 기준을 그대로 재사용했다.
이전에는 정답을 조회하지 않았고, 이번 최종 후보를 고정한 뒤 처음 측정했다. gate 위치를
새 실험 폴더에 복사해 노출 검사와 혼동하지 않고 원래 계획과 해시만 참조했다.

교사 부모16개와 선택수 뒤18개가 모두 정확한 cp로 승인됐다. 두 모델의 실제 검색은
각16번·10,000노드, 총32번이다. 실제 검색·선택수 뒤 교사 채점 부분은2.17초이며,
그 전의 과거 노출 파일 재검사는 별도 비용이다. 교사는 깊이10·최대100,000노드의 유한
탐색 참조이므로 완벽한 최선수나 무한 깊이의 점수로 간주하지 않는다.

| 검사 지표 | 시작 모델 | 새 모델 | 고정 통과 기준 |
| --- | ---: | ---: | --- |
| 교사1순위와 같은 수 | 4/16 | 4/16 | 최소2개 증가 |
| 기존4개 정답 유지 | 기준 | 모두 유지 | 별도 관측 |
| 평균 선택수 점수 변화 | 기준 | +4.375cp | 원래 차례 관점+20cp 이상 |
| 200cp 이상 악화 | 기준 | 0곳 | 0곳 |
| 계산 불일치 | 0곳 | 0곳 | 0곳 |

14곳은 같은 수를 골랐고 바뀐2곳은 교사 참조상 모두 낮아지지 않았다.

- 폰지아니 위치에서 `Bg5 → Na3`: 백 관점 선택수 뒤 점수+18→+22, +4cp. 작은 차이다.
- 이탈리안 위치에서 `Ng5 → Bg5`: 백 관점−45→+21, +66cp. 교사1순위 `h3`와는 다르다.

새 추천수 일치 횟수와 평균 개선 기준을 충족하지 못해 **기본 Regicide와의 대국은0판**이다.
결과를 보고 기준을 낮추거나 다시 학습·가중치 선택하지 않았다. 이16위치는 이제 개발에
노출됐으므로 다음 후보를 위한 새 독립 검사처럼 재사용하면 안 된다. 일부 선택수 개선과
기존4개 정답 보존은 해당 소표본의 관측이며 전체 기력 개선은 아직 미확정이다.

## 검증과 원자료

출력 보존 검사7개 통과. 보존 가중치0에서는 이전 학습의 파라미터·학습 이력·선택 결과가
정확히 같다. 별도 스칼라 계산으로 점수·점수차·보존 MSE의 STE를 검산한 최대 차이는
4.44e−16이다. 이는 정수 반올림의 수학적 미분이라는 뜻은 아니며 기존 근사 기울기 구현의
일치를 확인한 것이다. 추가 정수 단계 검사6개도 통과했다. 실제 두 번째 모델2,004위치의
Python·전체·증분 계산 불일치0개, native 모델13그룹·25,521확인도 실패0이다. 기존 native
실행 파일과 기본 게임·설치 모델은 유지한다.

독립 검토에서220개 파일의 해시, 두 학습의 전체 지표·최적 복원, 기존 gate 계획의 원본
보존과 실제 수 선택 점수·부호·합법 PV를 다시 확인했다. 지표 재계산 차이0이며, 각 회차의
정수 TRAIN 손실 비증가와 건너뛴 제안의6단계 실패 기록도 확인했다. 채택한 각 단계의
개별 손실값은 저장하지 않아 그 부분은 소스·검사와 회차 기록 범위에서 검증했다.
검토자는 추가 엔진·교사·학습을 실행하지 않았다.
