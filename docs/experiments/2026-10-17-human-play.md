# 최신 엔진 직접 대국 화면 검증

2026-10-17, 사용자가 오늘 개발분의 커밋과 최신 엔진 직접 대국을 요청했다. 시작 시 최신 `6488c70d775cb1ae6e4814d110194471b221eb83`는 깨끗했고 원격 브랜치와 일치했다. 규칙 코어부터 오늘의 모든 로컬/원격 브랜치 커밋이 이 커밋의 조상임을 확인했다. 기존 PR은 유지하고 사람용 화면을 별도 `feat/human-play` 브랜치에 추가했다.

## 변경 범위

루프백 HTTP 서버·자체 브라우저 화면·Windows 실행기를 추가했다. C++ 엔진 소스와 실행 파일은 변경하지 않았다. 실제 UCI 식별은 **Regicide 0.5.0**, 사용한 실행 파일 SHA256은 `cf4162a083d81756aa282595005ae0c9f06bebb4a15b098e0afabae5fb4bf7b9`로 앞선 100ms 비교의 동결 실행 파일과 같다.

기본은 사람 백·엔진 1초/수이며 색·생각 시간 변경, 특수 수·승격 선택, 되돌리기·기권, PGN 내려받기·매 수 자동 저장, 서버 종료를 제공한다. 실제 수 선택은 기존 자체 엔진이고 Python chess는 입출력·규칙 검증·판정·기보에만 사용한다. 외부 자산·서비스·추가 패키지는 없다.

## 실제 수행한 확인

- 새 모델·HTTP·실제 엔진 검증 **25/25 통과**. 실제 엔진은 백·흑 각각 100ms 연결을 확인했다. [로그](../checks/2026-10-17-human-play/tests.txt).
- 새 검증은 특수 수·종료·현재/예정 수 청구·전체 이력 전달·되돌리기·PGN/JSON 일치·새 대국 시 원본 보존·엔진 오류 복구·동시 요청의 오래된 revision 거부를 포함한다.
- Windows 실행기를 실제 실행해 숨김 서버의 시작·준비 파일·정상 HTTP 응답과 v0.5.0 식별을 확인했다. PowerShell 구문·공백/한글 경로 인용도 검사했다.
- 브라우저에서 `e2` 선택 후 `e3/e4` 합법 칸 표시, `e4` 후 엔진 `Nc6` 응수와 기보·생각 중 표시, 한 턴 되돌리기로 초기 상태 복원을 확인했다.
- 흑 선택 후 체스판 방향 전환·엔진 첫 `Nf3`·사람 차례 전환을 확인했다. 종료 버튼으로 서버가 정리되고 종료 상태가 표시됨을 확인했다. 이는 검증용 입력이며 사용자가 실제 대국한 결과가 아니다.
- 높이 712px 화면에서 8줄 체스판이 모두 보이도록 크기를 조정하고 실제 화면을 확인했다. JavaScript 구문·문서/요소 연결 검사를 통과했다.
- 기존 CMake/CTest **5/5**, 외부 규칙 교차 검증 **2,997사례**를 다시 실행해 통과했다. 기존 규칙·탐색 테스트와 C++ 소스에는 변경이 없다. 새 25개 검증을 Windows/Linux CI에도 추가했다.

이번 확인은 직접 대국 화면의 기능 검증이며, 엔진 경기력을 추가 측정하거나 이전 결과를 대체한 실험이 아니다. 기보·무승부 정책과 실행 방법은 [직접 대국 안내](../HUMAN_PLAY.md)에 남겼다.
