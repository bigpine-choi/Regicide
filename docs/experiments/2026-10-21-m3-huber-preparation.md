# M3: H100 후보 준비 범위

2026-10-21. [10/21 진단의 목표×손실 계획](2026-10-21-neural-target-ab-diagnosis.md)을 따라 기존 A/B 정답과 MSE/H100을 교차한12모델을 준비한다. 이번 요청 범위는 기존 MSE의 정확 재현·작은 손실 구현·학습·저장·native 검증·출처 동결이다. 새 확인 자료·수 순위 패널·192판 확인 대국은 실행하지 않는다. 기본 평가기와 채택 명세를 바꾸지 않는다.

조건은 기존 train2209행/validation723행, 같은 자체 bootstrap 배열,768입력×16은닉·S32,120epoch·batch128, 입력/편향 학습률0.00002·출력0.005, Adam과 기울기 norm10, 배치 시드20261020/21/22다. 모든 마지막 epoch를 보존하며 검증값으로 중간 epoch·시드·조건을 선택하지 않는다. 세 시드는 독립 초기화가 아니다.

H100은 `r=(예측cp−정답cp)/100`에 대해 `|r|≤1`이면 `r²`, 그 밖은 `2|r|−1`이다. 표준 Huber의2배이며 작은 오차의 손실과 기울기는 기존 MSE와 같다. 경계는100cp 한 가지로 고정하고 정답 행을 지우거나 잘라내지 않는다.

MSE6모델을 먼저 원래 실수·정수 배열, 직렬화한 모델 바이트, train/validation 정수 예측까지 비교한다. 그 뒤 H1006모델을 학습한다.10epoch마다 같은 기존 검증/학습 자료의 MAE·MSE·H100, 위치 종류·두 정답 차이 집단별 오차, 실제 배치 gradient norm, 입력 이동을 관측하며 학습은 끝까지 고정한다. 기존 보류687행과96판은 이번 준비 코드가 읽지 않는다.

각 모델은 저장/로드·재양자화, 전체2932행과 특수 수46위치의 Python/C++ 전체/증분 동값을 확인한다. 기존 C++ 모델 검사 실행 파일을 임시 복사해 특수 수·undo·분기·검색 중단 검증을 실제 가중치로 실행한다. 원본 실행 파일·모델·학습 자료와 native 소스를 변경하지 않는다.

원래 전체 실험 계획은 새 확인 시작 은행을 학습 전에 구성·동결하도록 요구한다. 이번 제한된 준비에서는 그 은행도 만들지 않고, 이미 문서에 고정된 namespace `ab-loss-v1`와 시드20261031만 보존한다. 따라서 이 준비를 전체 확인 실험 완료로 표현하지 않는다. 후속 설계에서는 이 범위 차이와 확인 자료의 미관측성을 명시해야 한다.

새 출력 경로에 실행 전 protocol·입력/소스 해시를 기록하고12모델을 모두 동결한다. 정확성·학습 오차·실제 대국 성적은 구분한다. 후보 준비만으로 기력 개선이나 M3 전체 완료를 주장하지 않는다.
