# 대국 중 생각 시간 변경 — 2026-10-19

브라우저와 Godot에서 **한 수 생각 시간**을 고르면 현재 대국에 바로 저장하고 다음 Regicide 검색부터 사용한다. 기물 색·새 대국·수 바꾸기와 분리했다. 이미 진행 중인 검색에는 시작할 때의 시간을 유지하며, Godot은 이번 수와 다음 수의 시간을 따로 표시한다. 0.1·1·3·5초 선택을 그대로 제공한다.

예를 들어 3초로 생각하는 중 5초를 고르면 현재 수는 3초로 마치고 다음 엔진 수는 5초로 생각한다. 판·색·수순·기보 번호를 유지하고 무르기를 해도 가장 최근 시간 설정은 유지한다. 수 바꾸기 미리보기와 과거 기보 다시 보기에서는 설정을 바꾸지 않는다. 새 실행부터 변경한 화면·관리기를 사용한다.

## 동작과 저장

- `/api/think-time`은 현재 `game_id`, 별도 `settings_revision`, 정수 `movetime_ms`를 검증한다. 허용 범위는 100~5000ms다. 이전 대국·이전 설정·불리언·문자열·범위 밖 값을 거절한다. 설정 변경은 착수용 revision을 바꾸지 않아 이미 제출한 엔진 요청을 무효화하지 않는다.
- 관리기는 엔진 검색에 판의 전체 이력 복사본·게임 토큰·시간을 전달하고, 검색 중 대국 잠금을 풀어 상태 조회와 설정 저장을 처리한다. 그동안 새 대국·무르기·기권·수 바꾸기 등 판을 바꾸는 요청은 거절한다. 종료·엔진 검색의 잠금 순서를 같게 하고, 완료 시 게임·토큰·착수 revision을 다시 확인한다. 종료된 세션의 대기 요청은 엔진을 다시 열지 못한다.
- 두 화면은 별도 설정 요청을 사용하고, 착수와 설정 버전을 각각 비교해 늦게 온 응답이 판이나 시간을 되돌리지 못하게 한다. 시간 변경으로 선택한 기물·승격 후보·시점을 지우지 않는다.
- JSON의 `time_settings_events`는 변경 시각·변경 전후 시간·당시 ply·진행 중인 검색 시간을 보존한다. `engine_movetimes_ms`와 PGN의 각 실제 엔진 수 주석은 해당 검색에 요청한 시간을 기록한다. `EngineMoveTimeMS` 머리글은 최신 설정이다. 무르기·수 바꾸기 확정으로 버린 수의 시간 기록도 제거하고, 미리보기 취소 시 원래 기록을 복원한다. 기보 보관함에서 다시 내보낸 PGN에도 시간 주석을 유지한다. 요청 시간을 실제 벽시계 소비 시간으로 해석하지 않는다.

엔진 `src/`·`include/`·선택 모델·대국 실행기는 변경하지 않았다. 실제 검증 실행 파일 SHA256은 `598ebec433334b2ce053d0ed6b143fbfd34f9dd3a76557adb62764dcd940c705`다. 경기력 실험과 독립적인 연습 화면 개선이다.
