# 현재 신경망에 추가 시간을 준 시범 대국 — 2026-10-19

**완료: 예정 6판을 모두 마쳤고, 원시 기보·UCI·시간·부하·입력 해시 감사가 통과했다.** 신경망 3초 대 기존 1초는 1승 2무 1패(득점률 50%), 신경망 5초 대 기존 1초는 1승 1무(75%)였다. 공통 Spanish 한 쌍은 두 조건 모두 1.5/2점(75%)이었다. 작은 시간 차등 시범 결과이며 기력 향상이나 5초 우위의 근거로 일반화하지 않는다.

이번 질문은 **“현재 1/32 모델에 3초 또는 5초를 주면 기존 평가기 1초에 어느 정도 대응하는가?”**다. 사용자의 최종 선택에 따라 양측 생각 시간이 다르다. 같은 시간의 기력 비교나 기본 평가기 교체 검증으로 해석하지 않는다. 모델의 새 학습·선택·조정은 하지 않는다.

## 새 시작 위치와 비노출 확인 범위

[오프닝 파일](../../tests/data/neural_long_time_openings_2026-10-19.json)의 12개 수순은 점수·엔진 추천·검색·대국 결과를 사용하지 않고 직접 작성했다. 선택에는 합법성, 미종료 상태, 이전에 노출된 기물 입력과의 중복 여부만 사용했다. 12개 모두 합법적인 16~18ply 위치이며, 전체 풀은 백 차례 6개·흑 차례 6개다.

실제 주조건에는 첫 **Spanish(백 차례)**·**Sicilian(흑 차례)** 두 위치만, 보조조건에는 같은 **Spanish(백 차례)** 한 위치만 사용한다. 각 위치에서 엔진의 백·흑을 바꾸므로 엔진 색은 균등하지만, 보조조건의 시작 차례·구조 표본은 한 가지뿐이다. 남은 열 개 위치는 이번 결과의 판수에 포함하지 않는다.

[신선도 감사](../matches/2026-10-19-neural-long-time/openings-audit.json)는 서로 다른 이전 자료 **191개 파일**을 묶고, 과거 **370개 실제 대국 궤적·619개 오프닝 수순·표본 학습/검증/보류 자료 5,686행**을 수집했다. 기록된 최종 예상 수순 31,035개와 이전 분석의 전체 수 이력 688개도 재생했다. 이 수집 항목에는 같은 자료가 중복 출현할 수 있으므로 각 항목을 독립 표본 수처럼 더하지 않는다.

기물 배치만의 입력을 색 교환·랭크 반전까지 정규화한 고유 노출 집합 **71,168개**와 새 위치의 교집합은 **0**, 새 12개 사이 중복도 **0**, 기록 재생 오류도 **0**이었다. 이는 경기 시작 전에 확인한 입력 신선도 결과이며, 대국 성적이 아니다.

감사 범위에는 보관된 match JSON, 이전 분석 JSON 및 query JSONL의 FEN·실제 수 이력·기록된 최종 예상 수순과 네 표본 데이터셋이 포함된다. **미채집 원시 학습 위치 전체, PGN에만 존재하는 궤적, 중간 UCI `info` 행의 모든 예상 수순까지 비노출을 보장하지 않는다.** 작성 중 Caro 수순의 출발 칸 오타를 첫 실행 전에 합법성만으로 고친 사실과, 예산에 따른 사용 쌍 축소도 감사에 남겼다.

## 종료·무효·미완료 처리

3회 반복·50수 무승부는 현재 상태뿐 아니라 합법적인 다음 수로 청구할 수 있는 경우도 청구하는 `claim` 정책이다. 점수를 기준으로 한 조기 승패 판정은 없다. 최대 500ply 또는 전체 예산에 도달한 미종료 판을 무승부로 바꾸지 않는다.

최종 기록에서는 예정 판수, 시작한 판수, 정상 종료 판수, 미완료 판수, 미실행 판수, 무효 블록을 구분한다. 외부 엔진 CPU 활동, 프로세스 식별 문제, 감시 공백, 입력 변경 또는 실행 오류로 무효가 된 블록은 정상 비교 성적에 넣지 않는다. 그 블록의 남은 기보와 오류는 진단 자료로 보존하며 좋은 결과만 추려 다시 실행하지 않는다. 정상 비교에 채택할 수 있는지는 독립 감사 완료 뒤에 결정한다.

벽시계 시간 초과를 강제로 몰수 처리하는 대회 시계는 사용하지 않는다. 역할별 요청 시간, 엔진 보고 시간, 실제 벽시계 경과, 내부 예산 초과와 요청 시간 초과를 각각 기록한다. 예산 상한에 따른 검색 중단과 일반적인 한 수의 시간 오차도 구분한다.

## 감사기 기록 형식 보완

실행 전 동결한 새 검증 게이트는 새 도구 검사 2개와 기존 런타임·모델 검사 8개를 가리키는 `reused_gate` 영수증으로 구성했다. 원래 동결한 감사기는 기존 검사 6개 이상과 엔진 메타데이터가 한 문서에 직접 들어 있는 형식을 가정했다. 첫 판이 끝나기 전에 이 형식 불일치를 발견했다. 해당 발견 시각은 대화 보고에 따른 약 UTC 06:25~26이며 정확한 순간은 별도 파일로 보존하지 않았다.

원래 감사기와 동결 파일·실행 도구·대국 조건·원시 기록을 보존하고, [별도 호환 감사기](../../tests/audit_neural_extra_time_results.py)를 추가했다. 새 2개 로그를 확인한 뒤 동결된 경로·SHA로 기존 8개 로그·엔진 식별·모델 체크섬 기록을 따라가며 검증한다. 그 외 수·예상 수순·시간·기보·부하·해시 검사는 동일하다. 기존 51개와 추가 19개 변조 거절 검사를 통과했다.

[변경 경위](../matches/2026-10-19-neural-long-time/audit-compatibility.json)는 실제 생성 시각 UTC 06:27:40.805194와 당시 두 번째 판이 진행 중이었다는 사실을 기록한다. 원래 감사기의 형식 오류 로그와 호환 감사기의 실제 대국 감사 결과를 각각 보존한다. 경기 결과에 따라 조건을 고르거나 재시도하는 변경은 하지 않았다.

## 해석의 한계

1. **생각 시간이 다른 비교다.** 신경망은 기존 평가기보다 한 수에 3배 또는 5배의 요청 시간을 받는다. 이 조건의 관측 승패로 같은 시간의 신경망 우위나 평가기 자체의 기력 향상을 주장할 수 없다.
2. **주조건 2쌍·보조조건 1쌍뿐이다.** 수작업으로 고른 정상 오프닝의 작은 시범 표본이다. 신뢰구간·bootstrap 구간·Elo를 제시하지 않는다. 전승·전패가 나와도 일반적인 기력을 확정하지 못한다.
3. **두 시간 조건의 위치 범위가 다르다.** 보조조건은 주조건의 Spanish 한 쌍만 재사용한다. 전체 득점률을 곧바로 비교해 5초가 3초보다 낫다고 해석할 수 없으며, 같은 한 쌍의 차이도 기술적인 사례로만 다룬다. 두 조건을 독립적인 하나의 합산 성적으로 제시하지 않는다.
4. **사전 예산 때문에 미완료가 생길 수 있다.** 완료된 소수 판만 남는다면 색·구조 불균형과 선택 편향을 명시한다. 결과를 채우기 위해 예산·판수·재시도 정책을 바꾸지 않는다.
5. **추가 시간이 도움이 된 원인까지 분리하는 실험은 아니다.** 모델·탐색의 상호작용, 특정 전술, 수 순서와 가지치기 중 어느 요인이 승패 차이를 만들었는지는 별도의 동일 위치 분석이 필요하다. 이전 100ms·1초 대국과 시작 위치도 다르므로 하나의 시간 증가 곡선으로 연결하지 않는다.

실행 조건을 확인하기 위한 명령 형태는 다음과 같다. 이번 실행은 각 대국 명령을 한 번씩 수행했으며 이전 기록을 덮어쓰지 않았다.

동결 파일은 절대 종료 시각을 포함하므로 그 시각이 지난 뒤의 대국 재실행은 거절된다. 기존 출력 디렉터리와 감사 파일도 덮어쓰지 못한다. 나중에 같은 조건을 반복하려면 이번 동결·원시 자료를 보존한 상태에서 새 시간 예산과 새 출력 경로를 별도 실험으로 사전 등록해야 한다. 무효·미완료 블록은 완료 대국용 감사의 PASS로 표시하지 않고 원인과 남은 기록을 함께 보고한다.

미완료 상황용 `audit_neural_extra_time_prefix.py`는 별도로 준비하고 개념 자체 검증을 했으나, 이번 실제 대국은 모두 완료되어 실자료에 실행하지 않았다. 이 도구의 출력은 항상 `INCOMPLETE / DIAGNOSTIC_ONLY`이며 완료 블록 감사와 동등한 판정이 아니다.
