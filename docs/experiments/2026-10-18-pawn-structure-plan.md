# 통과폰·폰 구조 평가 개발 계획

기준일: 2026-10-18 (한국 시간). 기준은 `585710724e93329a8f8baddfbc82724db4a4ce2a`의 v0.5.5, 새 후보는 v0.5.6이다. 규칙·탐색과 기존 왕 앞 폰 방패의 계수·국면·반올림은 유지한다.

## 고정 범위와 가설

폰의 전진 좌표 외에도 통과폰·겹친 폰·고립폰을 구별하면 위치를 평가하는 기준을 보강할 수 있다는 가설이다. 기력 향상은 아직 입증하지 않았다. 수치·코드는 자체 초기 설계이며 결과에 따라 계수나 표본을 바꾸지 않는다.

- 통과폰은 자기 진행 방향 앞의 같은 파일·인접 파일에 적 폰이 없는 폰이다. 같은 랭크나 뒤의 적 폰은 이 조건을 막지 않는다. 한 파일에 자기 폰이 여러 개 있으면 가장 앞의 폰만 보너스를 받는다.
- 자기 기준 랭크 0..7의 통과폰 중반 보너스는 `{0,0,5,10,20,35,60,0}`, 종반은 `{0,0,10,20,40,70,120,0}`cp다. 바로 앞 칸에 어떤 기물이든 있으면 각 보너스를 정수로 절반 줄인다. 승격이나 승리를 확정하는 판정이 아니다.
- 겹친 폰은 같은 파일의 첫 폰을 제외한 추가 폰마다 중반8/종반12cp 감점한다.
- 고립폰은 양옆 파일 어디에도 자기 폰이 없을 때 해당 파일의 각 폰마다 중반10/종반12cp 감점한다. 두 감점은 합산할 수 있다.
- 기존 기물 가치·폰 위치 보너스와 별도 항목이며, 양색 중반/종반 점수 차에 더한 뒤 기존 국면/24로 한 번 혼합한다. 왕 거리·공격 지도·연결 통과폰·후진폰·오프닝북·신경망은 범위 밖이다.
- `UsePawnStructure`, C++ `SearchOptions::pawn_structure` 기본 켬, 콘솔 `--no-pawn-structure`로 끈다. 기존 `UsePawnShield`와 독립적이다. 위치 평가 전체를 끄면 두 항목 모두 사용하지 않는다. 구조 OFF는 v0.5.5 평가를 재현한다.
- 기존 파일별 폰 비트를 공유 수집하며 새 전보드 스캔·캐시·동적 할당을 추가하지 않는다. 작은 constexpr 표로 파일별 폰 수·최전방 폰·방향 변환을 계산한다.

## 검증·기록 계획

1. 기존 6개 C++ 회귀와 독립 규칙 2,997사례, UCI·대국·추천·형세·핸디캡·보관함 검사를 유지한다. 기존 16,860개 v0.5.4 동결 평가 오라클은 구조 OFF를 명시해 그대로 보존한다.
2. 비트 표를 재사용하지 않는 폰 쌍 비교 scalar 오라클로 새 점수를 대조한다. 같은/인접 파일 전방·뒤·같은 랭크, 가장자리·양색, 겹친 폰 중복 보상, 고립·겹침 합산, 블로커·승격 근처, 색·차례·국면·반복·앙파상·되돌리기를 포함한다.
3. 신규 설정이 일반·안정화 탐색·중단 대체 점수에 반영되는지, 전이표 재사용과 탐색 중 토글이 이전 결과를 섞지 않는지 검사한다. 재료 평가 모드에서는 새 옵션을 무시한다.
4. Windows MSVC Release와 Linux GCC의 엄격 경고 검사 및 평가·탐색 ASan/UBSan을 실행한다. 로컬 검사와 원격 CI 결과를 구분한다.
5. 기존 전체10 `profile_positions.json`, Hash16, Move Overhead20, warmup1, seed20261018에서 구버전 대 새 구조 OFF를 깊이3/4 각3회(총60쌍) 대조하고 수·점수·노드·PV·TT 경로 정확 일치를 요구한다. 새 구조 OFF/ON 깊이3 3회(30쌍)는 점수 차이를 허용해 탐색량·비용 변화를 기록한다.
6. 기존 42위치 및 자체 폰 구조 경계 위치·색 반전을 타이밍 전에 고정한다. 평가 프로파일에 구조 OFF/ON×방패 OFF/ON 네 변형을 추가해 9블록의 균형 순서로 동일 호출 수를 비교한다. 참조 원본 동값 검사는 구조 OFF에서 유지하고 구조 ON의 다른 체크섬을 오류로 취급하지 않는다. 비용과 전체 기력 향상은 구분하며 외부 CPU 부하 샘플의 한계를 기록한다.
7. 실제 설치본·실행 파일·바로가기·기보를 백업한 뒤 검증한 v0.5.6을 로컬에 반영한다. 실제 창·추천 연결과 기존 기보 해시를 확인한다. 기록·원자료·해시를 커밋하고 GitHub 푸시 후 개발/설치/원격 SHA와 깨끗한 작업 폴더를 대조한다.

기존에 중단한 강도 대국 비교는 재개하지 않으며 이번 구현을 Elo나 일반 기력 상승의 증거로 제시하지 않는다.
