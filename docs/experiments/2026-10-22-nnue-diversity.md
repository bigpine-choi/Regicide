# NNUE 자료의 양과 초·중반 다양성 확대

2026-10-22 사용자의 요청으로 MSE·현재 NNUE v3 구조·과적합 방지를 유지하고,
Stockfish 정답 자료를 늘렸다. 기본 수식 Regicide와의 비교는 한 번의16판으로 제한한다.
자료 범위의 개선, 정적 오차, 실제 경기력은 별도로 판단한다.

## 자료와 구현

`scripts/neural_diverse_bank.py`는 기존 프로젝트의 기보·질의17,128위치에서 합법 이력과
FEN을 확인한다. 새 자기대국은 만들지 않는다. 기존431라벨·중복·색 반전 중복·분할 간
공유 특징·비교 대국의 등록 개시 수순을 제외하고, 정답 점수를 보지 않고2,000위치를
선정한다. 원본 기보 계열의 train/validation/test 구분을 유지한다.

선정 시 기물28개 이상50%,16~27개35%,15개 이하15%를 목표로 삼고 각 구간에서
기보 계열·손번을 나눠 고른다. 이 구간은 기물 수를 통한 대략적인 초·중·종반 분류다.
특정 오프닝이나 전술의 폭넓은 이해를 보장하는 지표는 아니다.

`prepare_nnue_diverse_data.py`는 기존431정답을 재사용하고 최대2,000위치에만
Stockfish18의10,000노드 정답을 요청한다. 제외한 위치는 다시 채우지 않는다.
교사 조건은 기존 Threads1·Hash16·강도 제한 해제·위치별 해시 초기화이며,
백 관점의 마지막 정확한 cp 점수와 합법 PV를 보존한다. 메이트·bound·절대1500cp 초과
등은 기존 정책대로 제외한다. Stockfish는 정답 생성에만 사용하며 수를 고르는 엔진은 Regicide다.
출처·버전·라이선스는 [교사 구현 기록](../STOCKFISH_TEACHER.md)을 따른다.

새 정답1,195개를 얻었고805질의는 제외했다. 제외 이유는 bound703·mate102·범위 초과1건이며
한 질의에 이유가 겹칠 수 있다. 기존431개와 합쳐1,626개를 보존했다.

| 실제 사용할 자료 | 이전 | 확대 후 | 역할 |
| --- | ---: | ---: | --- |
| 학습 | 350 | 1,294 | 가중치 업데이트 |
| 선택용 | 81 | 263 | 정수 MSE로 중단·가중치 선택 |
| 별도 점검 | 없음 | 69 | 선택을 마친 모델을 사후 점검 |

학습 자료는3.70배로 늘었고,28기물 이상 위치는41/350(11.7%)에서481/1,294(37.2%)로
증가했다. 확대 후 학습은 중반495·종반318개, 백 차례683·흑 차례611개,48기보 계열이다.
체크 중69위치·합법 포획이 있는991위치를 포함한다. 선택용16계열·별도 점검14계열은
학습 계열 및 기물 특징과 겹치지 않으며 색 반전도 중복으로 처리한다.

69개는 이번 추가 학습의 기울기·중단·후보 선택에 쓰지 않았다. 하지만 원본은 이전 개발에서
접근 가능했던 자료다. 완전히 새로운 독립 확인 표본이라고 부르지 않는다. 전술이 복잡하거나
평가가 불안정한 위치가 bound 정책으로 빠질 수 있다는 자료 편향도 남는다.

자료 생성은 총83.67초였고, 이 중 위치 선정16.05초·Stockfish 정답 생성51.74초였다.
원본431정답과 과거 실험 파일은 변경하지 않았다.

## 한 번의 학습과 과적합 방지

`train_nnue_diverse.py`는 직전 과적합 방지 모델의 실수 가중치에서 이어서 학습한다.
기물768+상대 손번1·공유 은닉16·v3 정수·S32, MSE, Adam, seed20261020,
batch128, 입력/편향 학습률0.0002·출력0.005, 기울기 norm상한10을 유지했다.

학습 전(epoch0)도 후보에 포함한다. 매5회 선택용 정수 MSE를 확인하고,5번 연속 개선이
없으면 중단한 뒤 최소 오차 가중치를 복원한다. 최대500회 중45회에서 중단했고,
20회째 가중치를 복원했다. 업데이트495번·학습0.82초·후보1개다.
69개 별도 점검은 복원·저장이 끝난 뒤 한 번 평가했고 결과를 보고 재학습하지 않았다.

| 같은 확대 자료의 정적 오차 | 학습 전 MAE | 학습 후 MAE | 학습 전 RMSE | 학습 후 RMSE |
| --- | ---: | ---: | ---: | ---: |
| 학습1,294 | 191.32 | 167.30 | 257.19 | 227.98 |
| 선택용263 | 189.42 | 183.84 | 255.07 | 250.30 |
| 별도 점검69 | 234.28 | **244.70** | 316.33 | **323.49** |

단위는cp이며100cp는 폰1개에 해당하는 평가 단위다. 선택용 MSE는65,061.82→62,647.79cp²로
줄었지만 별도 점검 MSE는100,062.39→104,642.61cp²로 악화됐다. 자료의 양과 분포는
개선했으나 일반화·과적합 문제가 해결됐다는 근거는 없다. 이번 실행에는 추가 학습량도
포함되므로 자료량 하나만 바꾼 엄격한 인과 비교로 해석하지 않는다.

## 정확성 검증과 짧은 대국

새 자료·훈련 래퍼 단위 검증은 각각6개 통과했다. 모델을 실제 C++에 연결해 전체1,626위치와
특수 수46위치의 Python·전체 재계산·증분 평가를 비교했고1,672개 모두 정확히 일치했다.
같은 후보로 native 모델13그룹·25,521확인도 실패0이었다. 변경 없는 구 모델 호환성은
동일 실행 파일 해시와 이전 검증 기록으로 연결했다.

대국 전 계획·모델·자료·소스의 SHA256을 고정했다. 두 쪽 모두 같은 자체 엔진 실행 파일
`97140c4ad1c40a9f2c67e2fb9a8c0718fe70722e83dcbe50a7011b71c97558d1`을 사용한다.
기본 쪽은 `classical.json`의 전체 수식 평가 설정이며 후보는 NNUE 활성화·모델 경로만 다르다.
실제 native 소스는 `e246d8102c58b4c8680b26ac3886095ab25e79f0`이다.

- 하드웨어: Ryzen AI7 350,8코어/16논리, Windows11 공유 PC.
- 자원: 양쪽 단일 탐색·Hash16MiB, 수당100ms, 동일8개시×선후공=16판.
- 종료: 합법 무승부 청구 허용·최대500반수, 자동 재시도·추가 대국 없음.
- 새 후보: `c73b510cd83ca221829eb9e1bf781b86d28c5b9c47ed922d8f9fa30e08385c86`.

실제16판은 **후보2승4무10패, 득점률25%,141.68초(2분22초)**였다. 미완료·실행 오류0,
재시도·추가 대국0이다. 후보 백은2승3무3패, 흑은0승1무7패였다. 제한된 표본에서 보인
색별 차이이며 손번 처리의 버그나 특정 패배 원인을 입증하지는 않는다.

실행 도구를 호출하지 않는 독립 감사는1회22.32초로 PASS였다. 고정 입력60개와
원본 수순·교사 점수·분할·선택 이력·복원 가중치·정수 오차를 확인했고, 별도 점검과
초기 모델의 과거 학습/선택2,932위치 간 기물 특징 중복도0이었다. 저장된16판의
전체1,806반수·1,714검색·PV8,538반수를 재생해 합법성·기보/FEN·종료 판정을 확인했다.

직전 보호 후보의2승3무11패와는 별도의 작은 시험이다. 득점이 조금 늘었다는 이유로
개선 효과를 입증했다고 해석하거나 과거 성적과 합치지 않는다. 기본 수식 평가가 이번에도
우세했으므로 설치 모델과 기본 게임은 유지한다. 자료 확대 도구와 정답은 다음 개발에서
재사용할 수 있게 보존한다.

이번에 달성한 것은 **중복·계열 누수를 검사하면서 초·중반의 정답을 짧은 예산으로 늘리고,
기존 과적합 방지 학습과 실제 엔진에 연결한 것**이다. 경기력 강화와 일반화 개선은 아직
달성하지 못했다. 다음 가설은 단순 자료량 추가보다 별도 점검 오차와 실제 패배가 함께
커지는 위치의 특징을 찾는 것이다. 이번 요청에서는 추가 검색·학습·대국을 시작하지 않는다.
