# B의 학습 잔차·패배 기보 분석과 다음 비교 실험

작성일: 2026-10-21(KST). 대상은 [정적 A / 탐색 B 비교](2026-10-20-neural-target-ab.md)의 attempt-002다.

**가장 유력한 설명은, 작은 망이 큰 탐색 보정값을 충분히 흡수하지 못하는 가운데 소수의 큰 오차를 줄이는 학습 목표가 보통 위치의 정확성과 충돌했다는 것이다.** 실제로 B의 학습 목적함수는 일부 위치에 집중됐고, 정상 시작 위치와 정적·탐색 점수가 비슷한 다수 위치에서는 A보다 오차가 컸다. 손번 없는 입력과 제한된 입력층 이동도 확인했다. 각각의 인과적 비중은 아직 확정하지 못했다.

따라서 첫 후속 실험은 **망 크기를 그대로 두고 정답 A/B × 손실 MSE/Huber를 비교하는 2×2 실험**으로 권한다. 학습량·학습률·손번 입력은 별도 요인으로 분리한다. 원래 보류와 96판은 이제 개발·원인 탐색 자료다. 다음 성능 확인에 재사용하지 않는다.

## 이번에 실제로 한 일

- 기존 3,619행·여섯 모델의 잔차, shadow float, 정수 가중치와 학습 이력을 재계산했다.
- 96판의 PGN·JSON·8,844수의 원시 UCI를 대조하고, 승패가 난 76판(A 27패·B 49패)의 패자 위치를 정해진 규칙으로 추출했다.
- 후기 기물 손실 직전 76위치와, 추가로 고정한 초반의 패자 여섯 번째 선택 76위치에서 A/B를 같은 10k노드로 재탐색했다. 실제 수·A/B 수·고전 교사 수의 고유 자식 위치를 각각 같은 100k노드로 비교했다.
- 같은 기물 배치에서 손번만 바꾼 16쌍을 검사했다. 초반 재실행에서 같은 쌍을 반복했으므로 독립 반례 32쌍으로 세지 않는다.
- 추가 검색은 총 779건·50,540,000노드, 두 실행 경과 시간 합계 약 106.31초였다. 검색은 빈 TT·Hash16MiB·단일 스레드였고 실제 기보 위치에는 전체 이력을 전달했다. 인위적 손번 쌍은 양쪽 모두 FEN에서 새로 시작해 반복 이력이 없다. 임시 절전 방지는 복원됐다. 속도나 새 대국 성적을 측정한 실험은 아니다.

**새 학습과 새 대국은 실행하지 않았다.** 기존 실행 파일·소스·모델·96판·원래 실패 시도는 수정하지 않았다. 처음에 기존 증거 450파일과 외부 소스/보고서 15파일을 검증했다. [독립 재계산 감사](../analysis/2026-10-21-neural-target-ab-diagnosis/peer-audit.json)는 잔차와 검색 원시 기록·점수 관점·전체 수순을 확인했다.

## 1. 잔차에서 확인한 학습 목표의 편중

잔차는 `신경망 예측−정답`이다. 아래 A/B 오차는 **둘 다 같은 10k 탐색 정답**에 대한 MAE이며, 실제 세 모델 각각의 지표를 평균했다. 서로 다른 자기 정답의 MAE를 비교한 표가 아니다.

| 학습 위치 집단 | 개수·비중 | A의 10k MAE | B의 10k MAE | B 전체 SSE 중 비중 |
|---|---:|---:|---:|---:|
| 전체 | 2,209·100% | 96.39cp | 95.42cp | 100% |
| 정적·탐색 정답 차이 <50cp | 1,551·70.21% | 16.68cp | 31.39cp | 2.70% |
| 정적·탐색 정답 차이 ≥300cp | 188·8.51% | 653.10cp | 601.84cp | **90.03%** |
| 정상 시작에서 파생 | 1,623·73.47% | 60.78cp | 64.81cp | 30.09% |
| 합성 종반에서 파생 | 586·26.53% | 195.04cp | 180.20cp | **69.91%** |

SSE는 잔차를 제곱해 합친 값이다. MSE는 이를 개수로 나눈 학습 목적함수다. 예를 들어 오차 500cp 한 개는 오차 50cp 한 개보다 MSE에 100배 크게 들어간다. 다만 **90.03%는 최종 제곱오차 기여율이며, 기울기나 Adam 업데이트의 90.03%라는 뜻은 아니다.** 큰 오차 집단이 다른 보정을 밀어냈는지는 손실 함수를 바꾼 비교로 확인해야 한다. ≥300cp는 B의 잔차 임계값이 아니라 두 교사 정답의 차이에 따른 분류다.

이 현상은 학습 자료에만 있지 않다. 기존 보류에서 두 정답 차이가 <50cp인 458개는 같은 10k 참조 MAE가 **A 20.68cp / B 32.86cp**다. 검증 전체 723개는 A 84.89 / B 89.09cp, 보류 전체 687개는 A 109.96 / B 112.10cp다.

100k 참조의 정상 시작 계열 평균 MAE는 A **107.13** / B **111.01cp**, 합성 종반은 A **274.79** / B **266.82cp**다. 원래 전체 계열 평균의 B 이점 2.04cp는 합성 종반 개선이 정상 시작 악화를 상쇄한 결과다. 실제 대국 시작 은행은 정상 시작이었다. 학습 손실의 비중, 오프라인 계열 가중치, 실전 위치 분포를 같다고 보면 안 된다.

확인된 것은 **작은 전체 학습 MAE 개선과 정상 위치 악화가 함께 존재한다는 것**이다. “탐색 정답을 배우는 방식 자체가 실패한다”거나 “합성 종반을 모두 없애야 한다”는 결론은 아니다. 큰 보정값은 중요한 전술일 수 있으므로 삭제·정답 잘라내기를 첫 처방으로 삼지 않는다.

## 2. 단순한 양자화 실패·포화 설명은 지지되지 않음

| 확인 항목 | 관측 | 해석 |
|---|---|---|
| B의 마지막 30epoch MSE | 여전히 7.30~7.63% 감소 | 학습이 수렴했다고 볼 근거가 없음 |
| 입력 정수 가중치 변화 | 여섯 모델 모두 변경량 최대 ±1칸 | 초기 특징에 강하게 묶여 있음 |
| B 입력 shadow 최대 이동 | 0.03238~0.03261, S32 한 칸=0.03125 | 더 복잡한 정답을 배울 만큼 입력 표현이 움직였는지 미확인 |
| 학습 위치 상한 활성 포화·출력 clamp·파라미터 경계 | 모두 0 | 상한에 막혔다는 설명과 맞지 않음 |
| B gradient norm 제한 | 2,160배치 중 7/6/13회 | 이 제한만을 주원인으로 보기 어려움 |
| B 정수 MAE−shadow float MAE | 학습 −3.87~−3.65cp, 보류 −0.47~+0.46cp | 단순 정수화 붕괴의 모습은 아님 |

QAT는 정수 예측을 직접 최적화한다. float와 정수의 차이를 전부 “양자화 손실”이라고 부르지 않는다. 기존 `activation_at_clip_fraction`은 0 이하 비활성 값도 합친 지표여서 약 28%를 상한 포화율로 읽으면 안 된다. 중간 검증 곡선은 저장되지 않아 과적합 시작 시점을 알 수 없다.

16개 은닉 중 왕 수 특징 한 개는 합법 위치에서 두 관점의 차이가 항상 0이고 출력 가중치도 0으로 유지됐다. 공통 초기화·용량 제약이지만 B만의 버그는 아니다. 학습률·학습량·입력 표현을 검증하기 전에 이를 B 패배의 주원인으로 단정하지 않는다.

유효 보류 670개에서 10k→100k 점수의 평균 절대 변화는 39.66cp, 100cp 이상 변화는 90개다. 양쪽 점수 절댓값이 50cp 이상인 550개 중 부호 반전은 1개였다. 교사 정답의 유한 탐색 변동은 존재하지만, 이것만으로 B의 큰 잔차와 패배를 설명할 근거는 부족하다.

## 3. 기보에서 확인한 것과 확인하지 못한 것

### 후기 패배 장면을 최초 실수로 오해하지 않기

처음에는 모든 결정 대국에서 “기물 열세 300cp 이상이 4반수 지속되기 직전 패자 선택” 등을 기계적으로 골랐다. 그런데 유한 cp가 있는 70개 위치 모두 고전 100k 루트 참조에서도 이미 불리했고, A/B 10k 선택도 62/76개가 같았다. 이 장면들로 최초 잘못 둔 수를 설명할 수 없었다.

그래서 원래 추출은 보존하고, 모든 76판에서 **패자가 대국 시작 은행 이후 여섯 번째로 선택한 수**를 추가로 비교했다. 이 초반 위치도 패배 결과에 조건부인 탐색 자료다. 일반적인 모든 위치의 실수율이나 새 성능 검증 표본은 아니다.

| 초반 고정 진단 | A 패배 위치 27개 | B 패배 위치 49개 |
|---|---:|---:|
| A/B 10k가 같은 수 선택 | 16 | 28 |
| A10k의 자식 참조가 B10k보다 ≥100cp 좋음 | 1 | 2 |
| B10k의 자식 참조가 A10k보다 ≥100cp 좋음 | 1 | 0 |
| 고전 교사 선택의 자식이 실제 수 자식보다 ≥100cp 좋음 | 0 | 5 |

초반 비교는 76개 모두 유한 cp였고, 후보 자식은 같은 100k 예산으로 평가했다. 다만 고전 교사의 루트 선택도 자식 재탐색에서 항상 최선은 아니며, 표는 **후보 사이의 자체 유한 참조 차이**다. 정확한 최선수 대비 손실이 아니다. 같은 계열·같은 위치의 반복도 포함돼 독립 사건 수로 해석하지 않는다. 후기 비교에서 cp가 없는 mate 사례는 제외 분모를 보존했다.

마지막 패자 차례에는 A 27패·B 49패 모두 다음 수 메이트를 피할 합법 수가 없었다. 끝의 메이트를 세는 것으로 “B가 메이트 한 수를 못 본다”는 버그를 주장할 수 없다. 색상별 B 득점률은 백52.08%·흑25.00%지만, 같은 색의 A와 비교하면 백·흑 모두 22.92%p 차이다. 흑만의 특수 오류라는 근거도 아니다.

### 실제 78번 대국: 무리한 체크 뒤의 평가 변화

시드20261022, B가 흑인 78번 대국의 `12...` 위치다. 고전 100k 루트 참조는 흑−41cp로, 큰 패배가 이미 확정됐다고 보는 위치는 아니었다.

| 선택 방법 | 선택 수 | 그 수 뒤 같은 100k 자식 참조, 흑 관점 |
|---|---|---:|
| A 10k | `12...Nbd7` | −55cp |
| B 10k | `12...Ne4+` | −246cp |
| 실제 B 100ms | `12...Ne4+` | −246cp |
| 고전 100k | `12...e6` | −41cp |

실제 수순은 `12...Ne4+ 13.Nxe4 dxe4 14.d5`였다. B는 `12...Ne4+`를 고를 때 흑+25cp로 보고했지만, `13.Nxe4` 뒤 `13...dxe4`를 검색할 때 이미 −213cp로 바뀌었다. 같은 위치 A/B 10k 후보의 참조 차이는 **191cp**였다. B의 당시 주 변화와 더 깊은 참조는 백의 후속 선택을 다르게 읽었다. 이는 잘못된 낙관이 수 선택으로 연결된 구체 사례이며, 손실 함수가 이 사례를 만들었다는 인과 증명은 아니다.

반대 사례도 남겼다. 4번 대국의 같은 위치에서는 B10k의 `Qe5+`가 A10k의 `Qb4+`보다 참조상 142cp 좋았다. 실제 A100ms도 `Qe5+`를 골랐다. 따라서 10k 차이를 그대로 실제 100ms의 실수 차이로 바꾸면 안 된다.

## 4. 손번 누락은 실제 표현 제약

현재 백 관점 망은 기물 배치가 같으면 같은 값을 낸다. 반면 탐색 정답은 누가 먼저 움직이는지에 따라 달라진다. 인위적으로 구성한 양 손번 16쌍 중 15쌍에서 유한 cp를 얻었다. 같은 망 값으로 두 정답을 맞출 때의 쌍별 최소 MAE는 `|백차례 정답−흑차례 정답|/2`이며, 이 진단 표본에서 평균141.2cp·최대524.5cp였다. 이것은 원래 자료의 불가피 오차 하한이나 실전 평균 오차가 아니다.

예를 들어 `ab2-pawn-002`의 같은 배치는 백차례 +28cp, 흑차례 −1021cp였다. 백이 먼저 두면 `Kg2` 후 대응할 수 있지만 흑이 먼저 두면 `...f1=Q+` 승격이 있다. 현재 입력은 둘을 구분할 수 없다. 공식 NNUE 설명도 손번에 따른 두 관점의 순서를 이용해 tempo, 즉 먼저 둘 수 있는 효과를 학습하는 이유를 설명한다. [Stockfish 공식 NNUE 문서](https://official-stockfish.github.io/docs/nnue-pytorch-wiki/docs/nnue.html#how-to-combine-multiple-accumulator-perspectives)

원래 자료의 정확 입력 중복은 제거됐기 때문에 이 반례가 원래 학습 행의 모순이었다는 뜻은 아니다. 누락 상태가 표현 가능성을 제한한다는 점은 확인했지만, 그 빈도와 49패에 대한 기여율은 미확정이다. 캐슬링·앙파상·무승부 이력도 별도 상태 문제다.

현재 학습은 조용한 루트 위치를 표집하지만, 실전 망은 탐색 말단과 quiescence의 stand-pat 기준값으로 사용된다. 필터는 체크·교사 첫 수의 잡기/승격을 제외할 뿐, 모든 전술이 해결된 상태를 보장하지 않는다. 방문 위치 분포가 달라지는 문제도 후속 가설로 남긴다. 순차적 선택이 미래에 방문할 분포를 바꾼다는 일반 원리는 [Ross·Gordon·Bagnell의 원논문](https://proceedings.mlr.press/v15/ross11a.html)과 연결되지만, 여기서 DAgger를 실행하거나 그 정리를 Regicide의 성능 보장으로 적용한 것은 아니다.

## 5. 첫 후속 실험: 목표 × 손실의 2×2 비교

가설 H1: **B의 큰 오차 꼬리에 대한 MSE의 민감도를 줄이면, 보통 위치와 실제 수 선택의 정확성이 회복된다.** Huber는 작은 오차에는 기존 제곱 손실을 유지하고 큰 오차에는 선형 손실을 쓴다. 큰 정답 행을 삭제하거나 정답을 잘라내지 않는다.

| 조건 | 같은 위치의 정답 | 손실 | 역할 |
|---|---|---|---|
| A-MSE | 정적 | 기존 MSE | 원래 A 재현·실전 기준 |
| B-MSE | 10k 탐색 | 기존 MSE | 원래 B 재현·주 대조 |
| A-H100 | 정적 | 아래 Huber | 일반적인 손실 변경 효과 통제 |
| B-H100 | 10k 탐색 | 아래 Huber | 사전 지정 주 후보 |

각 조건에 원래 세 대응 배치 순서 시드20261020/21/22를 모두 사용해 **12개 모델**을 만든다. 기존 동일 학습2209행·검증723행·bootstrap 초기값·768×16·S32·입력/편향LR0.00002·출력LR0.005·120epoch·batch128·Adam·gradient norm10을 유지한다. 모든 조건은 마지막 epoch다. 초기값·폭·정답 예산·자료 비율·학습률을 동시에 바꾸지 않는다. 세 시드는 독립 초기화가 아니다.

잔차를 폰 단위 `r=(예측cp−정답cp)/100`로 놓고 H100을 `|r|≤1: r²`, 그 밖에서는 `2|r|−1`로 정의한다. 이는 **표준 Huber의 2배**이며 작은 오차에서 기존 MSE와 기울기가 같다. 표준 Huber의 `0.5r²`를 그대로 쓰면 작은 오차의 학습 규모까지 절반으로 바뀌어 비교가 섞인다. δ는 100cp 한 가지로 사전 지정하고 50/200 등에서 좋은 것을 고르지 않는다.

먼저 기존 MSE 두 조건의 최종 배열·정수 예측이 원래와 일치하는지 확인한다. Huber의 안쪽/바깥쪽/경계 기울기·정규화·결정성을 검증한다. 10epoch마다 기존 검증의 MAE/MSE/Huber, 종류·큰 정답 차이별 오차, 실제 배치 gradient norm과 입력 이동량을 저장하되 조기 종료·최고 epoch 선택은 하지 않는다. 기존 보류687행과96판은 개발 진단에만 쓴다.

### 새 확인 자료와 오프라인 판정

은행 namespace `ab-loss-v1`, 생성 시드20261031로 **새 정상32·합성16 부모 계열, 각4변형**을 학습 전에 구성·동결한다. 옛 모든 부모·변형·관측 prefix·채택 입력·양 대국 은행 및 색/랭크 반전을 제외한다. 모델 12개를 동결한 뒤 새 확인 자료를 생성한다. 기존과 같은 자체 고전10k 교사·최대96반수·3반수 표집·공통 quiet 필터·전체 이력·빈 TT·Hash16을 쓴다.

계열별 최대24행을 점수와 무관한 변형별 round-robin 순서로 채택해 총 상한1152행으로 제한한다. 모든 시작을 한 번씩 처리한다. 정상≥600행·28계열 이상에12행, 합성≥240행·12계열 이상에12행이 최소다. 부족하면 해당 시도는 불충분으로 보존하며 좋은 계열만 보충하지 않는다. 새 확인 자료를 본 뒤 설정을 바꾸면 그것도 개발 자료로 전환하고 새 확인 자료를 다시 만든다.

모든 채택 행을 같은 고전100k로 다시 평가한다. 전체 예정 검색을 처리하고 유효 cp≥80%·정상28/합성12계열 이상을 요구한다. mate/bound/중단 제외는 모든 모델에 공통 적용하고 제외 수와 수순을 기록한다. 자체100k는 객관 정답이 아니다.

**주 비교는 정상 시작 계열 평균 공통100k MAE의 B-MSE−B-H100**이다. 세 시드를 먼저 각 계열 안에서 평균하고 유효 정상 계열(최소28·최대32)을 단위로 bootstrap10,000회(seed20261101)하여 구간을 낸다. 사전 실용 기준은 평균≥5cp 개선·95% 구간 하한>0·세 시드 중 적어도 둘에서 같은 방향이다. 합성 계열 평균 악화가10cp를 넘지 않는 것을 부작용 기준으로 함께 확인한다. 이 숫자는 이번 관측을 설명하는 최적 임계값이 아니라 다음 실행의 운영 기준이다.

전체 MSE/MAE·기물 수·손번·정답 차이·종반 세부 종류를 빠짐없이 보고한다. A-H100과 A-MSE의 변화도 비교해 손실 변경의 일반 효과와 B 특유 효과를 나눈다. 통계 주장은 미리 지정한 B 비교 하나에 한정한다. 평균 예측을 만드는 앙상블 대국은 하지 않는다.

### 같은 위치의 수 선택 검사

새 정상 계열당 하나의 적격 위치를 점수와 무관하게 고정해32위치를 만든다. 32계열 모두에서 적격 위치를 만들지 못하면 이 단계는 불충분으로 보존하고 유리한 계열로 교체하지 않는다. 12모델 각각10k와 고전100k가 고른 수의 고유 후보 집합을 만들고, 각 후보 자식을 같은100k로 평가한다. 가능한 최대13후보×32위치다. “패널 내 최상 참조보다100cp 이상 낮은 수”의 빈도와 참조 차이를 비교하고, mate를 임의의 cp로 바꾸지 않는다. 이는 후보 순위 검사이며 모든 합법 수의 정확 최선 판정이 아니다.

같은 계열의 모든 시드·후보를 묶어 보고하고, 소수 꼬리 MSE가 줄어도 이 큰 수 선택 차이가 늘면 경기력 개선 근거로 채택하지 않는다. 이 검사와 공통 MAE가 반대 방향이면 혼합 결과로 기록한다. 미관측 보류의 손실 함수 값만 보고 승자를 고르지 않는다.

### 100ms 확인 대국

확인 자료와도 겹치지 않는 **새 정상 시작32계열×양색×3시드=192판**을 고정한다. 첫 비교는 B-H100 대 B-MSE다. 양측100ms·Move Overhead20ms·Hash16·최대500ply·청구 무승부·같은 실행 파일/옵션을 쓴다. 시작별 시드·색 순서를 교대하며, 중간 성적을 보고 중단·추가·재시도하지 않는다. 블록 상한45분, 미완료는 무승부로 바꾸지 않는다.

정확성·모델 응답·전후 해시·원시 UCI/PGN·샘플 CPU 감시를 요구하고 요청100ms 및 내부80ms 초과를 따로 센다. 운영상 긍정 기준은 **전192판 정상·후보106/192점 이상·세 시드 중 둘 이상50% 초과·32계열 bootstrap95% 하한50% 초과**다. 구간이50%를 포함하면 불확실로 남긴다. 같은 초기값·같은 자료·같은 은행 조건부이며 보편적 Elo로 환산하지 않는다.

첫 비교가 긍정이면 사전에 따로 동결한 두 번째 새32계열에서 **B-H100 대 A-MSE 192판**을 진행한다. B를 개선한 것과 A를 넘어선 것은 별개다. 두 번째 블록도 같은 기준과45분 상한을 적용한다. 이득 확인 전 설치본·기본 평가기를 교체하지 않고 1초 대국은 자동으로 시작하지 않는다.

### 비용 상한과 완료 계약

- 모델12개×120epoch. 기존 관측의 학습 함수 시간은 모델당3.6~5.5초였으나 전체 소요 시간 보장은 아니다.
- 새 확인 자료 최대192시작×96반수×10k = **184.32M노드**, 확인 참조≤1152×100k = **115.20M노드**. 각각15분·검색당10초 상한으로 둔다.
- 후보 검사 최대384개10k 망 검색·32개100k 루트·416개100k 자식 = **48.64M노드**,10분 상한이다. 실제 중복·종료로 줄어든 수를 기록한다.
- 확인 대국은 첫192판, 조건 충족 시 두 번째192판, 각45분 상한이다. 모델 선택·모니터링·교차 검산 비용은 별도다.
- 기존 규칙 회귀를 유지하고 새 모델마다 저장/재양자화·C++ 전체/증분·특수 수·undo·탐색 취소 검증을 통과해야 한다. Huber 외 핵심 엔진 변경이 없다면 원래 C++ 소스/실행 파일 해시도 같아야 한다.
- 자료·소스·도구 버전·초기 배열·배치 순서·학습 설정·모델·원시 기록·실패와 미시도 수를 보존한다. 정확성, 오차, 수 선택, 시간 비용, 대국 성적을 따로 보고한다.

## 6. 그 다음 가설의 순서

| 가설 | 바꿀 요인 하나 | 나머지 조건 | 가설을 지지할 관측 |
|---|---|---|---|
| H2 입력 특징이 거의 움직이지 못함 | 입력/편향LR 2e-5→1e-4 | 출력LR·120epoch·선택된 손실 고정, A/B×전후 | B의 입력 이동·정상 새 참조·수 선택이 함께 개선 |
| H3 학습 반복 부족 | 120→480epoch | LR·손실·망 고정, A/B×전후 | 학습뿐 아니라 새 정상 참조도 개선; 학습만 좋아지면 일반화/표현 문제 남음 |
| H4 손번 정보 누락 | 기존16은닉에 손번 지시 특징1개 추가 | 기물 특징·너비·손실·교사 예산 고정, A/B×전후 | 새 양 손번 쌍·실전 위치 오차와 수 선택이 함께 개선 |
| H5 유한10k 교사 문제 | 같은 위치 교사10k→100k | 표현·손실·학습 고정 | 큰 정답 변동 위치에서만이 아닌 새 정상 참조·수 선택 개선 |
| H6 말단 위치 분포 차이 | 같은 양의 루트 자료와 실전 방문 말단 자료 비교 | 교사·손실·망·부모 분할 고정 | 새로 방문하는 말단의 오차·큰 수 선택 오류 감소 |
| H7 실제 표현 용량 부족 | 16→64은닉 | 충분히 검증한 LR/epoch/손실·자료 고정 | 새 오차 개선과 함께 같은 노드/같은 시간의 경기력 비교도 통과 |

H2와 H3를 동시에 바꾸지 않는다. H4는 두 관점에 `자기 색이 손번인지`를 넣는 공유 특징으로 설계할 수 있다. 새 형식은 구형 모델 읽기를 유지하고 손번 전환·특수 수·make/undo마다 전체 재계산과 정확히 일치해야 한다. 손번 하나를 추가해도 모든 이력 상태 문제가 해결되는 것은 아니다.

입력·망 크기를 바꾸는 H4/H7에서는 같은 노드 확인과 같은 시간 대국을 분리한다. 학습을 더 한다는 것, 더 큰 망을 쓴다는 것, 더 깊은 교사를 쓴다는 것을 한 후보에서 동시에 바꾸면 원인을 구분하기 어렵다. 이번에는 위 후속 학습·확인 대국을 실행하지 않았다.

## 산출물·재현·정정 기록

분석 원본·새 검색과 사본 기보는 [진단 폴더](../analysis/2026-10-21-neural-target-ab-diagnosis/)에 있다. 재현 도구는 `scripts/analyze_neural_ab_residuals.py`, `scripts/analyze_neural_ab_losses.py`, `scripts/select_neural_ab_early_positions.py`, `scripts/analyze_neural_ab_counterfactuals.py`다. 출력은 새 경로만 허용한다. 자체 검색 진단은 저장된 `diagnostic-freeze.json`의 입력 해시·예산을 먼저 확인하고 실행한다.

초반 실행에 재사용한 검색 도구의 동결 파일에는 선택 설명이 후기 기물 손실 규칙으로 남은 문구 오류가 있다. 실제 입력은 해시로 묶인 `early-games/selection-manifest.json`의 **여섯 번째 선택 규칙**이며,76개 모두 원기보와 독립 대조했다. 원본 동결·검색·문구를 덮어쓰지 않고 [독립 감사의 메타데이터 정정](../analysis/2026-10-21-neural-target-ab-diagnosis/peer-audit.json)에 남겼다. 수순·검색 조건·점수에는 영향이 없다.
