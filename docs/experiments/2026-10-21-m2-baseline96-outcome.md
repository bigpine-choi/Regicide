# M2 빠른 기준선: 실제 96판 완료

2026-10-21 KST. 사용자가 본 대국을 768판에서 96판으로 축소했다.
원래 은행의 첫 4개 개시 계열을 결과와 무관하게 고정하고, 세 평가 방식 × 두 상대 ×
100/1000ms × 양색을 모두 포함했다. 새 본 96판은 **1,154.505초(19분 14.5초)에 완주**했다.
오류·미완료·미시작은 0이다. 이번 결과는 작은 현황 파악용 기준선이며 경기력 개선이나
모델 승격을 증명하는 실험은 아니다.

## 성적

각 칸은 **승–무–패**, 조건당 8판이다. 다른 시간의 성적을 섞어 기력을 추정하지 않는다.

| 평가 방식 | Sunfish 100ms | Sunfish 1초 | Stockfish 18 100ms | Stockfish 18 1초 |
| --- | --- | --- | --- | --- |
| 수식 평가 | 6–2–0 | 6–1–1 | 0–0–8 | 0–0–8 |
| V2 보정망 | 4–2–2 | 5–0–3 | 0–0–8 | 0–0–8 |
| S32 NNUE | 6–1–1 | 6–1–1 | 0–0–8 | 0–0–8 |

이번 표본에서는 Sunfish 상대 성적이 좋았고 Stockfish와는 큰 격차가 있었다.
NNUE나 V2가 수식 평가보다 강하다는 근거는 확보하지 못했다. 기존 기본 수식 평가를
유지하며 자동 승격·Elo 산정은 하지 않았다. 직접 후보끼리 둔 대국이 아니고 개시 4계열/
넓은 상관군 3개·조건당 8판이므로 작은 차이의 순위를 확정하지 않는다. 은행은 이미 노출된
고정 작성 자료이며 새로운 보류 자료라고 부르지 않는다.

## 실제 실행과 검증

- 코드 `d2f73e677ff26f5a8a8e2ae8d668a2567f1d93d7`, 계획 SHA256
  `40727583562b8c3c38c375ef9026ad8faa9f380f49dde893f232ac32c9dc679d`.
- 동결 SHA256 `c566bdea7ddb29b77b669d49ee16a0b99bf5b284d3c53efe86dbc77338c0e297`.
  기존 v6의 33개 실행 소스와 엔진·모델은 그대로이며, 작은 96판 선택 어댑터만 추가했다.
- 네 lane, Threads 1/Hash 16, 기존 물리 코어 배분·500ply·claim 무승부·상대 버전과
  실행 파일/모델 해시는 [고정 계획](2026-10-21-m2-baseline96-plan.md)을 따른다.
- 실제 검색 7,747회, 검색 구간 엔진 CPU 합계 3,945.015625초, 합법 기보 9,043ply·PV 59,364ply.
  callable 최대 1.0916782초, 계측 envelope 최대 1.0917368초였다.
  요청 시간×2+0.25초 기준의 위반은 0이다. CPU/NPS 하한이나 CPU/wall 상한은 두지 않았다.
- 잔여 부하 경고 13개 창·2구간, 최대 27.480191%. **경고만 남기고 계속했다.**
  원시 소속 범위 4,555개, 최대 샘플 간격 0.5164089초, 알려진 외부 엔진 CPU 증가 0.
  최종 소유 Job은 총 168프로세스·active 0이며 retired 168개 종료·핸들 정리까지 확인했다.
- **제품·독립 감사 모두 PASS**다. 제품 감사 1회의 결과를 요약 생성에 재사용했다.
  독립 감사는 별도 도구로 기보/PV·설정·실제 endpoint·CPU·응답·프로세스 소속·계측 기록을
  검증했다. [본 96판 독립 감사](../checks/2026-10-21-m2-engine-cpu/peer-baseline96-run001-main.json)
  SHA256은 `14d5c9d3d8f22d2b5531eaaa3c581c61b3c4fe4652ba6ca5dcc92a61c6387a55`다.

CPU는 엔진이 소비한 전체 스레드 CPU이며 스케줄러 대기 시간을 직접 측정한 값이 아니다.
시스템·Job·진행 프로그램의 비동기 카운터에는 양자화 차이가 있어 잔여 부하도 추정값이다.
Sunfish는 launcher가 아닌 확인된 실제 Python 계산 프로세스를 계측했다. 개별 셀의
일반 CPU 요약에 남은 `UCI transport` 문구보다 실제 endpoint 식별 영수증을 기준으로 한다.
완전한 OS·열·클럭 격리나 지속적인 affinity 관측을 주장하지 않는다.

## 사전 검사와 과거 기록

`build-m2-engine-cpu/attempt-003`의 사전 24판은 595.218초에 완료했고 제품·독립 감사가
통과했다. 검색 2,213회·CPU 1,089.171875초, 잔여 경고 15개 창·3구간·최대 32.593519%,
최종 Job 42프로세스·active 0이다. 동일한 33개 실행 소스·사전 조건·모델·기보 입력과
두 감사의 SHA를 확인해 새 96판 계획에 참조했다. 사전 대국을 다시 두거나 본 성적에 합치지 않았다.

앞선 main 40판·194판은 감시 코드의 숫자 부모 PID 오인으로 중단된 무효 기록으로 남긴다.
새 사전 이후 원래 768판 main은 시작하지 않았다. 96판 선택 어댑터의 첫 준비 동결은
JSON 경로를 Path로 변환하지 않은 오류로 실패했으며 실제 대국은 0이었다. 그 입력과
원본 소스/관측을 보존하고 한 줄 수정 및 실제 JSON 경로 회귀를 포함한 10개 검사 PASS 후
첫 실제 본 대국 `build-m2-baseline96/run-001`을 시작했다. 완료한 사전/본 대국을 재시작하지 않았다.
