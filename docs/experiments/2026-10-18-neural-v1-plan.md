# 첫 자체 신경망 평가·자가대국 수집 계획

2026-10-18. 기준은 진단 커밋 `db7fc80be97512a7ec9276f1ff53cd853a9de780`, 설치된 v0.5.8 실행 파일 SHA256 `17b079ba319ba7ce8a94c0a78a201d40840b57cda452c9965d5a3d0039400ed1`이다. 학습 결과를 보기 전에 첫 실험의 범위와 조건을 고정한다.

## 작은 완료 목표

자체 대국 → 완결 기보에서 학습 위치 추출 → 더 깊은 자체 탐색의 점수와 최종 승패 결합 → 작은 평가망 학습 → Python/C++ 추론 대조 → 기존 규칙 검증 → 로컬 선택 실행까지 한 번 재현한다. 이번에는 지속 강화학습 서버, GPU 학습, 정책망/MCTS, 자동 모델 승격을 구현하지 않는다. 신경망은 실험용 선택 기능이며 기본 수식 평가는 보존한다. 불법 수·메이트·자동/청구 무승부 판정은 기존 규칙과 탐색이 담당한다.

## 모델과 학습

- 입력: 기물12종×64칸=768. 자기 기물 PNBRQK가 앞6면, 상대가 뒤6면. 흑 차례는 랭크를 뒤집어 같은 관점을 사용한다. 캐슬링 권리·앙파상·이력·폰 이외 관계를 별도 입력으로 넣지 않는 첫 모델의 한계를 공개한다.
- 자체 MLP: 768→32 ReLU→16 ReLU→1. 기본 기물 점수에 `600 × 망 출력`을 더하고 ±10,000cp로 제한한다. 메이트 점수 영역에 들어가지 않는다. 증분 계산/양자화는 별도 후속 과제다.
- NumPy2.3.5 CPU, float64, seed20261018. 가중치와 역전파·최적화 구현은 자체 코드다. 외부 엔진의 코드·망·가중치·학습 위치나 개인 기보를 가져오지 않는다.
- 목표는 `0.8*tanh(자체 탐색cp/600) + 0.2*최종 승패`이며 모두 현재 차례 관점이다. 예측은 `tanh(기물cp/600 + 망 출력)`. 평균 제곱 오차로 학습한다. 메이트 점수를 임의 cp로 바꾸지 않는다.
- 최초 학습은100epoch, batch64, seed20261018. 학습률 등 나머지 하이퍼파라미터는 도구 기본값을 동결한 소스와 보고서에 기록한다. 검증 오차가 가장 작은 epoch를 선택하고 최종 시험 집합은 선택 뒤 한 번 평가한다. 결과를 본 뒤 시험 집합에 맞춰 재학습하지 않는다.

## 최초 수집 조건

- 직접 작성한16개 오프닝 계열을 학습10·검증3·시험3으로 미리 분리한다. 같은 대국/계열은 나누지 않고 다른 분할에 중복된 정규화 위치도 제거·감사한다. 공개 fixture 전체 수순은 합법성을 검증한다.
- 계열당2판(총32판), seed20261018. 다양화를 위해 시작 수순 뒤 합법 무작위2반수를 추가하되 모든 이력을 저장한다. 이후 수는 자체 엔진이 선택한다.
- 실제 착수는 수당1,000노드, 최대256반수, 현재 가능한 반복/50수 무승부는 청구하는 정책. 4반수마다 표본을 고려하고 완결 기보만 훈련에 사용한다. 미완료·오류 판을 무승부로 간주하지 않는다.
- 표본의 교사 점수는 같은 자체 엔진의 별도10,000노드 검색에서 얻는다. 체크·종료·현재 무승부 청구·메이트/불완전/범위 점수 등을 제외하고 전체 시작 FEN/이력·깊이·노드·주요 수순·바이너리 해시를 보존한다.
- 최초 자료는 동작 확인용 작은 표본이다. 예측 오차 감소를 기력/Elo 개선으로 바꾸지 않는다. 향후 데이터 수집 규모를 늘릴 수 있는 도구를 함께 제공한다.
