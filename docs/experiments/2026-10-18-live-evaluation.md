# 2026-10-18 실시간 형세 표시 검증

기준 소스: `e34f89479dc707de9e89ff53c7ebbc2e5808d7df` (v0.5.3 개발 후보). 핵심 C++ 파일은 변경하지 않았다. 로컬에서는 해당 소스 파일을 가져온 검증용 Git 스냅샷에서 UI/대국 관리기 변경을 검사했다. 저장소 전체의 기존 실험을 다시 실행한 것은 아니다.

## 동작

실제 응수 탐색의 `SimpleEngine.analysis()` 정보를 백 기준으로 정규화하고, 별도 잠금의 인증된 GET 경로로 전달한다. 별도 분석 엔진은 실행하지 않는다. 완료 깊이가 없는 값, 다른 위치·대국의 늦은 응답, 최종 선택 수와 다른 PV의 점수는 표시하지 않는다. 착수 후 보존한 루트 값에는 `previous_search`와 원래 `source_fen`을 붙인다.

Godot와 기존 브라우저에 평가 막대·점수·출처/깊이를 추가했다. 평가 단위와 우세 시각화는 승률이 아니다. 복기에 현재 대국 점수가 섞이지 않게 격리했다. 자세한 의미와 사용법은 [기능 설명](../LIVE_EVALUATION.md)에 있다.

실제 엔진 사고 중 같은 revision/FEN의 점수가 도착했고, 착수 후 새 revision/FEN에 직전 루트 출처가 유지되는 것을 검사했다. 신호가 없는 부분 UCI 메시지는 마지막 완료 점수를 지우지 않는다. 스트림이 멈추는 경우 watchdog이 엔진을 닫고 착수 없이 오류 상태로 복귀하는 것도 검사했다.

Godot 검증은 자동 입력이며 사람의 수동 대국과 구분한다. 이 작업은 경기력 비교 실험이 아니며 승률·Elo·실행 속도 개선을 주장하지 않는다. 원격 Windows/Ubuntu 전체 회귀 결과는 이 변경의 PR과 Actions 기록에서 확인한다.
