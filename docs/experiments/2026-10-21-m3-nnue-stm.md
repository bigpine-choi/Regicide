# M3: MSE 유지, NNUE 손번 입력 구현·학습·16판

2026-10-21 KST. NNUE에 **현재 둘 차례의 관점에서 켜지는 입력 하나**를 추가했다.
MSE를 유지한 새 후보 하나를 학습했고, 준비된 기존 B-MSE와16판만 비교했다.
새 후보 **5승8무3패·9/16점·56.25%**, 대국 **164.789513초(2분45초)**다.
오류·미완료·미시작0, 독립 검증PASS다. 긍정적인 첫 선별 결과이며 기력 향상은 미확정이다.
추가 대국·시드 탐색·자동 승격을 하지 않았다.

## 실제 코드 변경

기존 NNUE의 백 관점 평가는 같은 기물 배치에서 손번에 따라 달라질 수 없었다.
보드·탐색이 관리하던 손번을 신경망에도 전달했다. 기존768개 기물 입력과 공유 은닉16개를
유지하고 손번 가중치16개를 추가했다. 이 가중치는 현재 차례의 관점에만, 활성화 함수로
자르기 전에 더한다. 기물 특징과 함께 작동하므로 고정된 보너스 수치에 한정되지 않는다.

v3 저장·불러오기·체크섬을 추가했다. v1/v2는 기존 배열·바이트·체크섬·평가를 보존한다.
증분 누산·수 적용·undo는 기물 누산 그대로이고 평가 때 실제 차례를 읽는다.
수식 평가와 기존 보정망은 변경하지 않았다. [설계와 재현 명령](../NEURAL_STM.md)을 따른다.

학습 **3.762610초**. 검증 MAE **89.455048→89.127248cp**, RMSE177.141394→176.856362cp다.
양자화한 손번 가중치16개 중1개가1로 변했고 나머지는0이다. 손번 가중치만 지운 동일
후보와 비교한3,078위치에서3,008위치의 점수가 달라졌고 차이는 최대3cp였다.
이는 입력이 실제 계산에 반영된 증거이며 전술 판단·기력 향상 증거와는 구분한다.
교사 점수는 기존 엔진의 추정치이므로 오차 감소가 더 좋은 수 선택을 보장하지 않는다.

기존 준비의 NumPy2.3.4와 이번2.3.5는 다르다. 공통 자료·초기 배열·학습 설정·배치
순서는 확인했지만 실행환경까지 완전히 같은 한 요인 확인 실험이라고 주장하지 않는다.
실행 버전과 소스 사본을 학습 전에 기록했다. 기존 보류687행과 과거 대국 위치는 학습·선택에
사용하지 않았다. 새 교사 정답이나 새 학습 자료도 생성하지 않았다.

  완전 일치, 활성 관점·기울기·clipping·색상 대칭·형식·변조 검증.
- 새 native 빌드에서 모델13그룹30,348단언, NNUE10그룹51,270단언,
  탐색61그룹21,389단언 모두0실패.
- 실제 학습 모델: 자료2,932위치·특수수46위치·동일 배치 차례 전환100위치,
  총3,078위치의 Python/전체 재계산/증분 평가 점수0불일치.
- 같은3,078위치에서 기존 MSE의 구·신 실행 파일 및 Python 점수0불일치.

  캐슬링·앙파상·모든 승격·되돌리기·탐색 연결 포함.

이 작업은 엔진·학습 코드 검증이다. 게임 화면이나 PGN 사용자 인터페이스를 다시 실행해
검증했다는 뜻은 아니다. 기존 설치 게임과 `build/regicide.exe`는 보존했다.

## 16판 조건·결과

양쪽 모두 새 `build-m3-stm/regicide.exe`를 사용하고 모델 파일만 다르게 설정했다.
AMD Ryzen AI7 350, 8코어16논리CPU, Windows 공유PC. 수당100ms, 검색1스레드,
Hash16MB, Move Overhead20, 증분NNUE와 동일 탐색 옵션, 기존 노출 개시8개·각 양색,
claim 무승부·500ply 상한이다. 새 감시·부하 중단 체계는 만들지 않았다.

본선16판은 체크메이트8판·반복무승부8판으로 종료했다. 각 엔진의 검색1,003회,
응답 누적 기준81.882482초/81.868915초다. 이는 프로세스 CPU 시간이 아니다.
검색 나무가 달라 보고 노드 수를 추론 속도 개선의 증거로 해석하지 않는다.
독립 감사1회0.50초에서 입력12개, 양색8쌍, 기보2,098ply·검색2,006회·PV10,978ply,
합법성·최종FEN·규칙 종료·5승8무3패를 확인했다.

소스 커밋 `e246d8102c58b4c8680b26ac3886095ab25e79f0`, 실행 전 계획 커밋
`ad84c5db864df379872fa4a738a9f112e9c4866a`. 실제 대국 시작 시 작업 트리는 깨끗했다.
새 실행 파일 SHA256은 `97140c4ad1c40a9f2c67e2fb9a8c0718fe70722e83dcbe50a7011b71c97558d1`다.
기준 MSE SHA256은 `267f65646c24292efa28f11a5f5990311ed7da4f6c134d7c4a6b6c1e0f7be1eb`,
새 후보는 `f001f1d3bd9b710e046d37c88040c13a90e8507b28bfb2c416814b9427332f26`다.

한 시드·노출된8개시·16판·공유PC의 빠른 선별이다. 설명용 개시쌍 bootstrap 범위도
