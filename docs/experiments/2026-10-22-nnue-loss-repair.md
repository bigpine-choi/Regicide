# 실제 패배 위치로 NNUE 판단 교정

2026-10-22. **패배 원인 진단과 교정 구현은 완료했지만 경기력 강화에는 실패했다.**
직전 자료 확대 후보의2승4무10패를 분석하고, MSE·현재 NNUE v3 구조·과적합 방지를 유지하며
실제 실패 위치의 정답을 보강했다. 한 번 학습한 후보는 기본 수식 Regicide와16판에서
**1승1무14패**였다. 새 후보는 채택하지 않고 기본 엔진·설치 모델·과거 기록을 유지한다.

## 확인한 원인과 아직 확정하지 못한 것

원본16판·1,806반수를 재생했고 패배10판에서 각각3개 위치를 먼저 고정했다.
선정 근거는 기록된 평가의 급반전과 이후 기물 손해다. 다음 위치의 기본 엔진 점수나
기물 수지만으로 NNUE 오판이라고 단정하지 않고 Stockfish로 추가 확인했다.

- **부호·손번·배율의 구현 오류 증거는 없다.** 현재 Python/실제 엔진 점수가 같고,
  색과 랭크를 뒤집은163개 위치의 점수 부호도 정확히 반대였다.
- **단순 계산량 부족이 우선 원인은 아니다.** 직전 NNUE는22.63M노드/70.06초,
  기본은21.98M/70.38초였다. 평균 완료 깊이는4.29 대4.15다. 서로 다른 위치의 평균이며
  탐색의 개별 수평선 문제까지 배제하지는 않는다.
- **물질 우세와 위치 안전성의 구분이 약하다.** 실제 패배에서 물질 채널6개의 절대 기여는
  평균358cp, 나머지10개의 기여는 평균18cp였다(실제 탐색 위치471개).
  현재 가중치의 기여 분해이며 신경망의
  일반적 설명이나 원인별 패배 비율은 아니다. 통과폰·왕 안전·즉각 위협의 오판이 관찰됐다.
- **위치 수만 늘려도 이런 판단을 자동으로 배우지는 않는다.** 기존1,626개 정답 중
  절대100cp 미만은140개(8.6%)이고 이 집단 유불리 부호 오류는38개였다.
  정수/실수 차이 MAE19.95cp·상한 포화0%로, 수백cp의 오판을 정수화만으로 설명하기는 어렵다.

기보에서 실제로 확인한 두 사례는 다음과 같다. 모든 점수는 **그 대국의 NNUE 쪽 관점**이다.
Stockfish는 위치당50,000노드의 정확한 cp 패킷만 표에 사용했다. 유한 탐색의 참조이며
완전한 체스 정답은 아니다.

| 실제 위치 | 교정 전 NNUE 정적 | Stockfish 참조 | 교정 후 NNUE 정적 | 해석 |
| --- | ---: | ---: | ---: | --- |
| 8번 대국24...f4 직전 | +108 | -201 | -169 | 흑이 유리하다는 판단을 불리로 교정 |
| 같은 수를 둔 직후 | +42 | -415 | -233 | 손해를 크게 과소평가하던 점수 개선 |
| 6번 대국24...Kf7 직전 | +9 | -528 | -62 | 왕 안전성 오판이 일부만 줄고 큰 오차는 남음 |
| 13번 대국10.Rd1 직전 | +195 | -140 | +119 | 학습에서 제외한 계열. 여전히 방향을 잘못 봄 |

6번 대국의 `...Kf7` 뒤 Stockfish 참조는 흑-927cp였고 추천 `...Be5` 뒤는-512cp였다.
교정 전 모델은 두 위치를-55/-97cp로 평가해 나쁜 수를 더 높게 봤다. 교정 후도-114/-135cp로
순서를 완전히 고치지 못했다. 평균 오차 감소를 모든 잘못된 수의 해결로 표현하지 않는다.
1번 대국43.Bf6의 승격 위협도 로그상 급반전 사례였지만 교사 마지막 패킷이 bound여서
정확한 정답 학습에는 사용하지 않았다. 다른 실제 위치와 PV 끝점의 정확한 정답은 사용한다.

## 개선: 실패 위치와 대안 위치를 함께 MSE로 학습

`prepare_nnue_loss_repair.py`는 고정한30위치에서 다음을 모은다.

1. 수를 두기 전 실제 위치.
2. 실제 착수 뒤와 Stockfish 추천수 뒤의 서로 다른 위치.
3. NNUE가 예상한 진행(PV)의 끝 위치와 실제 상대 응수 뒤 위치.

이를 같은 Stockfish18·Threads1·Hash16·위치별 초기화·50,000노드로 재평가한다.
최대150질의 중 실제142질의,11.69초였다. 메이트·상하한·절대1500cp 초과 등 기존 제외
규칙을 유지해 정확한 정답111개를 얻었다. 이 정답은 실제 Regicide 기보의 전체 이력과
연결한다. 교사 추천이 더 강한 수임을 항상 보장하지는 않는다.

원본 개시 쌍1~6의67개는 학습,7~8의44개는 선택에만 쓴다. 같은 대국·선후공 개시 계열을
양쪽에 나누지 않는다. 기존 자료의 모든 분할과 색 반전 기물 특징 중복도 제거한다.
기존 train1,294·선택263·별도69개를 모두 보존하고 새 정답을 합쳐1,361/307/69개가 됐다.

`train_nnue_loss_repair.py`는 교정 정답을4회, 기존 정답을1회씩 배열에 넣어 같은 MSE로
학습한다. 새 손실 함수를 만들지 않는다. 같은 위치를 반복한 것은 새 독립 표본으로 세지
않으며 고유 정답·반복 적용 오차를 따로 기록한다. 선택에도 사전에 고정한 같은 비중을
적용한다. 기존 자료가 교정 자료 학습 중 전체 판단이 무너지는 것을 억제하는 역할을 한다.

현재 c73 모델에서 이어 학습했다. 기물768+상대 손번1·은닉16·v3·S32, seed20261020,
batch128, Adam·학습률·기울기 상한10은 유지했다. 매5회 MSE 점검,5번 연속 개선이 없으면
중단·최적 복원, epoch0 보호도 그대로다. 실제30회에서 멈춰5회 모델을 복원했다.
학습0.74초·후보1개·재학습0회다.

| 같은 고유 자료의 MAE(cp) | 학습 전 | 학습 후 | 용도 |
| --- | ---: | ---: | --- |
| 교정 학습67개 | 332.63 | 188.12 | 직접 가중치 학습 |
| 다른 개시 계열 교정44개 | 329.66 | 274.14 | 중단·가중치 선택에 사용 |
| 기존 별도69개 | 244.70 | **248.20** | 저장 후1회 점검, 과거에 노출된 자료 |

교정111위치 전체의 유불리 부호 오류는46→20개, NNUE가 예상한 진행 끝18개 위치의 MAE는
305.4→191.1cp였다. 직접 학습67개와 선택용44개를 합친 개발 지표이므로 독립 성과가 아니다.

선택용 전체 가중 MSE는93,897.64→78,726.00cp²다. 선택용 원본263개의 MSE는
62,647.79→64,156.66cp²로 악화됐다. 새 실패 유형의 교정과 기존 분포의 오차 사이에
상충이 남는다. 선택용44개는 새 독립 검증이라고 부르지 않으며69개도 재사용 개발 자료다.
사후 점수나 국소 수 선택 검사로 모델·설정을 다시 고르지 않았다.

## 정확성·국소 회귀·16판

반복 비중·자료 누수·epoch0·사후 test를 다루는 새 단위 검사6개를 통과했다.
실제 후보로 전체1,737위치와 특수 수46위치의 Python/전체/증분 점수가 모두 같았다.
native 모델13그룹·25,521확인도 실패0이다. native와 이전 모델 호환성은 같은 실행 파일
SHA와 이전 검증 체인으로 확인한다.

각 패배의 가장 이른 적격 위치를1개씩 선정해 이전/새 모델에 동일10,000노드를 배정했다.
최대20검색·실제200,000노드·0.63초·재시도0이며 새 대국은 아니다. 선택수는6/10곳에서
달라졌지만 Stockfish 추천수 일치는 **4/10→2/10**으로 줄었다. 13번 대국 `Rd1`은 `e4`로
바뀌었지만 교사의 `e3`와는 달랐다. 1번 대국의 `g4`,4번의 `...Bg7`은 원래 교사와 같았지만
새 모델이 다른 수로 바뀌었다. 교사1순위 일치도 역시 경기력의 완전한 기준은 아니지만,
정적 오차 감소가 그대로 더 좋은 수로 연결된다는 주장을 뒷받침하지는 않는다.

본 대국은100ms·Hash16MiB·단일 탐색·양색16판·최대500반수·무승부 청구 허용이다.
실행 파일은 양쪽 동일 `97140c4ad1c40a9f2c67e2fb9a8c0718fe70722e83dcbe50a7011b71c97558d1`,
native 소스는 `e246d8102c58b4c8680b26ac3886095ab25e79f0`이다.
기본은 `classical.json` 전체 옵션이고 후보는 NNUE 활성화·모델 경로만 다르다.
Ryzen AI7 350·8코어/16논리·Windows11 공유 PC를 사용한다.

진단한 기보의 개시를 그대로 암기했는지만 보지 않도록 다른8개 시작을 대국 전에 고정했다.
기존 프로젝트가 작성한 M2 개시 목록에서 파일 순으로 고르되 진단 개시의4반수 이상 접두
수순과 현재 학습/선택/별도 자료 및 진단 기보의 대칭 기물 배치와 겹치는 시작은 제외했다.
과거 연구에서 알려진 프로젝트 개시이며 완전히 새로운 독립 표본은 아니다.
이전16판과 개시가 다르므로 성적을 직접 빼서 이번 변경의 향상폭으로 해석하지 않는다.

실제16판은 **후보1승1무14패·득점률9.375%·109.07초(1분49초)**였다. 완료16판,
실행 오류0·미완료0·재시도0·추가 대국0이다. 교정 자료의 정적 오차는 줄었지만 국소 수 선택
검사와 실제 기본 엔진 대국에서 이번 후보를 채택할 근거를 얻지 못했다.

독립 감사1회는18.49초로 PASS였다. 고정 입력110개·원본 패배30위치 선정 순위·교사142질의·
교정111정답·기보 계열 및 대칭 특징 분리·반복 비중·모델 복원·실제 정수 점수를 확인했다.
새16판의1,541반수·1,323검색·PV6,461반수를 재생해 합법성·점수 관점·종료 판정·PGN을
검사했다. 감사 때문에 엔진 검색·학습·대국을 다시 실행하지 않았다.

다른 개시에서의 비교이므로 이전2승4무10패와의 차이를 이번 변경의 정확한 악화폭이라고
주장하지 않는다. 확인된 것은 이번 조건에서 기본 엔진이 크게 우세했고, 교정 학습만으로
해당 격차를 해소하지 못했다는 점이다. 자료 부족·신경망 표현·학습 속도·탐색 수평선 각각의
정확한 패배 기여율은 확정하지 않았다. 다음 과제는 전체 점수 MAE 감소에 기대기보다
실제 수 선택과 위협 대응의 회귀가 통과되는지를 먼저 확인하는 것이다.
