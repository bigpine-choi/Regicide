# 신경망 추가 시간 시범 대국 사전 계획

대국이나 새 시작 위치의 엔진 평가를 실행하기 전에 조건을 고정한다.

- 질문: 현재 1/32 정밀도 모델에 더 긴 시간을 주면 기존 평가기 1초에 어느 정도 대응하는가?
- 주조건: 신경망 수당 3,000ms, 기존 평가기 수당 1,000ms. 시작 위치 파일의 첫 2개에서 색을 바꿔 4판.
- 보조조건: 신경망 수당 5,000ms, 기존 평가기 수당 1,000ms. 같은 파일의 첫 1개에서 색을 바꿔 2판.
- 각 위치에서 신경망 백, 신경망 흑 순서. 주조건 전체를 마친 뒤 보조조건을 실행한다.
- 기존 12개 새 시작 위치를 보존하고, 평가값을 보지 않고 파일 순서의 접두부만 선택했다. 새 위치는 보관된 이전 기보·분석 수순·표본 학습/검증/보류 자료와 기물 배치 및 색/순위 반전 기준으로 겹치지 않는다. 추출하지 않은 모든 원시 학습 위치에 대한 비노출 보장은 아니다.
- 전체 준비·대국은 UTC 2026-10-19 06:16:49부터 55분, 절대 종료 UTC 07:11:49(한국시간 16:11:49). 남은 5분 이내에 결과 감사·정리를 마쳐 전체 1시간 미만으로 제한한다. 시계가 끝나면 현재 검색을 중단하며 미완료 판은 무승부로 바꾸지 않는다.
- 판수·시작 위치·시간·모델은 결과에 따라 바꾸지 않는다. 재시도하지 않는다. 오염·실패·시간 초과도 보존하고 미완료 또는 무효로 기록한다.
- 엔진/모델은 기존 검증한 바이너리와 모델 그대로 재사용한다. 빌드 원본 bb3100c460618e888c42066ba9c54618c0127c9d, 현재 체크아웃 5ff2074aa142f915260739a8f0f3c2ddb8586ee5. 새 실험 도구는 실행 전 정확한 파일 해시로 고정한다.
- 동일한 바이너리 두 복사본, Hash 16MiB, Move Overhead 20ms, 기존 탐색 옵션, 증분 신경망 갱신 사용. 신경망 역할에만 외부 모델을 설정한다. 실제 모델 체크섬 응답을 확인한다.
- 판마다 새 게임 통지로 탐색 표를 초기화하며, 전체 수 이력을 전달한다. 500 ply 상한, 다음 합법 수를 포함한 규칙상 무승부 청구, 점수에 의한 조기 승패 판정 없음. 실제 수당 요청 시간과 보고된 내부/벽시계 시간을 모두 보존한다. 시간 초과를 자동 패배 처리하는 대회 시계 방식은 아니다.

- 주조건과 보조조건을 따로 보고하고 공통 첫 위치의 색 교대 결과를 기술적으로 비교한다. 소수 2쌍/1쌍에 신뢰구간이나 Elo를 붙이지 않는다. 동일 시간 기력 향상이나 5초가 3초보다 일반적으로 강하다는 결론을 내리지 않는다.
