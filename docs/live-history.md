# 대국 중 수순 탐색

2026-11-05. Godot 대국 화면과 웹 화면의 보드 아래에 `<`·`>`·`현재로`를 추가했다. 키보드 왼쪽·오른쪽 화살표로도 한 착수씩 이동하며, `End`는 최신 위치로 돌아간다. 입력란에서 사용하는 화살표 키는 그대로 유지한다.

과거 위치를 보는 동안에도 **실제 대국, Regicide의 탐색과 시계는 계속된다.** 과거 보드에서는 기물 선택·이동·승격·수 제출을 막는다. 최신 착수까지 앞으로 이동하거나 `현재로`를 누르면 실제 보드와 입력이 복원된다. 이동한 과거 수순은 화면에 표시하며, 현재 위치의 평가·추천 수를 과거 보드에 겹쳐 표시하지 않는다.

새 엔진 수가 도착해도 사용자가 고른 과거 위치는 유지하고 전체 착수 수만 갱신한다. 새 대국, 무르기, 분기 교체는 이전 탐색 위치와 캐시를 지운다. 이전 대국의 늦은 응답도 버린다. 기존 보관함·PGN 복기와 대국 중 탐색은 별도 상태로 관리한다.

기존 실행 중인 클라이언트는 유지했다. 변경된 화면은 새 Godot 클라이언트를 실행하거나 웹 화면을 새로 불러올 때 적용된다. 새 화면과 함께 `/api/history`를 지원하는 갱신된 호스트가 필요하다.

## 데이터와 동작

인증된 `GET /api/history`는 현재 게임 ID·버전·전체 수순과 `착수 수 + 1`개의 보드 프레임을 반환한다. 호스트는 잠금 안에서 보드와 식별자를 복사한 뒤 실제 수 이력을 python-chess로 재생한다. 클라이언트에서 캐슬링·앙파상·승격 같은 체스 규칙을 재구현하지 않는다.

화면은 진행 중인 실제 상태를 계속 보관하고 별도의 표시 위치만 바꾼다. 기보 요청은 엔진 착수 요청과 별도로 처리한다. 응답의 게임 ID, 실제 수순 접두부와 마지막 FEN을 대조해 무르기나 새 대국 이전의 자료가 현재 보드로 잘못 들어오지 않게 한다. 시계는 과거 프레임이 아닌 실제 대국의 최신 값으로 계속 표시한다. 수순 이동 자체는 착수 소리를 내지 않는다.

## 검증

실제 엔진을 시작하지 않는 독립 검사를 수행했다.

- Python 3개 검사 통과: 인증·동일 출처, 모든 프레임과 SAN, 캐슬링·앙파상·언더프로모션, 실제 보드·검색 플래그·파일 보존과 시계 진행.
- Godot 신규 11개 확인 통과: 실제 컨트롤러의 앞뒤 이동, 대기 중 엔진 요청 보존, 과거 입력 금지, 시계 진행, 새 착수·현재 복귀·새 게임·무르기·지연 응답.
- 웹 신규 동작 검사 통과: 실제 배포 스크립트와 제어된 HTTP/시간을 사용해 보드·수순, 시계·검색 지속, 현재 복귀, 새 게임·무르기·지연 응답과 입력란 키 처리를 확인.
- 관련 웹 7개 묶음 통과: 신규 탐색, 생각 시간, 래피드 시계, 오프닝 안내, 추천 수, 사이드바, 보드 이동 효과.
- 관련 Godot 검사 통과: 생각 시간 39개, 추천 수 121개, 오프닝 안내 51개, PGN 파일 41개.

1760×960 화면도 별도 오프스크린 Godot 프로세스로 1장 렌더링해 확인했다. 보드 아래 탐색 줄은 화면 좌표 `(22, 850)`, 크기 `916×36`으로 잘리지 않았고 `<`·`>`·현재 위치·실제 시계를 함께 확인했다. 순수 headless 드라이버는 더미 렌더러여서 이미지를 제공하지 않아, 숨긴 독립 Windows/OpenGL 프로세스를 사용하고 종료했다. 사용자 대국 앱에는 접근하지 않았다. 이미지와 위치 검증 기록은 `build/live-history-validation/history-1760x960.png` 및 같은 이름의 `.json`에 있다.

별도로 실행한 기존 `evaluation_bar_tests.gd`는 58개 중 6개가 실패했다. 변경 전 HEAD의 `main.gd`를 별도 경로에서 불러 실행해 같은 6개 실패를 재현했다. 현재 공통 Stockfish 게이지와 오래된 자체 점수·복기 표시 기대값 사이의 불일치이며, 이 작업에서 통과한 검사로 집계하지 않는다. 재현 자료는 `build/live-history-validation/baseline-evaluation.log`에 있다.

재실행 예:

```powershell
.\.venv-tests\Scripts\python.exe -m unittest discover -s tests -p live_history_tests.py -v
node tests/live_history_web_tests.js
& 'C:\Users\hanso\Tools\Godot\Godot_v4.7.2-stable_win64_console.exe' --headless --path godot --script res://tests/live_history_tests.gd
```

Python·웹·Godot 신규 검사는 기존 CI 묶음에도 연결했다. 위 결과는 자동화한 기능 검증이며 사람의 수동 사용성 평가나 기력 개선 실험이 아니다. 현재 개인 대국을 중단하거나 수를 대신 두는 검증은 하지 않았다.
