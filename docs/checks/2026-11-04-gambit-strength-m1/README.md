# 갬빗 기력 강화 M1: 탐색 시간 진단

2026-11-04 20:56 한국 시간 실행. [프로젝트 계획](../../GAMBIT_STRENGTH_PLAN.md)의 첫 진단을 완료했다. **분할 재탐색이나 일괄 시간 증액을 실전 정책에 채택하지 않는다.** 더 깊은 완료 결과가 더 좋은 수를 보장하지 않았으므로, 다음 개선 대상은 같은 국면의 탐색·평가 불일치다.

## 조건

- 기준 커밋: `059f7f70ba25ff3c616b081c99a310e1adf9e583`. 연구 분기 `experiment/gambit-strength-m1`. 실행 중 새 진단 도구와 문서가 미커밋 상태였음을 원본에 표시한다.
- 자체 실행 파일 SHA256: `5011da4c5e6ef01c452bd7125e4e22b372d2c9cfb858ed8759057325acb0e6ba`. classical 평가·UsePieceActivity=true·Hash 16MiB·단일 탐색 스레드.
- 하드웨어: AMD Ryzen AI 7 350, 8코어·16논리CPU, Windows. CPU 격리는 하지 않았다.
- 자료: 기존 운영 보고서에서 외부 손실 >150cp인 네 국면 전부와 기존 사전 선언 목록의 첫 네 중복 없는 시작 국면. 결과를 보고 고르지 않았으며 **모두 이전 개발자료**다. 새 미학습 평가 자료가 아니다.
- A: 같은 세션에서 1000ms와 750ms를 차례로 요청. B: 새 프로세스에서 한 번에 1750ms 요청. 국면당 1회. 첫 1000ms 결과도 보존한다. 실제 벽시간은 A 합계 약 1716~1718ms, B 약 1733~1735ms로 정확히 같지는 않다.
- 사후 감사: 로컬 Stockfish 18, SHA256 `9bde420202717ce083412027fbfb8c5c935b537591d712be8a8a8bae92f6e8d6`, Threads 1·Hash 32MiB·기력 제한 없음. 쿼리당 최대 500ms·깊이 14. 모든 자체 선택이 끝난 후 실행하고 답을 착수에 전달하지 않았다.

## 결과

손실은 같은 루트에서 외부 자유 탐색과 실제 선택 수의 차이다. **모든 비교의 공통 정확 완료 깊이는 14**다. 같은 선택 수는 외부에서 한 번만 분석한다. 작은 값이 좋으며 cp는 승률이 아니다.

재시작은 선택 수 변경 **0/8**, 완료 깊이 상승 **0/8**이었다. 연속 검색은 **5/8**에서 한 깊이를 더 완료했지만 외부 평가 기준 **3개 개선·2개 악화·3개 동일**이었다. 알려진 실패에서는 1개 개선·2개 악화·1개 동일이었다.

King's 첫 실패의 `Bb5 → Nc3`는 117cp, Morra의 `Ne6 → Kh1`은 75cp 추가 악화했다. 첫 King's는 프로젝트의 큰 추가 악화 경고 조건에도 해당한다. King's 두 번째의 `Nc3 → Nd4`는 148cp 개선했다. 기존 보고서의 깊이 12 손실과 이번 깊이 14 손실을 같은 수치로 취급하지 않는다. Budapest는 기존 저장 수 `Nb4` 대신 이번에 `Kh8`를 선택했다. 과거의 오류 위치를 다시 쓴 것이며 같은 선택 수가 항상 재현된다는 뜻은 아니다.

## 원인 구분과 다음 가설

현재 소스의 `TranspositionTable::prepare()`는 검색마다 세대 번호를 올리고 이전 점수·최선 수를 무효화한다. 같은 게임 식별자를 유지해도 **버퍼만 재사용하며 탐색 결과를 이어받지 않는다**. 8개 중 7개에서 첫 검색과 재시작의 완료 깊이·노드·평가·선택 수가 같았다는 관측과 일치한다. [기존 구현 설명](../../HASH_MEMORY_REUSE.md)을 참고한다. 활성 바이너리를 이번에 재빌드한 것은 아니므로 현재 소스와 해당 바이너리의 빌드 대응을 새로 증명한 것은 아니다.

따라서 ‘같은 세션에 남는 시간을 추가하면 완료 깊이가 늘어난다’는 가설은 이 표본에서 지지되지 않았다. 연속 검색도 두 알려진 오류를 악화했다. 다음 M2는 King's 첫 위치와 Morra의 **깊이가 늘면서 더 나쁜 수를 고르는 원인**을 자체 수순·기물 안전·왕 안전·안정화 탐색으로 나눠 진단한다. 평가기 문제인지 선택적 탐색 문제인지는 아직 확정하지 않았다.

갬빗 전체 정책·시계·인간 반응·완주 대국·Elo를 측정한 실험이 아니다. 실전 정책·C++ 엔진·활성 실행 파일·기존 학습 기억에는 변경을 적용하지 않았다.
