# 첫 자가대국 학습 자료 독립 재검증

2026-10-18. 수집기와 학습기의 검증 함수를 가져오지 않은 별도 Python 검사로 **32판·588개 위치의 구조와 출처 기록을 재검증했다. 모든 검사가 통과했다.** 이 감사는 학습 자료의 재현성과 내부 일관성을 확인한다. 학습 모델의 기력 향상이나 평가값의 객관적 정확성을 확인한 결과는 아니다.

감사 대상은 `build/learning-v1-data/` 원본이다. 공개 사본은 [수집 기록](data/manifest.json), [전체 대국](data/games.jsonl), [학습 위치](data/positions.jsonl), [PGN](data/games.pgn)에 보관한다. 공개 사본의 경로 문자열 정리나 JSON 재직렬화로 바이트가 달라질 수 있으므로 아래 원본 해시와 공개 사본 해시는 구분해야 한다.

## 자료 배분과 완료 상태

| 구분 | 오프닝 계열 | 대국 | 학습 위치 |
|---|---:|---:|---:|
| 학습 | 10 | 20 | 367 |
| 검증 | 3 | 6 | 96 |
| 시험 | 3 | 6 | 125 |
| 합계 | 16 | 32 | 588 |

- 32판 모두 규칙에 따라 종료했다. 미완료 대국 0판, 수집 오류 0건이다. 백 승 11판, 흑 승 13판, 무승부 8판이다. 같은 엔진끼리 둔 결과이므로 이 승패를 성능 개선 근거로 해석하지 않는다.
- 대국 길이는 37~157반수이고 총 2,985반수다. PGN 32판을 별도로 읽어 JSON의 초기 위치·전체 수순·결과와 일치함을 확인했다.
- 자기대국은 수당 1,000노드, 추가 교사 탐색은 위치당 10,000노드였다. 전체 대국 길이 상한은 256반수다. 시간 제한은 없으며 통신 정지 감지에만 600초 제한을 둔다.
- 시드 `20261018`, 계열당 2판이다. 고정 8반수 오프닝 뒤 합법 무작위 2반수를 두고 이후 4반수마다 표본을 고른다. 독립 검사에서 작업 순서·대국별 시드·무작위 2반수까지 재구성해 저장 수순과 비교했다.
- 체크 중인 후보 59개, 교사 탐색이 메이트 점수를 반환한 후보 32개, 완료 깊이가 없는 후보 1개를 제외했다. 저장된 588개 표본에는 이 경우가 없었다.
- 교사 탐색의 완료 깊이는 1/2/3/4/5/6/7에서 각각 9/70/292/167/38/9/3개다. 짧은 탐색으로 만든 작은 실험 자료임을 전제로 해석한다.

## 독립 검사의 범위

별도 검사 코드는 표준 라이브러리와 `python-chess`만 사용했다. `collect_learning_data.py`, `train_neural.py`, `neural_model.py`의 검증 함수를 실행하지 않았고, 실제 엔진을 추가 실행하지 않았다.

1. 세 자료 파일의 SHA-256과 오프닝 정의 파일의 해시·내용이 원본 manifest와 일치하는지 확인했다.
2. 32판의 전체 수순을 초기 FEN부터 합법적으로 재생했다. 현재 또는 다음 수를 선언한 무승부 청구가 가능한 상태에서 수순이 더 이어지지 않는지, 최종 FEN·종료 사유·승패가 규칙 판정과 일치하는지 확인했다.
3. 588개 표본이 해당 대국의 수순 앞부분이며, `ply`·차례·FEN·오프닝·분할이 일치하는지 확인했다. 종료·무승부 청구 가능·체크 상태 표본과 대국 내 중복 표본이 없음을 확인했다.
4. 기물값 P/N/B/R/Q/K = 100/320/330/500/900/0으로 차례 기준 재료 점수를 별도 계산했다. 완결 대국 결과로부터 차례 기준 승패 라벨 -1/0/1도 별도 계산해 저장값과 비교했다.
5. 교사 원본 UCI `info` 행의 cp 점수·완료 깊이·노드 수·PV가 각 표본 필드와 일치하는지 확인했다. 메이트를 cp로 변환한 라벨, 경계 점수, 0깊이 라벨이 없었다. 모든 교사 PV의 총 2,456반수를 합법적으로 재생했다.
6. 같은 오프닝 계열이 여러 분할에 속하지 않는지, 대국과 그 이웃 위치가 지정 분할을 유지하는지 확인했다. 시계 두 필드를 제외한 보드·차례·캐슬링·합법 앙파상 키의 교차 분할 중복은 0개였다.
7. 실제 신경망 입력의 교차 분할 중복도 별도로 검사했다. own PNBRQK와 opponent PNBRQK의 12개 채널, 흑 차례의 `square XOR 56` 랭크 반전 후 활성 입력 인덱스 집합을 비교했다. 색상 반전이나 캐슬링·앙파상 권리 차이로 FEN만 달라지는 동일 입력까지 포함해 중복 0개였다.
8. 수집기 소스 해시가 현재 파일과 일치하고, 연구 폴더와 기존 설치 폴더의 실행 파일이 모두 manifest의 `17b079…` 바이트와 일치함을 확인했다.

수집 코드의 입력 경로와 실행 설정을 읽은 범위에서 이 자료는 자체 오프닝 정의와 동일 Regicide 실행 파일의 자가대국·추가 탐색에서 생성되었다. 외부 엔진 라벨, 외부 신경망 가중치, 개인 대국 기록을 수집 입력으로 읽는 경로는 없었다. `b0bae28cd5573f0c0fdc2aa6d6bf04cd126a24b5`라는 실행 파일 소스 커밋은 호출자가 선언한 값이다. 실행 파일의 바이트 일치는 직접 확인했으나, 이 감사에서 소스와 실행 파일의 빌드 관계를 다시 입증한 것은 아니다. 연구 체크아웃의 변경 내역도 바이너리 빌드 출처 증명과 구분한다.

## 모델 연결부 읽기 검토와 한계

Python과 C++ 구현을 읽어 입력 채널·흑 랭크 반전·가중치 저장 순서 `w1,b1,w2,b2,w3,b3`가 일치함을 확인했다. 두 구현 모두 768→32→16→1 구조와 ReLU 두 층을 사용하며, 차례 기준 재료 점수에 신경망 잔차의 600배를 더한다. 출력 제한 ±10,000cp와 정확히 절반인 경우 0에서 멀어지는 정수 반올림도 같은 정의다. 이 항목은 소스 읽기 검토다. 실제 교차 언어 수치 비교와 통신·규칙 회귀 검사의 실행 결과는 별도 검사 기록으로 확인해야 한다.

32판의 위치 588개는 서로 독립적인 경기력 표본 588개가 아니다. 교사 점수는 현재 Regicide의 판단이므로 기존 약점도 포함할 수 있다. 계열 분리와 입력 중복 배제로 정확한 위치 누수는 막았지만, 비슷한 전략 구조까지 완전히 독립이라고 보장하지 않는다. 이번 자료와 학습 손실만으로 기력 향상, 특정 레이팅, 자동으로 계속 강해지는 효과를 입증하지 않는다.
