# M2 CPU 계측 수정과 재실행

새 프로토콜은 이전 기록을 보존하며 실험 Job CPU, 조정기·감시 CPU, 나머지 시스템·백그라운드 추정치를 분리한다. 나머지 부하를 사용자가 다른 앱을 켰다는 증거로 해석하지 않는다. 기존 2초 평균 20% 제한과 대국 조건은 유지한다.

## 실제 Windows 검증

최종 제품 소스의 native-integration-attempt-002에서 모든 자체 작업은 종료했고 Job active process 수는 0이었다. 독립 native API와 원시 기록 재계산을 사용했다.

| 확인 대상 | 실측 결과 |
| --- | --- |
| 긴 작업 4개 | Job·독립 Job API·guard·보유 프로세스 timer 모두 16.359375 CPU초 |
| 짧은 자식 32개 포함 | Job·독립 API·guard 모두 7.6875 CPU초; 보유 프로세스 timer 합계 7.765625 CPU초 |
| 경계 차이 | 0.078125 CPU초; 할당 경계/비동기·양자화 차이를 보정 없이 보존하며 정확한 원인을 단정하지 않음 |
| 조정기·감시 CPU | 긴 작업/짧은 작업에서 각각 0.453125 / 0.4765625 CPU초를 별도 차감 |
| Job 밖 자체 진단 작업 | 0.21875 CPU초, Job CPU는 0; 잔여 관측에 남음 |
| 엄격 20% 짧은 idle 검사 | 최대 2.8666264%, PASS; 실제 사전 대국과 별도 |

첫 native 실행의 강제 종료 단언 실패도 보존했다. 정확한 최초 실패 위치는 확인하지 못했으며, 종료 대기 순서를 보강한 개별 재실행과 최종 전체 재실행이 통과했다. 한 번의 진단 차이가 일반적인 오차 상한이라는 주장은 하지 않는다.

## 검증과 대국 상태

Job API, signed rolling 계산, coordinator identity/실패 baseline, bounded 종료 및 동결 대국 조건의 최종 회귀 63개를 모두 통과했다. 실행 로그는 preparation-tests에 보존했다. 원시 CPU와 요약·최종 Job CPU를 대조하는 제품 감사와 독립 감사를 연결한 뒤 새 입력을 동결한다.

새 attempt-001은 사전 16/24판(8쌍)을 완료한 뒤 230.103초에 잔여 부하 초과로 중단했다. 2쌍은 진행 중 종료했고 2쌍은 미시작이다. 본 대국은 시작하지 않았다. 제품 원시 감사와 독립 감사 모두 계측·기보 무결성은 통과했지만 대국 성적은 무효로 유지한다.

첫 초과이자 최대 2초 창은 전체 busy 39.4563531% − 대국 Job 12.2190182% − 조정기 0.2933233% = 잔여 26.9440116%였다. 최대 샘플 gap 0.5651114초, 알려진 외부 엔진 CPU 증가 0이었다. 최종 Job 35개 프로세스 모두 종료했고, 독립 검사에서도 live/unknown 0이었다. 종료 감시 뒤 최종 Job CPU 증가 0.078125초를 별도 보존했다. 이 합계로 특정 앱이나 과거 중단 원인을 지목하지 않는다.

추가 점검에서 root의 매 60초 검증이 짧은 Git 자식 작업을 Job 밖에서 실행하는 경로를 발견했다. 조정기 자체 timer에는 이 자식 CPU가 포함되지 않는다. 최초 실패는 230초에 발생해 이전 180초 검증과 시간 차가 있으며, 이 누락이 중단 원인이라고 단정하지 않는다. known 계측 누락을 제거하기 위해 v2와 그 동결본을 보존하고 새 v3 runner를 준비한다. 측정 전 실제 Git 검증 뒤에는 root도 worker와 같은 봉인된 정확-query receipt를 사용한다. 등록되지 않은 query는 오류로 중단한다.

v3의 root 초기·주기·종료 검증을 포함한 최종 회귀 19개가 통과했다(preparation-v3). 새 attempt-002의 사전 24판은 새 소스와 사전 기록을 동결한 뒤 진행한다. 사전 완료·기보·부하·설정 감사가 모두 통과해야 본 768판을 실행한다. 이전 중단 대국은 유효 성적에 합산하지 않는다.

엔진·모델·기본 평가기·게임 UI는 변경하지 않았다. 기존 두 개발 경로와 M3 Huber 후보 준비 성과도 보존한다. 이 실험은 이미 노출된 고정 오프닝 은행의 로컬 외부 기준선이며 보편적 Elo나 모델 승격 검증은 아니다.
