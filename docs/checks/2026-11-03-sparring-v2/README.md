# 스파링 v2: 형세 조절·지연 회복·래피드 추정

2026-11-03. 구현 소스는 `31715bfa163bd655fc8192f4d7b7ede4cec0b783`이다. 착수는 자체 Regicide만 결정한다. Stockfish는 검증 상대이며 사용자 레이팅의 정답으로 쓰지 않는다.

## 사용자 동작

Regicide를 다시 실행하고 새 대국에서 스파링 모드를 선택한다. 생각시간 1초 이상을 권장한다. 헤더에는 `추정 래피드 ~1420 (+18) · 실험` 같은 형식으로 마지막 검증 관측에 따른 추정과 변화량이 표시된다. 이 숫자는 사용자의 Chess.com 계정에서 조회한 공식 점수가 아니다.

대국을 끝낸 뒤 오른쪽의 `실제 Chess.com 래피드 레이팅`에 사용자가 아는 실제 점수를 입력하고 저장한다. 같은 대국은 정정해도 한 표본으로만 센다. 보정은 다음 대국부터 적용한다. 현재 대국의 추정 곡선을 정답에 맞춰 소급해서 바꾸지 않는다. 이 기능은 종료된 현재 스파링 대국용이며, 과거 보관함에서 라벨을 새로 붙이는 기능은 아직 없다.

## 최종 일정

- 각 색의 1~40번째 수: 자체 엔진의 선택 수 평가가 -100~+100cp 안에 있도록 목표를 둔다. 후보 중심은 봇 관점 +30cp다.
- 41~69번째 수: 같은 수 번호의 백·흑에 같은 진행률 `(수 번호-40)/30`을 적용해 양보를 줄인다.
- 각 색의 70번째 착수부터: 기준 탐색의 최선수를 그대로 사용한다. 표준 시작 기보에서 백의 139번째 반수, 흑의 140번째 반수가 첫 전력 착수다.
- 낮은 재료 위험 보호와 분석 불확실성 등 예외는 실제 이유를 기록한다. 승리나 매 순간 ±1점 유지를 보장하지 않는다. 평가 게이지의 숫자를 균형처럼 꾸미지 않는다.

## 위치를 보고 선택하는 정책

상대의 과거 평균 실수량과 현재 형세 조절을 분리했다. 평가가 +1점을 넘으면 관측 개수가 적어도 복원 후보를 찾고, 기존의 최대 90cp 목표·120cp 양보 상한 때문에 접전 후보를 배제하지 않는다. 불리한 -1점 미만에서는 기준 최선수를 유지한다.

얕은 탐색으로 최대 16개 후보를 넓게 찾고, 최대 4개를 기준 탐색과 같은 완료 깊이(최소 4)에서 재검증한다. 비교 점수와 최신 점수가 모두 범위 안인 후보를 우선하고 +30cp 중심에 가까운 수를 고른다. 발견 단계 점수만으로 착수하지 않는다. 불안정한 기준 평가는 같은 깊이로 다시 확인하며, 원래 게이지의 불안정 표시를 안정적으로 바꾸지는 않는다.

40수 전 기준수가 이기는 메이트이고 합법적인 완결 메이트 수순으로 확인된 경우에도 자연스러운 유한 CP 대안을 찾는다. 이때 메이트를 10000cp 같은 임의 숫자로 바꾸지 않는다. 메이트 기준의 실제 깊이와 별도 후보 검증 깊이(최소 4)를 구분하고 손실 CP는 `null`로 둔다. 메이트 회피는 일반 CP 양보와 별도로 집계한다.

## 큰 실수 뒤 천천히 균형 회복

상대 룩·퀸을 잡은 사실만으로 실수를 판정하지 않는다. 연속 포획·승격 묶음이 조용한 수로 정리될 때의 순재료 변화를 확인한다. 동등한 룩 교환, 연쇄 퀸·룩 교환은 제외한다. 자체 폰의 승격으로 생긴 이득은 상대의 기물 실수로 세지 않고, 상대의 승격 보상은 손실을 줄인 것으로 반영한다.

순재료 이득이 400cp 이상인 큰 손실이 확인되면 첫 기준 평가를 고정해 네 번의 봇 착수에 걸쳐 복원 목표를 낮춘다. 포획 묶음이 조용한 수로 정리된 뒤 첫 두 번의 봇 착수는 기물 반환 예외를 허용하지 않고 위치·공격 속도를 조절한다. 정리 전에는 stage 0으로 압력만 완화한다. 세 번째·네 번째에는 주의·중단 보호가 없을 때만 예를 들어 룩으로 작은 기물을 잡고 되잡히는 불리한 교환처럼 제한된 보상을 허용한다. 추가 실수로 회복 시계를 계속 뒤로 미루지 않는다. 일부를 돌려줬다면 남은 재료 차이만 대상으로 하고, 완전히 보상받으면 종료한다. 새 에피소드는 40번째 수까지 발생한 큰 손실만 대상으로 한다. 이후에는 기존 회복을 점차 줄이고 70번째 수부터는 수를 양보하지 않는다. 조건이 맞지 않으면 실제 기물 반환은 하지 않는다.

기물 보상의 조건은 실제 포획 이득이 이동 기물 가치의 절반 이상이며 최소 300cp, 예상 즉시 손실은 남은 보상량 및 400cp 이내다. 퀸을 그냥 내놓거나 폰 하나와 바꾸는 수는 허용하지 않는다. 비교·최신 평가의 -100cp 하한, 즉시 메이트 방지, 교환 뒤 마지막 승리 수단 보호도 적용한다. 사람이 자연스럽게 느낀다는 입증은 별도로 필요하다.

## 너무 이른 전력 전환을 피하는 2단계 보호

기물 수의 문턱은 공식 메이트 가능 판정과 다르다. 공식 죽은 국면은 어떤 합법 수순으로도 메이트가 불가능한지를 기준으로 한다. 룩 하나가 남았다고 메이트 불가능인 것도 아니다. [FIDE 규칙 5.2.2](https://handbook.fide.com/chapter/e012023).

1. **주의**: 양쪽의 킹·폰을 제외한 기물 가치 합이 20점 이하이거나 봇의 해당 기물이 두 개 이하이면 지연 기물 보상만 막는다. 자연스러운 위치 조절은 계속한다.
2. **양보 중단**: 40수까지 폰만 남은 종반, 양쪽 합계 비폰 기물이 두 개 이하이고 폰이 네 개 이하인 단순 종반, 또는 폰 없는 국면에서 봇에게 신뢰할 만한 메이트 수단이 없는 경우에는 기준 최선수를 유지한다. 한번 걸린 중단은 이후 승격으로 갑자기 해제되지 않으며, 무르기는 남은 기보에서 다시 계산한다.

이는 실험용 보호 기준이며 무승부 판정이나 강제 승리 증명이 아니다. 예를 들어 퀸 없는 룩+나이트와 여러 폰의 종반은 주의 단계만 적용해 위치 양보를 계속한다. 40/70수 일정의 이름을 바꾸지 않고 예외 사유로 기록한다.

## 레이팅 추정과 사용자가 주는 정답

품질 관측은 실제 인간수와 그 직전 같은 위치에서의 기준수를 같은 완료 깊이로 비교한 유효 기록만 사용한다. 강제수·불완전 점수·다른 분기의 기록은 제외한다. 사용자 수마다 가능한 관측을 반영하지만, 확인되지 않은 수에 임의의 변화량을 만들지는 않는다. 인간의 마지막 수로 대국이 끝나 엔진 응수가 없거나 생각시간이 너무 짧으면 추가 관측이 없을 수 있다.

첫 모델은 최근 최대 40개 관측의 가중 평균 손실(80cp 사전값에 8개 관측의 가중치로 축소)을 단순 로그 함수로 100~4000 표시 범위에 옮긴 **휴리스틱 사전 추정**이다. 실제 Chess.com 래피드 대응 관계가 검증된 공식은 아니다. 정답이 쌓이면 같은 평가 엔진과 방법별로 완료 대국의 오차를 모아, 10게임의 사전 가중치를 둔 표본이 적을 때 강하게 축소한 가산 보정을 학습한다. 아직 배우는 것은 평균적인 보정이며 복잡한 개인별 기력 모델은 아니다.

실제 라벨은 기보 폴더 안 `.sparring-rating-private/labels.sqlite3`에 로컬 저장하고 Git에서 제외한다. 공개 sidecar·PGN에는 실제 점수를 넣지 않는다. 관측이 없거나 핸디캡 대국이면 라벨을 저장해도 보정 학습에서 제외한다. 라벨을 붙인 대국을 무르면 해당 학습 표본도 무효화한다. 저장된 추정 곡선은 보관함에서 당시 수순까지만 재생하며 미래 관측을 미리 보여주지 않는다. 추정 점수는 수 선택 정책과 분리했다.

## 시간과 검증

일반 스파링은 설정한 기준 탐색 시간을 보존하고 최대 2000ms의 보조 예산을 사용한다. 70수 이후와 양보 중단 보호 상태에서는 기준수를 바꾸지 않고, 레이팅 관측만 최대 500ms 추가한다. 후보 탐색 예산은 0이다. 설정 시간이 600ms 미만이면 추가 관측과 자동 조절을 보류한다. 전력이라는 표현은 수 선택을 약화하지 않는다는 뜻이며, 별도 관측 비용까지 없다는 뜻은 아니다.

정책 33개·지연 회복/보호 12개·레이팅 모듈 13개·레이팅 호스트/HTTP 12개·스파링 상태/기보 8개·대국 하네스 8개·집계 25개 검사가 통과했다. Godot 모드/레이팅 70개·시간 39개·게이지 56개, 웹 관련 검사도 통과했다. 실제 엔진의 여섯 역사적 위치 재검증에서는 모두 유한 CP 목표 범위의 수를 택했다. 이는 단일 위치 검증이며 대국 전체의 성공률이 아니다. 여섯 위치 기록의 Git 표시는 커밋 직전 dirty 작업본이지만, 기록된 소스 파일 해시가 위 31715bf의 파일과 일치함을 별도로 확인했다.

[8판 외부 대국 결과·원본 기보·독립 감사](../../matches/2026-11-03-sparring-v2/README.md)를 남겼다. 결과는1승5무2패이며 모두40수에 도달했지만 연속 ±100cp 목표는0/8판으로 미달이다. 기존 v1 기록과 정책/일정은 그대로 읽을 수 있다. 작은 표본의 승패나 자체 평가를 인간 레이팅·학습 효과·자연스러운 체감의 검증으로 해석하지 않는다.
