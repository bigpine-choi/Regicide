# 클릭 시계 조절과 잔여 3분 시간 관리

2026-11-03. 시간제 스파링의 자동 생각시간을 유지하면서, 대국 중 양쪽 남은 시간을 클릭으로 조절한다. Godot와 브라우저의 **남은 시간 조정**을 펼치면 나와 Regicide 각각에 **−1분 / −10초 / +10초 / +1분** 버튼이 나온다. 숫자 입력은 필요 없다.

`regicide-engine-pacing-v8`의 시간 압박 시작점은 잔여 **3분 미만**이다. 정확히 180,000ms에서는 압박 계수 1이며 그 아래에서 연속적으로 감소한다. 사람 권장시간을 바탕으로 한 기본 배분, 짧은 오프닝 시간, 0.1초 목표의 쉬운 선택, 드문 긴 장고, 1초 단축, 10초 이하 추가 대기 생략과 20수 접전·21~69수 등차 강화·70수 전력 일정은 유지한다.

## 동작과 기록

- 서버가 클릭 시점까지 흐른 시간을 먼저 차감하고 선택한 시계에 가감한다. 시계만의 변경 번호로 중복 클릭·늦은 응답을 판 상태와 분리해 검증한다. 한 시계는 0~24시간 범위로 조절한다.
- AI 탐색·대기 중에도 조절한다. 현재 착수의 누적 생각시간을 초기화하지 않고, 최신 잔여시간으로 대기 목표를 재계산한다. 이미 시작한 자체 엔진 탐색을 새로 시작하지는 않으며, 시간이 줄어든 경우 현재 탐색에 중지를 요청해 합법 응답을 회수한다. 시간패 감시는 변경 전 고정 만료 시각 대신 현재 시계를 읽는다.
- 사용자 시간 0은 계속 진행한다. Regicide의 가동 중 시계가 0이면 시간패이며 끝난 대국을 시간 추가로 되살리지 않는다. 아직 차례가 아닌 Regicide 시계는 차례가 오기 전에 다시 늘릴 수 있다.
- 변경 내역은 JSON에 순서대로 남기고, PGN에 시간 조절 연습 대국이라는 표시를 넣는다. 완료한 수의 과거 `%clk`를 덮어쓰지 않는다. 무르기는 남겨진 수 완료 시점으로 시계와 변경 이력을 함께 복원한다. 복기·핸디캡 미리보기·종료 상태에서는 시계 조절을 막는다.

## 검증 범위

검증은 임시 게임과 통제된 시계·응답, 별도 실제 엔진 HTTP 실행을 사용한다. 사용자의 진행 중 대국을 재시작하거나 수정하지 않았다. 테스트 결과와 실제 엔진 실행 조건은 이 폴더의 JSON 및 로그에 기록한다. 화면 캡처는 실제 Godot 화면에 합성 상태를 넣은 오프라인 렌더이며 실대국 장면이 아니다.

기존 회귀 검사는 [python-regression.json](python-regression.json), 브라우저 동작 검사는 [web-validation.json](web-validation.json)에 기록했다. 생략된 검사는 로그의 이유를 따른다. 이 작업은 시계 조절·저장·동시 요청·시간 배분 기능 검증이며 기력 향상이나 사람과 같은 사고 패턴의 입증은 아니다.

기존 Python 회귀 250개 중 247개 통과, 바이너리 인수를 따로 요구하는 2개와 이 OS 계정에서 심볼릭 링크 생성이 필요한 1개는 생략했다. [실제 엔진 HTTP 검증](native-clock-adjustment.json)은 백·흑 각각 AI 생각 중 양쪽 시간 변경, 3분 아래로 줄여 압박 계수 감소, 시간을 다시 늘려 계수 1 복원, 합법 응답 및 저장 복원을 통과했다. 별도로 양 색에서 사용자 0초 후 착수 가능과 Regicide 0초 종료·부활 차단을 확인했다. 이 테스트는 별도의 임시 보관함과 현재 실행 바이너리를 사용했고 테스트 엔진과 서버 종료까지 확인했다.

추가 [시계·호스트 집중 검사 68개](core-host-summary.json)도 모두 통과했다(기존 회귀와 중복 포함). 새 검사 35개는 대기 목표 가감, 계산 도중 중지, 변경 전 만료 시각을 넘긴 시간 추가, 동시 클릭 충돌, 무르기·핸디캡 보존 등을 다룬다. 40반수 동안 분수 밀리초 간격으로 1,000번 시계를 조절하는 스트레스 검사를 양 색에서 수행했고, 저장 기록과 PGN 재구성을 확인했다. [독립 검토](core-host-audit.md)에 조건과 한계를 남겼다.

[Godot UI 248개 검사](godot-and-native-summary.json)와 브라우저 관련 5개 검사 파일이 통과했다. [900폭 화면](godot-click-clock-synthetic-900.png)과 [1240폭 화면](godot-click-clock-synthetic-1240.png)을 렌더하고 버튼의 겹침·잘림 여부를 확인했다. 실제 UI 수동 클릭 대국은 수행하지 않았으며, 실제 HTTP 검사는 버튼과 같은 요청을 전송한다.

기존 바탕화면 Regicide 바로가기가 이 저장소의 실행 스크립트를 가리키는 것을 확인했다. 실행 중인 프로그램은 그대로 유지하며, 종료 후 다시 실행하면 새 기능을 사용한다.
