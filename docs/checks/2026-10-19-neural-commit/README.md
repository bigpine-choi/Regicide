# 대국·결정적 위치 분석 커밋 연결 기록 — 2026-10-19

이 문서와 함께 저장하는 범위는 1/32 모델의 동일 시간 대국 32판, 결과가 바뀐 기보의 17위치·280회 진단, 실행·감사 도구, 기보와 원시 검증 기록이다. 기본 평가기는 기존 것을 유지하며 엔진 소스·학습 모델은 변경하지 않았다.

원래 보고서·프로토콜·manifest의 `미커밋`, `Uncommitted` 표기는 측정·분석 당시의 작업 트리 상태다. 사용자 요청에 따라 이번 저장 범위를 현재 브랜치에 함께 커밋해 원격으로 보존한다. 실제 완료 커밋은 이 파일의 Git 이력으로 식별한다.

커밋 준비 과정에서 다른 운영체제의 체크아웃도 같은 파일 해시를 복원하도록 줄바꿈 속성을 명시했다. 측정 입력에 포함된 기존 파일의 바이트는 그대로 유지했고, 동결 입력이 아니었던 최상위 .gitattributes와 이를 가리키는 최종 manifest 메타데이터만 갱신했다. 원래 측정 시점 manifest 두 개는 이 폴더에 바이트 그대로 별도 보존했다. 원시 기보·검색·CPU·UCI 로그와 사전 고정 프로토콜은 수정하지 않았다.

새 대국이나 모델 학습은 커밋 단계에서 실행하지 않는다. 기존 엔진 규칙·모델 검증은 기록된 통과 결과와 동일 소스 해시로 연결하며, 도구 단위 검사와 변조 거부 검사, 실제 기록의 독립 감사 및 Git 저장본 해시를 다시 확인한다.
