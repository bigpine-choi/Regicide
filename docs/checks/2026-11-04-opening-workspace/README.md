# 상시 오프닝 패널과 가독성 개선

Godot 기본 창을 1760×960으로 넓히고 430px 오프닝 패널을 보드와 대국 도구 옆에 배치했다. 켜기/끄기를 없애고 현재 위치를 자동 조회한다. 작은 창에서는 패널을 아래로 배치한다. 저장된 연결 복원과 숨겨진 분석창의 조회 중단을 보존한다.

통계행은 76px로 키웠다. Godot 주요 글자는 16px이며 웹은 수 표기 18px·주요 안내 14px를 사용한다. 분석 화면의 긴 오류문구가 보드를 밀어내던 문제도 3줄 요약과 전체 툴팁으로 수정했다.

[전체 검증 결과](verification.json): Godot 오프닝 40, 렌더·레이아웃 23, 실제 로컬 HTTP 17, 오프닝 안내 51, 분석 88, 분석 레이아웃 272개 검사 통과. 웹 오프닝 17, 사이드바 5, 안내 12개 사례 통과.

렌더링·HTTP의 통계는 합성 테스트 응답이다. 실제 인증 리체스 조회나 웹 브라우저 픽셀 검증으로 주장하지 않는다. 사용자의 진행 중 대국과 저장된 연결은 변경하지 않았다.
