# 자동 착수 시간과 명백한 선택의 빠른 판단

2026-11-03. 시간제 대국에서 Regicide는 자신의 착수 전 국면을 사람 관점으로 평가한 권장 총시간을 기준으로 둔다. 매 차례의 목표는 국면별 기본값에 시간 변동을 더해 정한다. 탐색과 요청 대기에 이미 쓴 시간을 포함하며, 수를 고른 뒤 부족한 시간만 기다린다. C++ 엔진이 수를 고르는 원칙은 유지한다.

## 스파링의 자동 시간 관리

스파링을 선택하면 수동 AI 생각시간 대신 **AI 시간 관리 · 자동으로 조절**을 표시한다. 현재 스파링 대국에서 다음 대국의 모드 선택만 바꿔도 수동 시간 설정 요청을 보내지 않는다. 새 스파링 대국은 수동 시간 값을 보내지 않으며, 호스트도 시간제 스파링의 수동 변경을 거부한다. 기본·보스 모드의 설정은 기준 탐색 상한이며 시간제 대국에서는 잔여 시간에 맞춰 줄어들 수 있다.

시간제 대국에서 착수 간격은 공통 권장 시간을 사용한다. 잔여3분 미만부터 해당 시점의 추천 총량에 `0.5 + 0.5 × 잔여시간/180초`를 곱해 추가로 줄인다. 추천식 자체도 잔여시간을 반영하므로 두 효과가 합쳐진다. 다음 증분을 현재 잔여시간으로 쓰지 않고, 계산·착수 완료 여유를 남긴다. 10초 이하에서 인위적인 대기를 없애는 것은 마지막 보호 장치이며, 그 전부터 탐색과 대기를 줄인다.

스파링의 기준 탐색은 전체 사용 가능 시간의 약3분의1로 자동 배분하고 최대3초로 제한한다. 남은 부분에 부가 검토와 대기를 배분한다. 부가 검토가 예산에 들어가지 않거나 관측에 필요한 기준 탐색600ms를 확보하지 못하면 기준 수를 사용하며 생략 이유를 기록한다. 시간 압박에서 기력 조절·상대 관측의 정밀도를 유지한다고 주장하지 않는다. 시간제 없는 기존 연구용 호출은 통제 실험을 위해 지정된 탐색시간을 유지한다.

기다리는 동안 실제 대국 시계는 계속 흐른다. 별도 조회는 응답하며, 시간 초과·종료·위치 변경 뒤에는 늦은 착수를 적용하지 않는다. 창을 닫으면 현재 차례의 인위적 대기를 해제하고 저장·종료를 진행한다. 시간 관리는 시간패 위험을 줄이는 기능이며 운영체제 정지나 엔진 장애까지 포함해 시간패를 불가능하게 만드는 보장은 아니다.

## 사람의 빠른 결정 반영과 착수 리듬

대표 오프닝의 정확한 배치이며 전술 경고가 없으면 사람 권장 총시간을 최대2초로 낮춘다. 합법 응수가 하나면1초, 즉시 메이트는2초, 퀸 포획 후 즉시 반박이 없는 명백한 이득은2.5초가 상한이다. 기존50% 계산과 낮은 잔여시간 제한을 함께 적용한다. 단순히 초반이라는 이유로 할인하지 않는다. 퀸을 잡은 뒤 되잡기·체크·승격·다른 퀸/룩 손실 가능성 등이 있거나 검사 한도를 소진하면 할인하지 않는다. 가능한 포획 방식이 여러 개면 모두 검사에 통과해야 한다.

대표 수순은 직접 적은8개 짧은 수순이며 외부 오프닝 데이터베이스를 가져온 것이 아니다. 배치 일치에 기반하므로 실제 사용자가 외웠다는 뜻은 아니다. 포획 뒤 상대 한 수의 합법 반박을 확인할 뿐 더 긴 함정의 부재를 증명하지 않는다. 같은 위치의 결과는 캐시하며 실제 경과시간은 매 조회 새로 계산한다.

Regicide의 실제 목표 시간에는 새 대국의 난수 시드와 국면으로 재현 가능한 변동을 준다. 명백한 선택은 원래 권장량의0.4~1.0배, 높은 복잡도는0.8~1.3배, 그 외는0.65~1.35배이며 가운데 값이 더 자주 나온다. 이후3분 압박·45초 상한·현재 잔여시간 보호를 적용한다. 같은 차례를 조회한다고 목표가 계속 바뀌지는 않는다. 목표·변동 계수·대기 경과를 기록한다. 이는 실제 사람의 착수시간 데이터를 학습한 모델이 아닌 조정 가능한 휴리스틱이다.

## 30수부터 70수까지의 강도

새 정책은 `regicide-sparring-play-v3`다. 30수까지 접전, 31수부터 강도 계수 `(수번호−30)/40`을 적용하며70수부터1이다. 즉31수2.5%,40수25%,50수50%,60수75%,69수97.5%,70수100%로 백·흑 모두 매 수2.5%포인트씩 오른다. 양보 계수는 반대로 같은 폭으로 줄어든다. 내부 제어계수의 등차 증가이며 실제 Elo가 같은 폭으로 증가한다는 주장은 아니다. 대국 상황·시간 압박·기존 자원 보호 예외에 따라 실제 선택은 달라질 수 있다.

기존 v1/v2 기보는 각 버전의 단계와 통계 기준으로 계속 해석한다. 새로운30수 정책의 완주 승률이나 Elo 대결은 수행하지 않았다.

## 사용자 시간 소진은 대국을 끝내지 않는다

새 시간제 연습 대국은 `timeout_policy=engine_only`다. 사용자는 시계0이어도 계속 착수할 수 있고, UI는 **내 시간 소진 · 계속 진행**으로 표시한다. 추천 시간만 중지하며 복잡도 안내는 유지한다. 초과 소비는 음수 잔액으로 쌓지 않고0으로 처리한다. 10+5/15+10에서는 다음 합법 착수 뒤5초/10초가 회복된다.

Regicide가0이면 사용자 승리로 끝나며, 이 학습 규칙에서는 상대 메이트 기물 부족에 따른 시간패 무승부 예외를 적용하지 않는다. 메이트·기권·정상 무승부 판정은 별개다. 기존 양쪽 시간패 규칙으로 저장된 기보는 그대로 해석한다. JSON/PGN에 시간 정책을 기록하며, 복기는 사용자 초과 시간·증분·정책과 사용자 색의 일치를 독립 검증한다.

이전 [시계 최초 구현](../2026-11-03-rapid-clock/README.md)과 [총 권장시간50% 조정](../2026-11-03-half-time/README.md)의 기록은 해당 버전 당시의 증거다. 새 기능은 재실행한 Regicide에 적용하며 이미 실행 중인 사용자의 대국을 중단하지 않는다.
