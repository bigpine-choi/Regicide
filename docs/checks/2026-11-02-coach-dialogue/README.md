# 짧은 영어 해설과 자동 음성

## 변경 이유와 참고

이전 루크는 수 분류를 반복하고 현재 착수와 먼 예상 수순의 사건을 함께 설명했다. 실제 저장된 38반수 보고서에서 23개 대사가 같은 칭찬으로 시작했고, 중앙 폰 전진에 9반수 뒤 포획을 붙이거나 퀸 포획을 기물 점수 산식으로 설명하는 사례를 확인했다.

Chess.com의 공식 [코치 설명 개선 안내](https://www.chess.com/news/view/chesscom-launches-game-review-v2)와 [2024년 화면 예시](https://www.chess.com/news/view/game-review-design-update)를 확인했다. 구체적인 기물·위협·응수의 결과를 짧게 설명하고 수순은 보드에서 확인하는 방식을 참고했다. 원문 대사, 캐릭터, 이미지나 외부 엔진을 제품에 복제하지 않았다.

사용자가 영어 사용과 간결한 설명, 수를 넘길 때 자동 음성을 요청했다. 메뉴와 수 분류는 한국어를 유지하며 코치의 대사·힌트·근거·총평은 영어다.

## 동작

- 실제 착수와 합법 예상 수순에서 백·흑, 기물, 포획, 체크·메이트를 다시 계산한다. 저장된 SAN이나 수의 주체를 그대로 믿지 않는다.
- 긍정적인 수는 착수와 바로 다음 응수, 실수는 첫 4반수 안의 주요 포획을 우선한다. 멀리 있는 포획·캐슬링은 말풍선과 근거 목록에서 제외한다. 메이트 수순은 즉각적인 메이트와 이후 예상 수순을 구분한다.
- 기물 포획은 그 수순에서 일어난 사건이며 강제적인 순이득이라고 단정하지 않는다. 상대의 되잡기도 설명한다. 확인하지 않은 포크·핀·전략적 의도는 추가하지 않는다.
- 다시 두기 힌트에는 추천 수의 SAN/UCI/도착 칸을 넣지 않는다. 저장된 분석도 재사용 시 최신 해설을 다시 구성하므로 평가 재계산은 필요하지 않다.
- 자동 음성은 기본 켜짐이며, 300ms 뒤 최신 국면만 읽는다. 같은 화면 갱신과 진행률 갱신은 중복 발화를 만들지 않는다. 이전 음성은 취소하고 현재 설명을 읽는다.
- 실제 수순 자동 재생 중에는 읽지 않고 목표 국면에 도착하면 읽는다. 코칭 종료·화면 숨김·기보 교체 시 예약과 발화를 취소한다. 숨긴 재도전 정답을 읽지 않는다. 음성 켜짐/꺼짐과 현재 읽기 중지를 지원한다.
- Godot는 설치된 영어 음성을 사용하고, 브라우저는 로컬 영어 음성만 사용한다. 음성이 없으면 텍스트는 유지한다.

## 실제 검증

- `tests/coach_explanations_tests.py`: 12개 통과. 영어·길이·불법/불일치 PV·양측 관점·교환·메이트·특수수·추천 힌트 비노출.
- `tests/character_coach_tests.py`: 20개 통과. 캐시 대사 재생성 및 재도전 격리 등.
- `tests/coaching_tests.py`: 25개 통과. 기존 평가·배지·캐시·취소 동작.
- `tests/coaching_http_tests.py`: 자체 Regicide 실행 파일과 폐기용 기보로 11개 검증 그룹 통과. 합법 수순, 영어 40단어 이내, 캐시, 재도전, 기존 대국/분석/저장 파일 보존. `http.json`에 기록.
- Godot: 사용자 프로젝트와 분리한 복사본에서 창 없는 장면 검사 399개 통과. 실제 Timer와 음성 출력 대역으로 자동 읽기·빠른 전환·중복 방지·음소거·재도전·종료를 검증했다. 세 화면 크기에서 보드 크기 변화 최대 0px. `native.json`에 기록.
- 브라우저: 코칭 62개와 기물 이동 21개 통과. 음성 합성 대역을 사용했으며 실제 오디오는 재생하지 않았다.
- 기존 개인 대국의 38반수를 읽기 전용으로 점검: 새 대사 12~19단어, 평균 13.58단어. 대표 5개 장면은 12~16단어. 기보 원본 해시는 전후 같았다. 개인 기보·대사 샘플은 버전 관리에서 제외한 로컬 `build/`에만 두었다.
- Windows 음성 목록에서 활성화된 영어 `Microsoft Zira Desktop (en-US)`를 확인했다. 실제 사용자 게임을 조작하거나 종료하지 않았고, 스피커 출력 청취 검증은 하지 않았다.

분석 엔진·수 선택·수 분류 기준은 바꾸지 않았다. 이 검증은 해설과 화면/음성 제어의 동작에 관한 것이며 경기력 검증이 아니다.
