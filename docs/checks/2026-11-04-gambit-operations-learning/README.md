# 희생 후 운영: 자체 대국 연습과 분석 기억

2026-11-04 실행. 이번 산출물은 희생 후 실제로 둔 자체 대국 분기와 **정확히 연습한 위치의 분석 기억**이다. 새로운 신경망이나 미학습 국면에 일반화된 전략 모델로 표시하지 않는다. 앞서 품질 기준에 못 미쳤던 `data/gambits/policy.json`은 계속 실험·비활성 상태로 유지했다.

## 실제 연습 조건

- 커리큘럼 48개 중 계열별 첫 운영 위치와 오프닝 자료 끝 위치를 한 개씩 사전 선택했다. 12개 계열·24개 분기이며, 선택할 때 엔진 점수를 보지 않았다. 모든 시작 위치는 실제 희생 포획과 순기물 부족이 확인되고, 해당 진영 차례다.
- 각 분기에서 갬빗 진영의 **8착수**를 실제 수행하고, 상대도 별도의 현재 국면 자체 분석에서 찾은 수로 응수했다. 전술적으로 가장 정확한 방어를 증명했다는 뜻은 아니며, 제한된 Regicide 탐색의 최선 응수다.
- 실제 Regicide 실행 파일 SHA256: `5011da4c5e6ef01c452bd7125e4e22b372d2c9cfb858ed8759057325acb0e6ba`. 현재 앱 기본 옵션과 기물 활동성 평가(`UsePieceActivity=True`), 기본 Hash 16MiB를 사용했다. 바이너리나 사용자 대국은 교체하지 않았다.
- 각 현재 위치의 기본 수와 최대 세 후보를 **쿼리당 고정 100,000노드 요청**으로 분석했다. 전체 합법 수 이력을 전달하고 매 쿼리마다 새로운 UCI 대국으로 탐색 표를 초기화했다. 766개 쿼리의 요청 합계는 76,600,000노드다. 개별 실제 노드 수·깊이·시간은 원본에 남겼다.
- 실제 플레이는 현재 위치의 자체 기준 수와 그 수를 둔 뒤 상대의 자체 기준 수로 진행했다. 나머지 후보의 예상 수순은 `native_search_pv_not_additional_played_game`으로 구분했다. 외부 엔진의 수나 평가를 연습 정답에 사용하지 않았다.
- CP가 정확하게 완료되고 깊이 4 이상이며 합법적인 상대 응수가 있는 후보만 기억에 넣었다. 메이트·경계값·불완전 분석을 CP 값으로 바꾸지 않았다.

`native-v1/predeclared.json`에 전체 시작 수순·출처·분리·노드·시드·소스 해시를 분석 전에 고정했다. 시드는 재현용 정수 `20261105`이다. 커리큘럼의 출처는 고정된 CC0 Lichess 자료와 별도로 표시한 프로젝트 작성 연습 응수다.

## 수행 결과

**24개 분기 모두 8착수**, 총 갬빗 진영 192착수·양쪽 실제 384반수를 수행했다. 24개 기보 결과는 모두 `*`인 미완료 분기다. 완주한 24판, 승률 또는 Elo 측정으로 환산하지 않는다. 실제 쿼리 경과 시간의 합계는 약 290.052초이며 프로그램 준비·파일 처리 시간은 별도다.

실제 두 수 뒤의 상태 변화로 분류한 연습 주제는 다음과 같다. 주제는 물질 차이·전개·왕 주변 위협·기물 활동의 관측값이며 올바른 전략이 보장됐다는 판정은 아니다.

| 관측된 주제 | 갬빗 진영 착수 수 |
| --- | ---: |
| 전개 | 35 |
| 공격 유지 | 13 |
| 기물 격차 회복 | 30 |
| 수비 전환 | 4 |
| 정리·안정화 | 110 |

원본 전체에는 깊이 4 이상 정확한 후보 목표값 555개가 있다. 이 중 **훈련·개발 계열의 160개 위치·460개 후보**를 실행용 분석 기억에 보관했다. Benko·From 계열의 32개 연습 위치는 검증 로그에만 남기고 실행용 기억에 넣지 않았다. 검증 계열의 현재 위치 및 **모든 합법적인 다음 위치**와 기억의 현재·후보 위치를 대조한 결과 중복은 0개다.

## 실행 경계

`scripts/gambit_practice_memory.py`는 실행 파일·평가기 ID, 전체 FEN, 실제 전체 수 이력과 기억 ID가 일치하는 위치에서만 후보를 반환한다. 새 수순·무르기·다른 평가기·불일치·손상 파일이면 기억을 적용하지 않는다. 이 표의 과거 CP 값은 출처 설명이며 현재 수의 안전 판정을 대신하지 않는다. 실제 착수는 별도의 현재 자체 탐색·동일 완료 깊이·기물 포획 검사를 다시 통과해야 한다.

`operations_memory.json`의 `approved`는 원본·이력·분리·분석 근거가 확인된 정확 위치 기억이라는 의미다. 신경망의 일반화, 모든 희생의 타당성 또는 기력 향상을 승인한 표시가 아니다. 미학습 Benko·From에서 기억 후보가 0개이고, 알려진 위치의 반환 후보가 원본과 일치하는 것을 실제 런타임 API로 확인했다.
