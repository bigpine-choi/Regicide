# v0.6.4 신경망 평가 비용 최적화 결과

**평가 점수와 고정 작업을 유지하면서 학습 V2의 전체 정적 평가 호출 비용을 약24%, 전체10,000노드 탐색 시간을 약4~5% 줄였다.** 같은100ms의 탐색 노드는 약6% 늘었다. 기본 수식 평가, 학습 가중치와 모델 채택 기준은 유지한다. 기력·Elo 향상을 입증한 대국 실험은 수행하지 않았다.

## 변경과 기준

- 기준 소스: `00dec89b08de4e5f573b18b440a93cd82f4b3311`(v0.6.3).
- 최적화/측정 소스: `7ee14504ea9c87fff6cef8731c86d97f23efa4b7`(v0.6.4).
- 기준 실행 파일 SHA256: `605681320aff062ba2878eece74f453bf6ee451f1faa223e74a18caece328e5a`.
- 새 실행 파일 SHA256: `ff63e5c1bb1aaa863f6bdaa19bfaf61c660350b88a702916b40372249f22f4b1`.

첫 층의 가중치를 모델을 읽을 때 `[뉴런][입력]`에서 `[입력][뉴런]`으로 재배치한다. 평가할 때 기물 하나의32개 가중치를 연속 읽어 독립 뉴런을 함께 갱신한다. 각 뉴런의 bias→보드칸0..63 덧셈 순서, double 정밀도와 ReLU 시점을 유지한다. 둘째·셋째 층·반올림·V1 제한·V2 수식 평가+100cp 보정은 그대로이며, V2에서는 쓰지 않는 별도 material 합만 생략한다. 모델 파일 형식과 엄격한 파서를 유지하고 캐시·증분 합산·정수화·빠른 수학 옵션은 도입하지 않았다.

[사전 계획](../../experiments/2026-10-19-neural-inference-opt-plan.md), [원리와 재현](../../NEURAL_INFERENCE_OPT.md), [측정 메타데이터](performance-metadata.json)를 함께 읽는다.

## 조건과 표본

AMD Ryzen AI7 350, 8코어/16논리CPU, Windows11 빌드26200, MSVC x64 C++20 `/O2 /DNDEBUG`의 기본 정밀 부동소수점 설정을 사용했다. 프로파일 드라이버·이전 참조·실제 평가 함수는 별도 번역 단위이며 LTO를 사용하지 않는다. Python3.13.16, python-chess1.11.2다.

평가 호출 비교는 기존42위치, 모델4개, 평가 옵션4조합의672개 점수 비교를 먼저 통과했다. 모델별 준비10,000회와 기준 함수만을 이용한 약150ms 분량 보정 후, 동일 반복 수로9블록×4쌍의 AB/BA 순서를 균형 배치했다. 모델 순서도 회전·반전한다. 원자료288개와 체크섬·블록별 요약을 [프로파일](profile.json), [별도 재계산](profile-audit.json)에 보존했다. V2 시간에는 기존 수식 평가도 포함되며 신경망 층만의 시간이 아니다. 파일 읽기·보드 파싱·동등성 검사·보정·출력 시간은 측정에서 제외했다.

실행 파일 비교는 개발용12위치,6회 반복, 시드20261019, 깊이3/10,000노드/100ms, Hash16MiB, 단일 탐색 스레드다. PVS·SEE·LMR·폰 방패·폰 구조 등 기존 옵션을 동일하게 켰다. 같은 전체 이력과 모델을 사용하고 매 검색 새 논리 대국/빈 TT로 시작했다. 두 프로세스는 지속 실행하며 시작/모델 로딩은 제외하고, 벽시계 시간에는 새 대국·준비 확인·UCI 통신이 포함된다. 위치별 이전/새 실행 순서는 각각3회다. [전체 조건과2,160검색](paired/comparison.json)을 참고한다.

## 속도 결과

각 수치는 모델 안에서 비교한 새/이전 비율의 중앙값에서 계산했다. 서로 다른 모델의 수치 차이를 모델 기력 차이로 해석하지 않는다.

| 동일 모델 | 정적 평가 호출 시간 감소 | 깊이3 전체 시간 감소 | 10,000노드 전체 시간 감소 | 100ms 탐색 노드 증가 |
|---|---:|---:|---:|---:|
| 학습 V1 | 25.74% | 4.94% | 4.61% | 5.68% |
| 이전 학습 V2 | 24.61% | 4.25% | 4.32% | 5.60% |
| 품질 개선 학습 V2 | 24.20% | 4.46% | 5.13% | 6.01% |
| 출력0 V2 | 24.40% | 3.27% | 6.30% | 5.53% |
| 수식 평가 대조군 | 해당 없음 | 1.83% | 0.54% | 1.13% |

이전/새 학습 V2의 호출 시간 중앙값은 각각516.42→390.85ns,516.25→390.86ns였다. 블록 시간 비율 범위는 이전V2가0.743~0.828, 품질V2가0.751~0.764였다.10,000노드에서는 각 위치의6회 중앙값이 이전V2 0.921~0.995, 품질V2 0.922~0.982로12위치 모두 줄었다. 얕은 깊이 측정에는 이전V2의 한 위치가 약6.7% 느린 경우도 있었다. 대조군의 작은 변동처럼 잡음이 있으며, 이 표본을 모든 위치·하드웨어의 보장으로 확대하지 않는다.

기본 실행은 수식 평가이므로 기본 대국이 약24% 빨라졌다고 하지 않는다. 이번 이득은 신경망 평가를 사용할 때의 비용 감소다. 같은 시간에 더 읽는 것은 기력 향상의 가능성이며 대국 기력 검증을 대신하지 않는다.

[평가 감시](profile-resource-guard.json), [검색 감시 원자료](paired/resource-samples.jsonl)를 보존했다. 측정은 UTC16:53:06~16:55:29에 완료했고 임시 절전 방지 요청을 해제했다. [종료 상태](power-state.json).

설치 전 v0.6.3 실행 파일은 로컬 `build/v063-before-neural-inference-opt/regicide.exe`에 백업했다. 검증한 v0.6.4 실행 파일과 설치 파일 SHA가 같다. 설치된 프로그램의13개 런타임 검사도 통과했다. 두 체크아웃의 학습 저장소105파일 전체 바이트가 같고 이전과 변함없다. 시도번호4, champion 없음, 기본 수식 평가를 유지한다. 최소32쌍·수당100ms·자원 감시·영속 시도별 alpha/점수 하한 등 채택 정책과 학습/보류 자료를 변경하지 않았다.

각 체크아웃의 기존 소스/모델/자료145개 보호 목록을 검사했다. 설치본 진단 JSON 한 개는 작업 전부터 CRLF가 남아 있었으며 내용은 기준과 같았다. 이번 설치 때 기준 LF 바이트로 복구한 한 건만 명시적으로 예외 처리했다. 복구 후 Git stat 캐시가 잠시 수정으로 표시해 설치 도구가 중단했으나 HEAD/인덱스/파일 객체가 동일함을 확인하고 같은 객체의 캐시를 갱신했다. 최종 소스·파일·학습 상태 검사는 통과했고 작업 트리는 깨끗했다. [설치 기록](installation.json), [설치 후 보호 검사](protection-after-install.json)를 참고한다.

## 증거와 재현

[sha256.json](sha256.json)은 공개 파일의 SHA256 및 원본→공개 해시를 기록한다. 실행 파일은 넣지 않고 코드/바이너리 해시와 빌드 방법을 남겼다. 사적 절대 경로 접두사만 치환했고 모델 바이트는 그대로다. 모델4개는 `models/`에 한 번씩 저장했으며 `paired/comparison.json`의 모델도 같은 바이트다. 위치 파일은 저장소의 `tests/data/evaluation_profile_2026_10_18.fens`, `tests/data/neural_diagnostic_positions_v1.json`이다.

저장소의 `scripts/profile_neural.cpp`, `scripts/profile_neural_audit.py`, `scripts/benchmark_neural_inference.py`와 [설명서](../../NEURAL_INFERENCE_OPT.md)로 재현한다. 함께 보관한 일회성 실행/설치/감사 도구는 작업 기록이다. 원래 `build/neural-inference-opt` 배치와 환경 경로를 복원한 뒤 사용한다. 이 결과에 모델 재학습·채택·기력 대국은 포함되지 않는다.
