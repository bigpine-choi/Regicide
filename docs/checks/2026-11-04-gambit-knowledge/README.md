# 갬빗 지식 확대: 실제 엔진 분기 검증

2026-11-04 검증. 지식 그래프는 실제 후보 검증에 적용했으며, 학습한 순위 모델은 홀드아웃 악화로 **실험 상태·미채택**을 유지했다. 이 기록은 외부 자료의 이름 수, 학습 적합도, 실전 경기력을 서로 다른 근거로 취급한다. 짧은 분기 검증을 완주한 대국이나 Elo 측정으로 표시하지 않는다.

## 실행 조건과 독립성

- 실제 Regicide 실행 파일 SHA-256: `5011da4c5e6ef01c452bd7125e4e22b372d2c9cfb858ed8759057325acb0e6ba`. 활성 실행 파일을 교체하지 않았다.
- 갬빗 측은 실제 `HumanGame` 경로로 착수한다. 기준 탐색 1000ms, 기존 추가 검증 상한 1000ms, 1스레드·Hash 16MiB·기물 활동성 평가를 사용한다. 시계 없는 연구 호출로 연출 대기를 제외하고 기존 고정 탐색 예산을 비교한다.
- 상대도 별도의 실제 Regicide이며 750ms를 사용한다. 첫 수락·거절 및 일부 조건부 방어만 사전에 정한 합법 수다. 이후에는 상대 엔진이 자유롭게 착수한다.
- Stockfish 18은 선택이 끝나고 저장된 수를 검증할 때만 사용한다. 1스레드·Hash 32MiB·약화 없음. 같은 루트의 제한 없는 탐색과 선택 수 제한 탐색을 각각 최대 250ms·깊이 12로 실행해, 공통 완료 깊이의 정확한 점수끼리 비교한다. Stockfish의 수는 어느 플레이어의 착수로도 사용하지 않는다.
- 각 분기는 갬빗 측 실제 착수 4회로 제한했다. 기보 결과 `*`는 미완료 그대로 남겼다. 시험용 대국과 엔진만 생성·종료했고 사용자 대국·기존 프로세스에는 접근하지 않았다.
- 시스템 정보, 원본 UCI 검색·반환, 전체 수 이력, PGN, 각 수의 정책 영수증과 외부 검증 패킷을 보존한다. 다른 개발 작업이 병행될 수 있어 전용 기계에서의 속도 비교는 아니다.

## 비교 전 선언과 기존 기준

`baseline-source.zip`과 `baseline-source-manifest.json`은 지식·학습 통합 이전의 실행 가능한 Python 소스와 오프닝 자료 217개 파일을 보존한다. `validation-harness-v1.py`와 해시는 같은 검증기의 복사본이다.

`predeclared/fixtures.json`은 엔진 답을 보기 전에 고른 10개 분기다. 에번스 수락·거절·조건부 방어·드문 응수, 스태퍼드 수락·거절·조건부 방어, 벤코 수락, 모라 거절, 블랙마 전치를 포함한다. 에번스·스태퍼드 전체 계열은 순위 모델의 훈련·조정에서 제외한 계열이다. 다른 사례는 해당 학습 계열의 기능 확인이며 미학습 일반화 시험으로 세지 않는다.

기존 엔진이 에번스에서 `5.a3`를 선택해 사전 선언한 `5.c3 Ba5` 조건부 분기가 발생하지 않았다. 이를 숨기거나 강제로 다른 수를 두지 않았다. 그 결과를 확인한 후, 수정된 엔진 결과를 보기 전에 `supplemental-predeclared/fixtures.json`에 두 개의 별도 작성 시작 국면을 선언했다. 에번스 `5.c3 Ba5` 이후의 작성 국면과 퀸스 갬빗의 확인된 전치 국면이다. 이 시작 수순을 엔진이 실제 선택한 것으로 집계하지 않는다.

기존 기준은 12개 분기·실제 48착수에서 기능 검사를 전부 통과했다. 외부 점수 비교도 48개 모두 공통 완료 깊이 12를 확보했다. 원본은 `native-before-v1/`, `native-before-supplement-v1/`, 요약은 `baseline-summary.json`에 있다. 소스·실행 파일 해시는 실행 전후 일치하며 시험용 엔진은 모두 정리됐다.

에번스 원래 수락과 조건부 방어가 실제로 같은 경로를 지나므로 이들은 독립 표본이 아니다. 동일한 분기 수나 평균 외부 손실만으로 일반적인 기력 개선을 주장하지 않는다.

## 수정 후 비교

`after-source.zip`과 manifest에 최종 소스·오프닝 자료·실험 모델 226개 파일을 고정한 뒤, 같은 검증기·시작 수순·시드·시간 한도로 수행했다. `native-after-v1/`과 `native-after-supplement-v1/`의 **12개 분기·실제 48착수 전부 기능 검사를 통과**했다. 소스·실행 파일 해시는 실행 전후 일치했고, 최종 작업 파일과 스냅샷의 차이도 0개다. 모든 시험용 엔진을 정리했다.

[최종 지문·모델 상태·엔진 정리 확인](verification.json)에 실행 검증기와 보존본의 일치, 두 소스 ZIP 및 네 실행 결과의 해시를 함께 기록했다.

[전후 비교 원본](comparison.json)과 [요약 생성기](compare.py)에 다음을 구분해 기록했다.

- 지식 경로를 사용한 실제 착수는 13회다. 이 중 5회는 자체 기준 수가 이미 자료의 후보였고, 8회는 자료 후보를 자체 엔진으로 검증해 기준 수 대신 선택했다.
- 교체된 8회 모두 자체 평가 손실 1~33cp와 즉시 포획 검사를 통과했다. 같은 루트에서 독립 Stockfish가 측정한 손실은 0~57cp였다. 자체 점수와 외부 점수의 수치를 빼거나 동일한 단위의 정답으로 취급하지 않는다.
- 실험 순위 모델의 실제 활성·순서 변경은 모두 0회다. 영수증은 `experimental_model`을 기록했다. 이 대국 결과를 학습 모델의 경기력 개선 증거로 사용하지 않는다. 훈련과 미채택 근거는 [학습 기록](../2026-11-04-gambit-learning/README.md)에 있다.
- 수정 후 Stockfish 검사는 47회가 공통 완료 깊이 12, 1회(에번스 거절 뒤 `Nxe5`)가 시간 한도 내 공통 완료 깊이 11이었다. 깊이를 맞춰 비교한 정확한 점수만 사용했고, 미완료 탐색을 깊이 12로 표시하지 않았다.
- 표본에서 150cp 초과 외부 손실은 기존·수정 후 모두 0회였다. 기존·수정 후 모두 최대 손실은 138cp였으며 자료가 끝난 모라 분기의 자체 기본 탐색에서 관측됐다. 이 작은 표본은 모든 기물 헌납을 배제하는 보장이 아니다.

같은 에번스 수락 국면에서는 기존 `5.a3` 대신 실제 `5.c3`를 선택했고 외부 손실은 117cp에서 3cp로 줄었다. 그 뒤 중앙 전개와 캐슬링을 실제 선택했으며 원래 선언한 `...Ba5` 조건부 방어도 도달했다. 반면 별도 `5.c3 Ba5` 시작 국면에서는 기존 `Qb3` 대신 `O-O`를 선택하며 외부 손실이 31cp에서 57cp로 늘었다. 각각의 제한된 국면 관측이며 전체 기력의 개선·악화로 일반화하지 않는다.

모라 거절과 블랙마 전치의 일부 시작 위치는 카탈로그 후속 수가 끝난 위치다. 새 수순을 발명해 붙이지 않고 자체 기본 경로로 계속 둔 것을 확인했다. 퀸스 갬빗 전치에서는 자료상의 전치 후보를 인식하지만 실제 착수는 자체 검증 결과를 따른다. 자료의 후보를 반드시 강제로 두는 기능이 아니다.

전체 외부 손실 평균이나 착수 시간 중앙값은 참고값으로만 JSON에 남겼다. 분기별 실제 수순이 갈라지므로 후속 위치는 동일하지 않으며, 지식 자료와 모델의 순수 기여를 분리한 기력 실험도 아니다.

루트 통합 회귀는 같은 폴더의 `root-regression-final.json`(155개 통과, 마지막 캐시 식별 수정 이전)과 `model-cache-followup.json`(최종 소스에서 관련 31개 통과)에 기록했다. 웹 갬빗 모드 검사도 통과했다. 이 회귀와 위의 실제 엔진 분기 검증은 별개의 근거다.

재현 명령의 실제 실행 파일은 활성 경로를 명시하고, 결과 경로는 매번 새로 사용한다.

```powershell
.venv-tests\Scripts\python.exe tests/gambit_knowledge_validation.py --source-root <비교할 소스 루트> --binary <활성 Regicide 실행 파일> --stockfish build-m2-opponents/stockfish18/package/stockfish/stockfish-windows-x86-64.exe --fixtures docs/checks/2026-11-04-gambit-knowledge/predeclared/fixtures.json --output <새 결과 경로>
```
