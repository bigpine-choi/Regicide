# 권장 생각시간 50% 조정

2026-11-03. 사용자의 요청에 따라 기존 권장 총 생각시간을 50%로 줄였다. 기본·보스·스파링 모드의 Godot/웹 화면은 공통 계산 결과를 사용하므로 함께 적용된다. 실행 중인 대국은 유지하고 다음 Regicide 실행부터 새 계산을 사용한다.

기존 배분·예비 시간·긴급 상한 계산이 끝난 뒤 총예산을 절반으로 줄이고, 이미 생각한 실제 경과 시간을 뺀다. 예를 들어 기존 총30초·이미10초 사용은 새 총15초·앞으로5초다. 최대 총예산도90초에서45초로 줄어든다. 복잡도 점수, 실제 대국 시계, 증분, AI 생각시간 설정은 바꾸지 않았다.

계산은 정수 밀리초 단위로 내림한다(최대0.5ms 차이). 기존 화면의 초 단위 올림 표시는 유지하므로 표시 숫자는 반올림 때문에 정확히 절반처럼 보이지 않을 수 있다. 안내 방법 식별자는 `regicide-human-decision-support-v2`로 구분한다.
