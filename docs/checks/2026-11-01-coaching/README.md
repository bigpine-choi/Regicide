# 최초 대국 코칭 검증

Regicide의 제한 시간 탐색으로 같은 위치의 최선 후보와 실제 착수의 평가·응수를 비교합니다. 엔진 실행 파일은 변경하지 않았습니다. 자체 엔진의 분석 기능이며 객관적 완전해 또는 기력 향상을 주장하지 않습니다.

- `backend/`: 흑백 관점, 메이트, 특수 수, 취소·교체, 캐시 검증 및 실제 엔진 기록.
- `http-evidence.json`, `fools-mate-report.json`: 실제 엔진과 인증된 HTTP를 통해 g4의 메이트 허용, Qh4# 추천, 모든 반환 수순의 합법성, 캐시 일치, 취소와 원본 보존을 검증.
- `godot/`: 네이티브 코칭 화면·실제 엔진 연결·세 창 크기에서의 안정된 보드 배치.
- `web/`: 브라우저 동작 검사. 당시 실제 브라우저 준비 화면까지만 확인하고, 사용자 Escape로 수동 컴퓨터 검수는 중단했습니다.

검증용 기보와 별도 저장 폴더를 사용했습니다. 사용자의 대국 파일을 수정하지 않았습니다. 이후 양쪽 기본 코칭, 실제 수순 이어 보기, 이동 효과와 보관함 개선은 [후속 검증](../2026-11-01-coaching-motion/README.md)에 기록합니다.
