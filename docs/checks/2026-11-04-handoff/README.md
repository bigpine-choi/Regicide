# 2026-11-04 로컬 개발 마감

한국 시간 2026-11-04에 아직 커밋하지 않은 개발 코드·자료·검증 결과를 함께 보존했다. 앞선 저녁부터 이어진 11월 3일 실험 원본도 포함한다. 코드 신뢰성과 실제 수행 기록을 함께 보관하며, 실패·중단·미채택 실험을 성공으로 바꾸지 않는다.

## 주요 변경

- 스파링 첫 20수 균형·기물 손실 검사와 21~49수 압박·양보 감소, 5분 이하 시간 관리.
- 기본·갬빗·스파링의 공통 착수 리듬, 양쪽 시계 조절, 완료 후 실제 상대 레이팅 입력.
- 대국·분석·코칭의 Stockfish 전용 표시 게이지. 평가 미준비는 중립으로 표시하고 실제 수 선택은 자체 Regicide 경로를 유지한다.
- 실제 세 번째 위치 반복과 50수 조건 이후 자동 무승부. 예정수 청구권만으로 조기 종료하던 문제 수정.
- 항상 보이는 오프닝 탐색기와 가로 공간 활용, Lichess 연결 유지, 넓어진 기보, 개선된 착수음.
- 코칭 배지·핵심 장면 이동·기보 표시·해설 및 별도 Stockfish 참고 평가.
- 갬빗 이름·특성 강화, 1,315개 수순 연결망, 실제 희생 후 운영 연습과 분석 기억.

## 검증 근거

- [마감 통합 검사](../2026-11-04-handoff-tests/README.md): 브라우저 13묶음·JS 구문 7개, Python 320개 중 309개 통과·선택적 11개 제외, 추가 경계 210개 및 실제 엔진 시작·코칭 HTTP. 기존 표시명과 어긋난 PGN 미리보기 기대값은 정정 후 재검증했다.
- [운영 최종 검증](../2026-11-04-gambit-operations/README.md): 최종 코드의 관련 회귀 191개 통과, 전후 12개 분기·각 120착수, 별도 수비 전환 및 동일 국면의 외부 검사. 최초 형태 후보의 추가 손실을 재현하고, 근거 없는 새 후보의 자체 손실을 허용하지 않도록 수정한 뒤 재실행했다.
- [희생 후 실제 연습](../2026-11-04-gambit-operations-learning/README.md): 24분기·갬빗 진영 192착수, 정확한 연습 위치 160개·후보 460개의 자체 분석 기억. 보류 계열은 실행 기억에 넣지 않았다.
- [공통 Stockfish 표시](../2026-11-04-stockfish-gauge/README.md), [반복 무승부](../2026-11-04-repetition-draw/README.md), [공통 시간 관리](../2026-11-04-common-human-pacing/README.md), [공통 UI·실제 렌더](../2026-11-04-shared-game-ui/README.md).

기존 선형 갬빗 순위 모델은 미학습 계열 검사 악화로 여전히 실험·비활성 상태다. 새 운영 기억은 정확히 연습한 수 이력의 분석이며 일반화된 신경망으로 표시하지 않는다. 짧은 분기 시험을 완주한 대국이나 Elo 향상으로 해석하지 않는다. C++ 자체 엔진 소스와 활성 실행 파일은 이번 정책·UI 변경으로 교체하지 않았다.

## 보존 경계

개인 기보·레이팅 DB·인증 정보·실행 세션·빌드 환경은 GitHub 공개 대상에서 제외했다. 실험용 가짜 대국·실패 기록·원시 UCI·소스 스냅샷·소리 자산과 라이선스는 보존했다. 전역 로그 제외 규칙에 걸리는 연구 원본 로그는 민감정보 확인을 통과한 명시적 파일 목록으로만 포함했다. 지문 검증이 운영체제의 줄끝 변환에 영향을 받지 않도록 코드·자료·증거의 바이트 보존 속성을 설정했다.

다른 연구 체크아웃에 남아 있던 2026-10-21 문서 원문은 [별도 역사 자료](../../archives/research-worktree-2026-10-21/README.md)에 보존했다. 최신 M1 문서의 현황을 과거 문서로 덮어쓰지 않았다.

GitHub 반영 뒤 로컬·원격 main의 실제 지문과 복구용 bundle/소스 압축본을 별도로 검증한다. 원격 CI의 완료 여부는 로컬 검사와 구분해 보고한다.
