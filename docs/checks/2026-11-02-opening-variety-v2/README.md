# 오프닝 다양성 v2 검증 — 2026-11-02

기준 버전은 `e82f149941f5a10220cd49db2ae28c4cd4bfdc30`의 v1 정책이다. 새 정책은 기본 수읽기 시간 전체를 보존하고, 처음 16반수까지 같은 국면의 카탈로그 후보를 최대 6개 검토한다. 허용 차이는 35→25cp, 최소 완료 깊이는 3→4로 강화했다. 자세한 규칙은 [오프닝 다양성](../../OPENING_VARIETY.md)에 있다.

## 조건과 분리

- 동일 Regicide 0.7.0-dev, 기본 수식 평가. C++ 엔진과 모델은 변경하지 않았다. 바이너리 SHA-256: `edd950fb673cfca4134968b64cc5ef0f3d77eda698e9f40d2965170f143d6e6a`.
- Windows 11, AMD Ryzen AI 7 350(8코어·16논리 프로세서), Python 3.13.16, python-chess 1.11.2. 엔진은 한 프로세스씩 순차 실행했다. 시스템 전체 CPU 독점이나 외부 부하 통제는 하지 않았다.
- 고정 국면 8개 × 시드 `000...000`~`000...00f` 16개 × 두 정책 = 실제 착수 256건. 매 실행은 개인 기보와 분리된 임시 대국이며 실제 `HumanGame.engine_move`·저장·결정 기록 경로를 사용했다. 양쪽 모두 화면용 힌트·평가 도우미를 동일하게 비활성화했다.
- 설정 시간은 1초. v1은 기본 검색·후보 검토가 이 1초를 나눠 썼고, v2는 기본 검색 1초 뒤 후보 검토에 최대 1초를 추가했다. 따라서 같은 총 연산 자원의 대국 강도 비교가 아니다.
- 자료는 기존 CC0 카탈로그 `a6189a30dc273ccb21fc2536a9a2fefd5592a67a`다. 외부 엔진이나 Stockfish는 사용하지 않았다.

`old-source/`, `new-source/`는 실제 실행한 두 소스의 원본 바이트를 보존한다. 각 manifest에 원본 해시를 기록했으며 새 두 소스는 검사 완료 시 작업 파일과 일치했다. `source-manifest.json`은 다른 변경 소스·검사 파일까지 CRLF→LF로 정규화한 해시다.

## 실제 선택 다양성

각 행은 같은 국면의 16개 시드 결과다. 표본 빈도를 일반적인 대국 확률이나 실력으로 해석하지 않는다.

| 국면 | 기존 선택 종류 | 새 선택 종류 | 가장 자주 선택한 수 비중: 기존 → 새 |
| --- | ---: | ---: | ---: |
| 백 첫 수 | 4 | 9 | 37.5% → 25.0% |
| `1.e4` 뒤 흑 | 4 | 9 | 37.5% → 31.25% |
| `1.d4` 뒤 흑 | 4 | 8 | 37.5% → 37.5% |
| `1.c4` 뒤 흑 | 4 | 6 | 43.75% → 25.0% |
| `1.Nf3` 뒤 흑 | 4 | 9 | 37.5% → 31.25% |
| `d4 d5 c4 e6` | 2 | 2 | 50.0% → 62.5% |
| 같은 국면의 `c4 e6 d4 d5` | 1 | 2 | 100% → 68.75% |
| `e4 e5 Nf3 Nc6 Bb5 a6` | 1 | 1 | 100% → 100% |

루이 로페즈의 `Ba4`는 해당 예산의 품질 검사를 통과하지 못해 `Bxc6` 선택이 유지됐다. 범위를 늘려도 모든 국면에서 다양성이 늘어나는 것은 아니다. QGD 정순의 최빈 비중은 이 표본에서 높아졌다. 백 첫 수에는 `h4` 같은 비주류 수도 포함되며, 명명된 오프닝이라는 이유만으로 채택하지 않았다.

새 128건은 기본 탐색 예산을 모두 1000ms로 유지했다. 대안 선택 85건, 통과 집합 중 기본 수 선택 21건, 통과 대안 없음 22건이었다. 후보 검토 500건 중 209건 통과, 204건 허용 차이 초과, 87건 동일 깊이 완료 부족으로 제외됐다. 채택 시점의 최대 차이는 25cp였고 실제 착수 오류·후보 탐색 실패·점수 충돌은 없었다.

## 독립적인 자체 엔진 재평가

선택된 서로 다른 수 50개와 각 국면의 전체 탐색 기준 8개를 별도로 깊이 8까지 평가했다. 원래 5초 상한에서는 선택수 50개와 기준 5개가 완료됐고, QGD 정순·전위 및 루이 로페즈의 기준 3개가 깊이 7에 머물렀다. 이 3개만 15초 상한으로 재시도해 각각 11.644·11.934·5.035초에 깊이 8을 완료했다. **고유 평가 58개 모두 완료, 실제 시도 61회**이며 최초 미완료 기록을 지우지 않았다. 요약에는 각 키의 최신 결과를 사용한다.

| 비교 가능한 선택 128건씩 | 기존 | 새 정책 |
| --- | ---: | ---: |
| 전체 탐색 기준보다 25cp 넘게 낮은 선택 | 10 | 8 |
| 100cp 넘게 낮은 선택 | 0 | 0 |
| 가장 큰 평가 차이 | 27cp | 31cp |

백 `h4`의 깊이 8 차이는 22cp, 흑의 `1.e4 a5`는 31cp였다. 적용 시점의 25cp 조건이 더 깊은 평가에서도 그대로 유지된다는 보장은 없다. 부호 있는 차이 평균은 5.57→4.23cp지만, QGD의 제한 탐색 `Nc3`(+13cp)가 전체 탐색의 `cxd5`(−1cp)보다 높게 평가되는 경로 차이가 포함된다. 평균 감소를 경기력 개선으로 해석하지 않는다. 제한 탐색과 전체 탐색은 선택적 수읽기 때문에 같은 깊이에서도 모순될 수 있다.

이 결과는 다양한 수를 선택하면서 큰 자체 평가 악화가 이 표본에서 관찰되지 않았다는 근거다. 같은 승률·Elo·실전 경기력의 무손실을 입증하지 않으며 비교 대국은 수행하지 않았다.
