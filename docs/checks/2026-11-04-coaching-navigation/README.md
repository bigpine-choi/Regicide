# 코칭 기호, 핵심 장면 이동, 기보 영역

- 판단 근거가 부족한 수는 내부 분류를 유지하되 회색 `…` 배지와 자동 대사·힌트를 표시하거나 읽지 않는다. 옛 보고서에도 적용한다.
- 좋은 수는 `👍`, 놓친 메이트 기회는 `×`다. 옛 좋은 수의 `✓`도 표시 시 변환한다.
- 보드 아래의 **이전/다음 핵심 장면**은 수업 장면과 중요한 실수로 즉시 이동한다. 내 수·상대 수 필터를 적용하고, 좋은 장면도 포함한다. 한 수 이동과 실수까지 실제 수순을 따라가는 기존 기능을 유지한다.
- Godot 기보를 해설 스크롤에서 분리했다. 확인한 창 크기 900×680, 1240×860, 1760×960에서 각각 9·11·13행을 표시한다. 웹은 넓은 화면에서 기보가 별도의 세 번째 열을 사용하고, 좁은 화면에서는 아래 목록으로 배치한다.

## 검증

- Python 코칭 및 독립 감사 회귀: 187개 통과. `python-tests.log`.
- 관련 웹 검사: 137개 통과(코칭 95, 형세 8, 사이드바 5, 오프닝 탐색 17, 오프닝 가이드 12). 코칭 로그는 `web-tests.log`.
- 격리 Godot 검사: 489개, 실패 0개. `native/coaching.log`, `native/coaching-native-synthetic.json`.
- 별도 오프라인 Godot 렌더: 3개 창 크기의 기호·핵심 장면 이동·먼 장면의 기보 자동 스크롤을 9장으로 확인했다. `native/native-navigation-render.json` 및 PNG들. 따봉은 실제로 보이며 빈 네모로 나오지 않는다.

사용자의 실행 중 게임·설정은 변경하지 않았다. 웹은 자동 동작 검사를 수행했으며 실제 브라우저 렌더나 스피커 음성 청취를 수행했다고 주장하지 않는다. 이 변경은 평가 기호와 코칭 화면 동작에 관한 것이며 체스닷컴의 비공개 분류 알고리즘과 일치한다는 주장이 아니다.
