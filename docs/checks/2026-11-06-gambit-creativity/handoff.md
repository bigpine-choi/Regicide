## 종료 준비의 범위

열려 있던 Regicide 창에 정상 종료를 요청해 현재 기보의 PGN/JSON 저장과
Godot·대국 서버·엔진 종료를 확인했다. 개인 저장 대국은 Git이나 실험 압축에 넣지 않는다.
컴퓨터 전원 종료 자체는 실행하지 않는다.

최종 커밋과 GitHub 동일성, 원격 검사, 복구 번들 정보는 커밋 후 생성하는
로컬 `build/handoffs/2026-11-06/` 마감 영수증에 기록한다.
이 문서만으로 아직 실행하지 않은 원격 검사 성공을 주장하지 않는다.

창의성 개발과 정확한 실험 소스는 `f42fd8c`에 귀속된다. 일부 기존 스크립트는
Git의 줄바꿈 정규화를 받으므로 전체 326파일의 정확한 바이트 복원 기준은
증거 ZIP이다. 핵심 변경 파일의 Git 바이트는 보존되며, 전체 checkout이
실험 소스 manifest와 바이트 단위로 같다는 뜻은 아니다.

이후 추가된 스파링 16수 강화 요청은 별도 변경으로 검증·커밋한다.
