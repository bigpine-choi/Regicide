# 20수까지 실제 탐색으로 균형 회복

2026-11-03. 정책 `regicide-sparring-play-v6`, 시간 배분 `regicide-engine-pacing-v9`. 비교 기준은 `d871d04b76b6f6d120f0fbf5e1c0ba972e296940`의 v5/v8이다. 자체 Regicide 바이너리는 바꾸지 않았다.

## 문제와 변경

이전 시간제 스파링은 첫 탐색에 최대 3초를 배분하고, 계산을 끝낸 뒤 사람다운 생각 시간을 기다렸다. Regicide가 −100cp 아래로 뒤지면 정책이 그 첫 탐색의 최선수를 곧바로 유지하여, 길게 기다리는 동안 추가 저항 수를 읽지 않았다. 반대로 짧은 오프닝 탐색에서는 600ms 미만의 기본 예산이 양보 후보 검사를 막을 수 있었다. 큰 기물 손실의 복구 허용도 안전한 후보를 실제로 찾았는지와 무관하게 네 차례 뒤 끝났다.

- 표준 시작 대국의 20번째 착수까지(탐색 시작 ply 0~39), 현재 반환 수와 일치하는 정확한 평가 패킷이 ±100cp 밖이면 복구 계산을 배분한다. 상한·하한 평가나 다른 수의 평가를 근거로 양보하지 않는다.
- 앞서는 경우 오프닝의 짧은 기본 예산과 별도로 후보를 최대 40개 탐색하고 최대 10개를 정확히 비교한다. 우선 후보가 충분한 깊이에 도달하도록 먼저 네 후보 규모로 시간을 배분한다. 실제로 덜 쓴 시간은 후순위 후보에 쓴다. 첫 후보의 상대 반격 검사가 실패하면 다음 검증 후보를 확인한다.
- 뒤지는 경우 이전에 대기하던 시간을 제한 없는 추가 탐색에 쓴다. 완료 깊이·합법 수·평가 일관성을 확인한 결과만 채택한다. 추가 탐색이 실패하면 이미 확보한 합법 수를 보존한다.
- 얕은 오프닝 평가가 앞섬을 가리키면 먼저 재탐색한다. 이때 뒤짐으로 바뀌면 저항 탐색으로 전환한다. 양보 후보에는 기존 최소 깊이 4, 기준 탐색과 같은 깊이 비교, 착수 후 상대의 모든 응수 검사, −100cp 안전 하한과 기물 보존 조건을 유지한다.
- 정상 잔여시간에서는 짧은 오프닝도 불균형 확인 시 총 6초 목표를 사용할 수 있다. 추가 계산은 앞섬 최대 12초, 뒤짐 최대 30초이며 이미 쓴 시간과 안전 잔액을 차감한다. 3분 미만에서는 이 상한을 연속적으로 줄이고, 10초 이하는 추가 복구 탐색을 배분하지 않는다. 모든 복구 계산 뒤에는 인위적인 추가 대기가 없다.
- 큰 기물 손실 뒤 첫 두 차례는 노골적인 기물 반환을 막는다. 이후 복구 실패만으로 기회가 만료되지 않으며, 20수까지 균형 회복·기물 차이 해소를 계속 시도한다. 21~49수 강도 상승과 50수 전력 전환은 그대로다.
- 핸디캡으로 수를 바꾼 합법적인 표준 시작 수순도 명시적 복구 예산이 있으면 현재 판에서 복구한다. 인위적으로 바뀐 수순은 사용자 기력 관측에서 제외한다. 기존 강제 수순 제외는 일반 경로에 유지한다.
- 시계를 조정하면 진행 중 탐색 한도도 다시 확인한다. 종료·수순 변경·즉시 착수 요청은 추가 탐색에 중단을 보내고, 무효화된 응답은 판에 적용하지 않는다. 사람 0초 계속 진행, Regicide 시간 초과 패배, 핸디캡 시계 복원도 유지한다.

## 같은 포지션의 실제 엔진 비교

`tests/recovery_native_integration.py`는 공개 프로젝트 대국의 18ply 수순과 명시적으로 합성한 기물 열세 수순 각각에서 이전/현재 호스트의 다음 수만 비교한다. 개인 기보는 열거나 수정하지 않는다. 10분 시계에 각자 600초, 같은 시작 포지션·시드·Regicide 실행 파일·1스레드·Hash16MiB를 사용한다. 추가 탐색 시간이 변경의 대상이므로 양쪽 계산량은 같게 제한하지 않는다.

선택한 수 뒤의 형세는 새 Regicide 프로세스로 2초 탐색하여 별도로 기록한다. 이는 같은 자체 엔진의 별도 평가이며 Stockfish 정답 판정이 아니다. 실행 중 관련 소스 해시가 바뀌면 검증을 실패 처리한다. [최종 네이티브 결과](native.json)는 이전/현재 × 두 포지션의 4건을 통과했고 시작/끝 소스 해시가 일치했다.

| 포지션 | 이전 수 → 현재 수 | 별도 평가(폰 단위, Regicide 관점) | 탐색 누적 벽시계 시간 | 후속 대기 |
|---|---|---|---|---|
| 공개 대국의 유리한 형세 | g4 → Qd6 | +3.81 → +0.46, 접전 범위 진입 | 0.54초 → 0.93초 | 0.45초 → 0초 |
| 합성한 불리한 형세 | d4 → d4 | −1.88 → −1.88, 미회복 | 0.41초 → 5.80초 | 0.40초 → 0초 |

첫 경우는 짧은 오프닝 기본 탐색에 막혔던 후보 검사를 48회 탐색 요청으로 수행하고 검증된 대안을 채택했다. 충분한 증거를 빨리 얻었으므로 6초를 채워 기다리지 않았다. 둘째 경우는 기본 완료 깊이 5에서 추가 탐색 뒤 7로 깊어졌지만 선택수와 별도 평가가 같았다. 추가 계산의 실행은 확인했으나 불리함의 해소는 확인하지 못했다. 전체 대국이나 일반 기력 비교가 아니다.

## 한계와 적용

±1점은 복구 목표이며 항상 가능한 체스 수의 존재를 보장하지 않는다. 이미 잃은 기물이나 강제 패배는 계산을 더 해도 회복되지 않을 수 있다. 유리한 쪽에서도 안전한 양보 후보를 찾지 못하면 현재 최선수를 둔다. 이 검사는 기능과 제한된 포지션에서의 변화이며 승률·Elo·일반적인 복구 성공률의 검증이 아니다. 시간 제한 탐색에는 외부 부하에 따른 변동이 있고, 실험에서는 이를 통제하지 않았다.

기존 대국 파일과 실행 중인 프로그램은 변경하지 않았다. 바탕화면 Regicide 바로가기는 이 저장소의 실행 스크립트를 가리킨다. 프로그램을 다시 실행하면 새 정책이 적용된다.
