# 갬빗 라인 지정·재개 연구 비교

2026-11-05, 한국 시간. 기준 커밋 `ac89101efb1409955038739c5bbd048b52f895f5`. 연구 도구에 계열·시작 라인 선택, 완료 검색별 저장, 중단 후 재개를 추가했다. **기존 분석 기억을 보존하고 기존/새 연속/재개 실행의 분석 결과 동일성을 확인했다. 기력 상승을 측정한 실험은 아니다.**

## 구현과 보존 경계

`train_gambit_operations.py`의 `--family`, `--case`, `--list-lines`로 시작 위치를 고른다. `--max-new-queries`로 새 검색 수를 제한하고 `--resume`으로 이어간다. 새 `gambit_research_session.py`는 완료한 검색의 전체 수 이력, 엔진·설정·소스 식별자와 원시 UCI 로그 구간의 해시를 저장한다. 재개할 때 저장 결과를 검증·재생해 원래 연습 수순을 다시 구성하고 남은 검색만 실행한다.

시간 초과·Ctrl+C 등으로 끝나지 않은 검색은 저장 완료로 인정하지 않는다. 설정이나 입력 변경, 손상된 저장 자료, 동일 출력의 동시 실행을 거부한다. 외부 내보내기는 세션 잠금 안에서 새 파일에만 게시한다. 파일 생성 경쟁이 발생해도 먼저 만들어진 파일을 덮지 않는다. 완료 기억은 정상 엔진 종료 코드 0을 실제 관측한 뒤에만 내보낸다.

계열 일부만 선택해도 전체 교육 자료의 보류 계열과 시작 국면·직후 국면을 예약한다. 해당 계열 및 겹치는 국면은 대국용 기억에서 제외한다. 기존의 `candidates=1`이 경우에 따라 후보 2개를 만들던 경계도 수정했다. 이 변경은 단위 검사에서 확인했고 실제 비교는 양쪽 모두 후보 2개 조건으로 수행했다.

기존 활성 기억 `data/gambits/operations_memory.json`의 실행 전후 SHA256은 동일했다.

```text
c00cef2484dac5e90ae4eaa851f5f1cb82850d51881a2be5eacfd4ec66babcfa
```

새 연구 결과는 활성 기억과 별도로 보존했다. 기존 기억과 병합하거나 실제 대국에 설치하지 않았다. 핵심 C++ 엔진, 갬빗 선택 정책과 신경망 가중치를 변경하지 않았다. [연구 도구 사용법](../../GAMBIT_LINE_RESEARCH.md).

## 자동 검사와 검토

연구 기능 검사 **21개**, 기존 분석 기억 검사 **10개**가 모두 통과했다. [실행 관측 기록](unit-verification.json)은 검사 에이전트가 도구 결과를 직접 확인한 기록이며 저장된 원시 테스트 출력은 아니다.

- 여러 번의 일시정지·재개, 연속 실행과의 결과 동일성, 완료 검색 중복 실행 방지
- 미완료 검색 재실행, 시간 초과·사용자 중단 처리, 전체 이력 보존
- 잘못된 선택·엔진·설정·교육 자료·소스 변경 및 손상된 로그·저장 자료의 거부
- 기존 활성 기억 보호, 보류 계열 제외, 보류 계열만 연구한 경우의 빈 내보내기 방지
- 내보내기 중 잠금 유지, 같은 파일 생성 경쟁에서 기존 내용 보존, 비정상·불명 종료 시 내보내기 거부

별도 코드 검토에서 발견한 내보내기 잠금 범위, 파일 생성 경쟁, 종료 상태 확인 문제를 수정했고 재검토에서 진행을 막는 결함은 발견되지 않았다.

Windows 별도 프로세스 검사에서는 살아 있는 작업의 잠금이 다른 작업을 막고, 잠금 소유 Python 작업을 강제 종료한 뒤에는 잠금 파일을 유지한 채 새 작업이 잠금을 얻는 것을 확인했다. 처음에는 가상환경 실행기와 실제 Python 작업의 PID를 혼동해 검사에 실패했고 이를 바로잡아 재확인했다. [잠금 검사 기록](lock-test-note.json)에 이 과정과 자동 승인 검토에서 거절된 임시 폴더 정리를 그대로 기록했다. 실제 엔진을 강제 종료하는 실험이나 전원 차단 실험은 수행하지 않았다.

## 실제 자체 엔진 비교

실행 전에 기존 표본 선택 규칙으로 세 시작 위치를 고정했다. King's 한 위치와 보류 계열인 Benko·From 각 한 위치다. 전체 교육 자료의 축소본으로 동작을 비교한 것이며 전체 계열의 연구를 완료한 것은 아니다.

- 위치: `benko-8b80cafa6524`, `from-cd701227a3b6`, `kings-b0c8d3df038a`
- 실행 파일 SHA256: `5011da4c5e6ef01c452bd7125e4e22b372d2c9cfb858ed8759057325acb0e6ba`
- 자체 Regicide 0.7.0-dev, 고전 활동성 평가, Hash 16MiB, LMR 활성
- 검색당 최대 100,000노드, 위치당 갬빗 소유자 2차례, 후보 2개, 시드 20261105
