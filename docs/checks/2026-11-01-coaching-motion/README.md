# 양쪽 코칭·수순 재생·기물 이동·대국 보관함

2026-11-01, Regicide 0.7.0-dev의 로컬 인터페이스를 개선했습니다. 엔진 C++ 소스와 실행 파일은 변경하지 않았습니다. 기물 이동 애니메이션은 이미 받아들인 위치를 그리는 기능이며, 합법 수나 AI의 수 선택을 바꾸지 않습니다.

## 동작

- 코칭은 양쪽 수를 기본 표시하고 백·흑별 요약, 내 수·상대 수 필터와 착수자 표시를 제공합니다. 이전 캐시의 수별 분석은 그대로 사용하고 요약만 다시 구성합니다.
- 다음 실수로 가면 현재 실제 기보 위치부터 목표 수 직전까지 0.65초 간격으로 순서대로 재생합니다. SAN 진행 수순, 일시정지·계속·바로 이동을 제공합니다. 가상 추천 수순은 실제 기보에 섞지 않습니다. 재생 중 수동 이전·다음은 현재 보이는 위치에서 이어집니다.
- 이동은 약 0.24초(네이티브 캐슬링 0.28초), 짧은 착지 효과, 잡힌 기물의 사라짐, 승격 교체, 왕·룩의 동시 이동을 지원합니다. 서버 위치는 즉시 적용하며, 시각 효과가 착수 요청이나 판정을 지연시키지 않습니다. 반복 상태 갱신은 재시작하지 않고, 빠른 변경·뒤집기·크기 변경·숨김·설정 끄기는 남은 효과를 정리합니다. 배치 편집은 즉시 표시합니다.
- 보관함은 실제 저장된 시작·종료 시각, 현지 시차, 색과 결과를 보여줍니다. 네이티브 검색은 날짜·시간·결과 등에 대응하며, 검색 후 선택은 대국 ID로 연결됩니다. 브라우저에서는 보관함 버튼으로 분석을 시작하지 않고 기보를 복기할 수 있습니다.

## 렌더링 검수와 한계

Godot의 실제 렌더러에서 나이트·캐슬링·포획 승격의 27개 시간별 프레임을 생성하고 시각적으로 확인했습니다(`animation/frames/`). 코칭의 양쪽 요약, 실수 사이 실제 기보, 날짜별 보관함 화면도 렌더링하여 확인했습니다.

- `native-both-sides.png`: 실제 엔진의 완료 결과와 양쪽 요약.
- `native-intervening-moves.png`: 실제 기보 1/2수 진행과 일시정지·바로 이동.
- `library-before-fix.png`: 렌더링 중 발견한 보관함의 과도한 높이.
- `native-library.png`: 수리 후 날짜·검색·목록·열기·닫기 버튼이 화면 안에 표시됨.

보관함의 초기 자동 크기 계산이 2559px 높이를 만들 수 있어 자동 확장을 끄고, 선택 설명은 높이가 제한된 스크롤 영역으로 바꿨습니다. 900×680·1240×860, 정상·긴 설명·검색 결과 없음, 여러 프레임에 걸쳐 창과 버튼이 화면 안에 유지되는 검사를 추가했습니다. 코칭 보드는 세 창 크기에서 국면·설명·재생에 따른 크기 변화가 없습니다.

이번 네이티브 검수는 실제 씬에 대한 자동 입력·실제 엔진 연결·렌더링 확인이며, 마우스로 수동 대국한 검수라고 표현하지 않습니다. 브라우저는 IAB가 사용 불가해 실제 렌더링은 수행하지 못했습니다. 브라우저 동작 검사와 실제 HTTP 제공·기보 보존 검사는 통과했습니다.

모든 실행은 별도 검수용 저장 폴더·기보·설정 파일을 사용했습니다. 사용자의 진행 중 대국과 개인 기보는 조작하지 않았습니다. 기력·속도·Elo 개선 실험은 수행하지 않았습니다. 파일 해시와 기반 커밋은 `source-manifest.json`에 기록합니다.
