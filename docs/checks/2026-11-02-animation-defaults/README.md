# 기본 기물 애니메이션

Godot와 브라우저의 기물 애니메이션 체크박스를 제거했습니다. 앱의 저장된 켜기·끄기 값을 읽거나 쓰지 않으므로 이전에 꺼둔 설정도 동작을 막지 않습니다. Godot 보드의 기본 활성 상태를 그대로 사용합니다. 브라우저의 시스템 움직임 줄이기 설정과 화면 이탈 시 효과 정리는 유지합니다.

수순 변경·착지 배지·캐슬링·승격을 포함한 기존 검증을 확인했습니다.

- Godot: 별도 복사한 프로젝트에서 창 없는 fixture 검사 377개 통과, 실패 0. 대국·분석·코칭 보드의 기본 활성 상태와 체크 UI 부재 확인. `native.json`, `native.txt`에 결과를 기록했습니다.
- 브라우저: 기존 이동 효과 21개와 코칭 57개 통과. 과거 저장값 `off`·`on`·없음에서 모두 효과가 작동하고 설정 저장소에 읽기·쓰기를 하지 않는 것을 확인했습니다.
- 실행 중인 사용자 게임 창이나 대국 서버에 연결하지 않았습니다. 이번 변경에 별도의 실제 화면 조작 검수는 수행하지 않았습니다.

실행 명령: `python tests/coaching_godot_tests.py --godot <Godot> --binary <Regicide>`의 fixture 장면과 동일한 `godot/tests/coaching_tests.gd`를 별도 프로젝트에서 실행했습니다. 브라우저 검사는 `node tests/web_board_motion_tests.js`, `node tests/web_coaching_tests.js`입니다. 기존 보고서의 애니메이션 설정 설명은 과거 동작 기록으로 남겨 두었습니다.
