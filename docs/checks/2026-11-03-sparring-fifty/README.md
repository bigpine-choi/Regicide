# 스파링 50수 전력 전환

2026-11-03. `regicide-sparring-play-v5`는 20수까지 접전을 목표로 조절하고, 21~49수에는 매 수 동일한 폭으로 양보를 줄이며, 백·흑 각각 **50번째 착수부터** 자체 엔진의 기준 최선수를 유지한다. 시간제 스파링의 자동 시간 관리·3분 미만 시간 압박·클릭 시계 조절은 그대로 유지한다.

강화 계수는 `clamp((현재 수 번호 − 20) / 30, 0, 1)`이다. 21수는 1/30, 30수는 1/3, 40수는 2/3, 49수는 29/30, 50수부터는 1이다. 같은 수 번호의 백과 흑에 동일하게 적용된다. 이 비율은 양보 정책의 전환 계수이며 실제 Elo나 착수 품질의 선형 상승을 뜻하지 않는다.

전력 전환은 착수 전 반수 98(백)·99(흑)에서 적용한다. 50수부터 양보 후보를 고르지 않으며 사용자 레이팅 관측은 계속할 수 있다. 초기 관측 수집, 기물 부족 위험의 조기 양보 중단과 기존 손실 보정 조건은 유지했다. 전력은 주어진 시간 안에서 자체 엔진이 찾은 수를 약화하지 않는다는 의미이며 승리를 보장하지 않는다.

과거 v1~v4 기보는 저장 당시 일정을 적용한다. 특히 v4는 20수까지 접전·70수부터 전력으로 계속 복기되며, 새 v5의 대국 집계는 50수 전환을 사용한다.

## 검증

- [핵심 정책 검사](core/validation.json): 59개 통과. 백·흑의 20/21수·49/50수 경계, 매 수 1/30 증가, 양보 목표의 감소와 과거 v1~v4 일정 보존을 확인했다. 일정 검사는 반복 가능한 합성 합법 수순을 사용하며 완주 대국이 아니다.
- [화면 검사](ui/validation.json): Godot와 브라우저의 안내·툴팁이 21~49수 강화·50수 전력으로 일치한다.
- [레이팅·집계 회귀 검사](report-rating-summary.json): 89개 통과. v5의 50수 전력·20수 접전 집계, 기존 정책의 복원, 레이팅 처리와 서로 다른 정책 결과의 혼합 방지를 확인했다.
- [실제 자체 엔진](native-boundaries.json): 고정된 합법 기보의 98/99반수 위치에서 백·흑 각각 한 수를 두었다. 두 경우 모두 원래 기준 최선수와 실제 선택이 같고, 양보 후보 탐색은 0회였다. 레이팅 관측 탐색은 계속 실행됐지만 이 두 표본은 관측 기준 깊이가 부족해 업데이트를 보류했다. 유효 관측일 때 추정치가 갱신되는 것은 별도 통제된 호스트 검사에서 확인했다. 전체 50수 대국을 새로 진행한 결과는 아니다.

검증은 임시 대국과 별도 테스트 실행을 사용한다. 사용자 대국을 재시작하지 않았다. 현재 실행 중인 프로그램에는 이전 정책이 남아 있으므로, 다음에 Regicide를 다시 실행하면 새 정책이 적용된다. 이 변경의 승률·Elo·사람이 느끼는 접전 정도는 측정하지 않았다.
