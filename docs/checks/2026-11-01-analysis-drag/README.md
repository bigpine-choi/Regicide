# 분석 배치 드래그 검증 · 2026-11-01

기존 자유 배치 분석 모드에 마우스 드래그를 추가한다. 기물 목록에서 판으로 끌면 복사하고, 판 위 기물을 다른 칸으로 끌면 이동·덮어쓰기 한다. 판에서 창 안의 판 밖이나 삭제 영역에 놓으면 제거한다. 취소·같은 칸·창 밖에 놓기는 배치를 유지한다.

Godot는 분석 전용 보드 하위 클래스로 입력을 처리한다. 일반 대국의 `chess_board.gd`와 C++ 수 선택 엔진, 분석 API는 바꾸지 않는다. 편집할 때는 눌렀다가 놓은 클릭과 드래그를 구분해, 드래그를 시작하는 순간 출발 칸이 현재 선택한 기물로 덮어써지는 것을 막는다. 출발 기물은 놓을 위치가 확정될 때 옮기거나 삭제한다.

자유 편집은 분석 시작 전의 배치 편집 화면에서만 허용한다. 분석을 시작한 뒤에는 기존 합법 수 이동을 사용하며, 다시 자유롭게 편집하려면 배치 편집으로 돌아온다. 변경된 판에는 캐슬링·앙파상 권리와 반수 카운터 초기화를 적용하고, 드래그를 취소하면 기존 메타데이터도 유지한다.

자동 검사와 직접 화면 조작의 최종 결과, 실행 파일·구현 파일 지문은 이 폴더에 보관한다. 검수용 대국은 `build/analysis-drag-manual/games/`를 사용하며 사용자의 실행 중인 대국 창과 개인 기보는 조작하지 않는다. 실제 대국 기력이나 Elo 비교는 수행하지 않는다.
