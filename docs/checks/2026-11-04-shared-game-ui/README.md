# 공통 대국 UI 검증 — 2026-11-04

일반 기보 탭은 부모 레이아웃의 세로 확장을 목록까지 전달해 남는 높이를 사용한다. 웹 기보 카드도 남은 높이를 채우며 목록 자체에서 스크롤한다. 기본·갬빗·스파링 모두 서버가 허용한 진행 중 시간제 대국에서 시간 ± 버튼을 사용하고, 완료된 대국에서는 추정 레이팅이 없어도 실제 레이팅을 기록한다. 복기·핸디캡·종료·쓰기 중 경계는 유지한다.

형세 게이지는 대국·분석·코칭에서 Stockfish 평가만 사용한다. 현재 위치와 요청 식별자가 일치하는 정확한 완료 평가만 채우며, 계산 중·사용 불가·오래된 평가·상하한 값은 중립으로 표시한다. 자체 엔진 수 추천과 수별 비교는 유지한다. 기록 재생에서도 자체 평가를 막대에 대신 쓰지 않는다. 확정된 승패·무승부는 규칙 결과를 표시한다.
