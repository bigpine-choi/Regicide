## 구현과 변경 범위

- 같은 실행 파일에서 기존 평가 / 출력층만0으로 만든 V2 / 이전 학습V2를 비교하는 `diagnose_neural_cost.py`를 추가했다. 깊이·노드·시간을 구분하고, 모델 읽기 시간은 측정에서 제외하며 순서·TT·전체 수순을 통제한다.
- `teacher_quality.py`는 누적train만 자체 수식교사10k→50k→200k노드로 다시 확인한다. 마지막 두 검색이 정확 유한CP, 완료깊이3이상, 같은 추천수, 점수차30cp이하이면 최종 라벨을 사용한다. 메이트·bound·불안정·낮은 깊이는 제외하고 모든 검색과 원래 라벨을 보존한다.
- 자동 순환은 기존 corpus 뒤에 별도 quality dataset을 만들고 훈련 입력만 바꾼다. 원본 self-play/loss/corpus와 validation/test는 덮어쓰지 않는다. 파생 자료 변조도 arena 전/중 검사하며, 빈train·실패 시 훈련과 채택을 막는다.
- C++ 규칙·탐색·평가·모델 수식/크기/100cp보정한도는 바꾸지 않았다. 실행 버전 표시는0.6.3이다. 기존 arena·registry·예약 fixture는 기준 커밋과 동일하다.

## 비용은 분리해 확인됨

진단 대상은 이전 미채택 V2 모델 `1a7ec95c4062e7b448bf3582dc189a9c94c570708c98fce6882eb84ac0d717fe`다. 이번 품질 자료로 학습한 후보와 구분한다. 새 자체 개발 위치12개를 고정했고, 학습·보류 자료와 예약 오프닝의 동일 보드/신경망 입력을 배제했다. 역할 순서6순열, 반복6회, warmup별도, Hash16MiB·단일스레드·같은 옵션·전체 이력·검색마다 새 논리 대국으로 비교했다.

**깊이3의72쌍과10,000노드의72쌍 모두 기존평가/0모델의 수·점수·PV·노드·TT작업이 완전히 같았다.** 시간과 메모리 재사용 통계는 동등성 비교에서 제외했다. 총216트리플/648검색이며 warmup은 집계에 넣지 않았다.

|---|---:|---|
| 같은 깊이3, 벽시계 시간 | 1.177199 | 같은 탐색 작업에서 약17.7% 더 오래 걸림 |
| 같은10,000노드, 벽시계 시간 | 1.202399 | 같은 탐색 작업에서 약20.2% 더 오래 걸림 |

엔진 자체 보고시간 비율은 고정깊이1.25/고정노드1.222222였으며 정수ms 표시의 영향을 받는다. 벽시계 시간에는 UCI 전송 비용도 포함되므로 두 값을 구분한다. 고정노드의 학습V2/기존평가 벽시계 비율은1.177702이며, 이는 추론 비용과 달라진 탐색 경로를 함께 포함한다.

이 결과는 이12위치·반복·하드웨어에서 추가 신경망 경로의 비용을 입증한다. 전체 대국의 속도 손실이나 패배 원인별 기여율을 이 숫자로 단정하지 않는다. [전체 진단](diagnostic/diagnostic.json), [모델 사본](diagnostic/learned-v2.nn), [0모델](diagnostic/zero-v2.nn)을 보존한다.

## 판단 차이는 있으나 대형 악수의 주원인은 미확정

같은10,000노드에서 학습V2가 선택한 수는12위치 중6위치에서 달랐다. 자체 수식교사100k/200k 검색 뒤 공통 완료깊이에서 선택수 합집합을 강제 탐색했다. 모든12위치의 순위 비교가 가능했고, 교사의 두 노드 예산 추천수는11위치에서 같았다.

변경된6위치에서 유한 교사의 선택수 집합 내 후회값은 신경망이3개 불리(각7·16·5cp),1개 유리(4cp),2개 동점이었다. 같은 노드 비교도 서로 다른 탐색 트리를 만들기 때문에 이것을 순수 정적평가 오류로 환원하지 않는다. 자체 교사·선택적 탐색·적은 개발 표본의 제한이 있으며, 여기서 심각한 악수가 다수 확인됐거나 전체 패배 원인이 밝혀졌다고 할 수 없다. 비용 손실과 수 선택 변화는 분리했지만 각 원인이 기존35패에 얼마나 기여했는지는 미확정이다. [위치별 진단 대용치](validation/decision-proxies.json)를 참고한다.

이 변경은 비용을 측정하고 불안정한 교사 라벨을 줄이는 연구 기반이다. 실제 기력 향상은 입증하지 못했다. 후속 가설은 확인된 추론 비용을 줄이는 계산 방식과 더 다양한 독립 개발 위치에서의 수 순위·정답 신뢰도다. 이번에NNUE증분 계산·정수화·모델 확대·보정한도 확대를 도입하지 않았다.

공개물은 개인 경로를 가리고 줄바꿈을 정규화할 수 있다. 내부원본 해시는 원래 바이트를 가리키며 [공개 명세](publication-manifest.json)의 원본/공개SHA 대응을 따른다. 모델 바이트는 그대로다. 실제 구현/모델 고정의 소스 커밋과 이후 결과 문서·저장용 속성 커밋은 구분한다.
