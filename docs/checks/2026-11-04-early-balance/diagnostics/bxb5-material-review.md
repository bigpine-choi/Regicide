# 최종 추가 백 15.Bxb5의 기물 노출 신호 검토

원본: `docs/matches/2026-11-04-early-balance-v3/pair3-1700-white/moves.jsonl`, 29ply. [전체 기보·FEN·합법 수 열거 근거](bxb5-material-review.json).

짧은 외부 평가는 착수 전 +137cp, 착수 후 +143cp였지만 최종 품질 검사는 `avoidable_material_donation`으로 기각했고 안전 대안을 못 찾아 원래 합법 수를 `unverified`로 유지했다. 이 원본 판정은 보존한다.

노출된 기물은 이동한 비숍이 아니라 a5의 기존 백 나이트다. `...Qxa5`는 후보를 두기 전부터 가능했다. 단순 같은 칸 교환 검사는 폰 100 획득−나이트 300 손실=−200으로 표시하지만, 다른 칸의 강제 체크와 룩 회수는 다루지 않는다.

`15.Bxb5 Qxa5 16.Bxd7+`를 합법 재생하면 흑의 모든 합법 응수는 **Kf8, Kd8, Ke7**뿐이다. 각각 백이 **Bxc8**로 룩을 잡을 수 있고, 흑의 합법 재포획은 Bxc8 또는 Kxc8이다. 세 경우 모두 착수 전 대비 백의 순수 기물 점수가 **+100cp**다. 나이트가 보상 없이 사라지는 수순이 아니다.

실제 대국은 `15.Bxb5 Nf6 16.Nxb7 O-O 17.Ba4 Qxh2+`로 이어져 b7 비숍을 회수했다. 따라서 이 기물 노출 신호를 헌납 확정으로 집계하지 않는다. 사후 해석이며 운영 코드에 새 예외를 추가하거나 원본 기각·미확인을 성공으로 바꾸지 않는다. 추가 엔진은 실행하지 않았다.
