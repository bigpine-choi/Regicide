# 앞선 실제 대국의 20수 접전 이탈 진단

이 분석은 기존 `2026-11-04-sparring-quality-v2`의 세 판을 읽기 전용으로 재현했다. 운영 코드·테스트·원본 대국 파일은 수정하지 않았다. [원본 실패 착수 추출](failed-early-extraction.json)과 [별도 3초 Stockfish 재검토](deep-reproduce.json)에 전체 기보·FEN·원본 해시·PV·깊이·자체 후보 근거를 남겼다. `deep_reproduce.py`로 재실행할 수 있다.

## 세 판의 실패 양상

- 첫 백: 스파링 착수 직후 15/17 위치가 ±100cp다. 밖의 2개는 16.Qd7+와 17.Qd8#로, 상대 15...Rxa2 뒤 얻은 강제 메이트를 진행한 것이다. 기물 헌납 때문에 불리해진 사례는 아니다. 이전 정책은 승리 메이트를 바로 품질 통과로 판정해 접전 복구를 시도하지 않았다.
- 흑: 4...Nc6, 5...Be7, 6...Ndb4 직후 세 위치가 −1.16, −1.31, −1.40점이었다(이전 200k노드 감사). 자체 평가는 각각 −0.14, −0.43, −0.16으로 접전이라고 오판했다. 외부 검사는 이미 불리한 현재 국면에서의 2~20cp 추가 손실을 허용해 품질 통과로 표시했으며 접전 복구는 시도하지 않았다.
- 추가 백: 13.Qd5에서 독립 평가상 약 1.1~1.4점 손실이 발생했다. 이후 20수까지 여덟 자체 착수가 접전 밖에 남았다. **이 경우는 안전한 대안을 찾지 못한 것이 아니라, 이미 찾은 대안을 승격 검사에서 버린 경우다.**

## 추가 백 13.Qd5의 직접 원인

자체 기본 수 Bxa6는 자체 +101cp였지만 별도 Stockfish 후보 검사에서 −419cp였다. 후보 풀에서는 Qd5(−114)가 가장 좋아 선택됐다. 최종 검사에서는 제한 없는 현재 위치가 +14cp였으므로 Qd5 이후 −135cp를 안전 하한 미달로 판정했다.

이후 실제 자체 기물별 탐색에서 **Nc3-d5**를 완료 깊이 2, +18cp로 발견했다. 별도 Stockfish는 그 후보를 −56cp로 평가해 안전 하한을 통과시켰다. 그러나 400ms singleton 자체 재탐색에서 요구한 완료 깊이 4의 증거를 얻지 못해 `incomplete_native_promotion`으로 버렸고, 최종적으로 이미 나쁘다고 확인한 Qd5를 유지했다. 원본 `quality_guard.attempts[2]`에 해당 기록이 있다.

별도 3초 재검토는 현재 −25cp, Qd5 이후 −138cp, **Nd5 이후 −31cp**였다. Nd5의 기물 헌납 신호는 없었다. 이 국면은 첫 번째 고정 회귀 사례로 적합하다.

## 흑의 경계 이탈과 예방

| 실제 수 | 3초 현재 위치(흑 기준) | 착수 후 |
| --- | ---: | ---: |
| 3...e6 | −79 | −95 |
| 4...Nc6 | −116 | −122 |
| 5...Be7 | −111 | −133 |
| 6...Ndb4 | −133 | −151 |

4...Nc6 이후는 이미 현재 최선 평가도 −100cp 밖이었다. 계속 접전을 유지하려면 이때 상대의 실수를 기대하거나 기물을 바치는 대신 최선의 저항을 해야 한다. 더 앞선 착수에서 ±100cp 경계까지 손실을 허용하는 정책을 바꿔, 가능한 경우 중앙에 가까운 안전한 후보를 찾는 것이 맞다. −100cp라는 측정 경계와 탐색 변동도 구분해야 한다. 이 표 자체로 더 앞선 국면의 안전한 대안 존재나 회복 불가능을 증명하지는 않는다.

## 첫 백의 조기 메이트와 대안

16수 현재 위치는 백의 메이트 2수다. 저장된 자체 후보를 같은 전체 기보에서 별도 3초 분석했다.

| 자체 생성 후보 | 이전 자체 평가 | 별도 Stockfish 착수 후 | 짧은 헌납 검사 |
| --- | ---: | ---: | --- |
| Qd7+ (실제 수) | 메이트 | 백 메이트 1수 | 헌납 없음 |
| Rxa2 | +441 | +257 | 헌납 없음 |
| Qc8+ | +38 | +502 | 헌납 없음 |
| Rd1 | −105 | −532 | 헌납 없음; 형세 검사에서 탈락해야 함 |

Rxa2는 상대 룩을 회수하는 수다. 기물을 바치지 않고 조기 종료를 피할 수 있는 자체 후보였으나, 이전 후보 비교는 메이트 점수와 유한 cp를 비교하지 않아 기본 메이트 수로 되돌아갔다. Qc8+는 자체 평가가 접전이라고 했지만 깊은 외부 평가는 큰 우세다. 검사한 후보 중 ±100cp 수는 없었으며, 이것을 모든 합법 수 중 접전이 불가능하다는 증명으로 보지는 않는다.

## 수정에서 지킬 점

접전 여부와 품질 하한 통과를 따로 남겨야 한다. 20수 전에는 안전한 자체 후보 중 목표에 가까운 위치를 찾되, 외부 평가의 최선 수를 자체 후보로 주입하지 않아야 한다. 이미 발견해 외부 하한을 통과한 자체 후보에 재확인 예산을 우선 배정하고, 판정 실패·취소·시계 부족을 접전 성공으로 표시하지 않아야 한다. 상대의 큰 실수로 생긴 우세를 정확히 돌려줄 안전한 수가 없을 때에는 기물 헌납보다 검증된 가장 가까운 국면과 명시적인 기준 미달을 선택해야 한다.

모든 재검토는 기존 로컬 Stockfish18, 1스레드·Hash32MiB·전력 제한 없음·위치별 3000ms·새 game 토큰으로 수행했다. 단일 Stockfish 프로세스를 순차 사용한 뒤 종료했다. 이것은 알려진 위치의 기능 진단이며 기력·Elo·20수 연속 접전 보장이 아니다.
