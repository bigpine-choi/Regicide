# M3 H100 후보 준비 결과

2026-10-21 KST. **12모델 준비·출처 동결과 native 검증을 완료했다.** 기력 승격·기본 평가기 변경·새 확인 자료·확인 대국은 없다. 실행 전 범위는 [준비 계획](../../experiments/2026-10-21-m3-huber-preparation.md), 원래 후속 가설은 [10/21 진단](../../experiments/2026-10-21-neural-target-ab-diagnosis.md)에 있다.

`attempt-001/protocol.json`은 실행 전 입력·설정·환경을, `attempt-001/freeze.json`은12모델과 결과 파일 해시를 묶는다. `execution.json`과 `preparation-attempt-001.txt`에 실제 실행 명령·환경·결과를 보존한다. 원래 NumPy2.3.4 환경을 사용했다.

- 기존 A/B MSE6모델의 실수 배열·정수 배열·직렬화한 모델 파일 바이트·train/validation 정수 예측이 모두 원본과 정확히 일치했다.
- 같은 초기값·2209학습행·723검증행·배치 순서 시드·학습률·S32·너비·120epoch에서 H1006모델도 만들었다. 모든 마지막 epoch를 보존하며 모델·시드·epoch를 선택하지 않았다.
- H100의 안쪽/바깥/±100cp 경계, 평균 정규화, 작은 오차의 MSE와 같은 기울기, 독립 sparse STE 계산,20epoch 소규모 결정성·callback 격리·저장/로드/재양자화를 검증했다. 신규11개와 기존 정밀도20·QAT21·첫 학습7·A/B10개, 총69단위 검사가 통과했다. H100 실제120epoch 모델을 다시 전부 학습했다고 표현하지 않는다.
- 각12모델에서 기존2932행과 특수 수46위치, **모델별2978위치**의 Python 정수 점수 = C++ 전체 재계산 = 증분 점수를 확인했다. 합계35736개 모델·위치 조합이다.
- 각 모델로 실제 C++ 모델 검사9그룹·26566검사를 실행해 모두 통과했다. 특수 수·형제 분기·전체 undo·검색 중단·컨텍스트/모델 전환을 포함하며,12회 합계108그룹·318792검사다.
- 10epoch마다 기존 train/validation의 MAE·MSE·H100, 종류·두 교사 정답 차이 집단, 모든 실제 배치 gradient norm과 가중치 이동을 저장했다. 이 관측으로 학습을 조기 종료하거나 후보를 고르지 않았다.
- 순수 학습 함수 시간 합계68.96초, native 검증 합계4.59초, 준비 전체87.38초였다. 공유 PC의 이번 실행 비용이며 엔진 속도·기력 개선 수치가 아니다.
- 엔진과 모델 검사 실행 파일은 임시 복사본만 실행하고 모든 소유 프로세스를 종료했다. 원래 입력·native 소스·실행 파일·모델의 해시는 전후 일치했다.

원래 계획은 새 확인 시작 은행을 학습 전에 구성하도록 요구하지만, 이번 요청은 새 확인 자료 없이 후보 준비까지만 진행하는 범위다. 새 은행을 만들지 않았다는 차이를 protocol에 명시했다. 기존 보류687행과96판도 읽거나 선택에 쓰지 않았다. 후속 확인 설계와 새 대국을 마치기 전에는 H100의 기력 향상을 주장할 수 없다.
