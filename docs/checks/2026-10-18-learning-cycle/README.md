# v0.6.1 자동 학습 순환 실제 검증

2026-10-18. 자동 순환을 구현해 실제 자체 대국·패배 분석·누적 자료·재학습·규칙 검사·이전 평가와의 대국을 연결했다. 최종 후보 판정은 **미채택 — 기존 평가 유지**이다. 강도 향상을 전제로 모델을 교체하지 않았다.

## 실제 자료와 학습

| 항목 | 결과 |
|---|---|
| 새 자료 | 2회 수집, 총 64판 완결. 기존 bootstrap 32판은 별도 보존 |
| 마지막 수집 | 32판, 후보 위치 525개, 미완료 0판 |
| 마지막 패배 분석 | 144위치, 교정 12개 |

| 최종 모델 SHA256 | `4b9dc188bb289d83f6563e9a996c27eaca4aef886c3421a8125c06dd108c3256` |

수집은 수당1,000노드, 별도 수식 교사10,000노드다. 패배 분석은 전체 이력을 보존한 동일 루트에서 자유 탐색과 실제 수 강제 탐색을 각각50,000노드로 수행한다. 판당 최대8개를 선별하며, 유한 exact cp·완료 깊이2 이상·자기대국보다 큰 예산·100cp 이상 차이·다른 대안 발견 등 조건을 충족한 train 위치만 교정에 넣는다. 더 큰 유한 탐색도 정답의 증명은 아니며 원인 분류는 추정이다.

완료한 수집 run은 아레나가 무효여도 보존한다. 첫 실행은32판·477개 원본 표본·23개 교정을 남겼으며 두 번째 순환에 실제로 포함됐다. 누적 manifest의 출처·라벨 교체·중복·보류 자료 제외 수를 보존한다. 원본과 기존 검증96개·시험125개 라벨을 덮어쓰지 않았고, 아레나 수순·점수는 학습 자료에 포함하지 않았다.

| 자료 | 기물 점수만의 MSE | 선택한 후보 MSE |
|---|---:|---:|
| test | 0.052026 | 0.062546 |
| train | 0.061300 | 0.008738 |
| validation | 0.068032 | 0.053913 |

위 오차는 제한된 자체 교사와 승패를 섞은 학습 목표에 대한 값이다. 전체 기존 평가 함수와의 강도 비교가 아니다. 검증 자료로 epoch를 선택하고 시험 오차는 보고용으로만 사용했다. 시험 수치나 첫 부분 대국 성적을 보고 구조·학습률을 다시 고르지 않았다.

## 이전 평가와의 대국 판정

- 시도 번호 2, 서로 다른 양색 대국64판/32쌍, 같은 v0.6.1 실행 파일·Hash16MiB·단일 탐색 스레드·수당100ms·무승부 청구 정책. 모델만 바꿨다. 하드웨어·옵션·전체 기보·시간·노드는 arena.json에 기록했다.
- 후보 기준 **8승 10무 46패**, 쌍 평균 점수 0.203125. 단측 하한 0.000000. 채택은 최소32개 완결 쌍과 하한0.5 초과가 모두 필요하다.
- 이번 시도의 오판 예산은 `0.008333333333333333`다. 실패와 중단도 소비하는 영속 번호 k에 `0.05/(k*(k+1))`를 적용한다. 같은 개시의 양색 두 판을 하나의 통계 단위로 다룬다.
- 가중치 고정 후 독립 난수로 예약된64개 시작 위치 풀에서 복원 추출했다. 관측한 중복은 유지했다. 이 분포·시간 조건의 비교이며 전체 체스 기력·Elo의 보장이 아니다.
- 검증 블록의 인식된 외부 엔진·브라우저 CPU 증가 `0`틱, 최대 감시 간격 `0.529206`초, 실패/오염 없음. 샘플 사이에 나타났다 사라지는 미지 엔진·임의 호스트 부하·온도 변화를 완전히 배제하지는 못한다.

첫 아레나는 Modern Standby로 약339초 감시 공백이 생겨33판 진행 뒤 전체 무효 처리했다. 해당 결과는 비교 성적이나 채택 근거로 합산하지 않는다. Windows506/507 이벤트를 보존하고, 학습 프로세스에 임시 유휴절전 방지와 상태 복원을 추가했다. 실제 Windows API smoke는 이전2147483648→실행중2147483649→이전2147483648 복원을 확인했다. `powercfg /requests` 조회는 관리자 권한이 없어 사용할 수 없었으며, 그 조회가 검증됐다고 주장하지 않는다. 감시2초·대국/통계 기준은 완화하지 않았다.
