# 갬빗 후보 순위 학습과 자체 탐색 자료

오프닝 자료는 연습 국면과 후보 수를 제공한다. 학습 목표 점수는 외부 엔진이나 온라인 승률에서 가져오지 않고 **Regicide 자체 탐색**으로 생성한다. 작은 선형 모델은 이미 합법적인 후보의 검토 순서만 바꾼다. 실제 착수의 점수·위험 한도·완료 깊이·기물 헌납 검사·최종 선택은 기존 자체 탐색 검증을 따른다. 신경망 평가기를 교체하거나 표시용 Stockfish 평가를 학습 정답으로 사용하지 않는다.

## 구현

- `scripts/gambit_learning.py`: 24개 특징의 순위 모델과 엄격한 실행 경계. 캡처·체크·전개·중앙 통제·열린 룩 파일·왕 압박 및 모든 즉시 합법 응수 뒤의 최소 활동성을 포함한다. 이 특징은 전술적 안전을 증명하는 값이 아니다.
- `scripts/train_gambit_policy.py`: 전체 오프닝 계열별 사전 분리, 고정 노드 자체 탐색, 원본 UCI 로그, 쌍별 순위 학습과 사전 채택 기준.
- `scripts/check_gambit_policy.py`: 원본 기록·전체 수순·CP 부호·완료 깊이·노드·학습 특징·분리·고정 시드 재학습을 검사한다.
- `data/gambits/policy.json`: 실행용 모델. `experimental` 상태면 자동으로 비활성이다. 바이너리/평가기/특징 코드/체크섬이 맞고 사전 채택 기준을 통과한 `promoted` 모델만 후보 순서를 바꾼다.

갬빗 지식 그래프와 학습 자료의 범위는 다르다. 전체 카탈로그가 있다는 이유로 그 모든 변형을 학습하거나 숙달했다고 표시하지 않는다. 아래 표본의 자체 탐색 정답도 객관적 체스 정답이나 인간 상대 승률이 아니다.

## 자료와 재현 조건

사용한 외부 원자료는 저장소의 고정된 Lichess 오프닝 카탈로그(CC0-1.0)다. 카탈로그의 명칭·수순·출처는 각 국면에 남긴다. 쿼리의 시작 위치는 표준 시작판이며, 전체 합법 수순을 UCI에 전달한다. 매 쿼리는 새 UCI 대국으로 시작하여 이전 쿼리의 탐색 표가 정답에 섞이지 않게 한다.

자체 엔진은 활성화된 `Regicide 0.7.0-dev`, SHA-256 `5011da4c5e6ef01c452bd7125e4e22b372d2c9cfb858ed8759057325acb0e6ba`다. 현재 앱의 기본 옵션을 복원하고 `UsePieceActivity=True`를 사용한다. 과거 자료 생성기의 일부 기능을 끈 프로필을 그대로 쓰지 않는다. 학습 시드는 `20261104`다. 폰 수락·되잡기·체크·포획 후보를 학습 자료에서 일괄 제외하지 않는다.

후보를 둔 뒤 상대 차례의 정확한 CP 점수를 자체 엔진으로 구하고 부호를 뒤집어 원래 착수 측의 점수로 기록한다. 메이트·경계 점수·누락·완료 깊이 3 미만은 CP 정답으로 바꾸지 않고 제외한다. 후보별 자원은 고정 노드로 통제하며, 완료 깊이가 다를 수 있으므로 이는 고정 깊이의 객관적 후보 비교가 아니다.

훈련 계열과 별도로 Smith-Morra·Budapest는 하이퍼파라미터 선택용, Evans·Stafford는 최종 분리 검사에 사용한다. 같은 형세로 전치한 위치가 서로 다른 분리에 섞이지 않게 현재 판과 후보 직후 판의 교차를 검사한다. 최종 검사 계열의 점수로 가중치나 하이퍼파라미터를 맞추지 않는다.

## 사전 채택 기준

학습은 고정된 네 정규화 값 중 검증 분리의 평균 후보 손실로 하나를 선택한다. 그 뒤 최종 분리를 검사한다. 검증·최종 분리에서 모두 기존 후보 순서와 기하학적 후보 순위 대비 평균 손실과 150cp 이상 손실 횟수가 악화되지 않아야 한다. 전체 합법 후보와 실제 그래프 복수 후보를 구분한다. 실제 그래프 복수 후보 비교는 각 분리에 최소 3국면이 있어야 한다. 이 기준을 결과를 본 뒤 완화하지 않는다.

## 예비 실행과 자료 부족 확인

- `native-v1`: 6,000노드. 실제 사용할 수 있는 66개 국면(훈련42·검증13·최종13)으로 학습했다. 전체 후보 비교에서는 두 기존 순위 기준보다 평균 손실과 큰 손실 횟수가 악화되지 않았다. 그러나 실제 그래프 복수 후보가 검증1·최종0개라 채택하지 않았다.
- `native-v2`: 첫 상대 응수 뒤의 되잡기 국면을 누락하던 샘플링을 고치고, 점수를 보지 않고 실제 복수 후보가 있는 분기점을 우선 포함했다. 사전 계획은 79개 국면, 복수 그래프 후보는 검증4·최종8개였다. 6,000노드에서는 조용한 후보가 완료 깊이 1~2에 머물러 필터에서 제외되었고, 실제 CP 비교가 가능한 복수 후보는 검증2·최종0개로 줄었다. 모델은 계속 `experimental`이다.
- `native-v3`: 같은 79개 계획·같은 모델·같은 채택 기준에서 쿼리당 고정 노드를 100,000으로 늘렸다. 예비 실행의 자료·결과는 덮어쓰지 않았다. 깊이 부족 문제는 해소됐지만 최종 품질 기준을 통과하지 못했다. 실제 모델은 계속 비활성으로 보존한다.

두 예비 실행은 후보 순위의 기력 향상을 입증한 결과가 아니다. 실행 파일이나 사용자의 대국·캐시·설정은 교체하지 않았다.

## 최종 v3 결과: 학습은 수행, 모델 채택은 거절

79개 국면(훈련51·검증13·최종15), 후보 정답 474개를 생성했다. 553번의 실제 엔진 쿼리가 각각 100,000노드, 총 **55,300,000노드**를 사용했다. 쿼리 경과 시간 합은 약 201.23초이며 모델 학습과 파일 처리 시간은 별도다. 정답 후보에는 포획 134개·체크 31개·조용한 수 309개가 있다(포획을 우선해 분류하므로 체크 포획은 포획에 포함된다). 훈련에는 Albin·Benko·Blackmar-Diemer·Danish·From·King's·Scotch·Vienna의 8개 계열이 실제 포함됐다. 선언했던 Englund 계열은 기준을 만족하는 후속 국면이 없어 이번 학습에 포함되지 않았다.

아래 손실은 그 국면에 수집한 후보 중 가장 높은 **자체 탐색 점수**에서 선택 후보의 점수를 뺀 값이다. 실제 대국에서 발생한 손실이나 객관적 실수 판정이 아니다. `기존 순서`는 재현 가능한 시드로 정렬된 자료 후보의 첫 수, `기하 순위`는 현재 자체 후보 생성의 활동성 선호다.

| 분리·후보 범위 | 국면 수 | 기존 순서 평균 손실 | 기하 순위 평균 손실 | 학습 순위 평균 손실 |
| --- | ---: | ---: | ---: | ---: |
| 검증·전체 수집 후보 | 13 | 23.538cp | 352.692cp | 15.769cp |
| 최종·전체 수집 후보 | 15 | 15.200cp | 176.600cp | 55.533cp |
| 검증·복수 그래프 후보만 | 4 | 33.500cp | 1.500cp | 0.000cp |
| 최종·복수 그래프 후보만 | 8 | 14.750cp | 32.000cp | 35.000cp |

최종 계열은 Evans 12개 국면·Stafford 3개 국면이며 훈련 및 하이퍼파라미터 선택에 포함하지 않았다. 최종 전체 후보에서 150cp 이상 손실을 고른 횟수도 기존 순서 0회에서 학습 순위 2회로 늘었다. 검증 분리의 개선을 최종 계열에 대한 개선으로 일반화할 수 없으므로, 정해 둔 기준에 따라 모델 채택을 거절했다. 최종 복수 그래프 비교의 8개 국면은 Evans 계열에만 있어 Stafford의 복수 후보 순위 효과도 입증하지 않았다.

`data/gambits/policy.json`과 `native-v3/policy.json`은 `status="experimental"`, `acceptance.passed=false`이다. 실제 런타임 호출이 입력 순서를 보존하고 `reason="experimental_model"`로 비활성임을 `runtime-adoption.json`에서 확인했다. 후보 지식 그래프의 확장·기존 자체 검증 경로는 별도 기능이며 이 실험 모델을 활성화하지 않고 사용할 수 있다.

`native-v3/audit.json`에서 모든 후보의 합법 이력·특징·원시 쿼리·CP 부호·완료 깊이·노드·전치 분리·모델 체크섬을 검증했다. 같은 훈련 자료·시드·정규화로 가중치·평균·척도가 정확히 재현됐다. 생성 전후 고정 소스와 실행 파일의 해시는 같았고, 모든 소유 엔진의 정상 종료를 확인했다. 원본 UCI와 중간 쿼리 JSON을 함께 보존한다.

이 결과는 작은 선형 기하 모델의 일반화 한계를 확인한 것이다. 단순히 공격적으로 보이는 특징을 선호하는 정도로 다양한 갬빗의 장기 보상을 익혔다고 볼 수 없다. 다음 실험에서는 이번 최종 계열을 다시 정답에 맞추기 전에 새로운 분리 계획과 별도 최종 계열을 정하고, 상대의 실제 응수 이후 구조와 충분한 탐색 근거를 표현하는 모델을 비교해야 한다. 이번 결과를 Elo나 사람 상대 함정 성공률로 환산하지 않는다.

## 실행 방법

```powershell
.venv-tests\Scripts\python.exe scripts/train_gambit_policy.py --output <새 결과 폴더> --nodes 100000 --roots-per-family 12 --candidates 6 --wall-seconds 900
.venv-tests\Scripts\python.exe scripts/check_gambit_policy.py <결과 폴더> --output <결과 폴더>/audit.json
.venv-tests\Scripts\python.exe -m unittest discover -s tests -p gambit_learning_tests.py
```

단위 검사 15개에서 원순서 보존, 실험 모델·다른 실행 파일/평가기·손상된 파일·불법/중복 후보 차단, 고정 시드 학습 재현, 백흑 대칭, 앙파상·승격·체크 포함, 실제 상대 메이트 응수 특징, 첫 운영 분기와 전체 계열 분리를 확인했다. 별도 실제 엔진 실행과 구분한다.
