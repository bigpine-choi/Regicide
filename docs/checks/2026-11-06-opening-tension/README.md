# 초반 접전 예방 조절

기준은 upstream `main`의 `059f7f70ba25ff3c616b081c99a310e1adf9e583`이다. 비어 있던 로컬 프로젝트에 GitHub 연결 도구로 소스와 필요한 검증 자료를 복원하고 별도 개발 브랜치에서 수정했다. 과거 강제메이트·갬빗 연구 PR의 미병합 변경은 포함하지 않는다.

## 변경

- 자체 선택 v7: 표준 시작의 8~39ply에서 자체 기준수 +60cp 초과~+100cp이면 기력 관측 수와 별개로 기존 탐색 예산 안에서 예방 후보를 검토한다. 세 평가(같은 깊이·최종 깊이·착수 후 반격) 모두 목표 거리 20cp 이상 개선이 필요하다. 실제 자체 회복 유보·자원 보호·체크·반복·시간 부족 조건은 기존 흐름을 따른다.
- 최종 검사 v6 / balance v2: 8~39ply에서 외부 완료 평가 +60cp 초과부터 예방 비교한다. 최초 8ply의 +80cp 기준은 유지한다. 예방 교체는 20cp 이상 개선을 요구하고 보호 대상의 단순한 기물 구성에서는 생략한다.
- 첫 ±80cp 성공 후보를 보존한 채 최대 5후보·8초 범위에서 중심 후보를 더 비교한다. 목표 +30cp에서 ±20cp면 조기 종료한다. ±80cp 성공 여부와 중심 도달 여부는 별도로 기록한다.
- v7 경기 실행·레이팅·집계 지원을 추가했다. v6 기록과 21~49수 전환·50번째 착수부터의 전력 사용은 보존했다.
- MSVC에서 기존 SEE의 constexpr 범위 반복이 컴파일되지 않아, 정확히 8개인 나이트 이동 배열을 같은 순서의 인덱스 반복으로 바꿨다. 탐색 로직은 바꾸지 않았다.

자체 CP와 Stockfish CP는 각각 해당 단계의 측정값이다. 서로 차감하지 않는다. 최종 독립 접전 검사는 자체 지연 복구 목표와 별개이며, 이번 변경이 모든 단계에서 동일한 형세를 보장하는 것은 아니다.

## 검증 환경

Windows x64, Python 3.14, python-chess 1.11.2, MSVC 19.44, Release 빌드. 로컬 검증용 의존성은 `build/test-deps`에 두며 저장소 변경에 포함하지 않는다.

재현 명령은 프로젝트 루트의 PowerShell에서 실행한다.

```powershell
$env:PYTHONPATH='build/test-deps;scripts;tests'
python -m unittest early_balance_quality_tests opening_tension_play_tests sparring_play_tests
python tests/opening_tension_native_integration.py --help
```

## 실행 결과

- 관련 Python 회귀검사 381개 통과. 최초 묶음 실행에서 임시 기보 파일 잠금 오류 1건이 발생했으나 해당 검사 단독 재실행과 최종 381개 전체 재실행 모두 통과했다.
- 새 실행 파일 Release 빌드 성공. CTest 12개 중 11개 통과(SEE 포함). neural 검사는 한글 소스 경로의 Windows 문자 변환 오류로 실패했다. 해당 검사와 신경망 코드는 이번 변경에서 수정하지 않았다. 전체 CTest 통과로 표시하지 않는다.
- 실제 HTTP 스파링 통합검사 백·흑 모두 통과. 합법 착수, 분석 취소, 기보 정책 보존과 소스 불변을 확인했다.
- [실제 native 비교](native-replay.json): 29개 국면을 검사해 적격 4개를 v6/v7로 비교했다. 동일한 실제 1초 기준 탐색을 공유하고, 각 정책의 추가 탐색은 별도 Regicide 프로세스로 수행했다. 상대 기력 관측은 두 버전 모두 비워 두었다.
- 4개 모두 v7 예방 탐색을 실행했다. 1개에서 자체 깊이 5의 +64cp를 +34cp로 낮추는 대안을 선택했고, 착수 후 제한 없는 깊이 4 검사도 +34cp였다. 나머지 3개는 충분한 검증 개선 후보가 없어 기준수를 유지했다. 실제 비교 국면은 모두 백 차례이며 양색 대칭은 회귀검사에서 확인했다.

진단 명령은 원래 upstream 이력이 있는 저장소에서는 다음과 같다.

```powershell
python tests/opening_tension_native_integration.py --binary build/native/regicide.exe --output build/opening-tension-replay.json --previous-ref 059f7f70ba25ff3c616b081c99a310e1adf9e583 --maximum-scans 32
```

이번 로컬 복원본의 실행에는 동등한 v6 소스 스냅샷 `2b3b0a69b34b95b5067ae14993888868c139db3d`를 `--previous-ref`로 지정했다. 보고서에 실제 사용한 리비전·소스·바이너리 SHA256과 탐색 이력을 보존했다.

## 해석 범위

Stockfish 실행 파일을 찾지 못했으며 공식 다운로드는 연결 시간 초과로 실패했다. 외부 평가에 따른 분기·증거·기물 헌납 방지·예산 만료·취소는 제어된 평가 응답으로 검사한다. 이 검사는 실제 Stockfish와의 대국 실험을 대신하지 않는다.

실제 접전 지속률, 기력, 승률과 체감 난이도 개선은 아직 입증하지 않았다. 기존 안전 하한·직접 헌납 검사·자체 완료 깊이·외부 평가 완료 깊이를 완화하지 않았다.
