# 분석 보드 크기 변화 수정 · 2026-11-01

## 원인과 변경

왼쪽 세로 배치 안에서 캐슬링 버튼의 줄 수, 캐슬링 불가 사유, 형세 상세 설명의 높이가 바뀌면 확장되는 보드 행의 남는 높이도 바뀌었다. 그 결과 착수나 점수 갱신 때 보드가 커지거나 작아지고 좌표도 움직였다.

왼쪽을 고정 한 줄의 차례/시점 도구(36), 한 줄 점수(26), 나머지 공간을 쓰는 보드로 정리했다. 모든 가변 설명·캐슬링 조작은 오른쪽의 독립 스크롤 영역으로 옮겼다. 오른쪽은 360 너비를 유지하며, 긴 내용이 보드 너비를 밀어내지 않게 했다. 보드를 덮는 입력 설명 툴팁과 별도 안내 문구도 제거했다. 실제 창 크기 변경에는 기존처럼 반응한다.

브라우저도 가변 길이의 캐슬링 영역을 보드 위에서 오른쪽 카드로 옮겼다. 페이지 스크롤바 공간을 예약해 내용 길이 변화로 사용 가능한 폭이 달라지는 것을 막았다. 고정 크기 판을 강제로 도입하지는 않았다.

## 좌표 검증

`analysis_layout_tests.py`와 `analysis_layout_tests.gd`는 보드 Control, 실제 칸 영역, 세계 좌표 중심, 평가 막대, 패널 경계를 각각 비교한다. 글자 길이와 오류·계산 대기/진행/완료·메이트·무승부·편집/분석·승격·긴 수순을 바꾼다.

- 원본 코드 109개 확인: 세 논리 화면 크기 1240×860, 900×680, 1500×1000에서 변화를 재현했다. 극단적인 긴 문구까지 포함한 최대 좌표 차이는 각각 560, 798, 560이었다. 일반 편집→분석 전환만으로도 판 영역과 위치가 바뀌었다.
- 수정 코드 320개 확인: 같은 세 크기에서 모든 상태의 보드·실제 칸·중심·평가 막대 변화가 0이었다. 8개의 실제 관리기 전환과 합법 캐슬링도 포함하며, 개인 대국과 저장 파일은 유지됐다. 명시적인 화면 크기 변경에만 판 영역이 바뀌었다.

이는 headless 환경의 Container 좌표 검사이며 실제 화면 조작이나 픽셀 비교로 과장하지 않는다. 원본 코드와 해시는 `original-analysis-mode.gd.txt`, `layout-source-sha256.json`에 보관했다. 원본/수정 좌표와 요약은 `baseline-geometry.json`, `fixed-geometry.json`, `layout-summary.json`에 있다.

## 실제 Windows 창 검수

별도 Godot 창과 `build/analysis-layout-manual/games/` 관리기를 사용했다. OS 마우스 드래그로 e2→e4, e7→e5를 둔 뒤 생산용 착수 API로 나머지 8반수를 진행했다. API의 각 수정 번호가 실제 화면에 표시될 때까지 기다렸고, 이어서 체크메이트·무승부 위치도 표시했다.

매 프레임 관찰에서 상태·점수·문구 길이 또는 좌표가 바뀐 표본을 기록했다. 총 24개 표본의 보드/실제 칸/평가 막대 좌표는 한 종류뿐이었다. 1240×860 논리 창에서 칸 영역은 `(131.5,172,641,641)`, 평가 막대는 `(81.5,172,22,641)`로 유지됐다. 실제 렌더링의 결과는 `native-geometry.json`, 정리된 화면은 `native-stable-board.jpg`다. 실제 캐슬링 수순도 두 색 모두 포함했다. 창 자체를 OS 마우스로 리사이즈한 검수는 하지 않았으며, 크기별 Container 검사는 앞의 자동 검사로 구분한다.

## 기능 보존

기존 Godot 분석 88개·입력 44개·엔진 연동 71개·정상 수순 캐슬링 114개가 통과했다. 원자료는 `godot-native/`에 있다. 브라우저 분석 42개·추천 10개·오프닝 8개·시간 설정 검사도 통과했다(`final-web*.txt`). 이전 브라우저 검사의 HTML 앞뒤 순서 조건은 이번 변경으로 의도적으로 없어진 배치였으므로 제거했고, 진단·비활성화·연결 오류·드래그·캐슬링의 동작 조건은 그대로 유지했다.

엔진 실행 파일·C++ 코드·공유 보드 렌더러와 평가 막대 렌더러·분석 관리기 규칙은 변경하지 않았다. 작업 전의 로컬 변경은 유지했다. 개인 보관함은 검수에 사용하지 않았으며, 최종 구현 파일 지문은 `source-manifest.json`에 보관한다.
