## 고정한 개선

- V2 점수 = **기존 전체 수식 평가 + 100*tanh(z)**. 학습 보정의 절댓값은100cp 이내다. 왕 안전·통과폰·폰 구조 등 기존 지식을 보존한다.
- V2 출력층은0으로 시작해 학습 전에는 기존 평가와 정확히 같다. V1 파일은 그대로 읽고 같은 수식·숫자 경로를 유지한다. 합법적인 다중 승격에서도 V2 기준을 보존하며, 탐색의 메이트 점수 구역 제한·종료/무승부 우선 처리는 유지한다.
- V2 목표는 tanh(자체 수식 교사의 탐색값/600)이다. 실제 기보 승패는 정합성 검사에 보존하고 목표에는20%로 섞지 않는다.
- L2=0.0001, 100epoch, 학습률0.003, batch64를 새 대국 전에 고정했다. 가중치 행렬만 정규화하며 검증 MSE로만 선택한다. epoch0도 후보이고 시험 오차를 보고 설정을 다시 고르지 않았다.
- 짝수 표집 간격에 실제 수순 offset0/1을 교대한다. 간격4면0,5,8,13,…이다. 차례를 뒤집고 점수 부호만 바꾸는 가짜 정답은 만들지 않는다. 제외된 위치에 따라 정확50:50이 보장되지는 않는다.

## 동일한 모델 채택 기준의 실제 대국

- 시도번호3를 기존 영속 저장소에서 이어갔다. 최소32쌍/64판, 수당100ms, Hash16MiB, 단일 탐색 스레드, 같은 실행 파일·옵션으로 모델만 비교했다.
- 새 후보 기준 **11승 18무 35패**, 점수0.312500, 단측하한0.019865. 이번 alpha는0.004166666666666667다.
- `alpha_k=0.05/(k*(k+1))`, 최소32쌍, 하한0.5초과 조건은 그대로다. 새 모델이 구 V1보다 나아 보이는 것만으로 채택하지 않는다.
- 후보 가중치와 소스 고정 뒤 새 난수로 기존 예약 분포에서 복원 표집했고 중복을 유지했다. 학습에 아레나 자료를 섞지 않았다.
- 인식된 외부 엔진·브라우저 CPU 증가0틱, 최대 감시간격0.531908초. 기록된 환경의 비교이며 임의 호스트 부하·온도 변화까지 완전히 통제하는 것은 아니다.

## 설치·출처·재현

실제 소스 고정은 `6550d6cd9bf74f98b08bf1789a9ebbedf55c72ac`, 실행 파일 SHA256은 `ec71a626b8124359fe2e47ab2876e9ea0bc342d42179869158c5aeda63fd921f`다. 이후 결과·설치 문서와 테스트 경로 정규화 커밋을 구분한다. 실험의 구현 해시는 실험 당시6550d6c를 가리키며, 사후 테스트 fixture의 경로 수정으로 실험을 다시 수행하거나 채택 기준을 바꾸지 않았다. 기본 Regicide는 채택된 모델만 다음 세션 시작 때 읽고, 후보가 미통과하면 기존 평가를 사용한다. 이전v0.6.1 소스·실행 파일·학습 상태를 보존하며 개인 기보를 수정하지 않는다.

공개 파일은 개인 경로를 가리고 JSON/줄바꿈을 정규화할 수 있다. 원본 내부 참조 해시는 원본 바이트를 가리키며 [공개 명세](publication-manifest.json)의 원본/공개 SHA 대응을 따른다. 모델 바이트는 그대로다. 공개 기보는 감사 근거이며 새 환경의 모델 채택 권한을 대신하지 않는다. 공개 누적 자료에서 같은 설정으로 재학습한 모델도 같은 SHA256을 재현했다. [재현 보고서](validation/public-reproduction-report.json)를 보존한다.
