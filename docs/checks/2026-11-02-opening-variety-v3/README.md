# 첫 세 수의 오프닝 다양성 v3 — 2026-11-02

첫 6착수에서는 모든 합법 수를 후보로 확장했다. 중앙 폰 전진·기물 전개 등에는 검토 순서 가중치 3, 나머지는 1을 주어 모든 수에 검토 기회를 남긴다. 같은 깊이의 25cp 검사를 통과한 대안만 기본 수와 함께 선택하며, 추가 시간 상한은 기존대로다. 최대 검토 후보는 이 구간에서 6개에서 10개로 늘었다.

## 조건

- 기존 버전: `9137e5f815ad9af12649968d9f8e7f0bb694fd9c`의 v2. 변경 버전: `regular/new-source/`와 `focus/new-source/`에 보존한 동일한 v3 소스.
- 기본 생각 시간 1000ms, 오프닝 추가 검토 최대 1000ms. 8국면 × 고정 시드 8개, 정책별 64회, 최종 비교 128회.
- 자체 Regicide 0.7.0-dev, classical 평가, Python 3.13.16 / python-chess 1.11.2 / Windows 11. 바이너리·소스 해시와 전체 국면·시드는 manifest에 보존한다.
- 매 요청은 새로운 임시 대국·독립 엔진이다. 화면용 힌트와 평가 도우미를 양쪽에서 동일하게 껐다. 개인 대국이나 실행 중인 게임을 변경하지 않았다.
- 공유 컴퓨터에서 순차 측정했으며 CPU를 독점하지 않았다. 시간 제한 탐색 깊이는 실행 부하에 영향을 받는다.

## 품질 기준과 지연

모든 최종 착수와 채택 후보의 예상 수순을 독립 규칙 구현으로 재검사했다. 채택된 대안은 모두 기본 탐색과 같은 완료 깊이·25cp 이내 조건을 충족했고, 선택된 대안의 최대 차이는 25cp였다. 기본 탐색 시간은 모두 1000ms로 유지됐다. 이 검사는 자체 평가 기준 준수이며 실제 경기력 무손실이나 Elo 향상 증명이 아니다.

요청 처리 시간 평균은 1.659초 → 1.968초, 관측 최대는 2.004초 → 1.994초다. 엔진 시작·카탈로그 최초 로딩을 제외하고 탐색·상태 구성·임시 기보 저장은 포함한다. 실제 사용에서는 첫 세 수에 남아 있던 추가 검토 시간을 더 쓰는 경우가 있다.
