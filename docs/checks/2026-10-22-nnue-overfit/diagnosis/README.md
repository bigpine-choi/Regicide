# 실패한 Stockfish 소규모 학습 진단

2026-10-22 KST. 과거 모델·자료·16판 결과를 읽고, 첫 게임의 초반 8개 후보 수에
대해 Stockfish 10,000노드 전후 평가 16회만 추가했다. 새 학습·대국은 실행하지 않았다.
원시 결과와 각 입력 SHA256은 `diagnosis.json`에 있다. 실행 코드는
`scripts/analyze_stockfish_overfit.py`다. 마지막 소스 변경은 콘솔 요약 출력 축소뿐이며
저장된 수치 계산에는 영향을 주지 않는다.

## 확인한 사실

- 학습 350개·46계열, 검증 81개·14계열이다. 학습 자료는 평균 16.17기물이며
  28기물 이상인 위치는 41개다. 전체 초기 배치와 가까운 조합을 충분히 검증한 자료는 아니다.
- 학습 중 MSE는 72,126→12,297cp²로 감소했으나 검증 MSE는 46,872→76,282cp²로
  악화됐다. 자연 자기대국 계열 검증 MAE도 149.13→214.66cp, 합성 엔드게임도
  191.71→248.35cp로 악화됐다. 한 검증 하위 집단만의 현상은 아니다.
- 시작판에서 비왕 기물 하나씩 제거한 유효 보드 30개 모두 기물 손실의 부호는
  올바르다. 평균 기물 손실 점수는 warm STM 대비 폰 128→78.38cp, 나이트
  338.25→243.25cp, 퀸 932→793cp로 축소됐다. 이는 한 배치에서의 국소 진단이며
  전체 체스에서 해당 기물 가치가 항상 이 수치라는 주장은 아니다.
- 첫 게임 `4.Qd2` 직전 정적 점수는 warm STM −108cp, 기본 수식 −116cp,
  실패 모델 +220cp다. 별도 Stockfish 정확 cp 패킷은 두기 전 −48cp, 두고 난 뒤
  −174cp여서 이 짧은 분석에서는 126cp 손실이다.
- 첫 게임 `8.Nh4` 전후 Stockfish 점수는 −76→−232cp다. 실패 모델 정적 점수는
  +254→+431cp로 오히려 좋아진다고 평가한다. 12수째에는 실패 모델 +675cp와
  warm −266cp·기본 수식 −330cp까지 벌어진다. 평가 함수의 포지션 판단이
  드리프트했다는 구체적인 사례다.
- 첫 게임 24ply에 등장한 기물 입력 특징 74개는 모두 학습 자료에도 있다.
  따라서 이 사례를 단순히 “미등장 특징이라 실패했다”라고 설명할 수 없다.
- 과거 대국에서 후보/기본 검색 깊이 중앙값은 모두 4, 요청 응답은 평균 약 81.6ms다.
  후보 검색 노드 평균 42,161, 기본 41,320으로 후보의 계산량 부족이 참패를
  설명한다는 증거는 없다. 위치·게임 길이가 달라 엄밀한 속도 비교는 아니다.

## 해석과 한계

500epoch 동안 작은 자료를 높은 입력 학습률로 반복하고 마지막 epoch를 무조건
채택한 조건에서, 학습 자료 암기와 보지 않은 포지션의 판단 악화가 함께 관측됐다.
검증 손실을 기준으로 일찍 멈추고 가장 좋은 가중치를 복구하는 개선이 이 증거에
직접 대응한다. 이 진단만으로 과적합이 15패의 유일한 원인이라고 확정하지 않는다.

warm STM과 기본 수식 Regicide의 같은 조건 직접 대국은 없으므로 “Stockfish
fine-tune 전에는 기본 엔진보다 강했다”라고 말할 수 없다. 정적 평가 예시는 전체
탐색의 정답률이나 Elo를 증명하지 않는다. Stockfish 진단은 FEN 기준의 짧은 유한
탐색이며, bound·메이트 패킷은 수치 손실 계산에서 제외했다. 추가 질의는 학습이나
검증 정답에 편입하지 않았다.
