# 자유 배치 분석 모드 검증 · 2026-11-01

`build/regicide.exe`의 기존 Regicide 0.7.0-dev를 사용해 분석 모드를 검증했다. 엔진 실행 파일 SHA-256은 `edd950fb673cfca4134968b64cc5ef0f3d77eda698e9f40d2965170f143d6e6a`다. 추천 수를 선택하는 C++ 탐색·평가 코드는 바꾸지 않았다.

## 자동 검증

- 분석 백엔드 22개 통과: 잘못된 배치의 원자적 거절, 백·흑의 실제 엔진 추천, 캐슬링·앙파상·승격과 정확한 무르기, 이전 추천 취소, 수정 충돌, 인증, 기존 대국·기보 보존. `analysis-backend.txt`.
- Godot 분석: 새 환경 실행, 합성 입력 22개·실제 엔진 연동 30개 확인 통과. 결과는 `godot-analysis/`에 보관한다. 직접 Windows 창 조작과 구분한다.
- 브라우저 분석 12개, 기존 추천 10개, 오프닝 8개와 시간 변경 검사 통과. `final-web-*.txt`.
- 기존 대국 25개·평가 상태 16개·추천 15개·핸디캡 19개·시간 설정 27개·오프닝 20개 통과. 기존 Godot 추천 76개·오프닝 59개 확인 통과. `baseline-summary.txt`와 개별 기록.
- 최초 병렬 검사에서 발생한 Windows 소켓 중단 1건은 기존 대국 전체 단독 재실행에서 재현되지 않았다. 초기 오류와 성공한 재실행을 모두 기록했다.

## 실제 화면 조작

Windows Godot 창을 별도 관리기와 `build/analysis-manual/games-final/` 보관함으로 실행했다. 사용자의 실제 대국 창과 개인 보관함은 검수 대상으로 조작하지 않았다.

1. 분석 모드 진입과 빈 판 만들기.
2. 왕이 없는 배치에서 분석 시작이 거절되고 한국어로 이유가 표시되는 것 확인.
3. 팔레트로 백 왕 e1·흑 왕 e8·백 폰 a7을 직접 배치.
4. `a8=Q+` 추천과 a7→a8 화살표 확인. 추천 수 적용 시 퀸 승격과 흑 차례의 `Kd7` 추천 확인.
5. 한 수 되돌리기로 원래 폰 배치와 백 추천이 복원되는 것 확인.
6. 흑 시점에서 좌표와 추천 화살표가 같은 칸을 가리키는 것 확인.
7. 직접 폰을 이동해 네 종류의 승격 선택 표시, 나이트 선택 후 기물 부족 무승부·추천 중단 확인.
8. 대국으로 복귀해 최초 기본 배치와 0수 상태가 남는 것 확인.

첫 검수에서 Godot의 주기적인 GET 요청 중 클릭이 무시되는 문제가 발견됐다. 조회 요청을 별도 객체로 분리하고, 착수가 시작되기 전의 늦은 조회는 무시하도록 수정했다. 지연된 GET이 끝나기 전에 기물 선택·승격 선택이 유지되고 착수 요청이 완료되는 회귀 검사를 추가해 통과했다.

수정 후 실제 창을 다시 실행해 기본 배치에서 백 e2→e4, 흑 e7→e5를 각각 첫 클릭으로 선택·이동했다. 조회가 이어지는 동안에도 선택 표시가 유지되고 양쪽의 새 추천이 갱신됐다. 한 수 되돌리기로 흑 폰 e7과 흑 차례를 복원한 뒤, 대국으로 돌아가 기본 배치·대국 수정 번호 1·착수 0개·분석 종료 상태를 API로도 확인했다. 이 상태는 `manual-final-state.json`, 추천 화면은 `native-analysis.jpg`에 보관했다. 실행 오류 출력은 비어 있었다.

브라우저에서도 실제 화면으로 FEN 불러오기, `a8=Q+` 추천·화살표, 추천 수 적용, 흑 차례 전환, 한 수 되돌리기와 기존 대국 복귀를 확인했다. 좁은 화면에서 판과 조작 영역이 잘리지 않는 것을 확인했다. `browser-analysis.png`는 이 검수 화면이다. 연결 회복 후 오류 문구가 남는 문제, 현재 배치 읽기 시간 초과 처리, 종료 요청 실패 시 복귀 문제를 수정하고 자동 검사에 추가했다.

분석 수순은 개인 대국 보관함이나 학습 자료에 자동 저장하지 않는다. 기존 실행 바로가기가 이 개발 폴더를 가리키는 것도 확인했다. 검수용 Godot 창·브라우저 탭과 두 검수 관리기를 종료했고 검수용 Python 프로세스가 남지 않은 것을 확인했다. 기준 커밋과 최종 구현 파일의 SHA-256은 `source-manifest.json`에 기록했다. 실제 대국 성능·Elo 비교는 수행하지 않았다.
