# 정식 M2 실행 기록 — 2026-10-21

현재 단계: **초기 사전2시도 중단 기록 보존·원인 보완 완료, 새 사전 검증 준비**. 완료한 사전 대국은0판이며 본 대국은 시작하지 않았다. 실행 결과가 들어오면 실제 상태로 갱신한다. 기력 향상·모델 승격을 선언하지 않는다.

[사전 계획](../../experiments/2026-10-21-m2-formal-plan.md)과 [정확한 JSON](../../experiments/2026-10-21-m2-formal-plan.json)에 조건을 고정했다. M1 수식·보정망 V2·정수 NNUE와 Stockfish18/Sunfish,100ms/1초, 새32개 시작 계열·양색의768판이다. 별도 첫 사전 계열의24판이 입력·부하·코어/기보 감사를 통과해야 본 대국을 시작한다.

물리8코어를 두 코어씩4구역으로 나누며 같은 계열/상대/시간의 세 평가 경로는 같은 구역에서 순서대로 둔다. 각 조건이 각 구역에8쌍씩 배분된다. 샘플0.5초·최대 간격2초·외부 known engine CPU 증가0·비소유 호스트2초 평균20% 이하를 요구한다. 이 수치는 완전한 OS·열·전력 격리를 보장하지 않는다. 첫 실패에서 전체 단계를 멈추며 미완료를 무승부로 세지 않는다.

## 준비 검증

- 새 [개시군 검사](openings/README.md): 과거 인벤토리1006개, 주요 은행/부모 직접 재생,8반수 부모·전치·최종입력·색/랭크 반전 충돌 검사. 보충 과거 PV 추출의 한계도 기록한다. 상위7개 묶음으로 상관을 보고한다.
- [부하 단위/실제 검증](load-unit/README.md): 최종33검사, 실제 정상4작업 cohort 및 외부 canary CPU 위반 검출. 최종 actor의 [실제 비동기 감시](native-timer/attempt-002/result.json)도 통과했다. 기존 사용자 프로세스는 종료하지 않았다.
- [실행·감사·통계 단위](formal-unit/report.json): 최종13검사 통과. 과거 시험 실패와 수정 후 결과도 보존한다.
- [실제 job 정리](native-job-smoke.json): 자체 부모가 끝난 뒤 살아 있던 자체 고아 자식이 job 종료 때 정리됨을 확인했다.
- [기기](hardware.json), [native 기준 보존](native-before.json), [원래 두 개발 폴더 상태](originals-before.json)를 남겼다. 바탕화면 게임 실행 파일은 교체하지 않는다.

실행은 ignored `build-m2-formal/attempt-001/`에 고정 복사본·원시 기보/검색/부하를 보관한다. 사전과 본 대국은 폴더와 점수를 분리한다. 원시 기록·해시·독립 감사가 완료된 뒤 요약을 추가한다.

초기 시도는 [전부 보존](preflight-attempts.json)한다. 001은 사용자가 별도로 연 게임의 실제 CPU 사용을 감지해 idle 단계에서 거절했고, 사용자가 게임을 직접 종료했다. 002는5초 idle 뒤 root의 동기 파일 검증으로 감시 간격이2.0156초가 돼 거절했다. 기준2초를 유지하면서 감시를 독립 스레드로 분리하고 native 요청을2초 응답 상한의 직렬 큐로 옮겼다. 동기 방식의 최초 idle 검사는 아직 worker가 없는 단계이며 별도 범위다. 기존 두 시도의 완료 대국은0판, 본 대국은0판이다.
