# 잔여6분부터 시간 절약

2026-11-03. `regicide-engine-pacing-v7`는 시간 절약 시작점을 잔여4분에서6분으로 앞당겼다. 기본 목표시간·장고 추가 시간·오프닝 상한이 같은 기준을 사용하며, 탐색 후에도 최신 잔여시간으로 다시 계산한다.

6분 이상에서는 기존 배분을 유지하고,6분 아래부터 연속적으로 짧아진다. 기본 압박 계수는 `0.5 + 0.5 × min(1, 잔여시간 / 360초)`다. 잔여6/4/3/2/1분에서 각각1,5/6,3/4,2/3,7/12이며, 이미 잔여시간을 반영한 권장시간에 추가로 적용된다. 장고의 추가 배수도 같은6분 기준으로 감쇠한다.

오프닝의 짧은 상한·0.1초 즉답·기존1초 단축·잔여10초 이하 추가 대기 생략은 유지했다. 스파링의20수 접전·21~69수 강화·70수 전력 일정과 사람 권장시간 계산은 변경하지 않았다. 과거 저장 정책을 보존하고 새 PGN에 v7을 기록한다.

## 검증

- [시간 정책82개](timing/validation.json)와 [호스트·저장64개](host/validation.json), 총146개 통과.6분 직전·경계·직후, 단계별 단조 감소, 탐색 후 최신 시계, 오프닝 상한, 낮은 잔여시간, 기존 계약과 과거 정책 복원을 확인했다.
- [브라우저 검사와 Godot77개](ui/validation.json) 통과. 안내 문구를6분으로 바꾸었으며, 스파링의 자동 시간관리와 일반 모드로 새 대국을 시작했을 때 수동 생각시간 선택 복원도 기존 UI 검사에서 확인했다.
- 테스트는 계산·제어된 호스트·자동 UI 검사다. 이번 변경으로 실제 대국의 평균 소모시간이나 시간패율을 측정한 것은 아니다.

스파링의 생각시간 선택창은 이전 요청에 따라 자동 관리로 대체된 상태를 유지했다. 스파링을 새 대국 모드로 선택하거나 현재 대국이 스파링이면 수동 선택이 숨겨진다. 현재 스파링 판에서 일반·보스를 선택만 해서는 진행 중인 판의 시간관리 방식이 바뀌지 않으며, 해당 모드로 새 대국을 시작하면 수동 선택이 돌아온다.

[소스 일치 확인](source-verification.json)과 [근거 파일 해시](artifact-manifest.json)를 보존했다. 실행 중인 사용자 게임과 개인 기록은 수정하지 않았다. 재실행 후 새 대국부터 적용된다.
