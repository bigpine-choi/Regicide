# 즉답과 긴 장고의 시간 대비

2026-11-03. 명백한 수는0.1초 수준으로 두고, 복잡한 갈림길에서는 드물게 확실히 오래 고민하도록 `regicide-engine-pacing-v5`를 적용했다. 학습한 인간 행동 모델이 아니라 국면·탐색 결과·게임별 시드에 따른 시간 배분 규칙이다.

## 변경

- 전체 착수 목표의 빠른 하한을250ms에서100ms로 줄였다. 유일한 합법 응수, 익숙한 오프닝, 명백한 메이트·퀸 포획 등의 기존 빠른 분류에 적용되며, 탐색 예산도 처음부터 이 목표 안에서 배정한다. 탐색 후 대기만 줄이는 방식이 아니다. 모든 쉬운 수가 항상100ms가 되지는 않는다.
- 장고 발동 조건은 그대로 유지한다. 복잡도45 이상이면서 뜻밖의 응수·탐색 후보 변경이 있거나, 복잡도70 이상일 때만 후보가 된다. 이때 시드에 따른 장고 선택 구간을18%에서10%로 줄이고 배수를1.85–2.25에서2.8–3.4로 늘렸다. 이 비율은 적격 국면에 대한 규칙이며 전체 대국의 장고 빈도는 아니다.
- 최근 실제로 완료한 장고 이후 두 번의 자기 차례에는 새 장고를 억제한다.44초 상한까지 기다린 장고도 억제 이력에 포함되도록 경계를 고쳤다.
- 기존 최대1초 단축, 잔여4분부터의 연속적인 시간 절약, 잔여10초 이하 추가 대기 생략을 유지한다. 실제로 사용한 탐색 시간은 전체 착수 시간에 포함한다. 선택 후 시간 보정은 탐색 예산을 늘리지 않는다.
- 수 선택은 기존 자체 엔진과 정책이 수행한다.100ms 목표의 짧은 탐색에서는 깊은 분석·레이팅 관측이 생략될 수 있으며, 충분한 근거 없이 관측치를 만들지 않는다. 사람에게 보여 주는 권장시간 계산은 바꾸지 않았다.
- 브라우저와 Godot 안내를 즉답·장고에 맞췄고, 저장·복원 PGN은 실제 v5 식별자를 보존한다. 과거 대국과 라벨을 수정하지 않았다.

## 실제 엔진 확인

[독립된 임시 게임의 HTTP 검증](native/native-result.json)은 실제 자체 엔진으로 수를 선택하고 실제 시계로 기다렸다. 국면과 초기 잔여시간만 검사용으로 설정했으며, 긴 장고의 출발 FEN과 합법 수순도 기록했다.

| 국면 | 목표 시간 | 실제 시계 차감 |
|---|---:|---:|
| 유일한 합법 응수 | 0.100초 | 0.113476초 |
| 공짜 퀸 포획 | 0.100초 | 0.111724초 |
| 복잡도75 국면의 장고 | 28.557초 | 28.560023초 |

모두 스파링 모드에서 합법 수를 반환했다. 세 개의 구성된 국면에 대한 기능 검사이며, 컴퓨터 부하·탐색 결과에 따라 실제 시간은 달라진다. C++ 실행 파일 SHA256은 `5011da4c5e6ef01c452bd7125e4e22b372d2c9cfb858ed8759057325acb0e6ba`다.

같은 장고 국면의 실제 탐색 결과를 재사용해 계산한 목표는 잔여4분/3분/1분에서22.646/11.901/0.551초였다. 이는 잔여시간별 계산 검사이고 추가로 실행한 실제 대기는 아니다.

## 회귀 검사와 한계

- 관련 단위·호스트 검사는 최종145개 통과했다. [기존 검사](unit-initial/validation.json)의118개, [새 정책 및 유지 계약22개](unit-new/validation.json), [진단5개 재검사](diagnostic-fix/validation.json)를 포함한다. 초기 진단1개는 비활성화된 긴급 탐색 예산까지 대기 목표로 비교해 실패했다. 활성 목표와 모든 잔여 대기량을 따로 비교하도록 진단을 수정했고5개 모두 재통과했다. 최초 실패 기록도 보존했다.
- [Godot77개 및 브라우저 검사](ui/validation.json) 통과. 자동 검사이며 수동 GUI 대국 검사는 아니다.
- [동일 입력 비교3,840건](comparison/comparison.json)은 고정 v4 커밋과5국면·128시드·6개 잔여시간을 비교했다. 잔여10분의640건에서150ms 이하 목표가0건에서145건으로 늘었고 평균 목표는6.530초에서6.496초로 줄었다. 이 기존5국면에는 장고 발동 조건을 만족한 사례가 없으므로 장고 변화는 위의 실제 엔진 검사와 별도 단위 검사로 확인했다.
- 실제 인간 착수 시간에 대한 적합도, 전체 대국 평균 시간, 기력·레이팅 정확도 향상은 검증하지 않았다. 종전1초 단축 계산은 유지되지만 새 장고 분포까지 포함한 실전 평균을 보장하지 않는다.

[소스 일치 확인](source-verification.json)과 [근거 파일 해시](artifact-manifest.json)를 보존했다. 재현은 `tests/contrast_pacing_tests.py`, `tests/contrast_pacing_integration.py --output <새 경로>`, 이 폴더의 `compare_pacing.py --output <새 경로>`를 테스트용 Python으로 실행한다. 실행 중인 사용자 게임은 건드리지 않았으며 앱 재실행 후 새 대국부터 적용된다.
