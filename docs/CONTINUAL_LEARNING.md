# 패배에서 배우는 자동 학습 순환

Regicide는 **자가대국 → 패배한 판의 실수 분석 → 학습 자료 누적 → 정답 안정성 확인 → 재학습 → 이전 채택 모델과 대국 → 통과한 모델만 채택**을 한 번의 실행으로 이어 간다. 사용자가 매 단계마다 명령을 다시 입력할 필요는 없다. 다만 대국이 늘 때마다 반드시 강해지는 것은 아니다. 새 모델이 기준을 통과하지 못하면 기존 채택 모델로 계속 대국하고, 완료한 학습 자료는 다음 순환에 남긴다.

이 문서는 구현된 동작과 사용 방법을 설명한다. 실제 실행의 성적이나 새 모델의 채택 여부를 미리 결과로 가정하지 않는다. 실험 조건은 [사전 계획](experiments/2026-10-18-learning-cycle-plan.md), 첫 신경망의 구조와 한계는 [신경망 평가 설명](NEURAL_EVALUATION.md)에 있다.

**기존 평가를 보존하는 V2 모델**

새 자동 학습의 기본값은 V2다. 기존 V1은 기물 점수에 신경망 출력을 더해 왕의 폰 방패·폰 구조 등을 포함한 기존 위치 평가를 대체했다. 작은 자료에서 배운 신경망이 기존 지식을 한꺼번에 대신하는 부담을 줄이기 위해 V2는 **기존 전체 평가 + 최대 100cp의 학습 보정**을 사용한다. 100cp는 평가 단위상 폰 하나다. 초기 보정은 0이므로 학습 전에는 기존 평가와 같다.

V2는 교사가 계산한 위치 점수를 학습 목표로 삼고, V1의 대국 승패 20% 혼합은 사용하지 않는다. 가중치가 과도하게 커지는 것을 억제하는 L2 정규화의 기본값은 `0.0001`이다. 이는 개선을 위한 설계이며 기력이 실제로 좋아졌다는 판정은 아래의 동일한 대국 기준으로만 내린다. 모델 형식·학습 목표·보정 한도는 각 순환의 `cycle.json`과 학습 보고서에 남는다.

```text
V1: material_cp_stm + 600*z
V2: classical_cp_stm + 100*tanh(z)
```

V1 파일과 이전 실험 실행기는 계속 지원한다. V1과 V2의 가중치가 뜻하는 점수는 다르므로 형식이 다른 채택 모델의 가중치를 그대로 이어 쓰지 않는다. 그 경우 후보는 새로 초기화하고, 기존 채택 모델은 자가대국과 비교 대국의 기준으로 유지한다. 같은 형식의 채택 모델이 있으면 해당 가중치에서 이어서 학습한다.

**어떻게 실수에서 배우는가**

설명을 위한 예로, Regicide가 룩을 공짜로 내주는 수를 두고 졌다고 하자. 분석기는 그 수를 두기 직전의 위치와 전체 수순을 복원한다. 같은 위치에서 자유롭게 찾은 최선 수의 점수가 `+50cp`, 실제로 둔 수를 반드시 두게 한 탐색의 점수가 `-450cp`였다면, 두 선택의 차이는 `500cp`다. `100cp`는 평가 단위상 폰 하나에 해당한다.

이 비교는 똑같은 위치와 같은 쪽의 관점에서 이루어진다. 앞뒤 위치의 점수를 단순히 빼서 차례가 바뀐 영향을 실수로 오인하지 않는다. 충분히 계산한 유한 점수가 있고 더 나은 대안이 발견된 학습용 위치만 교정 자료에 추가한다. 작은 신경망은 그 자료와 이전 자료를 함께 보고 위치의 가치를 다시 학습한다. 수를 고르는 일은 계속 자체 탐색 엔진이 맡는다.

분석기의 답도 제한된 계산에서 얻은 추정이다. “탐색이 좋은 수를 놓쳤을 가능성”, “평가가 어긋났을 가능성”이라는 분류를 남기지만, 한 번의 분석으로 원인을 확정하거나 그 악수가 영원히 사라졌다고 단정하지 않는다.

**한 번의 순환에서 하는 일**

1. **자료 수집:** 현재 채택 모델로 자가대국한다. 채택 신경망이 없으면 기존 수식 평가로 시작한다. 기본 설정은 16개 오프닝 계열에서 두 판씩 총 32판, 수당 1,000노드다. 일정한 수 간격으로 실제 대국 위치를 고르되, 간격이 짝수여도 백 차례와 흑 차례를 번갈아 수집하도록 표본 위치를 조정한다. 차례만 인위적으로 뒤집거나 교사 점수의 부호를 바꿔 복제하지 않는다. 시도 번호에 따라 수집·학습 시드가 달라지며 전체 수순과 실제 결과를 기록한다. 기본 교사 라벨은 신경망을 끈 자체 수식 평가가 10,000노드로 계산한다.
2. **패배 분석:** 끝까지 완료된 결정판에서 패한 쪽의 의심스러운 수를 판당 최대 8개 선별한다. 기본 50,000노드로 자유 탐색과 실제 수 강제 탐색을 각각 수행한다. 기본 100cp 이상 손실, 정확한 유한 점수, 완료 깊이 2 이상 등 신뢰 조건을 충족한 학습 계열 위치만 교정 라벨로 내보낸다. 메이트 점수를 임의의 cp로 바꾸지 않는다.
3. **자료 누적:** 이전에 완료한 수집 자료와 교정 자료를 함께 읽는다. 게임·수순·승패·PGN·파일 해시를 다시 검사하고, 같은 대국의 같은 위치에는 최신 교사 라벨을 사용한다. 신경망 입력이 정확히 같은 학습 위치는 한 번만 남긴다. 실패한 후보 모델의 자가 승격이나 아레나 자료의 학습 편입은 없다.
4. **정답 안정성 확인:** v0.6.3부터 누적train을 자체 수식교사10,000·50,000·200,000노드로 다시 확인한다. 마지막 두 검색의 추천수 일치·30cp 이내 점수차·완료깊이3이상 등 신뢰 조건을 만족한 최종 라벨만 별도 quality/ 자료로 학습한다. 원본과 검증/시험 행은 보존한다. 전량 탈락하면 훈련과 채택을 중단한다. 위치당 세 검색을 다시 하므로 계산 시간이 늘어난다. [비용 분리와 품질 도구](NEURAL_COST_QUALITY.md)를 참고한다.
5. **재학습:** 선택한 형식과 같은 채택 신경망이 있으면 그 가중치에서 이어서 학습한다. 채택 모델이 없거나 형식이 다르면 새로 초기화하며, V2의 마지막 출력층은 0으로 시작해 기존 평가를 보존한다. Adam 최적화기의 누적 상태는 매 순환 새로 시작한다. 검증 오차로 학습 시점을 선택하며, 재학습 전 가중치인 epoch 0도 후보에 남는다. 시험 오차는 보고용이며 모델 채택 기준으로 쓰지 않는다.
6. **규칙 검사와 대국:** 규칙 회귀 검사와 실제 C++ 모델 읽기 검사를 거친 뒤, 학습과 별도로 예약한 시작 위치에서 이전 채택 모델과 대국한다. 처음에는 기존 수식 평가가 비교 상대다.
7. **채택 판정:** 사전에 정한 통계 기준을 통과한 경우에만 전체 기보·자원 기록·모델과 실행 파일의 신원을 다시 확인하고 채택 명세를 원자적으로 교체한다. 다음 대국을 새로 시작할 때 새 채택 모델을 사용한다. 진행 중인 대국은 시작할 때 복사한 모델을 계속 사용한다.

검증·시험 자료는 첫 bootstrap 자료의 **검증 96개, 시험 125개**를 학습 저장소 안에 복사해 고정한다. 이후 자가대국에서는 학습 위치만 누적한다. 새 학습 위치가 고정 자료와 같은 보드 또는 같은 신경망 입력을 가지면 새 학습 위치를 제외한다. 기존 검증·시험 라벨을 덮어쓰거나 다른 split으로 옮기지 않는다. 각 순환에 출처 해시, 고정 자료 해시와 누설 제외 수를 남긴다.

**어떤 모델을 “더 강해졌다”고 채택하는가**

기본 대국 검증은 최소 **32쌍, 총 64판, 수당 100ms 이상**, 양쪽 Hash 16MiB와 단일 탐색 스레드를 사용한다. 한 쌍은 같은 시작 위치에서 선후공을 바꾼 두 판이다. 같은 실행 파일과 탐색 설정을 사용하고 평가 모델을 비교한다.

후보 가중치를 고정한 다음 새 난수 시드를 뽑아 예약된 시작 위치 분포에서 표본을 추출한다. 시작 위치를 결과에 맞춰 골라 바꾸지 않으며, 이 대국의 위치·승패·점수를 학습 자료에 넣지 않는다. 전체 판이 끝나야 하며 미완료, 불법 수, 통신 오류, 인식된 외부 엔진·브라우저의 CPU 사용 증가나 자원 감시 공백이 있으면 비교 전체를 채택 근거에서 제외한다. 임의의 다른 프로그램 부하나 온도 변화까지 완전히 통제하는 것은 아니다.

승리 1점·무승부 0.5점·패배 0점을 사용하되, 통계 단위는 두 판의 평균인 **한 쌍**이다. 단순히 득점률이 50%를 넘었다는 이유로 채택하지 않는다. 시도 번호를 `k`, 완료한 쌍 수를 `n`, 쌍별 평균 점수의 평균을 `s`라 하면 다음 기준을 적용한다.

```text
시도별 오판 예산 alpha_k = 0.05 / (k * (k + 1))
단측 점수 하한 = max(0, s - sqrt(log(1 / alpha_k) / (2 * n)))

채택: 최소 32쌍, 수당 최소 100ms, 모든 검사 통과, 단측 하한 > 0.5
```

점수 하한은 표본의 우연을 감안해 보수적으로 낮춘 값이다. 실패하거나 중단한 시도도 번호를 소비한다. 반복해서 실험할수록 오판 예산을 나눠 쓰며, 전체 합이 5%를 넘지 않도록 설계했다. 근거는 독립적인 유계 확률변수의 꼬리 확률을 제한하는 [Hoeffding의 원논문(1963)](https://www.tandfonline.com/doi/abs/10.1080/01621459.1963.10500830)과 `sum 1/(k*(k+1)) = 1`이다. 이 해석에는 정해진 분포에서의 독립 표집과 기록된 자원 조건이라는 전제가 있다.

따라서 채택의 의미는 **정해진 시작 위치 분포와 시간 조건에서 이전 모델보다 우세하다는 보수적인 기준을 통과했다**는 것이다. 모든 상대·모든 시간 제한에서의 우세, 세계 순위나 인간 Elo를 보장하지 않는다. 기준이 엄격하므로 64판을 완주해도 새 모델이 채택되지 않을 수 있다.

**실행 방법**

Windows에서는 `Learn-Regicide.cmd` 또는 바탕화면의 **Regicide - Collect and Learn**을 실행한다. 기본값은 위의 순환을 **3회** 연속 수행하는 묶음 실행이다. 완료하면 종료하며, 백그라운드에서 상시 실행하거나 다음 날 자동으로 다시 시작하는 예약 기능은 아니다. 대국 검증 동안에는 다른 Regicide 대국과 브라우저 사용을 쉬어 자원 비교가 무효가 되는 일을 줄인다.

실행기와 자동 순환의 새 기본 모델은 V2이며, 형식 변경 때문에 기존 자료나 시도 번호를 지우지 않는다. 예를 들어 기존 저장소의 시도 번호가 2이면 다음 실행은 3이다. 검증·시험 고정 자료와 보호된 아레나 분포·통계 공식도 그대로 유지한다.

한 순환만 실행하려면 저장소 폴더의 PowerShell에서 다음을 사용한다.

```powershell
.\.venv-tests\Scripts\python.exe scripts/learning_cycle.py --binary build/regicide.exe --rounds 1
```

작동 확인용으로 판수를 줄일 때는 별도 저장소를 사용한다. 다음 명령의 2쌍은 전체 연결을 확인하는 smoke 실행이며, 성적과 관계없이 모델을 채택할 수 없다.

```powershell
.\.venv-tests\Scripts\python.exe scripts/learning_cycle.py --binary build/regicide.exe --rounds 1 --state build/learning-cycle-smoke --arena-pairs 2
```

기존 V1 순환을 명시적으로 실행하려면 위 명령에 `--model-version 1`을 붙인다. PowerShell 묶음 실행기는 `.\scripts\learn.ps1 -ModelVersion 1`도 지원한다. 낮은 단계의 `scripts/train_neural.py`는 이전 호출의 재현을 위해 기본 형식 V1을 유지하므로, 직접 V2를 학습할 때는 `--model-version 2`를 지정한다. 자동 순환은 이 값을 명시해 전달한다.

낮은 단계의 학습 도구는 `--initial-model MODEL`로 기존 가중치에서 재학습하는 기능도 제공한다. 자동 순환은 이 입력으로 현재 채택 모델 중 선택한 형식과 호환되는 모델만 전달한다. V1과 V2는 각각 `small-v1.nn`, `small-v2.nn`으로 저장하며 후보의 실제 형식·해시와 학습 보고서가 일치해야 대국 검증에 들어갈 수 있다.

채택된 모델이 있으면 기본 **Regicide** 대국 실행기가 이를 읽는다. 기존 **Regicide - Neural Experiment** 또는 `Play-Regicide-Learned.cmd`는 명시적으로 지정한 첫 실험 모델 `models/regicide-small-v1.nn`을 사용한다. 명시 모델이 자동 선택보다 우선하므로 이 실험 실행기와 현재 채택 모델의 대국을 구분해야 한다. 채택 명세가 손상됐거나 현재 엔진과 맞지 않으면 기본 대국 실행기는 경고를 표시하고 기존 수식 평가로 대국한다.

**중단과 기록 확인**

기본 저장 위치는 `build/learning-cycle`이다. 먼저 각 run의 `summary.md`를 읽으면 이번 수집량·교정량·누적 표본·대국 판정·채택 여부를 확인할 수 있다.

| 위치 | 내용 |
| --- | --- |
| `latest.json` | 가장 최근 시도의 상태와 판정 |
| `catalog.json` | 영속 시도 번호, 완료 수집 자료와 진단 자료의 목록·해시 |
| `bootstrap/`, `bootstrap-snapshot.json` | 최초 자료의 불변 사본과 신원 |
| `runs/000001-…/summary.md`, `cycle.json` | 해당 순환의 쉬운 요약과 단계별 상세 기록 |
| 각 run의 `data/` | 자가대국의 전체 기보, 결과, 원본 학습 표본 |
| 각 run의 `loss-analysis/` | 의심 수 분석, 제외 이유, 신뢰 조건을 통과한 교정 표본 |
| 각 run의 `corpus/` | 누적 학습 자료, 고정 split과 중복·누설 검사 결과 |
| 각 run의 `quality/` | 원본train의 단계별 교사 재탐색·선택/제외 근거, 고정 검증/시험 보존, 실제 재학습 입력 |
| 각 run의 `model/`, `training.log` | 학습 후보 가중치, 초기 모델 SHA, 학습 오차와 선택 시점 |
| 각 run의 `rules/`, `arena/` | 규칙 검사와 선후공 대국·자원 감시·채택 기준의 증거 |
| `champion.json`, `models/` | 통과한 경우에만 생기는 채택 명세와 보존 모델 |

`Ctrl+C`로 중단할 수 있다. 완료된 자료와 이전 채택 모델은 보존하며, 다음 실행은 새 시도 번호를 사용한다. 중단된 수집 run 전체를 완결 자료로 등록하거나 미완료 대국을 무승부 정답으로 바꾸지 않는다. 같은 저장소를 동시에 쓰는 두 학습 프로세스는 운영체제 잠금으로 막고, 소유 프로세스가 종료되면 잠금이 해제된다.

Windows에서는 학습 순환이 실행되는 동안 유휴 시간에 따른 자동 절전을 잠시 억제하고, 정상 종료나 오류·중단 시 이전 실행 상태로 복원한다. 화면을 계속 켜 두도록 요구하거나 영구 전원 설정을 바꾸지는 않는다. 사용자가 직접 절전을 선택하거나 덮개를 닫는 등의 동작까지 막는 기능은 아니며, 실제 절전이나 긴 감시 공백이 발생한 대국 검증은 계속 무효로 처리한다.

카탈로그·고정 자료·누적 파일이 손상되면 시도 횟수를 0으로 되돌려 계속하지 않고 중단한다. 원본 기록을 보존하고 원인을 확인해야 한다. 학습·아레나 중 구현 코드나 설치 실행 파일이 바뀌어도 후보의 자동 채택을 막는다.

현재 자동 수집 대상은 자체 자가대국이다. 사용자가 사람과 둔 모든 개인 기보를 자동으로 가져오거나, 대국 화면을 켜 둘 때마다 곧바로 학습하는 기능은 포함하지 않는다. 새 자료가 쌓이면 다음 학습에 활용되지만, 자료 수 증가·학습 오차 감소·학습 반복 횟수만으로 기력 향상을 선언하지 않는다.
