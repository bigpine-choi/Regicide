# 최근 5패 진단 기록 검토

2026-10-18. 완성된 원자료를 별도 읽기 전용 검사로 재계산했다. 추가 엔진 검색이나 계수 조정은 하지 않았다. 자체 진단 도구 작성 담당자가 결과를 검토한 기록이며, 외부 기관의 독립 성능 인증은 아니다.

**선정한 5개 위치 중 2개는 같은 평가 함수에서 탐색 예산을 늘리면 외부 분석이 지지하는 대안을 찾았다. 나머지 3개는 평가와 탐색 경계의 한계가 섞인 미해결 사례다. 순수한 평가 함수 버그는 확정하지 못했다.** 별도 보조 위치에서는 LMR 때문에 더 나쁜 수를 택하는 국소 사례가 확인됐다.

## 입력과 비교의 정합성

- 채택된 재대국의 패배 game 1·3·9·13·16만 사용했다. 각 후보 착수 226개를 50,000노드 외부 검색으로 선별한 결과는 `g1-p49`, `g3-p65`, `g9-p23`, `g13-p81`, `g16-p50`이다. game 1·3·16은 첫 유의미한 하락과 최대 하락의 중복 선택, game 9·13은 최대 하락 선택이다. 서로 다른 위치를 임의로 추가해 10개를 채우지 않았다.
- 자체 검색 90개, 정적 관찰 108개를 원본 전체 이력과 대조했다. CLI 원문과 저장된 수·점수·깊이·노드·PV, 한도, 정적 TSV의 FEN·색·합법 수·관점 변환이 일치했다. v0.5.7과 v0.5.8 LMR OFF의 30쌍은 시간과 새 LMR 통계를 제외한 원문 탐색 결과·통계가 동일했다.
- 외부 점수와 bound는 같은 마지막 원문 score packet에 연결된다. 이전 누적 bound가 남았던 시도는 제외됐으며, 이번 확인 자료로 합산하지 않았다. 노드 제한 분석에서 실제 bound가 남은 질의도 있어, 그 숫자를 정확한 cp 하락으로 빼지 않았다.
- 추가 깊이 16·20 대조는 6개 위치 모두 요청 깊이를 완료하고 bound 없이 끝났다. 아래 cp 차이는 이 두 깊이에서 외부 자유 검색과 실제 수 강제 검색 사이의 차이다. 유한 탐색 결과이며 Regicide의 cp와 같은 척도라는 뜻은 아니다.

game 1·9·13의 선후공 교대 상대판과 각각 전체 실제 수순이 같았다(game 1/2·9/10·13/14). 이 패배들을 모두 LMR만의 고유 손상으로 설명할 수 없다. 선정 위치도 각 패배의 유일한 원인이나 처음 패배가 확정된 지점이라는 뜻은 아니다. 예를 들어 game 1의 원래 수 이후에도 외부 값은 양수이고, game 3·16의 더 나은 대안도 후속 분석에서는 불리하다.

## 보조 위치에서 확인한 LMR 영향

game 3/4가 공유하는 73반수 뒤 흑 차례(`pair2-p74`)는 여섯 번째 패배로 세지 않는다. 원래 기록과 같은 119,576노드에서 v0.5.7/OFF는 `f3f2`(+557), ON은 `d1e2`(+247)를 택한다. 별도의 **깊이 6 완료** 비교에서도 이 차이가 유지된다. 외부 깊이 16·20은 `f2`를 일관되게 선호하며 실제 `Be2`와의 차이는 107·116cp다.

따라서 이 위치에는 LMR이 수 선택을 나쁘게 바꾸는 재현 가능한 국소 근거가 있다. ON도 250,000노드부터 `f2`를 찾는다. 이 한 위치를 일반적인 LMR의 기력 저하, 전체 대국 결과의 단독 원인, 또는 5패 모두의 원인으로 확대할 수는 없다.

## 평가 관찰과 회귀 PASS의 범위

정적 관찰 108개에는 체크·자동 종료·현재 즉시 무승부 청구가 없었다. 이것만으로 모든 위치의 전술적 안정성을 입증하지는 못한다. PV 끝은 TT 때문에 잘린 위치일 수 있고 실제 평가 말단이라고 단정할 수 없다. 네 설정의 차이도 정수 반올림이 포함된 관찰이며 정확한 가법적 기능 분해가 아니다.

즉시 착수 후 정적 값은 game 1의 Ndxc4를 Nexc4보다 11cp, game 9의 Bd5를 h3보다 12cp 높게 본다. 그러나 game 1은 동일 평가로 더 읽었을 때 Nexc4를 찾는다. 정적 순위와 외부 순위가 다르다는 사실만으로 평가 구현 버그나 특정 계수의 오류가 입증되지 않는 예다. 또 game 13의 정적 외부 후보 관찰은 선별 당시 `Rb6`에 대한 값이며 후속 확인의 `Ra6` 값으로 바꾸어 해석하면 안 된다.

새 회귀의 PASS는 **기보·전체 이력·점수 형식·합법성·진단 절차를 재현했다는 뜻**이다. 알려진 약점 목록을 통과한 것이 좋은 수 선택 문제의 해결을 뜻하지 않는다. game 1·3은 예산 증가 회복 사례로, 나머지와 보조 위치는 미해결 목표로 보존하는 구성이 타당하다. 이번 기록만으로 확정 최선 수 전술 검증이나 전체 기력 향상을 주장할 수 없다.
