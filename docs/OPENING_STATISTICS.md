# 분석모드와 포지션별 오프닝 통계

Godot 대국 화면에서 **이 위치에서 분석**을 누르면 현재 위치를 복사한 별도
체스판이 열린다. 백과 흑의 수를 모두 직접 둘 수 있고, 착수·한 수 무르기·다시
두기에 따라 오른쪽의 통계가 갱신된다. **처음 배치에서 분석**으로 오프닝부터
시작할 수 있다. **분석 끝내기 · 이전 화면으로**는 원래 대국이나 읽기 전용 기보로
돌아간다. 원본 대국·기보는 수정하지 않는다.

분석 수순은 자동 보관하지 않는다. 남기려면 **분석 기보 저장 (PGN)**을 사용한다.
임의 위치에서 시작한 경우에도 PGN의 시작 FEN을 보존한다. 분석 PGN은 결과를
`*`로 기록하므로 완료 대국 통계에 섞이지 않는다. 분석모드에서는 상대 엔진의
자동 응수와 실시간 형세·추천 수를 사용하지 않는다.

## 표시하는 통계

- 현재 포지션에 도달한 기보 수와 백승·무승부·흑승 비율.
- 상위 12개 다음 수의 SAN 표기, 선택 비율, 기보 수, 백승·무승부·흑승 비율.
- 선택한 자료 출처. 마스터 API가 반환하면 오프닝 이름과 ECO 코드도 표시한다.

판을 뒤집거나 흑 차례여도 결과는 항상 **백승 / 무승부 / 흑승** 순서다. 다음
수의 선택 비율은 그 수의 기보 수를 **현재 포지션 전체 기보 수**로 나눈다.
상위 후보 일부만 표시하므로 선택 비율 합계가 100%가 아닐 수 있다. 소수점
반올림으로 결과 비율 합계가 99.9% 또는 100.1%가 될 수도 있다.

예를 들어 현재 포지션 기보 3판이 `e4 백승 1판 + e4 흑승 1판 + d4 무승부 1판`이면
전체 결과는 `33.3% / 33.3% / 33.3%`, e4 선택 비율은 `66.7%`, e4의 결과는
`50.0% / 0.0% / 50.0%`다. 이 수치는 과거 표본의 관측 결과이며 현재 포지션의
객관적 승률이나 엔진 평가를 뜻하지 않는다.

## 기본 출처: 내 완료 기보

자동 보관 폴더 `문서/Regicide/games/`의 PGN을 집계한다. 별도 `--save-dir`을
사용했다면 그 폴더가 대상이다. 하위 폴더도 읽으며 완료 결과가 있는 표준 체스
기보의 본 수순만 사용한다. 미완료·핸디캡·잘못된 기보·변형 체스는 제외한다.
표본이 없으면 **표본 없음**으로 표시하며 0% 승률을 만들어 표시하지 않는다.

수순이 달라도 같은 포지션이면 합산한다. 기물 배치·차례·캐슬링 권리·실제로
가능한 앙파상 권리는 구분하고 수 카운터는 제외한다. 한 게임에서 동일 포지션이
반복되면 최초 1회만 집계한다. 동일 게임의 복사본을 여러 파일에 넣은 경우에는
각 기록을 별개 표본으로 집계하므로 중복 기보를 넣지 않는 편이 좋다.

한 PGN은 16MiB, 한 게임은 2,048 ply까지만 처리한다. 변경 없는 파일은 다시
파싱하지 않으며, 파일 추가·수정·삭제를 다음 조회에 반영한다. 외부 서비스로
로컬 기보·이름·파일 경로를 보내지 않는다.

## 온라인 출처: Lichess 마스터 기보

2026-11-01 확인 기준 Lichess Opening Explorer는 인증이 필요하다. Lichess의
[개인 토큰 설정](https://lichess.org/account/oauth/token)에서 별도 권한 범위를
선택하지 않은 토큰을 만들고, 실행하는 PowerShell에서 다음처럼 설정한다.

```powershell
$env:REGICIDE_LICHESS_TOKEN = '<본인의 Lichess 토큰>'
.\Play-Regicide-Godot.cmd
```

그 창에서 실행한 Regicide의 통계 출처를 **Lichess 마스터 기보 · 온라인**으로
바꾼다. 토큰은 백엔드 프로세스 환경에서만 읽으며 화면·기보·URL·로그에 넣지
않는다. 토큰 미설정·거절 시 설정 안내를, 요청 제한·네트워크 실패 시 해당 상태를
표시한다. 로컬 통계와 출처를 자동으로 섞지 않는다.

공식 `https://explorer.lichess.org/masters`에 현재 FEN만 조회한다. 마스터 자료는
일반 온라인 플레이어 표본과 다르며 필터는 API의 기본값을 따른다. 현재 FEN만
보내므로 일부 포지션에서는 오프닝 이름이 반환되지 않을 수 있다. 결과가 없는
포지션에 임의의 이름이나 통계를 붙이지 않는다.

네트워크 요청은 한 번에 하나, 기본 타임아웃은 8초다. 최근 128개 포지션의
결과를 최대 24시간 메모리에 캐시한다. 같은 포지션의 동시 요청을 합치고, 429
응답 후에는 최소 60초와 서버가 지정한 대기시간을 존중한다. 자동 재시도는 하지
않으며 필요한 경우 **통계 다시 조회**를 누른다. 화면은 350ms 동안 연속 착수를
모은 뒤 조회하고 FEN·출처·요청 세대가 맞는 응답만 표시한다.

API 호출은 대국용 잠금을 사용하지 않는다. 느린 응답이나 조회 실패가 분석
착수·실제 대국을 막지 않는다. 이 기능은 통계 표시용이며 엔진의 수 선택이나
학습 모델을 변경하지 않는다.

공식 자료:

- [Masters API 명세](https://github.com/lichess-org/api/blob/master/doc/specs/tags/openingexplorer/masters.yaml)
- [Lichess 변경 내역](https://lichess.org/page/changelog)
- [API 요청 지침](https://lichess.org/page/api-tips)

Lichess 서버 코드를 가져오지 않고 공식 API로 데이터를 조회한다. 온라인 자료의
출처는 Lichess Opening Explorer다.

## 재현 가능한 검증

```sh
python -m unittest discover -s tests -p opening_explorer_tests.py
python -m unittest discover -s tests -p analysis_session_tests.py
python -m unittest discover -s tests -p opening_stats_http_tests.py
GODOT --headless --path godot --script res://tests/opening_stats_tests.gd
python tests/opening_stats_godot_tests.py --godot GODOT --binary build/regicide
```

통계 집계·인증·실패 처리는 고정 응답을 주입해 검증한다. 실제 Godot 통합검증은
격리된 테스트 PGN 3판과 실제 Regicide 프로세스를 사용해 표본 `3 → 2 → 1`,
무르기·다시 두기, 시점 반전, 원본 대국·기보 보존을 확인한다. 테스트용 기보는
사용자의 기보 폴더에 설치하지 않는다. 토큰이 없는 상태의 실제 외부 API 호출은
401을 확인했으며, 인증된 온라인 성공 응답은 이 환경에서 실조회하지 않았다.
