# 신경망 A/B 잔차·패배 기보 진단

2026-10-21(KST)에 수행한 사후 탐색 분석이다. 새 학습·대국 결과가 아니다.

[분석 결론과 다음 비교 실험 계획](../../experiments/2026-10-21-neural-target-ab-diagnosis.md)을 먼저 읽는다.

- `residuals/`: 세 모델별 잔차·집단별 오차·학습 곡선·정수/float 재계산.
- `games/`: 전96판 재생과 기계적 후기 선택, 사례78 기보 사본·정확한 수순.
- `counterfactuals/`: 후기76지점의 같은 위치 A/B10k 및 고전100k 후보 자식 비교, 손번16쌍.
- `early-games/`: 모든 결정 대국에서 패자의 여섯 번째 선택을 고정한 추가 명세.
- `early-counterfactuals/`: 그 초반76지점의 동일 조건 비교. 손번 쌍은 앞 실행과 같은 쌍의 반복이다.
- `diagnostic-summary.json`: 초반/후반 참조 차이·제외 분모·실행 비용.
- `peer-audit.json`: 잔차·779검색의 전체 수순/PV·원시 UCI·점수 관점에 대한 독립 감사. 초반 동결 설명의 문구 재사용 오류도 기록.
- `artifact-integrity.json`: 모든 새 산출물과 기존 실험 보존을 확인하는 해시 목록.

교사는 자체 엔진이며 유한 참조 차이가 객관적인 최선 수나 패배의 인과적 원인을 증명하지 않는다. 원래 보류와96판은 후속 연구에서 개발 자료로 취급한다.
