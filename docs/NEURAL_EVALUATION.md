# 작은 신경망 평가와 자체 대국 학습

자가대국 자료를 모아 작은 평가망을 학습하고, 같은 망을 C++ 탐색에서 사용할 수 있다. **첫 모델은 별도 시험 자료에서 기물 점수 기준보다 오차가 커졌다. 기력 향상이 입증되지 않아 기본 대국은 기존 평가를 유지한다.**

## 실행

Windows 저장소 폴더에서 다음 파일을 실행한다.

- `Learn-Regicide.cmd`: 새 자체 대국을 수집하고 100회 학습한다. 결과는 매번 새로운 `build/learning/run-…/data`, `model` 폴더에 저장한다.
- `Play-Regicide-Learned.cmd`: 저장소에 포함된 `models/regicide-small-v1.nn`을 사용하는 실험 대국을 연다. 화면의 엔진 이름에 **학습 평가 실험**이 표시된다.
- 기존 Regicide 바로가기: 기존 평가를 사용한다.

학습 환경은 기존 Python 환경에 `requirements-learning.txt`를 설치한다. 학습은 NumPy 2.3.5, CPU 한 스레드에서 실행하며 GPU는 사용하지 않는다. 기본 수집 조건은 16개 오프닝 계열마다 2판, 수당 1,000노드, 평가 정답 생성에 10,000노드, 최대 256플라이, 4플라이 간격 표본이다. 제한에 도달해 끝나지 않은 판은 승패 정답에 사용하지 않는다.

설정을 바꾸거나 새로 학습한 망을 실행할 수 있다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/learn.ps1 -GamesPerOpening 2 -Nodes 1000 -TeacherNodes 10000 -Epochs 100 -Seed 20261018
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/play_godot.ps1 -NeuralModel "build/learning/run-…/model/small-v1.nn"
```

완료한 모델이 기본 대국 설정이나 포함된 모델을 자동으로 교체하지 않는다. 현재 학습은 매번 같은 시드의 초기 가중치에서 시작한다. 같은 자료와 설정을 반복하면 같은 모델이 나올 수 있으며, 실행 횟수만큼 강해지는 구조는 아직 아니다.

## 무엇을 학습하는가

기존 탐색이 수를 선택하고, 신경망은 탐색 끝의 위치에 점수를 준다. 현재 단계는 **자체 엔진의 탐색값과 완료된 대국의 승패를 이용한 지도학습**이다. 게임 도중 가중치를 바꾸는 온라인 학습이나 자동 강화학습 순환은 구현하지 않았다.

모델은 `768 → 32 ReLU → 16 ReLU → 1`이며 가중치와 편향은 25,153개다. 입력 768개는 자기편 `P N B R Q K`, 상대편 `P N B R Q K`의 각 64칸 점유 여부다. 흑 차례에는 랭크를 뒤집어 자기편이 아래쪽에서 전진하는 방향으로 맞춘다. 캐슬링 권리, 앙파상 권리, 수 카운터, 반복 이력은 망의 입력에 없다.

출력 `z`는 기물 점수에 더할 보정값이다. 점수와 학습 정답은 모두 **수를 둘 쪽 기준**이다.

```text
실행 점수 = round(clip(기물 점수 + 600 × z, -10000, +10000))
학습 정답 = 0.8 × tanh(자체 엔진 탐색값 / 600) + 0.2 × 대국 결과
학습 손실 = mean((tanh(기물 점수 / 600 + z) - 학습 정답)²)
```

기물 점수는 폰 100, 나이트 320, 비숍 330, 룩 500, 퀸 900이다. 결과는 현재 차례 쪽의 승리 `+1`, 무승부 `0`, 패배 `-1`이다. 반올림은 정확히 절반인 경우 0에서 멀어지는 방향이다. 점수는 보정되지 않은 모델 평가이며 승률을 뜻하지 않는다.

NumPy float64로 역전파와 Adam을 직접 구현했다. 학습률은 0.003, 배치 크기는 64, 기울기 노름 제한은 10이다. 실행 시 C++는 점유된 칸의 입력만 합산한다. NNUE의 수마다 누산값을 갱신하는 구현, 정수 양자화, GPU 학습은 아직 없다.

## 자료 분리와 모델 선택

오프닝 계열별로 학습 10개, 검증 3개, 시험 3개를 수집 전에 고정했다. 한 대국의 인접 위치와 같은 계열은 같은 분할에 남긴다. 서로 다른 분할에 나타나는 동일 위치와 **동일 신경망 입력**은 모든 해당 분할에서 제외한다. 권리가 다르더라도 망 입력이 같거나, 흑백·랭크 대칭으로 같은 입력이 되는 경우도 포함한다.

수집 자료에는 전체 수순, FEN, 검색 깊이·노드·주요 수순, 결과와 엔진 해시를 남긴다. 완료된 판의 결과는 규칙으로 다시 확인한다. 체크 중인 위치, 메이트 점수, 경계값, 완료 깊이가 없는 평가 등은 학습 정답에서 제외한다. 학습기는 수순 재생, 점수 방향, 기물 점수와 분할 중복을 다시 검사한다.

100회 중 검증 손실이 가장 작은 모델을 선택하며, 초기 모델도 후보에 포함한다. 동률이면 먼저 나온 모델을 유지한다. 시험 자료는 선택 완료 후 최종 평가에만 사용한다. 모델, 자료, 코드 해시와 환경은 보고서에 기록한다. 같은 시드와 NumPy 버전만으로 모든 운영체제·BLAS 구현에서 비트 단위 재현까지 보장하지는 않는다.

## 첫 실행 결과 — 2026-10-18

기존 v0.5.8 자체 엔진으로 32판을 모두 끝냈고 588개 위치를 얻었다. 학습은 20판·367개 위치, 검증은 6판·96개 위치, 시험은 6판·125개 위치다. 시드는 `20261018`, 검증 기준 선택은 97회차였다.

아래 수치는 위 혼합 정답에 대한 평균제곱오차로, 작을수록 좋다. 비교 기준은 **기물 점수만 사용한 예측**이다. 기존 Regicide의 전체 평가 함수와 대국한 결과가 아니다.

| 분할 | 기물 점수 기준 | 선택한 신경망 |
|---|---:|---:|
| 학습 | 0.052953 | 0.000374 |
| 검증 | 0.068032 | 0.060415 |
| 시험 | 0.052026 | **0.070073 — 악화** |

학습 자료의 오차는 크게 줄었지만 별도 시험 자료로의 일반화는 부족했다. 검증·시험 계열이 각 3개뿐인 작은 실험이므로 원인을 과적합 하나로 확정할 수도 없다. 이번 결과는 자료 수집·학습·엔진 연결의 동작 증거다. 전체 기력이나 Elo 향상의 증거는 아니다. 시험 결과를 본 뒤 모델이나 설정을 다시 골라 이 시험을 개선 근거로 사용하지 않았다.

같은 환경·자료·시드로 재학습한 모델의 SHA-256은 첫 실행과 일치했다.

```text

```

공개 자료와 보고서는 [첫 실행 검증 기록](checks/2026-10-18-neural-v1/)의 `data/`, `training/`에 있다. 포함된 모델의 설명은 [models/README.md](../models/README.md)를 참고한다.

## 엔진 연결과 규칙

UCI 기본값은 `UseNeuralEvaluation=false`다. `EvalFile`로 유효한 망을 읽은 뒤 활성화한다. 잘못된 망으로 교체를 시도하면 기존 설정을 유지한다. `UsePositionalEvaluation=false`는 기존과 같이 기물 점수만 선택한다.

```text
setoption name EvalFile value models/regicide-small-v1.nn
setoption name UseNeuralEvaluation value true
position startpos
go nodes 10000
```

직접 명령으로도 사용할 수 있다.

```powershell
.\build\regicide.exe search 4 --nodes 10000 --eval-file models/regicide-small-v1.nn
.\build\regicide.exe eval --eval-file models/regicide-small-v1.nn
```

`eval`은 정적 평가만 출력한다. 실제 탐색에서는 체크메이트, 스테일메이트, 자동 무승부와 무승부 청구 처리가 평가망보다 우선한다. 망은 합법 수 생성이나 규칙 판정을 바꾸지 않는다. 대국 화면은 세션용 모델 사본을 사용해 본 엔진과 추천 엔진을 일치시키며, JSON·PGN에 평가 방식과 모델 SHA를 저장한다.
