# 형세 품질 검사 2차 선후공 검증 조건

1차 검증에서 백33ply와41ply의 큰 손실이 독립 재평가로 확인됐다. 1차 원본은 `2026-11-03-sparring-quality`에 그대로 보존한다. 2차는 그 사례와 이전 고정 사례를 재현한 뒤 별도 폴더에서 실행한다.

검증 대상 수정은 세 가지다. 허용 하한을 완전히 충족하지 못해도 원래의 큰 붕괴를 충분히 줄이는 자체 후보를 검증했다면 그 후보를 선택하되 `mitigated`와 `floor_met=false`로 남긴다. 얕은 자체 후보가 외부 검사상 유망하면 동일 후보의 자체 재탐색이 필요한 깊이를 충족한 뒤에만 적용한다. 두 차례 전체 후보 탐색에서 적절한 수를 찾지 못하면 아직 후보로 검토되지 않은 자기 나이트·비숍의 합법 수 묶음도 자체 엔진으로 탐색한다. 외부 엔진 PV를 후보로 주입하지 않는다. 안전 검증 통과·손실 축소·미확인은 구분한다.

- 표준 시작 배치, Regicide 스파링 백·흑 각1판. 실제 `HumanGame` 호스트와 최종 품질 검사 사용.
- 상대는 기존 Stockfish18, `UCI_LimitStrength=true`, `UCI_Elo=1700`, 1스레드, Hash16MiB. 외부 전력 심판은1스레드, Hash32MiB.
- 동일 시드 입력 `2026-11-03-quality-guard`, Regicide 요청3000ms, 상대300ms, 10+0, 최대220ply. 실제 시간 배분은 호스트가 결정한다.
- 1차와 조건·스파링 시드가 같아도 Stockfish 내부 확률 선택을 통제하지 못하므로 동일 대국 재실행이나 단순한 전후 승률 비교라고 부르지 않는다.
- 수정하지 않은 `tests/sparring_validation_match.py`를 사용한다. 화면용 표시만 끄고 연출 대기는 실제 수면 없이 게임 시간에 부과한다. 실제 탐색 시간은 그대로 부과한다.
- 두 판을 병렬 실행하되 감사까지 포함한 무거운 작업은 최대2개로 유지한다. 먼저 끝난 판은 다른 판 진행 중 별도 감사를 시작할 수 있다.
- 평가로 승패를 정하지 않는다. 합법적인 종료·시간 종료·미완료·오류를 구분하며, 진행 중 측정 소스를 변경하지 않는다.

초기 위치와 모든 실제 착수 후 위치를 별도 전력 Stockfish로 각각 새 탐색200000노드 평가한다. 의심 장면은 전후 각각3000ms, 개수 상한 없이 추가 평가한다. 메이트·미확인을 cp나 접전 충족으로 바꾸지 않는다.

20수까지 초기 위치 포함41개 위치의 ±100cp 유지와 스파링 직후·상대 직후 비율을 따로 보고한다. 21~49수 하한, 50수 이후 검사, 미확인·생략·앞선 전술 검사 실패로 인한 미실행을 구분한다. 모든 대체·손실 축소 수는 원본 Regicide 루트 재탐색과 대조하고, 필요했던 후보 재탐색도 확인한다.

기존 감사 스크립트의 선택 종류·램프 집계는 새 `quality_guard`를 해석하지 못한다. 별도 요약에서는 해당 집계를 새 검사 성적표로 사용하지 않고, 독립 위치·심층 점수와 새 최종 검사 기록을 분리한다. 20수 이전에 우세를 ±100cp 접전으로 되돌린 검증된 양보는 불필요한 붕괴와 구분한다.

2판은 기능 진단이다. Elo, 전반적인 강도 향상, 인간 체감 또는 모든 대국의 접전을 입증하지 않는다.

## 백 단계 도달 보강 — 추가 대국 실행 전 결정

첫 백 대국이33ply 체크메이트로 끝나20수와21수 이후의 백 동작을 관찰하지 못했다. 이를 성공한20수 접전 검증으로 세지 않으며, 이 대국과 독립 감사는 모두 유지한다.

백의 단계 도달 범위를 보강하기 위해 백1판을 추가한다. 별도 시드 입력은 `2026-11-04-quality-coverage`, 출력은 `1700-white-extra/`다. 상대1700·시간3000/300ms·10+0·220ply·표준 시작·독립200000노드/의심 장면3000ms 조건은 같다. 기존 백 대국을 대체하지 않고 총3판 전부 보고한다. 추가 백이 다시 일찍 끝나도 숨기거나20수 검증 성공으로 바꾸지 않는다. 백 첫 감사가 끝난 뒤 흑 대국과 함께 최대2개 작업만 실행한다.
