# 형세 품질 검사 적용 후 선후공 대국 검증

고정 오류 국면 재현 검사가 끝난 뒤 실행할 후속 검증 조건이다. 결과를 보기 전에 정했으며, 기존 대국 파일은 덮어쓰지 않는다.

- 표준 시작 배치에서 Regicide 스파링 백·흑 각 1판, 총 2판.
- 상대: 동일 로컬 Stockfish 18, `UCI_LimitStrength=true`, `UCI_Elo=1700`, 1스레드, Hash 16MiB. 설정 숫자는 인간의 실력 또는 Regicide Elo가 아니다.
- 동일 스파링 시드 입력: `2026-11-03-quality-guard`. Stockfish의 내부 확률 시드는 통제하지 못한다.
- 실제 `HumanGame` 경로와 수정된 마지막 형세 품질 검사 사용. 기본 수, 20수까지의 접전 조절, 21~49수의 점진적인 양보 해제, 50수 이후를 모두 관찰한다.
- 10+0 시계. Regicide 기본 요청 3000ms, 상대 요청 300ms, 실제 Regicide 시간 배분은 호스트가 결정한다. 엔진별 계산량은 동일하지 않다.
- 전력 Stockfish 심판은 1스레드, Hash 32MiB. 외부 엔진은 위치 평가를 제공하며 실제 대체 수는 Regicide가 생성한다.
- 수정하지 않은 `tests/sparring_validation_match.py`를 사용한다. 화면용 힌트·평가만 끄고 연출 대기는 실제 수면 없이 게임 시계에 동일하게 부과한다. 탐색 시간은 실제 경과 시간을 사용한다.
- 최대 220ply. 평가에 의한 승패 판정은 하지 않으며, 제한에 도달하면 미완료 `*`로 남긴다.
- 선후공은 함께 실행한다. 각 대국의 시작·종료 시 소스와 바이너리 해시 및 원본 탐색 기록을 남긴다. 실행 중 측정 대상 코드는 변경하지 않는다.

실행 결과는 `1700-white/`, `1700-black/`에 별도로 저장한다. 각 폴더의 `metadata.json`, `game.json`, `game.pgn`, `native-searches.jsonl`이 원본 근거다.

## 독립 평가 및 판정

별도 전력 Stockfish로 초기 위치와 모든 실제 착수 후 위치를 각각 새 탐색으로 200000노드 평가한다. 기존 `scripts/audit_sparring_validation.py`를 수정 없이 사용하며, 의심 장면은 착수 전후 각각 3000ms로 추가 평가한다. 의심 장면 수에 상한을 두지 않는다. 메이트·미확인 점수는 cp 또는 접전 충족으로 바꾸지 않는다.

20수까지는 초기 위치 포함 41개 위치의 `|cp| <= 100` 연속 유지 여부와 스파링 직후·상대 직후의 비율을 구분한다. 대국이 일찍 끝나면 20수 도달 여부를 따로 기록한다. 마지막 검사에서 채택됐다는 이유로 독립 평가의 접전이나 전술 안전을 입증했다고 보지 않는다.

기존 감사 스크립트는 새 `quality_guard`를 해석하지 않는다. 따라서 그 스크립트의 `selection_kind`, 램프 양보 개수·위반 개수를 새 검사 전체의 판정으로 사용하지 않는다. 모든 위치 평가·깊은 재검토 결과는 재사용하고, 별도 요약에서 다음을 원본 기록으로 계산한다.

1. 20수까지 / 21~49수 / 50수 이후 각각 마지막 검사 호출 수, 검증·대체·미확인·생략 수와 사유.
2. 실제 최종 수의 외부 평가와 허용 하한. 실패 시 이전 기본 수의 평가와 최종 판정을 구분한다.
3. 대체한 모든 수가 동일 위치의 Regicide 허용 루트 재탐색에서 실제 반환됐는지 원본 탐색 기록과 대조한다. 외부 평가의 PV를 직접 두지 않았는지 확인한다.
4. 독립 평가의 ±100cp 접전 비율, 큰 손실·메이트 전환, 기물 노출과 보상 없는 손실 의심 장면, 시간 종료·오류·불완전 검증을 별도로 보고한다.
5. 소스·바이너리 불변, 합법 기보, JSON/PGN 일치, 실행 프로세스 종료를 확인한다.

앞선 자체 전술 검사에서 엔진이 중단·폐기되면 마지막 형세 검사를 실행하지 않을 수 있다. 이때 `quality_guard` 기록 부재는 앞선 검사 실패에 따른 미실행으로 따로 집계하며, 검증 성공이나 안전으로 세지 않는다.

두 판은 기능 진단이며 전체 경기력, Elo, 인간 체감 또는 모든 대국의 접전을 보장하지 않는다. 실패와 미확인 결과도 모두 보존한다.
