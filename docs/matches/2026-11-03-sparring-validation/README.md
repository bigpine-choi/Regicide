# 수정 스파링 4판 실대국 검증 — 부분 통과

## 결론

수정된 동일 소스로 실제 호스트 대국 4판, 총 410ply를 끝까지 실행했다. 네 판 모두 합법적인 체크메이트로 종료했고 Regicide가 승리했다. 그러나 **사용자가 요구한 접전 유지와 불필요한 형세 붕괴 방지까지 완전히 통과한 것은 아니다.** 승패를 기능 요구 충족으로 간주하지 않는다.

- 20수까지 모든 위치에서 ±1.00을 연속 유지한 판: **0/4**.
- 상대 착수 직후의 이탈을 제외하고 Regicide 착수 직후 20회만 보면 전부 접전 범위였던 판: **2/4**.
- 21~49수의 Regicide 착수 **104회**, 그중 실제 기본 수를 바꾼 의도적 양보 **6회**. 저장된 평가와 독립적으로 재계산한 손실 상한의 **규칙 위반 0건, 근거 미확인 0건**. 독립 심층 평가상 상한+50cp를 초과한 대안 선택도 확인되지 않았다.
- 세 판이 50수 이후까지 진행했고, 해당 전력 구간의 Regicide 착수 **22회**를 관찰했다.
- 별도 심층 검토 **30장면 완료**, 미검토 0건. 단순 기물 헌납으로 확정한 사례는 없지만, **기본 수의 전술·위치 평가 오류는 남았다**. 특히 50수의 Ne5는 독립 평가상 0.00에서 -3.94로 악화됐다.

## 조건

표준 시작, Stockfish 18의 UCI_Elo 설정 1320/1700 각각 선후공 한 판씩, 공통 입력 시드 `sparring-20261103-validation-v1`. 상대 설정은 인간 Elo나 플랫폼 레이팅으로 해석하지 않는다. Regicide는 현재 클래식 활동성 평가를 사용했다. 실제 HumanGame의 스파링·별도 심판·회복 탐색·전술 안전 검사·양보 해제를 모두 켰다. 10+0 시계, Regicide 기준 요청 3000ms(실제 시간 배분으로 조정), 상대 300ms, 각 엔진 1스레드였다. 두 대국을 동시에 실행했고 종료한 판의 독립 평가를 겹쳐 수행했다. CPU는 AMD Ryzen AI 7 350, 8코어/16논리 프로세서이며 부하를 완전히 격리한 속도 비교는 아니다.

화면 전용 힌트·자체 표시 탐색은 끄고 연출용 대기는 가상 시간으로 시계에 동일하게 부과했다. 탐색 시간은 실제 벽시계로 부과했다. 따라서 대국 제한 시간을 늘리지 않았지만, 화면 대기 동안의 백그라운드 작업 스케줄까지 실제 GUI와 완전히 동일하지는 않다. 수 제한은 220ply였으나 네 판 모두 그 전에 종료됐다.

모든 초기/착수 후 위치를 별도 전력 Stockfish 18로 200000노드씩 새 게임 토큰으로 평가했다. 의심 장면은 착수 전후 각각 3초로 다시 평가했다. 평가와 수 선택을 분리했고, 약화 상대의 merged play info를 실제 선택 수 점수로 사용하지 않았다. 각 샤드의 metadata.json과 독립 분석 summary.json에 실행 파일·소스 해시, 옵션, 환경을 기록했다.

## 결과 표

접전 위치는 초기 위치와 20수까지 양측 착수 후를 합친 41개 위치다. ±1.00 기준의 제한된 탐색 추정치이며 경계 근처는 탐색에 따라 달라질 수 있다.

| 상대 설정 | Regicide | 종료 | 초반 접전 위치 | Regicide 착수 직후 | 실제 후반 양보 / 규칙 위반 |
|---|---|---|---:|---:|---:|
| 1320 | 백 | 50수 백 메이트 승 | 40/41 | 20/20 | 2 / 0 |
| 1320 | 흑 | 37수 흑 메이트 승 | 28/41 | 14/20 | 0 / 0 |
| 1700 | 백 | 66수 백 메이트 승 | 22/41 | 9/20 | 1 / 0 |
| 1700 | 흑 | 53수 흑 메이트 승 | 37/41 | 20/20 | 3 / 0 |

1320 백의 유일한 초반 이탈은 상대의 12수 직후였고, 다음 Regicide 수 이후 접전으로 돌아왔다. 1700 흑의 네 초반 이탈도 상대 착수 직후에 해당한다. 나머지 두 판에는 Regicide 착수 직후에도 접전 범위를 벗어난 위치가 있어 상대의 실수만으로 설명할 수 없다.

## 남은 실패와 의심 장면 검토

아래 점수는 모두 해당 Regicide 색 기준이며, 독립 3초 탐색의 착수 전후 평가다. 기본 수란 엔진이 정상 탐색으로 고른 수이며 의도적으로 약한 수로 바꾼 경우와 다르다.

| 대국 / 수 | 기본 수 자체의 변화 | 판단 |
|---|---:|---|
| 1320 흑, 15...axb4 | +0.55 → -1.65 | 폰 획득 뒤 상대 a5를 과소평가. 자체 깊이 6은 -0.23으로 접전 판단. 초반 접전 실패 |
| 1320 흑, 21...Nxe4 | +0.67 → -1.54 | 동가 교환의 후속 위치 판단 오류. 양보 한도 위반이 아님 |
| 1320 백, 27.Qxb7 | +2.78 → 0.00 | 기본 수가 우세를 놓침. 자체 깊이 6은 +0.24 |
| 1700 흑, 43...Bxc3 | +0.49 → -2.08 | 기본 수 평가 오류. 자체 깊이 6은 +1.47 |
| 1700 백, 50.Ne5 | 0.00 → -3.94 | 전력 모드에서도 남은 전술 오류. 자체 깊이 6은 +1.32, 별도 심판 양보는 이미 종료된 상태 |

자동 기물 손실 의심 표시는 1320 흑의 32...Kf8 한 건이었다. 이 위치는 체크를 피해야 했고, 킹 응수들은 비숍을 노출하며 다른 응수 ...Rxg7도 교환 희생을 포함한다. Kf8 이후에도 독립 평가는 +9.05였고 실제 상대는 노출된 비숍을 잡지 않았다. 이를 뜬금없는 무보상 헌납으로 단정하지 않는다. 다만 안전 검사에서 모든 대안이 재료 노출 필터로 제외되는 한계는 확인됐다. `no_safe_native_alternative`는 지역적 필터의 결과이며 체스상 안전한 대안이 없다는 증명이 아니다.

전술 안전 검사는 총 8회 발동했다. 1회는 보상이 확인돼 유지했으며, 3회는 탐색 증거가 충분하지 않았고, 3회는 검증된 개선 수를 찾지 못했으며, 1회는 위 체크 응수 필터의 제한에 걸렸다. 이번 네 판에서 안전 검사가 실제 수를 교체한 사례는 없었다. 따라서 발동 횟수만으로 헌납 예방 성능을 입증하지 않는다.

## 다음 개선의 초점

1. 직접적인 기물 노출이 없어도 **기본 수의 후속 전술과 위치 손실**을 검증할 수 있어야 한다. 나이트 폰 획득 한 사례를 막은 안전 장치만으로 충분하지 않다.
2. 체크 상황에서 모든 응수가 재료 노출을 포함하면, 후보를 전부 배제하지 않고 보상 있는 응수를 자체 엔진과 상대 응수 탐색으로 비교할 경로가 필요하다.
3. 50수 전력 모드는 의도적 양보의 종료를 뜻한다. 제한된 깊이의 기본 엔진이 실수하지 않는다는 뜻은 아니므로, 이를 별도 품질 목표로 다뤄야 한다.

시간 배분의 구체적 재현 근거도 남겼다. 50.Ne5의 실제 기본 탐색은 약 0.78초였고 이후 연출 대기 약 2.31초가 시계에 부과됐다. 43...Bxc3는 약 1.58초 탐색 뒤 약 3.90초 대기가 있었다. 20수 이후 일부 대기 시간을 실제 검증 탐색으로 전환하는 것은 검증할 가치가 있는 가설이다. 더 오래 탐색하면 반드시 해결된다는 결과를 얻은 것은 아니다.

이번 실행 중 생산 코드를 변경하지 않아 4판의 비교 조건을 보존했다. 실패 장면은 후속 수정의 재현 자료로 남겼으며, 전체 경기력 개선이나 문제가 모두 해결됐다고 보고하지 않는다.

## 산출물과 무결성

- `all-games.pgn`: 네 판 전체 기보. 다시 파싱하여 4판과 합법 수순을 확인했다.
- `summary.json`: 집계 지표.
- `1320-white/`, `1320-black/`, `1700-white/`, `1700-black/`: 원본 대국, 매 수 로그, 탐색 패킷, 시계, 생산 호스트 저장본.
- `audit-*/`: 별도 위치 평가와 심층 검토 결과.
- `reviewed-cases.json`: 주요 장면의 FEN·수순·평가·원인 검토.
- `protocol.md`: 결과 확인 전 정한 조건과 분석량 보강 기록.

네 판의 소스 해시가 서로 같고 실행 전후 및 현재 파일과 일치했다. 실행 파일 해시도 유지됐다. 오류·시간패·미완료 대국은 없었고 JSON/PGN 기록이 일치했다. 모든 대국 및 분석 프로세스는 종료했다. 이는 자동 호스트 대국 검증이며 사람이 GUI에서 직접 플레이한 검증은 아니다.
