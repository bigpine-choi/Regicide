# 수정 스파링 실제 대국 검증 계획

결과를 보기 전에 정한 1차 조건: 표준 시작 배치, Stockfish 18 UCI_Elo 설정 1320/1700 각각 Regicide 선공·후공 한 판씩 총 4판. 제한 강도 설정은 사람의 Elo 추정치가 아니다. 각 설정의 선후공은 같은 스파링 시드를 사용하되 Stockfish의 확률 선택 시드는 통제할 수 없다.

실제 HumanGame 스파링 경로, 클래식 활동성 평가, 별도 Stockfish 심판, 전술 안전 검사, 20수 이후 양보 제한을 모두 사용한다. 10+0 시계, Regicide 요청 기준 3000ms(실제 호스트의 시간 배분이 적용됨), 상대 300ms, 엔진당 1스레드. 최대 220ply는 미완료 '*'로 남기며 평가 점수로 승패를 판정하지 않는다. 2개 대국을 동시에 실행하고 동일 조건 선후공을 모두 보존한다.

화면 힌트·자체 표시용 평가만 끈다. 화면 연출용 대기는 시계에 동일 시간을 부과하면서 실제 수면만 생략한다. 실제 탐색 벽시계 시간은 그대로 부과한다. 검색 예산을 늘리거나 시계를 임의로 보충하지 않는다. 상대와 스파링의 연산량은 같지 않다.

별도 전력 Stockfish로 초기 위치와 모든 착수 후 위치를 20000노드 평가한다. 의심 장면은 추가 분석한다. 메이트 점수는 cp로 바꾸지 않는다.

첫 대국 결과 및 본 분석을 보기 전 보강: ±100cp 경계의 얕은 탐색 변동을 줄이기 위해 최종 모든 위치 평가는 **200000노드**로 올린다. 의심 장면은 착수 전후 각각 3초로 추가 분석한다. 다른 비교 조건은 유지한다.

검증 항목:

1. 20수까지: 40ply 도달 여부, 초기 및 착수 후 41개 위치의 ±100cp 연속 유지 여부, 알려진 위치 중 비율. 상대 착수로 벌어진 차이와 스파링 착수 후의 차이를 구분한다.
2. 21~49수: 선택의 원래 기본 수·양보 후보·응수 검증을 확인해 허용 손실 상한과 부호 역전 금지를 검사한다. 안전 검사로 교체되었다면 교체 전 기록도 추적한다. 50수 도달 여부와 외부 양보 종료를 별도 보고한다.
3. 기물 헌납: 위험 징후 자체를 실패로 보지 않는다. 기물 손실과 별도 심층 평가의 불필요한 손실을 함께 보고 의도적 양보, 기본 수 오판, 검증 미완료를 구분한다.
4. 기보 합법성, JSON/PGN 일치, 시간 종료, 오류, 소스/바이너리 해시, 실행 프로세스 종료를 확인한다.

4판은 기능 진단이다. 전반적인 경기력·Elo·인간 체감이나 모든 대국의 접전을 보장하지 않는다. 실패를 숨기지 않고 수정 전후 데이터는 분리한다. 1차 결과 뒤 수정이 필요하면 고정 사례 재검증과 후속 대국의 조건을 따로 기록한다.
