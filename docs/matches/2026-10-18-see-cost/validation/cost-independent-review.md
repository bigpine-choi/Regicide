## 해석 범위

- 깊이 3에서는 중앙값 기준 느려졌고, 깊이 4와 손실 장면에서는 조금 빨라졌다. 모든 위치에서 이득이라는 근거는 없다.
- 밀리초 단위의 짧은 탐색은 UCI 전달·리셋 및 운영체제 스케줄링 잡음의 영향이 크다. 외부 체스 엔진 CPU 0이 전체 PC 부하 0을 뜻하지 않는다.
- 일치한 기록 필드는 관찰된 탐색 동작이 같다는 근거다. 전체 방문 트리의 해시를 비교한 것은 아니다.
- 앞서 측정한 SEE 계측 비중 7.17%와 원본/수정 SEE 값 402개 일치는 별도 실험이다. 이 감사의 125쌍에 합산하지 않는다.
- 고정 깊이 실행 비용은 같은 시간 조건의 경기력 결과와 별도로 해석한다.
