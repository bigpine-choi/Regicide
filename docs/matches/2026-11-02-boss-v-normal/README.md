# 보스 대 앱 기본 모드 16판 원자료

2026-11-02에 실행했다. [결과 보고서](../../experiments/2026-11-02-boss-v-normal.md)와 [실행 전 계획](../../experiments/2026-11-02-boss-v-normal-plan.md)을 함께 읽는다.

- `all16.pgn`: 전체 16판 합본. 보스7승7무2패이며 1900반수 모두 재생 검증했다.
- `summary-independent.json`: 모드별 승무패·선후공 쌍·통계의 한계·실제 경과시간.
- `all16-pgn-audit-independent.json`: 모든 수·종국·설정·원본 기록·해시의 독립 감사.
- `all16-decisions-audit.json`: 보스/기본의 실제 선택·시드·관측·예산·갬빗/미끼 사용 감사.
- `audit_independent.py`, `audit_decisions.py`: 결과 분석에 사용한 독립 감사 스크립트. 실행 폴더의 원본 경로를 사용하며 생산 엔진 검색을 수행하지 않는다.
- 각 `pairs-A-B` 폴더: 읽기 쉬운 `match.json`과 `match.pgn`, 실제 양쪽 호스트 기록을 포함한 46개 원본 파일의 `raw-records.zip`, ZIP 항목별 `raw-records-manifest.json`. 네 그룹의 184개 원본 파일을 모두 해시로 대조했다.
- `smoke-match-excluded.json`: 실제 실행 경로의 짧은 2판 검사. 2반수 제한에 걸린 미완료이며 본16판 점수에서 제외했다.
- `sha256.json`: 이 폴더의 보관 파일 해시(목록 자체 제외).

동결 커밋은 `dcc40800c9e42f652864dcc145e9a59b46272d2c`다. 모든 대국은 같은 앱 기준1초 설정이며 모드별 추가 계산량과 실제 경과시간은 다르다. 서로 다른8개 개시가 아니라 표준 시작위치에서 8개 시드로 선후공을 바꾼 비교다. 보스 우세가 관측됐지만 검증된 미끼 선택은0회여서 함정 효과를 입증한 결과는 아니다.

ZIP 항목은 원래 실행폴더의 상대경로를 유지한다. 저장소 루트의 `build/boss-v-normal-20261102` 아래에 원본을 복원하고, 두 감사 스크립트도 그 폴더로 복사한 뒤 해당 위치에서 실행한다. 기록된 바이너리 경로와 동결 소스도 준비해야 한다. 실행 파일은 포함하지 않는다.
