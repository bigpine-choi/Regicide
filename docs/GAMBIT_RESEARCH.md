# 갬빗 이론 학습과 신규 수순 연구

에번스·스미스 모라·벤코·알빈 네 계열의 알려진 분기를 자체 엔진으로 분석하고, 같은 기점에서 새로운 기물 제안을 조사한다. 이 도구는 오프라인 연구용이다. 생성한 순위 모델이나 발굴 후보를 대국 모드에 자동 적용하지 않는다.

## 실행

Python 3.10 이상, `requirements-test.txt`의 python-chess, 자체 Regicide 실행 파일이 필요하다. 모든 결과 경로는 새 디렉터리여야 한다.

```sh
python -m pip install -r requirements-test.txt
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release

# 엔진 없이 재현 가능한 이론 훈련 국면 생성
python scripts/gambit_research.py curriculum --output research/theory-01

# 자체 분석, 후보 순위 학습, 신규 희생 조사와 PGN 출력
python scripts/gambit_research.py all --binary build/regicide --output research/run-01 --nodes 100000 --wall-seconds 600
```

Windows의 Visual Studio 빌드에서는 `--binary build/Release/regicide.exe`를 사용한다. 연구 예산은 전체 실행의 벽시계 상한이다. 시간이 부족하면 `unknown`을 남기고, 분석하지 않은 방어를 통과한 것으로 처리하지 않는다. 긴 이론 학습과 발굴을 각각 다른 실행으로 수행하려면 `all` 대신 `study`, `discover`를 사용한다.

## 이론 학습

고정된 CC0 오프닝 원자료에서 각 계열 최대 8국면을 생성한다. 제안 직전·상대 응수·후속 운영·자료 종료 지점을 구분하고, 갬빗 진영과 방어 진영을 모두 연습한다. 단계명은 수락의 역사적 사실이나 정답의 품질 판정이 아니다.

훈련은 에번스·모라, 하이퍼파라미터 선택은 알빈, 보류 검사는 벤코로 분리한다. 현재 위치뿐 아니라 모든 합법적인 직후 위치까지 분리 간 전치를 검사한다. 원자료의 전체 UCI 이력, 합법적인 앙파상 권리, 출처·라이선스·체크섬을 남긴다.

각 국면의 책 후보, 자체 기준 수, 고정 시드로 뽑은 대안을 비교한다. 기본 예산과 4배 예산에서 정확한 CP, 최소 완료 깊이 4, 최대 평가 차이 80cp를 충족한 자체 분석만 학습 목표로 사용한다. 메이트·경계값·불완전·불안정 결과는 CP 정답으로 바꾸지 않는다. 목표값은 해당 국면의 착수자 관점이며, 방어 훈련에서도 갬빗 진영 관점으로 뒤집지 않는다.

기존 24특징의 쌍별 순위 학습을 재사용한다. 훈련 분리로 가중치를 학습하고 검증 분리로 정규화 값을 선택한 뒤 보류 결과를 한 번 평가한다. 수집한 후보 내부의 손실을 기존 순서 및 자체 기준 수와 비교한다. 각 분리에 안정적 국면이 4개 미만이면 학습하지 않는다. 채택 권고에는 검증·보류 각각 8국면 및 2계열 이상과 비악화 조건을 추가한다. 첫 네 계열 실험은 검증·보류 계열의 폭이 부족하므로 모델을 자동 채택할 수 없다.

`study/model.json`은 항상 `experimental`, `active=false`다. 가중치가 생성됐다는 사실은 신경망 평가기의 개선, 이론 숙달, 대국 기력 상승을 뜻하지 않는다. 현재 위치의 분석 기억과 새로운 위치에 대한 일반화를 구분한다.

## 신규 희생 조사

선택한 공격자 차례의 기점에서 합법적인 기물 제안 후보를 생성한다. 이동한 말뿐 아니라 다른 말이 잡히는 제안과 앙파상도 포함한다. 상대의 수락 뒤 즉시 균형을 회복할 수 있는 단순 교환은 보수적으로 제외한다. 따라서 전술적으로 나쁜 되잡기만 가능한 진짜 희생도 일부 제외할 수 있다.

후보 직후 위치와 모든 합법적인 첫 방어 응수를 자체 엔진으로 분석한다. 수락·포획 방어·체크·조용한 수비를 구분한다. 상대의 이후 대응은 각 제한된 탐색에 포함되지만, 모든 깊이의 방어를 완전히 증명한 것은 아니다. 기본 품질 기준은 공격자 관점 -100cp 이상 및 자체 기준 수 대비 60cp 이내다. 이 값은 연구 필터이며 객관적 건전성의 보장이 아니다.

`--reply-limit 0`은 모든 합법적인 첫 방어를 검사한다. 양수로 제한하면 응수 범위가 불완전해진 후보는 검증을 통과할 수 없다. 후보 수 제한에 따른 미검토 범위도 별도로 남긴다. 자료에 없는 국면의 생존 후보는 4배 노드 예산에서 다시 조사하고, 동일 후보의 평가 안정성과 완료 깊이까지 확인한다. 이 두 단계가 통과해도 표현은 제한된 자체 분석을 통과한 연구 후보다.

신규성은 갬빗 카탈로그와 전체 정식 오프닝 a~e 원자료의 위치·전이를 함께 대조한다. `--reference-pgn path/to/games.pgn`을 반복하면 실제 기보와 변형도 비교 범위에 추가한다. `known_transition`, `known_transposition`, `unseen_position`을 구분하며, 마지막 표시는 기록된 출처 범위에 없다는 뜻이다. 인류 최초·세계 최초를 의미하지 않는다. 원자료가 없거나 손상되면 신규성 판정은 `unknown`이다.

## 결과와 재현

| 파일 | 용도 |
|---|---|
| `predeclared.json` | 시드·분리·기점·자원·소스·실행 파일 식별 |
| `curriculum.json` | 출처를 가진 공격·방어 훈련 국면 |
| `analysis/native-uci.jsonl` | 실제 UCI 송수신, 전체 이력, 노드 요청 |
| `analysis/queries.jsonl` | CP 관점·완료 깊이·PV·불확실성·쿼리 ID |
| `analysis/analysis_summary.json` | 자원 사용·프로세스 종료·소스 불변 검사 |
| `study/dataset.json`, `study/model.json` | 제외 근거를 포함한 자체 분석 자료와 실험 순위 모델 |
| `study/study_report.json` | 검증·보류 품질 및 채택 제한 |
| `discovery.json`, `discovery.pgn` | 실패·미검증을 포함한 후보와 실제 보드에서 볼 수 있는 수순 |
| `summary.json` | 전체 집계와 수행 범위 |

실행 중 소스를 바꾸지 않는다. 날짜·파일 지문·실행 환경이 다른 실험은 같은 결과로 합치지 않는다. 승률과 Elo는 이 도구가 측정하지 않으며, 이후 동일 시간 조건의 완주 대국으로 따로 검증해야 한다.
