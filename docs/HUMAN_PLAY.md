# 최신 Regicide와 직접 대국하기

체스판 옆 **흑백 형세 막대와 백 기준 점수**가 실제 엔진 사고 중 갱신된다. `+`는 백, `−`는 흑 우세이며 막대는 승률이 아니다. 아직 값이 없으면 대기로 표시한다. [평가값·갱신·검증 안내](LIVE_EVALUATION.md)를 참고한다.

Windows에서는 저장소의 **`Play-Regicide.cmd`를 더블클릭**한다. 브라우저에 로컬 체스판이 열린다. 현재 엔진은 v0.5.0이며, 엔진의 수 선택·평가·탐색 코드는 기존 검증 버전 그대로다.

## 두는 방법

1. 기본은 내가 백, Regicide가 흑이다. 기물을 누른 다음 표시된 도착 칸을 누른다.
2. 다른 색이나 생각 시간을 원하면 설정을 선택하고 **새 대국 시작**을 누른다. 흑을 고르면 체스판 방향이 바뀌고 엔진이 먼저 둔다.
3. 생각 시간은 수당 0.1초·1초·3초·5초 중 선택한다. 기본은 1초다. 사람의 생각 시간에는 제한을 두지 않는다. 엔진에는 기존 Move Overhead 20ms 설정이 적용된다.
4. 캐슬링은 왕을 두 칸 이동한다. 승격할 때는 퀸·룩·비숍·나이트 중 고른다. 앙파상과 체크 회피도 일반 이동과 같이 클릭한다.
5. **한 턴 되돌리기**로 내 수와 엔진 응수를 함께 되돌릴 수 있다. 내가 흑이면 엔진의 첫 수는 남긴다.
6. **기보 저장**은 현재 PGN을 내려받는다. **종료**는 로컬 대국 프로그램을 정리한다. 브라우저 탭만 닫으면 프로그램은 계속 실행된다.

진행 중인 수순은 매 수마다 Windows의 실제 문서 폴더 `Regicide/games/`에 PGN·JSON으로 자동 저장한다. 새 대국은 새 파일을 사용하므로 앞선 대국이 남는다. 예전 `build/human-games/` 기록은 원본을 보존하면서 가져온다. JSON에는 전체 수순·시작/최종 FEN·엔진 이름·실행 파일 SHA256·화면 코드의 체크아웃 커밋·시간 설정·저장 상태를 기록한다. 화면 코드의 커밋과 엔진 실행 파일의 원본 커밋을 동일하다고 추정하지 않는다. 지난 대국은 [Godot의 내 대국 기보](GODOT_PLAY.md)에서 읽기 전용으로 다시 볼 수 있다.

반복·50수 규칙으로 청구 가능한 무승부는 양쪽 모두 자동 청구하는 정책이다. 예정 수로 청구할 수 있는 경우도 포함하며, 이는 기존 대국 도구와 같다. 되돌리기를 허용하는 연습 대국이므로 공식 경기력 측정과는 구분한다. 엔진 오류는 승패로 바꾸지 않고 미완료와 오류로 기록한다.

## 실행 환경과 재실행

최초 준비가 필요한 새 컴퓨터에서는 기존 C++ 빌드와 Python 의존성을 준비한다.

```powershell
python -m venv .venv-tests
.\.venv-tests\Scripts\python.exe -m pip install -r requirements-test.txt
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1 -Test
.\Play-Regicide.cmd
```

현재 개발 PC에는 이 환경이 준비되어 있다. 실행기는 엔진 실행 파일이 없으면 기존 빌드 스크립트를 실행하며, Python 도구가 없으면 설치 명령을 안내한다. 새 패키지를 자동 설치하지 않는다. 실행 로그는 `build/human-play/`에 남는다.

Linux에서는 같은 Python 의존성과 CMake 엔진 빌드 후 다음을 사용한다.

```sh
python scripts/play_human.py --binary build/regicide
```

브라우저가 자동으로 열리지 않으면 실행 시 출력된 `http://127.0.0.1:포트` 주소를 연다. 매 실행에서 빈 포트를 선택한다. 인터넷 서버에 배포하지 않고, 해당 컴퓨터의 루프백 주소에서만 동작한다. 외부 폰트·자산·웹 서비스는 사용하지 않는다.

## 검증과 외부 도구의 역할

실제 수는 C++ Regicide가 UCI로 선택한다. 기존 `chess==1.11.2`는 통신·합법성·종료 판정·기보만 담당한다. Python 패키지의 GPL-3.0-or-later 이용 조건은 [엔진 설명](ENGINE.md)에 기록되어 있다. 새 화면·서버는 자체 작성했고 추가 패키지는 없다.

```powershell
.\.venv-tests\Scripts\python.exe tests/human_play_tests.py build/regicide.exe
```

모델·HTTP·실제 엔진의 양색 대국 연결을 검사한다. 합법 수와 차례, 전체 반복 이력, 캐슬링·앙파상·4종 승격, 메이트·청구 무승부, 기권·되돌리기, 새 대국 시 기보 보존, 오류 복구, 오래된 요청 거부와 로컬 요청 검증을 포함한다. 기존 엔진 규칙 검증도 그대로 유지한다.
