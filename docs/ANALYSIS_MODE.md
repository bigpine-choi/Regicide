# 자유 배치 분석 모드

Regicide 대국 화면에서 **분석 모드**를 열면 원하는 위치에서 자체 엔진의 추천 수를 확인할 수 있습니다. Godot 창과 브라우저 화면 모두 같은 분석 서비스를 사용합니다.

## 사용 방법

1. **분석 모드**를 열고 기물 목록에서 백·흑 기물을 판으로 드래그해 배치합니다. 기물을 고른 뒤 칸을 클릭하는 기존 방식도 사용할 수 있습니다. 기본 배치·빈 판·현재 대국 위치도 사용할 수 있습니다.
2. **백 차례 / 흑 차례**와 한 위치를 읽을 시간을 선택합니다. 자유 배치 후에는 캐슬링과 앙파상 권리를 임의로 만들지 않습니다. 정확한 권리를 보존하려면 아래의 FEN을 사용합니다.
3. **분석 시작**을 누르면 현재 차례의 Regicide 추천 수를 글자와 화살표로 표시합니다. 판 옆의 형세 막대와 점수도 같은 탐색에서 실시간으로 갱신됩니다. 추천만 확인할 수도 있고, 양쪽 기물을 직접 움직여 다음 위치를 분석할 수도 있습니다. 승격할 기물도 고를 수 있습니다.
4. **한 수 무르기**는 분석에서 직접 둔 한 수만 취소합니다. **배치 편집**으로 돌아가 기물을 다시 놓거나 **대국으로 돌아가기**로 원래 대국 화면에 복귀합니다.

**FEN**은 기물 배치와 차례·특수 권리·수 번호를 한 줄로 표현하는 표준 체스 위치 형식입니다. 다른 곳에서 복사한 여섯 항목의 FEN을 불러올 수 있고, 화면의 현재 FEN을 복사해 분석 위치를 보관할 수 있습니다.

```text
4k3/P7/8/8/8/8/8/4K3 w - - 0 1
```

위 예시는 백 왕 e1, 흑 왕 e8, 백 폰 a7에 백 차례인 승격 연습 위치입니다.

## 드래그로 배치 편집

- **목록 → 판**: 선택한 기물을 새로 추가합니다. 목록의 기물은 계속 사용할 수 있습니다.
- **판 → 다른 칸**: 출발 칸의 기물을 옮깁니다. 도착 칸에 기물이 있으면 그 기물을 덮어씁니다.
- **판 → 삭제 영역 또는 창 안의 판 밖**: 끌고 온 기물을 제거합니다. 지우개로 칸을 눌러 지울 수도 있습니다.
- **같은 칸에 놓기, Esc로 취소, 창 밖에 놓기**: 원래 배치를 유지합니다. 목록에서 끌어온 기물을 판 밖에 놓아도 기존 배치는 바뀌지 않습니다.

기물 배치를 바꾸면 앙파상 권리와 반수 카운터를 초기화합니다. **폰·나이트·비숍·퀸을 편집해도 기존 캐슬링 권리는 유지**합니다. 원래 칸의 왕이나 해당 룩을 옮기거나 제거한 경우에만 관련 권리를 해제하며, 원위치에 다시 놓아도 없어진 권리를 자동으로 부여하지는 않습니다. 배치를 바꾸지 않고 드래그를 취소할 때는 기존 권리도 유지합니다. 자유 배치 드래그는 **배치 편집 중**에만 사용할 수 있습니다. 분석을 시작한 뒤에는 합법 수로 기물을 움직이며, 판 밖에 놓아도 기물을 삭제하지 않습니다.

## 캐슬링 설정과 착수

1. 기본 배치에서 분석을 시작하거나 왕·룩 외의 기물을 편집했다면 기존 캐슬링 권리가 유지됩니다. 빈 판부터 만든 사용자 배치 등 권리가 없는 위치에서는 편집 화면의 **캐슬링 권리**에서 해당 색·방향을 명시적으로 선택할 수 있습니다. 왕과 해당 룩이 원래 칸에 있어야 선택할 수 있습니다.
2. **분석 시작 후 대국을 진행하면서 왕을 두 칸 드래그**합니다. 백은 e1→g1 또는 e1→c1, 흑은 e8→g8 또는 e8→c8입니다. 룩도 함께 이동하고, 다음 위치의 추천과 형세를 새로 계산합니다. 왕→자기 룩 또는 자기 룩→왕으로 끌거나 클릭하는 조작도 실제로 합법인 경우 같은 캐슬링 수로 처리합니다.
3. 오른쪽 분석 패널의 **킹사이드 캐슬링 / 퀸사이드 캐슬링** 버튼도 사용할 수 있습니다. 현재 차례에 합법일 때만 켜지고, 불가능한 경우에는 권리 누락·체크·막힌 칸 등 이유를 함께 표시합니다. **한 수 되돌리기**는 왕·룩과 이전 캐슬링 권리를 함께 복원합니다.

권리를 켰더라도 왕이 체크이거나 경로에 기물이 있거나 왕이 지나는 칸·도착 칸이 공격받으면 캐슬링할 수 없습니다. 실제 가능 여부와 불가 사유는 관리기가 판단합니다. 시작 FEN에 없던 권리나 실제 왕·룩 이동으로 잃은 권리를 대국 중 임의로 복구하지는 않습니다. FEN에 기록된 권리도 체크 항목에 반영되며, 잘못된 FEN 권리를 화면이 임의로 고치지는 않습니다.

빈 경로의 캐슬링 연습 위치입니다. 흑부터 연습하려면 두 번째 항목 `w`를 `b`로 바꾸거나 차례를 선택합니다.

```text
r3k2r/8/8/8/8/8/8/R3K2R w KQkq - 0 1
```

## 백·흑 형세 표시

점수는 항상 **백 기준**입니다. `+1.20`은 백 우세, `−1.20`은 흑 우세이고 `0.00`은 균형입니다. `1.00`은 폰 한 개에 해당하는 평가 단위입니다. 막대는 점수를 시각적으로 보여주며 승률을 뜻하지 않습니다. 판의 시점을 뒤집어도 점수의 부호는 바뀌지 않고, 막대의 백·흑 위치만 바뀝니다.

설정한 분석 시간 동안 자체 엔진이 더 깊은 탐색을 마칠 때마다 점수와 탐색 깊이를 갱신합니다. 추천 수와 형세는 **같은 탐색**에서 나오며 계산이 끝나면 마지막 결과를 표시합니다. 수를 두거나 무르면 새 위치를 다시 계산합니다. 새 계산을 기다리는 동안에는 이전 위치의 점수를 지우고, 배치 편집 중에는 분석 대기를 표시합니다.

엔진이 메이트를 예상하면 해당 색과 수를 표시하고, 실제 체크메이트·무승부 위치는 확정된 결과로 표시합니다. `≥`·`≤`는 정확한 점수 대신 탐색으로 확인한 하한·상한입니다. 입력 오류나 연결 실패 때는 오래된 점수를 유지하지 않습니다. 이 점수는 Regicide의 추정이며 객관적인 최선 수나 경기력을 입증하는 수치는 아닙니다.

## 보드와 안내 영역

왼쪽에는 한 줄짜리 차례·점수와 보드만 표시합니다. 자세한 형세 설명, 캐슬링 버튼과 불가 사유, 배치 설정과 수순은 오른쪽 스크롤 영역에서 확인합니다. 문구의 길이·계산 상태·착수에 따라 보드가 커지거나 작아지지 않으며, 창 크기를 바꾸면 그 공간에 맞춰 조절됩니다. 보드 위에 입력 설명 툴팁이 떠서 칸을 가리는 동작도 제거했습니다. [레이아웃 검증](checks/2026-11-01-analysis-layout/README.md)에 좌표 검사와 실제 창의 착수 전후 기록을 보관했습니다.

## 허용되는 위치와 종료

편집 중에는 왕을 지우거나 자유롭게 기물을 놓을 수 있습니다. 분석을 시작할 때는 표준 체스의 기본 조건을 확인합니다. 각 색의 왕이 하나씩 있어야 하고, 왕이 붙어 있거나 차례가 아닌 쪽의 왕이 체크인 위치, 1·8행의 폰, 색마다 8개를 넘는 폰이나 16개를 넘는 기물 등은 이유를 표시하고 분석을 시작하지 않습니다. 잘못된 입력은 직전 분석 위치와 이력을 바꾸지 않습니다.

캐슬링 권리는 해당 왕과 룩의 원래 위치가 필요합니다. 앙파상 칸은 직전 상대 폰의 두 칸 이동과 맞아야 합니다. FEN의 반수 카운터는 0 이상, 수 번호는 1 이상이며 엔진과 같은 최대 1,000,000,000을 적용합니다. 과거 대국 전체를 역산해 그 위치에 도달할 수 있는지까지 증명하지는 않습니다.

체크메이트·스테일메이트·메이트 불가능한 기물 구성과 반복·50수 청구를 포함한 무승부 위치는 종료 상태를 표시합니다. 추천할 다음 수는 표시하지 않으며, 무르기나 배치 편집을 사용할 수 있습니다. FEN에는 이전 반복 이력이 없으므로 반복 판정은 분석 시작 이후 직접 둔 수순에 한정됩니다.

## 대국과의 분리

분석은 대국과 별도 체스판·수순·번호·수정 번호를 사용합니다. 추천 엔진도 별도 프로세스로 실행하며 실제 대국의 수를 대신 두지 않습니다. 분석 시작·착수·무르기는 대국 상태와 개인 기보 파일을 바꾸지 않습니다. 분석 수순은 개인 대국 보관함이나 학습 자료에 자동 저장하지 않습니다. 진행 중 대국에서 분석을 열더라도 이미 시작한 상대 엔진의 응수는 정상 완료될 수 있습니다.

위치 수정·무르기·분석 종료 시 이전 추천 탐색을 취소합니다. 뒤늦게 도착한 응답은 위치 번호·수정 번호·FEN이 현재 위치와 맞아야 표시됩니다. 추천 수는 실행 중인 Regicide의 판단이며, 최선 수의 증명이나 경기력 향상을 의미하지 않습니다.

## 내부 연결과 검증

`AnalysisSession`은 기존 `MoveHints`의 취소·시간 제한·합법 수 확인을 재사용합니다. python-chess는 위치 검증·합법 수·종료 판정과 표기만 담당하며 추천 수는 Regicide가 선택합니다. 분석은 세션의 대국과 같은 평가 모델 설정을 사용합니다.

- `GET /api/analysis`: 분석 위치와 현재 추천 응답을 읽습니다.
- `POST /api/analysis`: `action`이 `start`, `move`, `undo`, `stop`인 작업입니다. 모든 변경에 현재 `revision`이 필요합니다.
- 잘못된 입력은 HTTP 400, 오래된 위치 번호는 HTTP 409와 현재 `analysis`를 반환합니다. 요청 인증과 4KiB 크기 제한은 기존 로컬 대국 API와 같습니다.

재현 검사:

```powershell
.\.venv-tests\Scripts\python.exe tests\analysis_tests.py build\regicide.exe
.\.venv-tests\Scripts\python.exe tests\analysis_evaluation_tests.py build\regicide.exe
.\.venv-tests\Scripts\python.exe tests\analysis_castling_workflow_tests.py build\regicide.exe
```

이 검사는 잘못된 FEN의 원자적 거절, 백·흑 추천, 실제 엔진의 합법 추천, 캐슬링·앙파상·양쪽 승격·무르기, 취소 후 오래된 응답 거절, 동시 수정 충돌, 대국·평가·기보 보존과 HTTP 인증을 확인합니다.
