# 통계형 오프닝 탐색기

현재 보드에서 실제로 많이 둔 다음 수와 그 경기들의 결과를 살펴보는 기능입니다. 기존 오프닝 안내가 제공하는 이름·대표 분기·구상에 실제 기보 통계를 더합니다. 통계 자료는 리체스에서 조회하고, 추천 수와 형세 판단은 기존 Regicide 자체 엔진이 담당합니다.

## 시작하기

1. Regicide를 실행하면 대국·분석 화면 오른쪽에 **오프닝 탐색기**가 항상 표시됩니다. 켜기/끄기 버튼은 없습니다. 저장된 연결키가 있으면 현재 위치를 자동으로 조회합니다.
2. 처음 연결할 때만 탐색기 안의 **연결 설정** 탭에서 연결키를 입력합니다. 이미 저장했다면 저장된 연결을 사용한다는 안내가 표시되며 다시 입력할 필요가 없습니다. 키를 바꿀 때만 **연결키 변경**을 누릅니다.
3. 탐색기의 **통계** 탭에서 **마스터 대국** 또는 **리체스 일반 대국**을 선택합니다. 일반 대국은 레이팅 구간·시간제도 선택할 수 있습니다.
4. 보드 위치나 필터를 바꾸면 다음 수별 대국 수·선택 비율·백승/무승부/흑승 비율을 새로 조회합니다.
5. **이 수로 탐색**을 누르면 해당 수를 둔 위치에서 별도 분석 보드를 엽니다. 실제 대국의 수나 저장된 기보를 대신 바꾸지 않습니다. 분석 보드의 기존 Regicide 추천·형세 평가를 함께 볼 수 있습니다.
6. **참고 기보** 탭에서 경기를 선택하면 리체스의 실제 경기 페이지를 엽니다.

기본 창은 1760×960이며 보드·대국 도구 옆에 430px 오프닝 전용 패널을 둡니다. **대국 / 기보** 도구를 전환해도 오프닝은 계속 보입니다. 수 목록의 글자와 통계 막대를 키웠고, 목록 안에서 스크롤할 수 있습니다. 연결 설명·참고 기보는 통계 목록과 별도 탭에 두었습니다. 작은 창에서는 오프닝 패널을 보드 아래로 내려 읽을 공간을 확보합니다. [화면과 검증 기록](checks/2026-11-04-opening-workspace/README.md)을 참고하세요.

연결키가 없는 첫 실행에서는 패널이 연결 방법을 안내합니다. 한 번 저장한 연결은 다음 실행부터 자동으로 불러와 현재 위치의 통계를 조회합니다. 대국·분석 중 화면에 보이는 보드만 조회하고, 숨겨진 분석창은 조회를 중단합니다. 조회에는 현재 체스 위치와 선택한 자료 필터를 전송합니다. 개인 기보 파일 전체나 Regicide의 분석 보고서는 업로드하지 않습니다.

## 리체스 연결키: 사용자가 할 일

**연결키(토큰)는 Regicide가 리체스 통계를 조회할 때 쓰는 전용 열쇠**입니다. 로그인 비밀번호와 별개이며 처음 한 번 만들어 연결하면 됩니다. 리체스 화면에서는 이 열쇠를 Personal access token이라고 부릅니다.

1. [리체스 개인 토큰 발급 페이지](https://lichess.org/account/oauth/token/create)에 로그인합니다.
2. 설명에 `Regicide opening explorer`처럼 알아볼 수 있는 이름을 씁니다.
3. **추가 권한은 선택하지 않습니다.** 공식 탐색기 API는 별도 권한이 없는 인증 토큰으로 조회할 수 있습니다.
4. 발급된 값을 Regicide의 **리체스 연결** 입력란에 직접 붙여 넣습니다. 채팅·기보·저장소에는 붙여 넣지 않습니다.
5. **이 Windows 계정에 연결 기억**은 기본으로 선택돼 있습니다. Windows 사용자 계정에 묶인 암호화 저장을 사용하며, 게임을 다시 켜도 자동으로 불러옵니다. 저장하지 않으면 현재 실행 중에만 사용할 수 있습니다. 입력란은 요청 직후 비웁니다.

토큰 설정 여부와 실제 조회 성공은 다릅니다. 저장된 키가 있으면 빈 연결 입력란 대신 저장 상태를 보여줍니다. 잘못되었거나 만료된 토큰은 조회 시 실제 인증 오류를 안내하고 입력란을 다시 엽니다. 리체스에서 토큰을 취소했다면 새 토큰으로 다시 연결합니다. 이미 켜 놓은 다른 Regicide 창도 저장된 키의 변경을 다시 읽습니다.

Windows 저장 위치는 `%LOCALAPPDATA%\Regicide\credentials\lichess.dpapi`입니다. 보호된 저장을 사용할 수 없으면 현재 실행에만 적용하고 화면에 알립니다. 공개 통계 캐시는 `%LOCALAPPDATA%\Regicide\opening-explorer`에 최대 24시간, 128개·8MiB 범위로 보관합니다. 캐시에 인증 토큰은 포함하지 않습니다.

개발 환경에서는 `REGICIDE_LICHESS_TOKEN` 환경변수도 사용할 수 있습니다. **환경변수가 화면 입력·저장 토큰보다 우선**합니다. 토큰을 소스·명령행 인수·브라우저 저장소에 넣지 않습니다.

## 숫자를 읽는 방법

- **대국 수:** 해당 위치에서 그 수를 둔 표본 수입니다.
- **선택 비율:** 해당 위치의 전체 표본 중 그 수가 등장한 비율입니다. 화면에 일부 수만 표시되면 행들의 비율 합은 100%보다 작을 수 있습니다.
- **백승/무승부/흑승:** 그 수를 둔 뒤 경기 전체가 어떤 결과로 끝났는지 나타냅니다. 현재 위치의 객관적인 승률이나 그 수의 최선 여부를 뜻하지 않습니다.
- **자료 출처·조회 시각:** 마스터/일반 대국과 필터를 확인합니다. 필터를 바꾸면 비교 대상도 바뀝니다.

표본이 적거나 없는 위치도 있습니다. 데이터가 없다는 사실을 나쁜 수라는 판정으로 바꾸지 않습니다. 레이팅 차이, 상대 선택, 시간제 등도 결과에 영향을 줍니다. 외부 경기 통계를 자체 엔진의 경기력 측정으로 해석하지 않습니다.

## 연결과 검증 원칙

외부 조회는 공식 `https://explorer.lichess.org`의 마스터·일반 대국 조회만 사용합니다. 요청을 직렬화하고, 같은 위치·필터의 결과는 캐시합니다. 요청 제한 응답을 받으면 최소 1분 기다린 뒤 다시 시도합니다. 인터넷 실패·인증 오류·조회 중에는 다른 위치의 예전 결과를 현재 통계처럼 표시하지 않습니다.

이동 순서가 달라도 기물 배치·차례·캐슬링·실제로 가능한 앙파상 권리가 같으면 같은 위치로 조회합니다. 반수 카운터와 수 번호가 다른 캐시 응답을 재사용하더라도 분석 보드로 넘기는 위치는 현재 요청에서 다시 만듭니다.

서버는 응답의 수를 합법 수와 대조하고, 표시용 표기와 착수 후 위치를 직접 계산합니다. 참고 기보 링크도 검증된 경기 ID와 자료 출처에서 생성합니다. 화면은 현재 위치·자료·필터에 맞는 응답만 표시합니다.
