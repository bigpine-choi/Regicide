# 대국 코칭

한 판의 수순을 다시 읽어 중요한 실수 후보와 Regicide가 찾은 대안을 비교하는 복기 기능입니다. 수를 고르는 것은 현재 실행 중인 Regicide의 자체 엔진입니다. python-chess는 기보 검증, 합법 수와 수순 재생에 사용합니다.

## 사용 방법

1. 대국을 마친 뒤 **대국 코칭**을 누릅니다. Godot에서는 대국 보관함의 기보나 열어 둔 PGN에서도 진입할 수 있습니다. 브라우저에서는 코칭 화면에서 저장된 대국 또는 PGN 파일을 선택할 수 있습니다.
2. 자신의 색과 분석 시간을 확인하고 **분석 시작**을 누릅니다. 빠르게는 탐색당 0.5초, 기본은 1.5초, 깊게는 5초입니다. 한 수마다 최대 두 번 탐색하므로 80반수 대국의 기본 분석 예산은 약 4분, 깊은 분석은 약 13분 20초입니다. 실제 시간에는 기보 처리와 엔진 준비 비용이 더해지고, 조기 종료로 짧아질 수 있습니다.
3. 완료된 수부터 즉시 읽을 수 있습니다. 기본은 **양쪽 수**이며, 백·흑 각각의 분석 요약과 실수를 표시합니다. 내 수·상대 수로 좁혀 볼 수 있고, 내 색을 바꿔도 이미 분석한 수를 다시 계산할 필요가 없습니다.
4. 수나 복습 국면을 선택하면 **실제 수를 둔 뒤**의 보드를 보여주고, 움직인 기물 위에 평가 배지를 표시합니다. **두기 전**으로 전환하면 당시 국면을 확인할 수 있습니다. **다음 실수**를 누르면 현재 국면부터 목표 실수까지 실제 기보를 약 0.65초 간격으로 재생하고, 해당 수가 착지한 뒤 멈춥니다. 일시정지·계속·바로 이동을 지원하며, 다른 수를 직접 선택하면 재생을 중단합니다.
5. **실전의 수**와 **추천 수**의 평가 및 예상 수순을 비교합니다. 실수 교정에서는 **왜 더 좋은지 · 6수 보기**로 추천 수부터 상대의 응수와 후속 수까지 해설과 함께 따라갑니다. 일시정지·이전·다음으로 살펴본 뒤 실제 기보로 돌아와 복기를 이어갑니다.
6. 분석 중에는 중단할 수 있습니다. 완료한 보고서는 로컬에 보관하여 같은 조건으로 다시 열 때 재사용합니다.

## 기물 위 평가 배지

실제 착수한 기물의 오른쪽 위에 다음 기호가 나타납니다. 백과 흑 모두 같은 기준을 적용하며, 수순 재생 중에는 현재 보드에 도착한 수의 배지를 표시합니다.

| 기호 | 의미 |
| --- | --- |
| `!!` | 탁월 후보: 다른 대안과 비교해 두드러진 추천 수 |
| `★` | 이번 탐색의 추천 수 |
| `✓` | 좋은 수 |
| `?!` | 아쉬운 수 |
| `?` | 실수 또는 메이트 기회 놓침 |
| `??` | 큰 실수 또는 메이트 허용 |
| `…` | 비교 근거가 부족해 판단 보류 |

`!!`는 단순히 추천 수를 뒀다는 이유로 붙이지 않습니다. 실제 수가 추천 수이고 착수한 쪽 기준 0.00 이상 또는 승리 메이트로 평가되면, 실제 수를 제외한 다른 합법 수들을 같은 시간 예산으로 한 번 더 탐색합니다. 그중 최선 대안조차 −2.00 이하 또는 패배 메이트일 때만 **탁월 후보**로 표시합니다. 두 결과 모두 한쪽 경계값이 아닌 비교 가능한 점수여야 하며, 합법 수가 하나뿐이면 붙이지 않습니다. 이는 Regicide의 제한 시간 비교 규칙이며, 희생 묘수나 객관적인 유일수를 증명했다는 뜻은 아닙니다.

배지는 실제 기보의 착수·도착 칸·국면이 모두 일치할 때만 표시합니다. 기물 이동이 끝나면 나타나며, 즉시 전환하는 위치에서는 바로 표시합니다. **두기 전**, 추천 변화 수순, **다시 두기**에서는 숨겨서 다른 수의 평가나 연습 정답이 노출되지 않게 합니다. 보드를 뒤집어도 기물의 도착 칸을 따라가고 보드 크기를 바꾸지 않습니다.

추천 수를 실제로 둔 일부 국면에 비교 탐색이 추가되지만, 한 수당 최대 두 번이라는 분석 예산은 같습니다. 새 판단 근거를 저장하도록 보고서 버전을 올렸으므로 이전 버전의 캐시 대신 처음 한 번 다시 분석합니다.

## 코치 루크와 다시 두기

룩을 본뜬 Regicide의 코치 **루크**가 영어로 총평과 국면별 해설을 제공합니다. 메뉴와 수 분류는 한국어를 유지합니다. 중요한 실수와 복습할 좋은 수 중 최대 다섯 국면을 골라 기보 순서대로 안내합니다. 짧은 기보나 아직 분석 중인 경기에서는 준비된 국면만 표시합니다. 기존의 모든 수 복기와 양쪽 수 필터도 사용할 수 있습니다.

해설은 별도의 언어 모델이나 외부 서비스 없이 보드와 합법적인 예상 수순에서 구성합니다. 기본 대사는 한두 문장이며, 실수 교정에서는 체스 원리를 포함해 최대 세 문장으로 설명합니다. 좋은 수에서는 착수와 바로 다음 응수, 실수에서는 가까운 수순의 주요 포획과 추천 수의 효과를 우선합니다. 백·흑과 실전 수·추천 수를 명시해 상대의 수를 사용자의 수처럼 칭찬하거나 다른 수순의 사건을 섞지 않습니다. 확인된 체크·체크메이트·포획·캐슬링 등은 판에서 직접 확인할 수 있습니다. 예상 수순의 기물 교환은 그 수순에서 일어난 일로 설명하며, 기물을 공격한다는 사실만으로 반드시 얻는다고 단정하지 않습니다. 표시된 예상 수순은 실제 경기 기록과 구분합니다.

**다시 두기**를 누르면 착수 직전의 연습 보드가 열립니다. 추천 수와 평가를 가린 상태에서 기물을 클릭하거나 드래그해 수를 선택합니다. 승격은 퀸·룩·비숍·나이트를 고를 수 있습니다. 힌트를 확인하거나 추천 수를 공개해 비교할 수도 있습니다.

선택한 수는 해당 국면에서 Regicide가 새로 찾은 추천 수와 같은 시간 예산으로 비교합니다. 다른 수라도 평가 차이가 작으면 좋은 대안으로 인정하고, 비교 근거가 부족하거나 탐색 결과가 엇갈리면 판단을 유보합니다. 기존 보고서와 다른 결과가 나올 수 있으며, 이는 제한된 탐색의 차이로 원래 기보를 수정하지 않습니다. 한 번에 하나의 다시 두기 분석만 실행합니다. 다시 두기는 대국 분석이 완료되거나 중단된 뒤 분석된 국면에서 사용할 수 있습니다.

연습 착수는 현재 대국·보관함·원래 보고서에 기록되지 않습니다. 다른 국면이나 기보로 이동한 뒤 도착한 응답은 해당 화면에 적용하지 않습니다.

국면을 바꾸면 해당 해설을 컴퓨터의 **영어 음성으로 자동 재생**합니다. 이전 설명은 멈추고 새 설명을 읽으며, 같은 화면의 갱신으로 반복해서 읽지 않습니다. 빠르게 여러 수를 넘기면 마지막으로 고른 국면을 읽고, 다음 복습 국면까지 실제 수순을 자동 재생할 때는 목적지에 도착한 뒤 해설합니다. **음성 켜짐 / 음성 끔** 버튼으로 자동 음성을 조절할 수 있습니다. 코칭을 나가거나 화면을 숨기면 읽기를 멈춥니다.

Windows Godot에서는 별도 설치된 **Kokoro 미국식 신경망 음성**을 우선 사용합니다. 기보의 `Nf3`는 “knight to f three”처럼 풀어 읽습니다. 새 문장은 준비 시간이 필요하며, 다시 듣는 문장은 로컬 음성 캐시를 사용합니다. 신경망 음성을 사용할 수 없으면 설치된 Desktop 영어 음성으로 전환하고 상태를 표시합니다. 두 방식 모두 로컬에서 WAV를 만들어 게임이 재생하며 코칭 내용을 외부로 전송하지 않습니다. 영어 음성이 없는 환경에서는 글로 된 해설을 그대로 사용할 수 있습니다. 브라우저에서는 기기에 설치된 로컬 영어 음성만 사용합니다. 설치와 출처·라이선스는 [루크 음성 안내](ROOK_VOICE.md)를 참고하세요.

저장된 분석을 다시 열 때에도 검증된 수순으로 최신 해설을 구성합니다. 문구 변경만으로 기존 기보를 수정하거나 엔진 분석을 다시 실행하지 않습니다.

### 전략·전술과 실행 계획

해설 v6에서는 보드에서 확인할 수 있는 주제가 있을 때 **핵심 구상 / 실행 계획 / 상대 대응**을 선택할 수 있습니다. 평소에는 짧은 영어 요약을 읽고, 각 항목을 누르면 근거가 되는 예상 수순의 장면으로 이동하여 더 자세히 설명합니다. **기본 해설**로 돌아오면 실제 착수 뒤의 보드가 복구됩니다.

- **핵심 구상:** 어떤 기물을 동시에 공격하는지, 어떤 파일이나 거점을 활용하는지 등 해당 수의 구체적인 목적을 설명합니다.
- **실행 계획:** 저장된 수순에서 다음에 무엇을 하는지와 그 역할을 연결합니다. 예를 들어 `Bc4 Nf6 d3`에서는 `Nf6`가 공격한 e4 폰을 `d3`로 지킨다는 점을 짚습니다.
- **상대 대응:** 상대가 공격자를 잡거나 핀을 풀거나 폰 구조를 바꾸는 등, 계획에 영향을 주는 실제 예상 응수를 설명합니다.

현재는 포크, 왕에 대한 핀, 디스커버드 어택, 룩의 열린·반열린 파일, 수비받는 통과폰, 폰으로 지지한 거점, 엔드게임 왕의 활동, 목적 있는 전개, 폰으로 상대 폰 구조에 도전하는 수를 구분합니다. 양색과 사용자 관점에 맞춰 표현하며, 좋은 수는 실제 착수의 수순을, 실수 교정은 추천 수의 수순을 설명합니다. 기존 **왜 더 좋은지 · 6수 보기**의 해당 단계에도 이 설명을 연결합니다.

이 기능은 제한 시간 안에 Regicide가 찾은 수순과 보드 규칙을 바탕으로 설명합니다. 확인되지 않은 장기 계획이나 강제 승리를 만들어내지 않으며, 뒷받침할 주제가 없으면 기존 해설을 유지합니다. 짧은 수순에는 후속 근거가 부족하다고 표시하고, 체크메이트나 자동 무승부 설명은 일반적인 계획보다 우선합니다. 전개는 자기 진영의 시작 칸, 엔드게임 왕의 활동은 퀸이 없고 나머지 기물의 양도 적은 경우로 범위를 제한합니다. 엔진의 수 선택과 탐색 시간은 바뀌지 않습니다.

심화 설명을 바꾸면 선택한 내용을 자동으로 읽습니다. 총평·다시 두기·다른 수·다른 기보로 이동하면 이전 설명과 음성을 중단하며, 연습 정답을 가리는 동안에는 심화 해설도 숨깁니다. [전략 코칭 검증 기록](checks/2026-11-02-coach-strategy/README.md)에 재현 조건과 확인한 범위를 남겼습니다.

해설은 선택한 내 색에 맞춰 `you/your`를 사용합니다. 실수한 국면에서는 **대신 둘 수·그 수의 확인된 효과·다음 대국에 적용할 원리**를 함께 설명하고 자동으로 읽습니다. 위협받는 기물 처리, 수비받는 칸 고르기, 전개와 위협, 재포획 계산처럼 해당 국면과 연결되는 원리 하나를 고릅니다. 기본 대사는 최대 40단어·세 문장 이내로 유지하며, 좋은 수에 억지로 교정 설명을 붙이지 않습니다. 근거가 부족하면 대안은 알려주되 이유를 더 살펴봐야 한다고 밝힙니다.

해설 v5의 **왜 더 좋은지**는 한 문장에 긴 수순을 몰아넣지 않고 보드의 장면별로 나눠 설명합니다. 여기서 6수는 추천 수를 포함해 백·흑이 번갈아 두는 여섯 번의 착수입니다. 착수 직전부터 시작해 추천 수의 효과, 상대의 응수, 이어지는 포획·체크·전개를 보여주고 마지막에 그 수순의 결과와 배울 점을 정리합니다. 음성을 사용할 때는 해당 설명이 끝난 뒤 다음 장면으로 넘어갑니다. 음성이 없거나 꺼져 있으면 글을 읽을 시간을 둡니다.

보드에는 분석에서 확인한 합법 수순만 표시합니다. 여섯 번보다 짧은 수순이면 실제 길이를 표시하며, 체크메이트나 무승부로 끝나면 거기서 멈춥니다. 확인하지 못한 수를 덧붙이지 않습니다. 이는 상대가 해당 응수를 선택했을 때의 **예상 전개**이며 강제 수순이나 확정된 미래를 뜻하지 않습니다. 다른 국면·기보·다시 두기로 이동하면 해설 재생과 이전 음성을 중단합니다. 기존 분석을 다시 열어도 저장된 수순으로 새 해설을 구성하므로 이 기능 때문에 추가 엔진 탐색을 실행하지 않습니다.

내 색을 바꾸면 대사와 힌트도 즉시 바뀝니다. 다시 두기에서는 추천 수와 원리를 가려 연습 정답이 노출되지 않게 합니다. 단순히 기물을 옮겼다는 이유만으로 공격에서 벗어났다고 하거나, 포획을 공짜 이득으로 단정하지 않습니다. [미국식 음성 검증](checks/2026-11-02-natural-rook/README.md)과 [대안·체스 원리 검증](checks/2026-11-02-coach-teaching/README.md)에 재현 조건을 남겼습니다.

### 백의 오프닝과 흑의 대응

표준 시작 위치부터 기록된 대국의 초반 24착수(백·흑 각각 최대 12수)에서는 **오프닝 해설**로 양쪽의 계획을 살펴볼 수 있습니다. **백의 구상 / 흑의 대응 / 초반 판세**를 선택하면 실제로 그 수를 둔 뒤의 보드를 보여주며 루크가 해당 영어 설명을 읽습니다. 기본 수별 해설은 짧게 유지하고, 자세한 오프닝 설명은 원하는 항목을 골라 듣습니다. 중반이나 종반을 보고 있어도 **오프닝 복기**를 누르면 분석된 초반의 마지막 확인 지점으로 이동합니다.

백의 체계와 흑의 대응은 같은 수순 안에서 함께 식별합니다. 레티로 출발했더라도 이후 다른 오프닝의 위치로 전환되면 그 구분을 알려줍니다. 현재 위치의 확인과 이전에 마지막으로 확인한 이름도 구분하며, 이름 목록에서 벗어난 사실만으로 악수라 판단하지 않습니다. 표준 시작 이전의 이력이 없는 사용자 지정 FEN에서는 누가 어떤 오프닝을 선택했는지 추측하지 않습니다.

공식 자료에서 확인한 대표 계획을 바탕으로 중앙 장악, 폰 구조, 기물 전개와 반격 지점을 설명합니다. 시실리안의 열린·닫힌 전개, 프렌치의 전진·교환 구조, 퀸스 갬빗에 대한 수락·거절·슬라브 대응 등은 실제 수순에 따라 구분합니다. 단순히 한 수를 보고 아직 결정되지 않은 체계나 이후 계획을 확정하지 않습니다.

**초반 판세**는 특정 오프닝이 다른 오프닝을 무조건 이긴다는 상성표가 아닙니다. 이번 대국의 실제 착수에 대한 Regicide 평가를 사용합니다. 12착수 전에는 아직 이르다고 안내하고, 이후에도 실제 수의 합법 수순·경계가 아닌 평가값·깊이 4 이상을 확인한 경우에만 현재 탐색의 잠정적인 우열을 설명합니다. 백 기준 평가의 절댓값이 0.50 미만이면 뚜렷한 우세 없음, 0.50 이상 1.00 미만이면 약간 유리, 1.00 이상이면 이번 탐색에서 해당 측의 초반 국면을 더 선호한다고 표현합니다. 점수와 함께 잠정 평가임을 명시하고, 더 깊은 탐색도 확정된 오프닝 승리로 표현하지 않습니다. 이 수치는 승률이 아니며 깊이·점수 구간은 표시 정책으로, 평가 정확성의 보증이 아닙니다. 근거가 부족하면 우열을 보류하고, 실제 체크메이트·자동 무승부는 별도로 설명합니다.

추천 수를 두었을 때의 점수를 실전 결과로 바꿔 말하지 않습니다. 이후 중반 실수로 크게 변한 평가도 오프닝 상성의 결과로 소급하지 않습니다. 추가 엔진 탐색이나 인터넷 요청 없이 기존 분석과 함께 제공하며, 저장된 보고서도 최신 문구로 다시 구성합니다. 지식 문구는 직접 작성했으며 [공식 출처와 검증 기록](checks/2026-11-02-opening-coach/README.md)에 확인 범위를 남겼습니다.

## 대국 보관함과 기물 이동

**대국 보관함**에서 자동으로 저장된 경기를 날짜·시작 시각·내 색·결과로 확인하고 열 수 있습니다. Godot에서는 날짜나 결과 등의 텍스트로 검색할 수 있습니다. 선택한 경기의 시작·종료 시각은 컴퓨터 현지 시각과 UTC 시차로 표시하며, 오래된 기록에 시간이 없으면 시간 정보가 없다고 표시합니다. 원본 UTC 기록은 보존하므로 날짜가 자정을 넘어도 최신순 정렬이 정확합니다. 첫 수부터 자동 보관하며, 중단된 경기도 남습니다.

보관함의 복기는 분석 시작 없이 사용할 수 있습니다. 처음·이전·다음·끝으로 이동하고, 필요한 경우 같은 기보의 코칭을 시작합니다. 현재 대국으로 돌아오면 원래 위치에서 계속 둘 수 있습니다.

대국·분석·복기에서 기물이 짧게 미끄러져 이동하고 착지하며, 잡힌 기물은 사라집니다. 캐슬링은 왕과 룩이 함께 움직이고, 앙파상·승격·한 수 되돌리기도 최종 배치와 일치합니다. 기물 애니메이션은 기본으로 적용하며 별도 켜기·끄기 설정은 없습니다. 이전 버전에서 꺼둔 앱 설정도 사용하지 않습니다. 브라우저는 시스템의 움직임 줄이기 설정을 따릅니다. 자유 배치 편집이나 여러 수를 건너뛴 위치는 중간 수를 추측해 애니메이션으로 꾸미지 않습니다.

## 판단 원리와 한계

착수 직전의 같은 위치에서 모든 합법 수를 탐색한 결과와 실제 착수만 첫 수로 허용한 결과를 비교합니다. 두 탐색에는 동일한 시간 예산을 주고 각각 도달한 깊이와 실제 예상 수순을 기록합니다. 백·흑 점수는 백 기준으로 통일하고, 손실은 실제로 착수한 쪽의 관점으로 계산합니다.

평가 손실 50cp 이상은 부정확, 100cp 이상은 실수, 200cp 이상은 큰 실수의 후보로 분류합니다. 100cp는 평가 척도상 폰 한 개 정도이며 승률이 아닙니다. 메이트를 허용하거나 놓친 경우는 별도로 분류하고 임의의 거대한 점수 손실로 바꾸지 않습니다. 같은 추천 수를 둔 경우 탐색 간 점수 흔들림을 실수로 처리하지 않습니다. 비교를 뒷받침할 점수나 수순이 없으면 판단을 유보합니다.

화면의 최선수와 실수 표시는 **선택한 시간 안에 Regicide가 찾은 결과**입니다. 제한 시간이 같아도 탐색 깊이가 다를 수 있고, 더 깊게 읽으면 판단이 바뀔 수 있습니다. 해설은 확인된 평가 차이, 실제 기물 포획·체크와 합법적인 예상 수순에 근거합니다. 예상 수순은 이후 실제로 벌어진 기보와 구분해 표시합니다.

## 보존과 재현

- 진행 중인 대국, 자유 배치 분석 보드, 원본 JSON·PGN은 변경하지 않습니다.
- 완성된 코칭 결과는 대국 저장 폴더의 별도 `coaching/` 하위 폴더에 저장합니다. 엔진 실행 파일, 평가 모델, 기보, 자신의 색, 시간 설정과 보고서 버전이 맞는 결과만 재사용합니다.
- 분석은 시작 버튼으로 실행하며, 취소·다른 기보·창 종료 뒤 늦게 도착한 결과는 새 화면을 덮어쓰지 않습니다.
- 기존 기보를 자동 학습에 넣거나 외부 서비스에 보내지 않습니다.
