# 대국 중 최대 세 개의 추천 수

Godot 대국 창과 브라우저에서 **추천 수: 끔** 버튼을 누르면 **추천 수: 켬**으로 바뀐다. 기본값은 끔이며, 현재 둘 차례인 쪽의 다음 수를 자체 Regicide 엔진이 최대 세 개 추천한다. **내 추천 수**와 **Regicide 후보 수**를 구분해 안내하며, 양쪽 모두 **1순위 빨강, 2순위 주황, 3순위 노랑** 화살표와 순위 숫자, 수 이름을 표시한다. 내 차례에는 직접 착수하고, Regicide 차례에는 엔진이 별도로 수를 선택한다.

## 사용 방법

1. 대국 도중 **추천 수** 버튼을 켠다. 내 차례와 Regicide 차례 모두 현재 위치의 후보를 계산한다.
2. 같은 깊이에서 후보 비교가 끝나는 대로 순위별 화살표와 수 이름을 표시하고, 더 깊게 계산하면 갱신한다. 합법 수가 하나나 두 개뿐이면 그 수만 표시하며, 승격 수는 승격할 기물도 함께 표시한다.
3. 내 차례에는 직접 기물을 움직인다. Regicide가 생각하는 동안에는 상대 후보를 확인할 수 있으며, 실제 착수 뒤에는 이전 화살표를 지우고 새 차례의 후보를 계산한다.
4. 언제든 버튼을 끄면 추천 표시를 지우고 진행 중인 추천 계산을 취소한다. 상대의 응수를 기다리는 중에도 설정을 바꿀 수 있다.

추천 시간은 새 대국에 적용한 **한 수 생각 시간**을 따른다. 백·흑 어느 쪽으로 두어도 사용하며, 시점을 뒤집으면 표시 방향도 함께 바뀐다. 새 대국·무르기·핸디캡 변경·종국에서는 이전 위치의 추천을 지운다. 기보 다시 보기에는 현재 대국의 추천을 섞지 않는다.

## 추천의 의미

빨강·주황·노랑 화살표는 출발 칸 정중앙에서 시작해 도착 칸 정중앙에 화살촉이 닿는다. 판을 뒤집거나 창 크기를 바꿔도 같은 기준을 유지한다. 승격처럼 경로가 겹치는 추천은 선 굵기와 옆으로 나눈 순위 숫자로 구분한다.

추천은 현재 설치된 자체 Regicide의 제한된 수읽기 결과다. 외부 엔진이나 온라인 AI 서비스의 판단을 사용하지 않으며, 최선 수나 승리를 보장하지 않는다. 형세 막대는 엔진 차례에는 실제 응수 탐색, 사람 차례에는 별도의 현재 국면 평가를 사용한다. 후보를 제한한 추천 계산의 점수로 형세 막대를 바꾸지 않는다.

같은 깊이에서 전체 합법 수 중 추천을 찾은 뒤, 이미 고른 수를 제외해 다음 후보를 찾는다. 세 후보의 비교를 모두 마친 깊이만 채택하고, 현재 둘 차례의 점수로 순위를 정한다. 서로 다른 깊이의 결과나 상한·하한 점수를 섞지 않는다. 다음 깊이의 비교가 시간 안에 끝나지 않으면 직전의 완성된 비교를 사용한다. 표시 순위는 해당 탐색의 추정이며, 후보 간 우열이 언제나 확정됐다는 뜻은 아니다.

추천 전체가 기존의 한 수 생각 시간 안에서 계산되므로, 한 후보만 찾을 때보다 도달하는 깊이가 낮아질 수 있다. 첫 비교도 끝내지 못하면 임의의 수를 추천으로 채우지 않고 계산 실패를 알린다. 분석 모드와 대국 코칭의 탐색 방식은 유지한다.

기능이 꺼져 있으면 추천용 엔진을 실행하지 않는다. 켜져 있으면 양쪽 차례에 별도의 Regicide 프로세스로 전체 수순 이력을 복사해 계산한다. Regicide의 실제 수 선택은 추천 계산을 기다리지 않으며, 오프닝 다양성 정책과 탐색 깊이 차이 때문에 표시된 1순위와 다른 수를 둘 수 있다. 짧은 생각 시간에는 후보를 보는 시간도 짧아질 수 있다. 실제 대국의 기물 배치·차례·수순·대국 결과는 추천 표시가 바꾸지 않는다. 추천이 실패해도 일반 대국은 계속할 수 있다.

## 상태와 자원 관리

추천 응답의 대국 ID·revision·FEN이 현재 화면과 모두 같고 합법 수일 때만 표시한다. 뒤늦게 도착한 이전 위치의 추천이나 끄기 전 응답은 버린다. 끄기·위치 변경·종료 시 진행 중인 추천을 취소하며, 추천용 프로세스의 실패·시간 초과는 대국용 엔진과 분리한다.

후보 목록은 세 행의 공간을 유지해 후보 수나 문구 길이가 바뀌어도 보드 크기를 흔들지 않는다. 같은 출발·도착 칸을 가진 승격 후보는 선 굵기와 순위 숫자로 구분한다. 화살표는 마우스 입력을 가로채지 않으며, Regicide 차례에 사용자가 상대 기물을 움직일 수 있게 만들지 않는다.

검증 조건과 결과는 [세 후보 추천 검증 기록](checks/2026-11-02-ranked-hints/README.md)을 참고한다.

양쪽 차례 표시와 계산 중 갱신은 [후속 검증 기록](checks/2026-11-02-both-side-hints/result.json)에 남겼다. 실제 엔진과 연결한 Godot 화면에서 백·흑 Regicide의 착수 전 후보를 확인했고, 별도 1초 대국 검사에서도 상대가 수를 두기 전에 후보가 표시됐다.
